# 原子卡片批量操作效率规则

修改现有卡片时按以下优先级选择方案，防止不必要的 Token 浪费。

## 通用原则

执行修改前先检查是否符合提示词格式规则，格式问题优先直接修复，不要反复 Read 确认。

## 优先级 0：单文件直接 Edit

**1 个文件** → 用 `Edit` 工具精确替换。禁止为单个文件写脚本、调 agent、或用 `-c` 执行 Python。

## 优先级 1：批量脚本（>10 文件）

**>10 个文件**的机械替换（格式统一、文本追加等） → 用 Python 一次遍历：

- `glob.glob("**/*.md")` → 逐文件处理 → 全程 0 Token
- 多项修改合并为一次遍历，禁止分多轮
- 先用 `grep` / `glob` 筛选匹配文件，不遍历全部

## 何时用 agent

只有需要**语义理解**的任务才使用 agent（判断公式变量是否已标注、重写段落、补充知识点）。

口诀：机械性修改 → 脚本；需要"看懂了再改" → agent。
