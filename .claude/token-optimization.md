# Token 优化规则

## 核心原则

能直接 Write 就不调 agent，能用 Python 就不走对话。

## 批量创建卡片的正确流程

| 步骤 | 做法 | Token 成本 |
|:-----|:-----|:-----------|
| 1. 提取知识点 | 单次读取源文件，整理核心内容 | 一次开销 |
| 2. 创建卡片 | **直接 `Write`**，不调 agent，每张卡片一条 Write 调用 | 仅卡片内容本身 |
| 3. 批处理验证 | Python 脚本做引用检查、代码块检查、总览更新 | **0 Token** |
| 4. 更新配置 | `Edit` 改一行的数字 | **0 Token** |

## 具体规则

### 创建新卡片
- 先对照模板确认格式要求
- 用 `Write` 直接写入完整文件，不要分多次编辑
- 不调 agent，不调 Workflow
- 公式、变量标注、引用等在写入前一次性构思完整

### 批量处理
- **引用检查** → Python脚本 `glob.glob("**/*.md")` 扫描，一次正则匹配全部卡片
- **代码块闭合检查** → Python脚本，0 Token
- **更新卡片总览** → Python脚本，0 Token
- **更新模板输出目录表** → `Edit` 改一行数字

### 禁止操作
- 禁止为创建单张或少量卡片启动 agent
- 禁止为格式验证反复读取文件内容
- 禁止在创建卡片过程中做中间确认（除非格式规则有歧义）

## 引用的句法格式

引用链接统一使用以下格式（严格对齐，句末无标点）：

```
- 需要理解[具体原因]参见 [名称](./编号-名称.md)
```

每行一个引用，前有 `## 参考引用` 标题。
