# 原子卡片输出要求

执行流程：

1. **执行前自检**：每次生成或修改前，先对照 `原子化生成提示词.md` 的格式规则完整检查一遍
2. 知识点归属已有分类 → 写入对应目录，编号为当前最大编号 + 1（两位数补零）
3. **编号预占位**：多张卡片并行写入前，必须先占位防冲突；全新分类 → 新建目录，从 01 开始
4. 生成完成后，执行**引用断链检查**：所有 `[名称](../分类/编号-名称.md)` 路径必须真实可解析
5. 生成完成后，执行**代码块闭合检查**：所有 ` ``` ` 必须成对出现
6. **强制更新卡片总览**：新卡片后同步更新 `Atomic-Cards/卡片总览.md`（插入行 + 更新总数 + 新增分类表）
7. 多张卡片可并行写入，注意引用链完整性
8. **同步更新输出目录表格**：更新本提示词中对应分类的编号范围和内容范围
