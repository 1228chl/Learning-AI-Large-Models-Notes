## 一、向量检索的数学基础

### 1.1 向量空间模型

**核心思想**：将文本映射到向量空间，通过向量距离衡量语义相似性。

```
"我喜欢吃苹果" → [0.23, -0.15, 0.67, ...]  # 向量A
"我爱吃水果"   → [0.21, -0.18, 0.65, ...]  # 向量B（与A接近）
"今天天气真好" → [-0.45, 0.32, 0.12, ...]  # 向量C（与A较远）
```

### 1.2 三种距离的几何意义

#### 欧式距离（L2）

**公式**：
$$d(x, y) = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}$$

**几何意义**：两点之间的**直线距离**

```
    y
    ↑
    |   * B (1,2)
    |  /
    | /  距离 = √((2-1)² + (3-2)²) = √2
    |/
    * A (2,3) → x
```

**特点**：
- 受向量**长度**影响
- 对异常值敏感
- 适用于向量已归一化的场景

**Python实现**：
```python
import numpy as np

def euclidean_distance(x, y):
    x = np.array(x)
    y = np.array(y)
    return np.sqrt(np.sum((x - y) ** 2))

# 示例
a = [1, 2, 3]
b = [4, 5, 6]
print(euclidean_distance(a, b))  # 5.196152422706632
```

#### 内积（Dot Product）

**公式**：
$$dot(x, y) = \sum_{i=1}^{n} x_i \cdot y_i = \|x\| \cdot \|y\| \cdot \cos\theta$$

**几何意义**：两个向量的**投影乘积**

```
dot(A, B) = |A| × |B| × cos(θ)

当θ=0°（同向）：dot最大
当θ=90°（垂直）：dot=0
当θ=180°（反向）：dot为负
```

**特点**：
- 同时考虑**方向**和**长度**
- 值越大越相似
- 适用于推荐系统（考虑用户偏好强度）

**Python实现**：
```python
def inner_product(x, y):
    return np.dot(x, y)

# 示例
a = [1, 2, 3]
b = [4, 5, 6]
print(inner_product(a, b))  # 32
```

#### 余弦相似度（Cosine Similarity）

**公式**：
$$
\cos\theta = \frac{x \cdot y}{\|x\| \cdot \|y\|} = \frac{\sum_{i=1}^{n} x_i y_i}{\sqrt{\sum_{i=1}^{n} x_i^2} \cdot \sqrt{\sum_{i=1}^{n} y_i^2}}
$$


**几何意义**：两个向量**夹角的余弦值**

```
cos(θ) = 1  → θ=0°  → 完全同向（最相似）
cos(θ) = 0  → θ=90° → 垂直（无关）
cos(θ) = -1 → θ=180° → 完全反向（相反）
```

**关键特性**：**只考虑方向，不考虑长度**

```
A = [1, 2, 3]      # 长度 = √14
B = [2, 4, 6]      # 长度 = √56 = 2√14

欧氏距离: √((1-2)² + (2-4)² + (3-6)²) = √14 ≈ 3.74  # 距离大
余弦相似度: cos(A,B) = (1×2 + 2×4 + 3×6) / (√14 × √56) = 1.0  # 完全相同
```

**结论**：A和B方向相同，语义一致，余弦相似度正确识别为1.0。

**Python实现**：
```python
def cosine_similarity(x, y):
    x = np.array(x)
    y = np.array(y)
    return np.dot(x, y) / (np.linalg.norm(x) * np.linalg.norm(y))

# 示例
a = [1, 2, 3]
b = [2, 4, 6]
print(cosine_similarity(a, b))  # 1.0（完全相同方向）
```

### 1.3 为什么文本检索用余弦相似度？

| 考量 | 说明 |
|------|------|
| **语义 vs 词数** | "Python"和"Python是一种编程语言"语义相似，但词数不同 |
| **长度无关性** | 余弦相似度只关注方向，不关注长度 |
| **归一化** | 将向量归一化到单位球面，余弦相似度等价于欧氏距离 |

## 二、Embedding模型的底层原理

### 2.1 什么是Embedding？

**定义**：将离散的文本映射到连续的向量空间的函数。

```
f: 文本 → 向量
f("Python") = [0.23, -0.15, 0.67, ..., 0.12]  # 1024维
```

### 2.2 Embedding的训练原理

**对比学习（Contrastive Learning）**：

```
正样本对（相似文本）：("Python", "Python语言") → 向量距离近
负样本对（不相似文本）：("Python", "今天天气") → 向量距离远

训练目标：
min ∑ d(f(x_i), f(x_j))  对于正样本对
max ∑ d(f(x_i), f(x_j))  对于负样本对
```

### 2.3 BGE-M3的双塔架构

BGE-M3同时生成**稠密向量**和**稀疏向量**：

```
输入: "Python是一种编程语言"

稠密向量 (1024维):
[0.23, -0.15, 0.67, ..., 0.12]  # 低维，捕捉语义

稀疏向量 (词表大小维):
{1024: 0.5, 5123: 0.3, 8901: 0.2, ...}  # 高维，捕捉关键词
# 1024对应"Python"，5123对应"编程"，8901对应"语言"
```

**为什么需要两种向量？**

| 向量类型 | 优势 | 劣势 |
|----------|------|------|
| 稠密向量 | 理解同义词、语义 | 可能丢失关键词 |
| 稀疏向量 | 精确匹配关键词 | 无法理解同义词 |

**示例**：
```
查询: "Python学费"
文档A: "Python课程价格为5000元"  # 稠密向量得分高（语义相关）
文档B: "Java学费是6000元"       # 稀疏向量得分高（关键词匹配）

混合检索: 综合两者，选择最佳结果
```

## 三、向量索引的底层原理

### 3.1 为什么需要索引？

暴力搜索的复杂度是O(n)，当数据量达到百万级时不可接受。

**目标**：在保证一定精度的前提下，将搜索复杂度降低到O(log n)。

### 3.2 IVF_FLAT索引

**原理**：倒排文件索引（Inverted File Index）

```
步骤1: 用K-Means将向量空间聚类为K个簇
步骤2: 每个向量归属于某个簇
步骤3: 搜索时，先找到最近的簇，再在簇内搜索

原始数据: 100万个向量
聚类: K=128个簇
搜索: 先找最近的簇（O(1)），再在簇内搜索（O(n/K)）
```

**参数说明**：
- `nlist`: 簇的数量（如128）
- `nprobe`: 搜索时检查的簇数量（如10）

### 3.3 HNSW索引

**原理**：层次可导航小世界图（Hierarchical Navigable Small World）

```
构建过程:
1. 每个向量是一个节点
2. 相似向量之间建立边
3. 构建多层图，上层稀疏下层密集

搜索过程:
1. 从最上层开始，找到最近的节点
2. 逐层下降，每层精细化搜索
3. 到达最底层，返回最近的K个节点
```

**优势**：高召回率、低延迟

### 3.4 索引类型选择

| 索引类型 | 原理 | 适用场景 |
|----------|------|----------|
| **IVF_FLAT** | 聚类+倒排 | 中等规模，平衡速度和精度 |
| **HNSW** | 图搜索 | 高召回率要求 |
| **SPARSE_INVERTED_INDEX** | 稀疏向量倒排 | 关键词匹配 |

## 四、混合检索的数学原理

### 4.1 加权融合公式

```
final_score = w₁ × sparse_score + w₂ × dense_score

其中 w₁ + w₂ = 1

项目配置: w₁ = 0.7 (稀疏), w₂ = 0.3 (稠密)
```

### 4.2 为什么稀疏向量权重更高？

**教育领域问答的特点**：

```
查询: "Python学费是多少？"
关键词: "Python", "学费"
```

如果只用稠密向量（语义检索）：
- 可能返回"Java课程介绍"（语义相关但主题不对）

如果只用稀疏向量（关键词检索）：
- 可能返回"Python是什么"（关键词匹配但没回答学费）

**混合检索**：两者结合，既保证主题相关，又保证关键词匹配。

### 4.3 重排序的原理

```
混合检索结果 (top-10)
    ↓
BGE-Reranker (Cross-Encoder)
    ↓
对每个(query, document)对打分
    ↓
重新排序，返回top-5
```

**Cross-Encoder vs Bi-Encoder**：

| 模型类型 | 原理 | 优势 | 劣势 |
|----------|------|------|------|
| **Bi-Encoder** | query和document分别编码 | 速度快，可预计算 | 精度较低 |
| **Cross-Encoder** | query和document一起编码 | 精度高 | 速度慢，无法预计算 |

**策略**：先用Bi-Encoder快速检索top-K，再用Cross-Encoder精排top-M。

## 五、Milvus向量数据库详解

### 5.1 Milvus的核心概念

| 概念 | 类比MySQL | 说明 |
|------|-----------|------|
| **Collection** | 表 | 存储向量数据 |
| **Schema** | 表结构 | 定义字段类型 |
| **Index** | 索引 | 加速检索 |
| **Partition** | 分区 | 数据分片 |

### 5.2 Schema设计

```python
from pymilvus import MilvusClient, DataType

# 创建Schema
schema = client.create_schema(auto_id=False, enable_dynamic_field=True)

# 主键
schema.add_field(field_name="id", datatype=DataType.VARCHAR, is_primary=True, max_length=100)

# 文本内容
schema.add_field(field_name="text", datatype=DataType.VARCHAR, max_length=65535)

# 稠密向量（BGE-M3输出1024维）
schema.add_field(field_name="dense_vector", datatype=DataType.FLOAT_VECTOR, dim=1024)

# 稀疏向量
schema.add_field(field_name="sparse_vector", datatype=DataType.SPARSE_FLOAT_VECTOR)

# 父块信息（父子块策略）
schema.add_field(field_name="parent_id", datatype=DataType.VARCHAR, max_length=100)
schema.add_field(field_name="parent_content", datatype=DataType.VARCHAR, max_length=65535)

# 学科类别（用于过滤）
schema.add_field(field_name="source", datatype=DataType.VARCHAR, max_length=50)
```

### 5.3 混合检索的实现

```python

# 创建两个搜索请求
dense_request = AnnSearchRequest(
    data=[query_dense_vector],
```

## 六、LangChain中的向量存储

### 6.1 创建向量存储的完整流程

```python
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import DashScopeEmbeddings
from langchain_text_splitters import CharacterTextSplitter
import os

# 1. 读取文档
with open('knowledge.txt', 'r', encoding='utf-8') as f:
    content = f.read()

# 2. 文档切片
text_splitter = CharacterTextSplitter(
    chunk_size=100,
    chunk_overlap=10
)
texts = text_splitter.split_text(content)

# 3. 创建embedding模型
embeddings = DashScopeEmbeddings(
    model="text-embedding-v3",
    dashscope_api_key=os.getenv('API_KEY')
)

# 4. 创建向量数据库
db = Chroma.from_texts(
    texts, 
    embeddings, 
    persist_directory="outputs/chroma.db"
)

# 5. 相似度搜索
query = "什么是Python？"
docs = db.similarity_search(query, k=2)
print(f"找到{len(docs)}个相关文档")
for doc in docs:
    print(f"- {doc.page_content[:50]}...")
```

### 6.2 相似度搜索方法

```python
# 方法1：similarity_search
docs = db.similarity_search(query, k=2)

# 方法2：similarity_search_with_score（返回相似度分数）
docs_with_scores = db.similarity_search_with_score(query, k=2)
for doc, score in docs_with_scores:
    print(f"相似度分数: {score}, 内容: {doc.page_content[:50]}...")

# 方法3：创建检索器
retriever = db.as_retriever(search_kwargs={"k": 2})
docs = retriever.invoke(query)
```
