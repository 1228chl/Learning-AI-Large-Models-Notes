## NLP文本分类项目参考面试问题

### Q1: 简述下你们的项目背景、为什么做这个项目？

当当网作为国内头部图书电商平台，拥有海量图书数据。为了实现图书的自动化分类管理，提升用户检索和推荐体验，我们需要构建一个文本分类系统。我们收集了当当网81万条图书标题数据，覆盖44个类别（如童书、小说、传记、计算机/网络等），目标是训练一个能够根据图书标题自动预测其所属类别的多分类模型。

### Q2: 你们的数据来源？数据内容是什么？做了哪些预处理动作?

**数据来源**：当当网图书数据，原始文件为CSV格式，包含`parent_category`（类别）和`title`（标题）两列，共812,151条记录，44个类别。

**预处理步骤**：
1. **类别合并**：将13个罕见类别（如"随堂用书"、"文创"、"法文原版书"等）合并为"其他小众书"，使最小类别样本数从几百提升到1,107条
2. **分层抽样拆分**：使用`sklearn.model_selection.train_test_split`的`stratify`参数，先按8:2拆出训练集和临时集，再将临时集按1:1拆为验证集和测试集，最终比例为8:1:1
3. **标签编码**：读取`category_index.txt`建立类别→索引映射字典（0~43），将文本类别转换为整数标签
4. **分词处理**（随机森林用）：使用jieba分词，将标题文本切分为词语序列
5. **FastText格式转换**：将数据转换为`__label__类别名 文本`的格式，分别生成词级和字符级两个版本

### Q3: 你们基线模型选择的是哪个,为什么选择它?

基线模型选择的是**随机森林 + TF-IDF**。选择原因：
1. 随机森林是经典的集成学习算法，对文本分类任务有不错的泛化能力
2. 实现简单，训练速度快，适合作为baseline快速验证数据质量
3. 对特征工程要求不高，配合TF-IDF即可使用
4. 支持`class_weight='balanced_subsample'`处理类别不平衡问题

### Q4: 你们用了几个模型,哪个模型训练效果最优，它相比其他模型它有什么优势?

我们用了三个模型进行对比：

| 模型 | 准确率 | F1分数 | 特点 |
|------|--------|--------|------|
| 随机森林+TF-IDF | 49.6% | 46.6% | 基线，速度快 |
| FastText词级 | 82.5% | 79.3% | 性价比最高 |
| BERT微调 | 更高 | 更高 | 精度最高，但计算成本大 |

**FastText词级模型效果最优**（在传统模型中），相比随机森林提升33个百分点。优势在于：
1. 引入了**子词信息**（wordNgrams=2），能捕捉短语级别的语义
2. 使用**哈希技巧**处理词表，内存效率高
3. 训练速度极快，支持自动调参（autotune）
4. 对中文文本分类任务天然适配

### Q5: 项目的整体架构是怎样的?

```
数据层：原始CSV → 数据清洗 → 分层拆分 → 标签编码
                                    ↓
特征层：分词(Jieba) → TF-IDF/ FastText格式转换 / BERT Tokenizer
                                    ↓
模型层：随机森林 / FastText(词级+字符级) / BERT微调
                                    ↓
压缩层：量化(INT8) / 剪枝(L1Unstructured) / 蒸馏(BERT→BiLSTM)
                                    ↓
评估层：准确率、精确率、召回率、F1分数、分类报告
```

代码结构采用模块化设计：
- `config/config.py`：统一配置管理
- `scripts/baselines/`：传统模型训练脚本
- `scripts/bert/`：BERT训练和压缩脚本
- `model/`：保存训练好的模型文件
- `data/`：原始数据和处理后数据

### Q6: 简述下你做这个项目印象深刻的问题,如何解决的?

**显存不足问题**：BERT模型在6GB显存的RTX 2060上训练时，batch_size开大会OOM。

解决方案：
1. 通过文本长度统计分析，发现99%的标题长度在96以内，将`max_len`从默认的512降到96，大幅减少显存占用
2. 引入**梯度累积**（`gradient_accumulation_steps=2`），在不增加显存的情况下等效增大batch_size
3. 开启**混合精度训练**（AMP），使用FP16减少显存占用同时加速计算
4. 使用**多进程DataLoader**（`num_workers=4`）+ `pin_memory`加速数据加载

### Q7: 简述下随机森林做分类任务的流程

1. **数据预处理**：对文本进行jieba分词，转换为空格分隔的词语序列
2. **特征提取**：使用TF-IDF将文本转换为数值特征向量
   - 参数：`max_features=50000`（限制特征维度）、`ngram_range=(1,2)`（二元词组）、`sublinear_tf=True`（对数平滑）
   - `fit_transform`在训练集上拟合并转换，`transform`在验证/测试集上只转换
3. **模型训练**：使用`RandomForestClassifier`，参数包括`n_estimators=200`（200棵决策树）、`max_depth=20`（限制深度防过拟合）、`class_weight='balanced_subsample'`（类别权重平衡）
4. **评估预测**：在验证集和测试集上计算准确率、精确率、召回率、F1分数

### Q8: 简述下TF-IDF核心思想

TF-IDF（词频-逆文档频率）用于衡量一个词在文档中的重要程度：
- **TF（词频）**：词在当前文档中出现的频率，`TF = 词在文档中出现次数 / 文档总词数`
- **IDF（逆文档频率）**：词在整个语料库中的稀有程度，`IDF = log(文档总数 / 包含该词的文档数 + 1)`
- **TF-IDF = TF × IDF**：一个词如果在当前文档中频繁出现（TF高），但在其他文档中很少出现（IDF高），则TF-IDF值高，说明该词对当前文档有很强的区分能力

项目中使用`sublinear_tf=True`进行对数平滑：`TF = 1 + log(tf)`，避免高频词权重过大。

### Q9: 简述下fit(),transform(),fit_transform()有什么区别？

- **fit(X)**：在数据X上计算所需的统计量（如TF-IDF的词表、IDF值），但不转换数据。返回学习到的参数。
- **transform(X)**：使用已学习到的参数将数据X转换为新表示（如TF-IDF矩阵），但不重新学习参数。
- **fit_transform(X)**：等价于先调用`fit(X)`再调用`transform(X)`，一步完成拟合和转换。

**项目中的使用场景**：
```python
X_train = tfidf.fit_transform(train_df['words'])  # 训练集：拟合+转换
X_dev = tfidf.transform(dev_df['words'])          # 验证集：只转换
X_test = tfidf.transform(test_df['words'])        # 测试集：只转换
```
关键点：验证集和测试集不能用`fit_transform`，否则会造成**数据泄露**（使用了测试集的统计信息）。

### Q10: 简述下flask和fastapi的核心区别?

- **Flask**：同步框架，基于Werkzeug，生态成熟，社区资源丰富，适合传统Web应用
- **FastAPI**：异步框架，基于Starlette，原生支持async/await，自带数据校验（Pydantic），自动生成API文档（Swagger/OpenAPI），性能更高
- FastAPI的类型提示和自动文档使其更适合构建ML模型推理API

### Q11: 简述下fasttext做分类任务的流程?

1. **数据格式转换**：将文本转换为FastText要求的格式`__label__类别名 文本内容`
2. **训练模型**：调用`fasttext.train_supervised()`训练分类器
   - 关键参数：`epoch=25`（训练轮次）、`wordNgrams=2`（二元词组）、`dim=200`（词向量维度）、`minCount=2`（最小词频）
3. **自动调参**：使用`autotuneValidationFile`和`autotuneDuration`参数，让FastText在验证集上自动搜索最佳超参数组合
4. **评估预测**：使用`model.predict([text], k=1)`进行预测，返回标签和置信度

项目中分别训练了**词级模型**（jieba分词后输入）和**字符级模型**（逐字符切分），词级模型效果更好。

### Q12: 简述下Bert模型做分类任务的流程?

1. **加载预训练模型**：从HuggingFace加载`bert-base-chinese`的Tokenizer和模型
2. **数据编码**：使用Tokenizer对文本进行分词、截断、填充，生成`input_ids`和`attention_mask`
3. **添加分类头**：使用`BertForSequenceClassification`，自动在BERT输出层添加一个线性分类层（`num_labels=44`）
4. **微调训练**：在下游分类数据上进行有监督训练，更新全部参数
5. **评估与保存**：在验证集上评估F1分数，保存最佳模型

项目中的关键优化：`max_len=96`、`batch_size=64`、梯度累积、混合精度、早停机制。

### Q13: 简述下大模型做分类任务的流程?

大模型（如GPT、LLaMA等）做分类通常有两种方式：
1. **Prompt方式**：将分类任务转化为自然语言推理任务，通过Prompt模板引导模型输出类别
2. **微调方式**：在大模型的最后一个token输出上添加分类头，进行有监督微调（类似BERT）
3. **API调用方式**：直接调用大模型API（如GPT-4），通过Few-shot Prompt让模型输出分类结果

相比BERT，大模型的优势是参数量大、泛化能力强，但推理成本高、延迟大，对于简单的文本分类任务通常BERT已经足够。

### Q14: 简述下Bert模型的架构

BERT（Bidirectional Encoder Representations from Transformers）由以下部分组成：
1. **Embedding层**：由三部分相加得到
   - Token Embedding：词片段嵌入（WordPiece分词）
   - Position Embedding：位置编码（学习得到，最大512）
   - Segment Embedding：句子编码（区分句子A和B）
2. **Transformer Encoder**：12层（base版本），每层包含
   - 多头自注意力机制（Multi-Head Self-Attention）
   - 前馈神经网络（Feed-Forward Network）
   - 层归一化（LayerNorm）和残差连接
3. **输出层**：取`[CLS]` token的隐藏状态，用于下游任务

BERT-base参数量约1.1亿，12层Transformer，隐藏维度768，注意力头数12。

### Q15: 简述下huggingface的datasets库和torch.utils.data.TensorDataset以及自定义torch.utils.data.Dataset区别

- **datasets库**：HuggingFace提供的高级数据处理库，支持懒加载（内存映射）、自动缓存、流式处理，适合处理大规模数据集，API简洁
- **TensorDataset**：PyTorch内置，将已加载到内存的Tensor打包成Dataset，适合数据量较小、已在内存中的情况
- **自定义Dataset**：继承`torch.utils.data.Dataset`，重写`__len__`和`__getitem__`，最灵活，可以按需加载数据（如从磁盘读取），适合自定义数据格式

项目中使用了自定义`BertDataset`，因为需要在`__getitem__`中动态调用Tokenizer进行编码。

### Q16: 简述下dataloader中三个核心参数的关系(dataset,batch_size,collate_fn)

- **dataset**：提供数据的Dataset对象，`__getitem__`返回单个样本
- **batch_size**：每个批次的样本数量，决定从dataset中取多少个样本组成一个batch
- **collate_fn**：自定义的批处理函数，将多个样本（list）合并为一个batch的tensor。默认的`collate_fn`会自动将同维度的tensor堆叠

关系：DataLoader从dataset中按batch_size取样本，然后调用collate_fn将这些样本组装成一个batch。项目中自定义了BertDataset的`__getitem__`返回编码后的tensor，默认collate_fn即可完成堆叠。

### Q18: 简述下你们项目中用的损失函数,为什么?

- **BERT微调**：使用`BertForSequenceClassification`内置的**交叉熵损失**（CrossEntropyLoss），因为这是多分类任务的标准损失函数
- **知识蒸馏**：使用**混合损失** = α × KL散度软标签损失 + (1-α) × 交叉熵硬标签损失
  - α=0.7，temperature=4.0
  - 软标签损失让 student 学习 teacher 的概率分布（暗知识），硬标签损失保证 student 不偏离真实标签

### Q19: 简述下你们项目中用的优化器,为什么?

- **BERT微调**：使用**AdamW**优化器，lr=3e-5
  - AdamW在Adam基础上解耦了权重衰减，对Transformer模型效果更好
  - 配合线性预热调度器（`get_linear_schedule_with_warmup`），前10%步数学习率从0线性增长到3e-5，之后线性衰减到0
- **蒸馏训练**：使用AdamW，lr=2e-4，配合CosineAnnealingLR调度器
  - 学生模型（BiLSTM）参数量小，需要更大学习率

### Q20: 简述下你们项目中用了哪些评估指标,主要对比哪个指标?

评估指标：
- **准确率（Accuracy）**：整体预测正确的比例
- **精确率（Precision）**：各类别预测为正例中实际为正例的比例（macro平均）
- **召回率（Recall）**：各类别实际正例中被正确预测的比例（macro平均）
- **F1分数**：精确率和召回率的调和平均（macro平均）

**主要对比F1分数**，因为：
1. 项目存在类别不平衡（最大类60,124条，最小类1,107条）
2. F1同时考虑精确率和召回率，比准确率更能反映模型在少数类上的表现
3. 配置中设置`best_metric = 'f1'`，早停和最佳模型保存都基于F1分数

### Q21: 简述下模型压缩的意义和常见四种方式

**意义**：大模型（如BERT）参数量大、推理慢、部署成本高，压缩可以在保持精度的前提下减小模型体积、加速推理。

**四种方式**：
1. **量化（Quantization）**：降低权重和激活的数值精度（如FP32→INT8），减少存储和计算量
2. **剪枝（Pruning）**：移除模型中不重要的权重（置零），减少参数量
3. **蒸馏（Distillation）**：用大模型（教师）指导小模型（学生）学习，将知识迁移到更小的模型
4. **结构化设计**：使用更高效的模型架构（如MobileBERT、TinyBERT）

### Q22: 简述下模型量化的核心思想和常见的几种方式

**核心思想**：将模型权重和/或激活从高精度（FP32）转换为低精度（INT8/FP16），减少存储空间和计算量。

**常见方式**：
1. **动态量化**（项目中使用）：推理时动态计算量化参数（scale和zero_point），只量化Linear层权重，简单易实现
2. **静态量化**：训练后校准，使用代表性数据集统计激活值的范围，量化权重和激活
3. **量化感知训练（QAT）**：在训练过程中模拟量化误差，让模型适应低精度计算
4. **混合精度训练**：使用FP16和FP32混合计算，加速训练同时保持精度

项目中使用`torch.quantization.quantize_dynamic`对BERT的Linear层进行INT8动态量化。

### Q23: 简述下模型剪枝的核心思想和常见的几种方式

**核心思想**：移除模型中对输出影响较小的权重（将其置零），减少参数量和计算量。

**常见方式**：
1. **非结构化剪枝**（项目中使用）：逐个权重判断是否剪枝，稀疏度高但硬件加速效果有限
   - 项目使用`L1Unstructured`方法，按权重绝对值大小排序，剪掉最小的20%
2. **结构化剪枝**：整行/整列剪枝（如整个注意力头、整个神经元），硬件友好，可直接加速
3. **半结构化剪枝**：如N:M稀疏模式（每M个权重中保留N个），NVIDIA Ampere架构原生支持
4. **迭代剪枝**：多轮小比例剪枝+微调，逐步提升稀疏度

项目中对BERT编码器的所有线性层（attention Q/K/V/output + FFN intermediate/output）进行全局20%剪枝。

### Q24: 简述下模型蒸馏的核心思想和常见的几种方式

**核心思想**：将大模型（教师）的"暗知识"（soft label概率分布）迁移到小模型（学生），让学生模型学到比硬标签更丰富的信息。

**常见方式**：
1. **离线蒸馏**（项目中使用）：先训练好教师模型，冻结教师参数，只训练学生模型
2. **在线蒸馏**：教师和学生同时训练，互相学习
3. **自蒸馏**：模型自身作为教师，进行知识提炼

项目实现：教师为BERT（1.1亿参数），学生为BiLSTM（2层双向，hidden_dim=256，参数量远小于BERT），使用KL散度损失+交叉熵损失的混合损失函数。

### Q25: 简述下软标签蒸馏中的两个超参数

1. **Temperature（温度）T**：控制soft label的平滑程度
   - T越大，概率分布越平滑，暗知识信息越丰富
   - T=1时退化为原始softmax
   - 项目中T=4.0
   - 公式：`soft_label = softmax(logits / T)`

2. **Alpha（平衡系数）**：控制软标签损失和硬标签损失的权重
   - alpha越大，越重视teacher的知识
   - alpha=1时只用软标签，alpha=0时只用硬标签
   - 项目中alpha=0.7
   - 公式：`loss = α × soft_loss + (1-α) × hard_loss`

### Q26: 简述下KL散度损失和交叉熵损失的区别和联系

**交叉熵损失**：衡量模型预测分布与真实标签（one-hot）之间的差异
- `H(p, q) = -Σ p(x) log q(x)`，p是真实分布（one-hot），q是预测分布

**KL散度损失**：衡量两个概率分布之间的差异
- `KL(p || q) = Σ p(x) [log p(x) - log q(x)]`
- 非对称，不可逆（KL(p||q) ≠ KL(q||p)）

**联系**：
- 交叉熵 = KL散度 + 信息熵（真实分布的熵是常数）
- 所以最小化交叉熵等价于最小化KL散度
- 在蒸馏中，teacher的soft label不是one-hot，所以用KL散度衡量student和teacher输出分布的差异
- 实际计算中`F.kl_div`已经包含了softmax归一化

## 技能部分

### Q27: AI_ML_DL之间的关系?

- **AI（人工智能）**：最广泛的概念，让机器模拟人类智能的所有技术
- **ML（机器学习）**：AI的子集，通过数据驱动的方法让机器从经验中学习
- **DL（深度学习）**：ML的子集，使用多层神经网络（深度神经网络）自动学习特征表示

关系：AI ⊃ ML ⊃ DL。深度学习是机器学习的一个分支，其核心优势是能够自动提取特征，避免了传统机器学习中繁琐的手工特征工程。

### Q28: 简述下AI三要素?

1. **数据**：AI的"燃料"，高质量、大规模的数据是模型训练的基础
2. **算法**：AI的"引擎"，包括机器学习、深度学习等各类算法
3. **算力**：AI的"动力"，GPU/TPU等硬件提供训练和推理所需的计算能力

三者缺一不可：没有数据算法无法学习，没有算法数据无法利用，没有算力大规模模型无法训练。

### Q29: 简述下有监督学习和无监督学习的区别和代表算法?

**有监督学习**：训练数据包含输入和对应的标签（目标值），模型学习输入到输出的映射
- 分类：逻辑回归、SVM、决策树、随机森林、神经网络
- 回归：线性回归、岭回归、随机森林回归

**无监督学习**：训练数据只有输入没有标签，模型自动发现数据中的结构和模式
- 聚类：K-Means、DBSCAN、层次聚类
- 降维：PCA、t-SNE、AutoEncoder
- 异常检测：Isolation Forest

**半监督学习**：少量有标签+大量无标签数据，如自训练、标签传播

### Q30: 简述下标准化和归一化的核心区别，你们常用哪种?

**归一化（Normalization）**：将数据缩放到[0,1]区间
- 公式：`X_norm = (X - X_min) / (X_max - X_min)`
- 对异常值敏感

**标准化（Standardization）**：将数据转换为均值为0、标准差为1的分布
- 公式：`X_std = (X - μ) / σ`
- 对异常值更鲁棒

**区别**：归一化有界，标准化无界。标准化更常用，因为大多数算法假设数据服从正态分布。

**项目中**：NLP任务通常不直接对文本特征做标准化/归一化，而是通过TF-IDF或BERT的Embedding层隐式处理。

### Q31: 简述下梯度下降的核心思想?

梯度下降是一种优化算法，通过迭代调整模型参数来最小化损失函数：
1. 计算损失函数对当前参数的**梯度**（偏导数），指示参数更新方向
2. 沿梯度的**反方向**更新参数（因为要最小化损失）
3. 更新公式：`θ = θ - η × ∇L(θ)`，η为学习率

**变体**：
- 批量梯度下降（BGD）：使用全部数据计算梯度，稳定但慢
- 随机梯度下降（SGD）：使用单个样本，快但震荡
- 小批量梯度下降（Mini-batch）：折中方案，项目中使用

### Q32: 简述欠拟合和过拟合产生的原因和解决方案?

**欠拟合**：模型在训练集和测试集上表现都差
- 原因：模型太简单、特征不足、训练不充分
- 解决：增加模型复杂度、增加特征、减少正则化、延长训练时间

**过拟合**：模型在训练集上表现好，但测试集上表现差
- 原因：模型太复杂、训练数据太少、训练时间过长
- 解决：增加数据、正则化（L1/L2/Dropout）、早停、数据增强、简化模型

**项目实践**：BERT训练中使用Dropout=0.2、早停（patience=3）、梯度裁剪（max_norm=1.0）防止过拟合。

### Q33: 简述极大似然估计和最小化交叉熵的区别和联系?

**极大似然估计（MLE）**：选择使训练数据出现概率最大的参数
- 目标：`max Π P(y_i|x_i; θ)`

**最小化交叉熵**：最小化真实分布与预测分布之间的交叉熵
- 目标：`min -Σ y_i log ŷ_i`

**联系**：在分类任务中，最小化交叉熵等价于极大似然估计（取对数后）。交叉熵损失就是MLE的对数似然的负数形式。

### Q34: 简述精确率,召回率,F1分数的区别和应用场景?

- **精确率（Precision）**：预测为正的样本中实际为正的比例。关注"预测为正的是否准确"
- **召回率（Recall）**：实际为正的样本中被正确预测的比例。关注"正样本是否都找到了"
- **F1分数**：精确率和召回率的调和平均，`F1 = 2 × P × R / (P + R)`

**应用场景**：
- 精确率优先：垃圾邮件过滤（宁可漏掉不要误判）
- 召回率优先：疾病筛查（宁可误判不要漏掉）
- F1优先：类别不平衡时的综合评估（如本项目44类分类）

### Q35: 简述bagging和boosting思想以及各自的代表算法?

**Bagging（Bootstrap Aggregating）**：
- 思想：有放回采样生成多个子训练集，每个子集训练一个基学习器，最终投票/平均
- 特点：降低方差，适合不稳定学习器
- 代表：**随机森林**（项目中使用）

**Boosting**：
- 思想：串行训练，每个基学习器重点关注前一个学习器分错的样本
- 特点：降低偏差，逐步提升性能
- 代表：AdaBoost、GBDT、XGBoost、LightGBM

**区别**：Bagging是并行训练降低方差，Boosting是串行训练降低偏差。

### Q36: 深度学习优缺点?

**优点**：
- 自动特征提取，不需要手工设计特征
- 在大数据和大模型下性能优越
- 表示能力强，能学习复杂非线性关系
- 迁移学习能力强（如BERT预训练+微调）

**缺点**：
- 需要大量数据和算力
- 模型可解释性差（黑盒）
- 训练时间长，调参复杂
- 对超参数敏感

### Q37: 简述sigmoid,tanh,relu,softmax等激活函数的区别和应用?

- **Sigmoid**：输出(0,1)，用于二分类输出层。缺点：梯度消失、非零中心
- **Tanh**：输出(-1,1)，零中心化。缺点：仍有梯度消失问题
- **ReLU**：`max(0,x)`，计算简单，缓解梯度消失。缺点：Dead ReLU问题
- **Softmax**：多分类输出层，输出概率分布（和为1）

项目中BERT分类头使用Softmax输出44类概率。

### Q38: 简述参数初始化的七大方式,以及常用的操作?

1. **零初始化**：所有参数为0（不推荐，对称性问题）
2. **常数初始化**：所有参数为同一常数
3. **随机初始化**：从均匀/正态分布采样
4. **Xavier初始化**：考虑输入输出维度，适用于Sigmoid/Tanh
5. **He初始化**：考虑ReLU，方差为`2/n_in`
6. **正交初始化**：权重矩阵正交，保持梯度范数
7. **预训练初始化**：加载预训练模型参数（项目中使用）

**常用操作**：深度学习框架默认使用He或Xavier初始化，BERT微调时直接加载预训练权重。

### Q39: 简述搭建神经网络模型类的步骤?

1. 继承`nn.Module`
2. 在`__init__`中定义网络层（线性层、激活层、Dropout等）
3. 重写`forward`方法，定义数据前向传播路径
4. 选择损失函数和优化器
5. 编写训练循环：前向传播→计算损失→反向传播→更新参数

```python
class MyModel(nn.Module):
    def __init__(self, ...):
        super().__init__()
        self.layer1 = nn.Linear(...)
        self.dropout = nn.Dropout(...)
    def forward(self, x):
        x = self.layer1(x)
        return x
```

### Q40: 简述分类和回归任务下分别选择什么损失函数?

- **分类任务**：
  - 二分类：BCELoss（二元交叉熵）
  - 多分类：CrossEntropyLoss（交叉熵，项目中使用）
- **回归任务**：
  - MSELoss（均方误差）
  - L1Loss / MAE（平均绝对误差）
  - SmoothL1Loss（Huber Loss，对异常值鲁棒）

### Q41: 简述Adam和AdamW的区别和联系?

**Adam**：结合了Momentum（一阶矩估计）和RMSProp（二阶矩估计）的自适应学习率优化器
- 更新：`θ = θ - η × m̂ / (√v̂ + ε)`，其中m和v分别是梯度的一阶和二阶矩估计

**AdamW**：Adam + 解耦权重衰减
- Adam中的L2正则化与自适应学习率耦合，导致正则化效果不均匀
- AdamW将权重衰减从梯度更新中解耦：`θ = θ - η × (m̂ / (√v̂ + ε) + λ × θ)`

**联系**：AdamW是Adam的改进版，对Transformer模型效果更好。项目中BERT训练使用AdamW。

### Q42: 简述下L1,L2,DropOut正则化核心思想?

- **L1正则化**：在损失函数中加入权重绝对值之和`λΣ|w|`，产生稀疏权重（部分权重变为0），可用于特征选择
- **L2正则化**：在损失函数中加入权重平方和`λΣw²`，使权重趋向于较小的值，防止过拟合
- **Dropout**：训练时随机丢弃部分神经元（置零），迫使网络学习冗余表示，减少神经元之间的共适应

项目中BERT训练使用Dropout=0.2（hidden和attention层各0.2）。

### Q43: 简述模型训练的整体流程?

1. **数据准备**：加载数据、预处理、拆分训练/验证/测试集
2. **模型定义**：搭建网络结构、加载预训练权重
3. **损失函数和优化器**：选择合适的损失函数和优化器
4. **训练循环**：
   - 前向传播：`outputs = model(inputs)`
   - 计算损失：`loss = criterion(outputs, labels)`
   - 反向传播：`loss.backward()`
   - 参数更新：`optimizer.step()`
5. **验证评估**：在验证集上评估性能，早停判断
6. **模型保存**：保存最佳模型参数
7. **测试评估**：在测试集上最终评估

### Q44: 简述下one-hot的优缺点?

**优点**：
- 实现简单，易于理解
- 无信息损失，精确表示每个类别

**缺点**：
- 维度灾难：词表大小为V时，每个词用V维向量表示，V很大时非常稀疏
- 无法表达词与词之间的语义关系（任意两个不同词的距离相同）
- 存储和计算效率低

### Q45: 简述下word2vec中的cbow和skip-gram的核心区别

- **CBOW（Continuous Bag of Words）**：用上下文词预测中心词
  - 输入：上下文词的平均向量
  - 输出：中心词
  - 训练速度快，适合频繁词

- **Skip-gram**：用中心词预测上下文词
  - 输入：中心词向量
  - 输出：上下文词
  - 训练速度慢，但对罕见词效果更好

**核心区别**：CBOW是多对一，Skip-gram是一对多。Skip-gram在语义相似度任务上通常表现更好。

### Q47: 简述下RNN和LSTM以及GRU在结构和功能上的核心区别

- **RNN**：简单的循环结构，隐藏状态`h_t = tanh(W_hh × h_{t-1} + W_xh × x_t)`。问题：梯度消失/爆炸，难以捕捉长距离依赖

- **LSTM**：引入三个门控机制
  - 遗忘门：决定丢弃哪些信息
  - 输入门：决定存储哪些新信息
  - 输出门：决定输出哪些信息
  - 还有细胞状态（cell state），梯度可以沿着细胞状态传播，缓解梯度消失

- **GRU**：LSTM的简化版，将遗忘门和输入门合并为更新门，将细胞状态和隐藏状态合并
  - 参数更少，训练更快
  - 效果与LSTM相当

**蒸馏项目中**使用BiLSTM作为学生模型（2层双向）。

### Q48: 简述下为什么引入注意力机制以及什么是注意力机制

**为什么引入**：RNN/LSTM存在长距离依赖问题，且无法并行计算。注意力机制可以让模型直接关注输入序列中的任意位置，解决长距离依赖问题。

**什么是注意力机制**：给定Query、Key、Value，计算Query与所有Key的相似度（注意力分数），用softmax归一化后作为权重对Value加权求和。

`Attention(Q,K,V) = softmax(QK^T / √d_k) × V`

**自注意力**：Q、K、V来自同一序列，每个位置都能关注序列中的所有位置。

### Q49: 简述下transformer架构

Transformer由**Encoder**和**Decoder**两部分组成：

**Encoder**（BERT使用的是纯Encoder）：
- 多头自注意力层（Multi-Head Self-Attention）
- 前馈神经网络（FFN）
- 残差连接 + 层归一化
- 重复N层（BERT-base为12层）

**Decoder**：
- 掩码多头自注意力（防止看到未来信息）
- 编码器-解码器注意力
- 前馈神经网络
- 残差连接 + 层归一化

**核心创新**：
- 自注意力机制替代RNN，支持并行计算
- 位置编码（Positional Encoding）注入位置信息
- 多头注意力从不同子空间捕捉不同关系

### Q50: 简述下层次softmax和传统softmax的区别

**传统Softmax**：对所有类别计算概率，时间复杂度O(V)，V为词表大小
- `P(w) = exp(score_w) / Σ exp(score_i)`

**层次Softmax（Hierarchical Softmax）**：将分类转化为二叉树上的路径选择
- 每个叶子节点对应一个词/类别
- 从根到叶子的路径上，每个内部节点做一次二分类
- 时间复杂度O(log V)
- FastText和Word2Vec中使用，大幅提升训练和推理速度

### Q51: 简述下BERT模型的两大任务

1. **MLM（Masked Language Model）**：随机遮盖输入中15%的token，让模型预测被遮盖的token
   - 80%替换为[MASK]，10%替换为随机词，10%保持不变
   - 学习上下文语义表示

2. **NSP（Next Sentence Prediction）**：判断两个句子是否是上下文相邻关系
   - 50%正例（相邻句子），50%负例（随机拼接）
   - 学习句子间的关系

BERT通过这两个任务进行预训练，学习通用的语言表示，然后在下游任务（如文本分类）上微调。

### Q52: 简述下BERT模型的架构

BERT-base架构：
- **Embedding层**：Token Embedding + Position Embedding + Segment Embedding
- **Transformer Encoder**：12层，每层包含
  - Multi-Head Self-Attention（12个头）
  - Feed-Forward Network（中间维度3072）
  - LayerNorm + Residual Connection
- **输出**：[CLS] token的隐藏状态（768维），用于分类

总参数量：约1.1亿（124M）
隐藏维度：768
注意力头数：12
层数：12
最大序列长度：512

### Q53: 简述下BERT输入部分是由哪三部分组成的

1. **Token Embedding**：将输入token映射为向量
   - 使用WordPiece分词，特殊token：[CLS]（句首）、[SEP]（句分隔）、[PAD]（填充）
   - 例："我喜欢NLP" → [CLS] 我 喜 欢 NLP [SEP]

2. **Position Embedding**：表示token在序列中的位置
   - 与Transformer不同，BERT使用可学习的位置编码（非正弦函数）
   - 最大支持512个位置

3. **Segment Embedding**：区分不同句子
   - 句子A用 embedding 0，句子B用 embedding 1
   - 单句分类任务中全部为0

三者相加后输入Transformer Encoder。
