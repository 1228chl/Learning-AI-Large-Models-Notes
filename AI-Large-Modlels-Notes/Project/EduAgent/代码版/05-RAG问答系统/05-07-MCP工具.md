# MCP 工具 — 从零理解

## 一、MCP 是什么？

MCP（Model Context Protocol）是 Anthropic 提出的**标准化工具调用协议**，让 AI Agent 通过统一接口调用外部工具。

```
┌──────────────┐     JSON-RPC     ┌──────────────────┐
│  QA Agent    │ ◄──────────────► │  MCP Server      │
│  nodes.py    │                  │  web_search.py   │
│              │  POST /mcp       │  ┌────────────┐  │
│ call_mcp_    │  {"jsonrpc":"2.0",│  │ @mcp.tool()│  │
│ tool()       │   "method":"tools/│  │ web_search│  │
│              │   call",          │  └────────────┘  │
│              │   "params":{...}} │                  │
└──────────────┘                  └──────────────────┘
```

## 二、MCP 客户端

### 2.1 call_mcp_tool

```python
async def call_mcp_tool(server_url, tool_name, arguments, timeout=30.0):
    payload = {
        "jsonrpc": "2.0",
        "id":      1,
        "method":  "tools/call",
        "params": {"name": tool_name, "arguments": arguments},
    }

    headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",  # 必须！json_response=True 的 Server 需要
    }

    async with httpx.AsyncClient(timeout=timeout, trust_env=False) as client:
        resp = await client.post(f"{server_url}/mcp", json=payload, headers=headers)
        resp.raise_for_status()

    # 解析 JSON-RPC 响应
    data = resp.json()
    if "error" in data:
        raise ValueError(f"MCP error: {data['error']}")

    # 处理多个 TextContent 条目
    content = data.get("result", {}).get("content", [])
    for item in content:
        text = item.get("text", "")
        if text:
            parsed = json.loads(text)
            if isinstance(parsed, list):
                return parsed  # 整个列表在一个 TextContent 里
    return items
```

### 2.2 list_mcp_tools

```python
async def list_mcp_tools(server_url, timeout=10.0):
    payload = {"jsonrpc": "2.0", "id": 1, "method": "tools/list", "params": {}}
    async with httpx.AsyncClient(timeout=timeout, trust_env=False) as client:
        resp = await client.post(f"{server_url}/mcp", json=payload, headers=headers)
    return resp.json().get("result", {}).get("tools", [])
```

## 三、MCP 知识库服务

FastMCP 快速创建 MCP Server：

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP(name="EduAgent-KnowledgeBase", stateless_http=True, json_response=True)

@mcp.tool()
async def search_knowledge_base(query, tenant_id, course_id=None, top_k=3):
    """Hybrid semantic + keyword search over the EduAgent Milvus knowledge base."""
    loop = asyncio.get_running_loop()
    ranked_docs, confidence = await loop.run_in_executor(
        None, lambda: retrieve(query, tenant_id, course_id, rerank_top_k=top_k),
    )
    return [
        {"content": doc.content, "source_name": doc.metadata.get("source_name", ""),
         "score": round(doc.score, 6), "confidence": round(confidence, 4),
         "is_high_confidence": confidence >= 0.75}
        for doc in ranked_docs
    ]
```

## 四、MCP 网页搜索服务

### 4.1 Tavily 搜索

```python
async def _search_tavily(query, max_results, api_key):
    async with httpx.AsyncClient(timeout=15.0) as client:
        resp = await client.post("https://api.tavily.com/search", json={
            "api_key": api_key, "query": query, "max_results": max_results,
        })
        resp.raise_for_status()
    return [{"title": r["title"], "url": r["url"], "snippet": r["content"][:500]} for r in resp.json()["results"]]
```

### 4.2 DuckDuckGo 搜索（免费降级）

```python
async def _search_duckduckgo(query, max_results):
    from duckduckgo_search import DDGS

    def _sync_search():
        results = []
        with DDGS() as ddgs:
            for r in ddgs.text(query, max_results=max_results):
                results.append({"title": r["title"], "url": r["href"], "snippet": r["body"][:500]})
        return results

    return await asyncio.to_thread(_sync_search)
```

### 4.3 自动选择

```python
@mcp.tool()
async def web_search(query, max_results=5):
    settings = get_settings()

    # 优先 Tavily
    if settings.tavily_api_key:
        try:
            return await _search_tavily(query, max_results, settings.tavily_api_key)
        except Exception as e:
            logger.warning("tavily_failed", error=str(e))

    # 降级 DuckDuckGo
    return await _search_duckduckgo(query, max_results)
```

## 五、MCP 在 QA Agent 中的使用

async def web_search_node(state: QAState) -> dict:
    from backend.mcp.client import call_mcp_tool

## 七、总结

```
MCP 协议 = JSON-RPC 标准化工具调用

客户端（client.py）
  ├── call_mcp_tool()    → 调用工具
  └── list_mcp_tools()   → 列出工具

服务端
  ├── knowledge_base_server.py  → 知识库检索（@mcp.tool search_knowledge_base）
  └── web_search_server.py      → 网页搜索（@mcp.tool web_search）
```

**核心思想：MCP 让 Agent 和工具解耦，工具可以独立部署、独立维护。**
