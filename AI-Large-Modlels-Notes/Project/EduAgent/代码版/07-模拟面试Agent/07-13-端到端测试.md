## 一、测试场景总览

端到端测试覆盖完整的面试生命周期：

| 步骤 | 操作 | 验证点 |
|:-----|:-----|:-------|
| ① | 学员登录 | JWT Token 获取成功 |
| ② | 创建面试会话 | `POST /sessions` 返回 session_id 和开场白 |
| ③ | 发送自我介绍 | `POST /chat` 返回面试官回应 |
| ④ | 多轮技术问答 | 面试官持续出题，回答质量评估正常 |
| ⑤ | 项目深挖 | 简历联动正常，追问逻辑正确 |
| ⑥ | 反问环节 | 开场白和问题回应正常 |
| ⑦ | 强制结束或正常结束 | `current_stage = finished` |
| ⑧ | 查询报告 | `GET /sessions/{id}/report` 返回五维度评估 |
| ⑨ | 历史列表 | `GET /sessions` 返回面试记录 |

## 三、正常流程测试

### 3.1 创建会话

```python
# 学员登录
student_token = login("student", "Student@123456")

# 创建面试会话
resp = httpx.post(
    f"{BASE_URL}/interview/sessions",
    headers={"Authorization": f"Bearer {student_token}"},
    json={"target_position": "AI工程师", "resume_review_id": None},
)
session_id = resp.json()["session_id"]
opening = resp.json()["message"]
assert "欢迎" in opening
```

### 3.2 多轮对话

```python
# 发送自我介绍
resp = httpx.post(
    f"{BASE_URL}/interview/sessions/{session_id}/chat",
    headers={"Authorization": f"Bearer {student_token}"},
    json={"message": "我叫张三，是一名计算机科学专业的学生，主修AI方向..."},
)
assert resp.json()["current_stage"] in ("warmup", "tech_base")

# 多轮技术问答
for _ in range(10):
    resp = httpx.post(
        f"{BASE_URL}/interview/sessions/{session_id}/chat",
        headers={"Authorization": f"Bearer {student_token}"},
        json={"message": "Transformer的核心思想是自注意力机制..."},
    )
    data = resp.json()
    if data["is_finished"]:
        break
```

### 3.3 验证结束

```python
assert data["is_finished"] == True
assert "report_summary" in data
assert data["report_summary"]["overall_score"] > 0
```

### 3.4 查询报告

```python
resp = httpx.get(
    f"{BASE_URL}/interview/sessions/{session_id}/report",
    headers={"Authorization": f"Bearer {student_token}"},
)
report = resp.json()
assert report["overall_score"] > 0
assert len(report["dimensions"]) == 5
```

## 五、SSE 流式接口验证

```python
# scripts/manual_tests/test_interview_stream.py
# SSE 流式接口测试
import httpx, json

with httpx.Client() as client:
    with client.stream(
        "POST",
        f"{BASE_URL}/interview/sessions/{session_id}/chat/stream",
        headers={"Authorization": f"Bearer {student_token}"},
        json={"message": "请介绍一下你自己"},
        timeout=30,
    ) as response:
        for line in response.iter_lines():
            if line.startswith("data: "):
                event = json.loads(line[6:])
                if event["type"] == "token":
                    print(event["content"], end="")
                elif event["type"] == "done":
                    print(f"\n完成: {event['is_finished']}")
```

## 六、后端日志关键字

| 事件 | 日志关键字 | 说明 |
|:-----|:---------|:------|
| 会话创建 | `interview.session_started` | 面试会话创建成功 |
| 首轮初始化 | `load_context.first_round_initialization` | 首轮加载题库和简历 |
| LLM 出题 | `generate_questions_llm.done` | LLM 动态出题完成 |
| DB 题库加载 | `load_context.db_questions_loaded` | DB 题库加载完成 |
| 阶段推进 | `check_stage.advance` | 阶段推进（含 `from_stage`/`to_stage`） |
| 强制结束 | `check_stage.forced_to_finished` | 学员触发强制结束 |
| 评估质量 | `evaluate_answer.done` | 回答质量评估完成 |
| 报告生成 | `generate_report.done` | 五维度报告生成完成 |
| 报告持久化 | `save_report.done` | 报告写入 DB 完成 |

## 七、边界情况

| 场景 | 预期表现 |
|:-----|:---------|
| 无简历创建会话 | 项目深挖环节走 `no_resume` 兜底路径 |
| 发送"结束面试" | 强制结束，生成报告 |
| 连续发送空消息 | 触发 `NO_ANSWER` 评估，不调 LLM |
| SSE 连接中断 | 重连后发送消息，MemorySaver 恢复上下文 |
| 同时创建多个会话 | 每个 session_id 独立，互不干扰 |
| 查询未结束的会话报告 | 返回 400 "面试尚未结束" |
