# 异常体系 — 从零理解

## 一、为什么需要自定义异常？

Python 内置了很多异常：`ValueError`、`TypeError`、`RuntimeError` 等。但项目中只用内置异常有两个问题：

```python
# 问题1：无法区分不同来源的异常
try:
    result = call_llm()
except Exception as e:
    # 是 LLM 超时了？还是输入非法？还是网络断了？
    # 处理方式完全不同，但只能统一捕获
    pass

# 问题2：缺少上下文信息
raise ValueError("调用失败")
# 是哪个 Agent 调用的？失败了能不能重试？这些信息都没有
```

**自定义异常**就是给异常"打标签"，让捕获方知道该怎么做。

## 二、逐行读 exceptions.py

### 2.1 基类

```python
class EduAgentBaseError(Exception):
    def __init__(self, message: str, agent_type: str = "", details: dict = None):
        super().__init__(message)
        self.agent_type = agent_type  # 哪个 Agent 出的错
        self.details = details or {}  # 额外细节
```

比普通 Exception 多两个字段：

- `agent_type`：哪个 Agent 出的错（"qa"、"exam"、"resume"）
- `details`：额外细节字典（如 `{"model": "deepseek-chat", "tokens": 4096}`）

### 2.2 异常分类

```python
# 可重试异常
class LLMAPIError(EduAgentBaseError):      # 大模型 API 调用失败
    pass

class MilvusConnectionError(EduAgentBaseError):  # Milvus 连接失败
    pass
```

```python
# 不可重试异常
class InvalidInputError(EduAgentBaseError):  # 用户输入不合法
    pass

class AuthenticationError(EduAgentBaseError):  # 认证失败
    pass
```

```python
# 业务异常
class AgentExecutionError(EduAgentBaseError):  # Agent 业务逻辑失败
    pass

class PipelineError(EduAgentBaseError):  # 流水线编排失败
    pass

class IntentRouteError(EduAgentBaseError):  # 意图识别失败
    pass

class FileParseError(EduAgentBaseError):  # 文件解析失败
    pass
```

## 三、异常怎么用

### 3.1 抛异常

```python
raise InvalidInputError(
    "仅支持 PDF 格式",
    agent_type="resume",
    details={"filename": "test.txt", "ext": ".txt"},
)
```

### 3.2 在 retry.py 里分类处理

```python
# 可重试 → 重试
RETRYABLE_ERRORS = (
    LLMAPIError,
    MilvusConnectionError,
    TimeoutError,
    ConnectionError,
)

# 不可重试 → 立即抛出
NON_RETRYABLE_ERRORS = (
    InvalidInputError,
    AuthenticationError,
    AgentExecutionError,
    PipelineError,
    IntentRouteError,
    FileParseError,
)
```

## 四、异常体系全图

```
Exception
  └── EduAgentBaseError
        ├── LLMAPIError              ← 可重试：API 超时/限流/网络错误
        ├── AgentExecutionError      ← 不可重试：Agent 执行失败
        ├── PipelineError            ← 不可重试：流水线编排失败
        ├── IntentRouteError         ← 不可重试：意图识别失败
        ├── MilvusConnectionError    ← 可重试：Milvus 连接失败
        ├── FileParseError           ← 不可重试：文件解析失败
        ├── InvalidInputError        ← 不可重试：输入不合法
        └── AuthenticationError      ← 不可重试：认证失败
```

## 五、总结

```
抛出异常时：raise InvalidInputError("消息", agent_type="resume", details={...})
    │
    ▼
retry.py 捕获后判断：
    可重试 → 等 1s → 重试（最多 3 次）
    不可重试 → 立即抛出，不浪费重试次数
    │
    ▼
所有重试失败 → 降级处理（返回友好提示）
```

**核心思想：给异常打标签，让捕获方知道该怎么做。**
