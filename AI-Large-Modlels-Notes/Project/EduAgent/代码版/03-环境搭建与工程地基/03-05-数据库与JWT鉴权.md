# 数据库与 JWT 鉴权 — 从零理解

## 一、两个文件的分工

```
backend/dependencies.py    ← 依赖注入：数据库会话 + JWT 鉴权
backend/api/v1/auth.py     ← 路由：登录接口 /login + /me
```

- `dependencies.py` 提供"工具"（数据库连接、鉴权函数）
- `auth.py` 使用这些工具实现登录接口

## 二、数据库连接

### 2.1 异步引擎

```python
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker

engine = create_async_engine(
    settings.database_url,  # postgresql+asyncpg://user:pass@localhost:5433/eduagent
    pool_size=10,           # 连接池大小
    max_overflow=20,        # 最大溢出连接数
)
AsyncSessionLocal = async_sessionmaker(engine, expire_on_commit=False)
```

**为什么用异步？** FastAPI 是异步框架，如果用同步数据库，每次请求都会阻塞事件循环。

### 2.2 数据库会话依赖

```python
async def get_db() -> AsyncGenerator[AsyncSession, None]:
    async with AsyncSessionLocal() as session:
        try:
            yield session
            await session.commit()   # 正常 → 提交
        except Exception:
            await session.rollback() # 异常 → 回滚
            raise
```

**用法**：FastAPI 自动注入，用完自动释放：

```python
@router.post("/login")
async def login(req: LoginRequest, db: AsyncSession = Depends(get_db)):
    result = await db.execute(text("SELECT * FROM users WHERE username = :val"), {"val": req.username})
    row = result.fetchone()
```

## 三、JWT 鉴权

### 3.1 JWT 是什么？

JWT（JSON Web Token）是一个字符串，包含三部分：

```
header.payload.signature
```

- **header**：声明算法（如 HS256）
- **payload**：存放用户信息（user_id、role、过期时间）
- **signature**：用密钥对前两部分签名，防止篡改

### 3.2 Bearer Token 认证流程

```
客户端                    服务器
  │                         │
  │  POST /login            │
  │  {username, password}   │
  │ ─────────────────────►  │  验证用户名密码
  │                         │  → 签发 JWT Token
  │  {access_token: "..."}  │
  │ ◄─────────────────────  │
  │                         │
  │  GET /resume/upload     │
  │  Authorization: Bearer <token>
  │ ─────────────────────►  │  解码 JWT Token
  │                         │  → 提取 user_id, role
  │                         │  → 执行业务逻辑
  │  {result}               │
  │ ◄─────────────────────  │
```

### 3.3 签发 Token（auth.py）

```python
def _create_access_token(data: dict, expires_minutes: int) -> str:
    payload = data.copy()
    expire = datetime.now(timezone.utc) + timedelta(minutes=expires_minutes)
    payload["exp"] = expire  # 标准过期字段
    return jwt.encode(payload, settings.jwt_secret_key, algorithm=settings.jwt_algorithm)
```

### 3.4 验证 Token（dependencies.py）

```python
bearer_scheme = HTTPBearer()  # 自动解析 Authorization: Bearer <token>

async def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(bearer_scheme),
) -> dict:
    try:
        payload = jwt.decode(
            credentials.credentials,
            settings.jwt_secret_key,
            algorithms=[settings.jwt_algorithm],
        )
        user_id = payload.get("sub")
        role = payload.get("role", "student")
        if not user_id:
            raise credentials_exception
    except JWTError:
        raise credentials_exception

    return {"user_id": user_id, "role": role, "tenant_id": tenant_id}
```

**用法**：在需要鉴权的接口加 `Depends(get_current_user)`：

```python
@router.post("/upload", status_code=202)
async def upload_resume(
    file: UploadFile = File(...),
    current_user: dict = Depends(get_current_user),  # ← 自动鉴权
):
    student_id = current_user["user_id"]  # 从 Token 里拿用户信息
```

## 四、登录接口

### 4.1 密码哈希

```python
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
```

密码不存明文，存哈希值：

```python
# 注册时
password_hash = pwd_context.hash("Student@123456")

# 登录时验证
password_ok = pwd_context.verify(req.password, row.password_hash)
```

### 4.2 异步验证

```python
# 密码验证是 CPU 密集型（~100ms），用线程池避免阻塞事件循环
loop = asyncio.get_running_loop()
password_ok = await loop.run_in_executor(
    None, pwd_context.verify, req.password, row.password_hash
)
```

## 五、完整登录流程

```
POST /login
  │
  ▼
从请求体解析 username, password
  │
  ▼
SQL 查询用户（参数化查询防注入）
  │
  ├─ 用户不存在 → 401 "用户名或密码错误"
  │
  ├─ 账号被禁用 → 403 "账号已被禁用"
  │
  └─ 用户存在
       │
       ▼
  在线程池里验证密码
       │
       ├─ 密码错误 → 401 "用户名或密码错误"
       │
       └─ 密码正确 → 签发 JWT Token → 返回
```

## 七、总结

```
dependencies.py
  ├── get_db()            → 数据库会话（自动提交/回滚）
  └── get_current_user()  → JWT 鉴权（自动解析 Token）

auth.py
  ├── POST /login          → 登录签发 Token
  └── GET /me              → 验证 Token 有效性
```

**核心思想：依赖注入让业务代码不需要关心数据库连接和鉴权逻辑。**
