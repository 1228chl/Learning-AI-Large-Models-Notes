## 三、SSE 流式测试

```python
# test_unified_chat_e2e.py
BASE_URL = "http://localhost:8000/api/v1"
student_token = login("student", "Student@123456")

def test_sse_stream(message: str, expected_event_types: list):
    """测试 SSE 流式接口，验证事件类型序列"""
    with httpx.Client() as client:
        with client.stream(
            "POST",
            f"{BASE_URL}/chat/stream",
            headers={"Authorization": f"Bearer {student_token}"},
            json={"session_id": str(uuid.uuid4()), "message": message},
            timeout=30,
        ) as response:
            events = []
            for line in response.iter_lines():
                if line.startswith("data: "):
                    event = json.loads(line[6:])
                    events.append(event["type"])
            assert events == expected_event_types, f"预期 {expected_event_types}，实际 {events}"

# 测试路由分支
test_sse_stream("你好", ["token", "done"])
test_sse_stream("什么是Transformer", ["routing_decision", "progress", "token", "meta", "done"])
test_sse_stream("我要提交试卷", ["routing_decision", "guidance", "done"])
test_sse_stream("帮我准备求职", ["routing_decision", "pipeline_plan", "done"])
```

## 四、后端日志确认

| 事件 | 日志关键字 | 说明 |
|:-----|:---------|:------|
| 规则拦截命中 | （无，零 Token） | `_pre_filter` 返回模板 |
| LLM 路由 | `unified_chat.llm_route_result` | 含 label + reason |
| 路由决策推送 | （SSE `routing_decision`） | 前端接收 |
| QA 流式执行 | `qa.*` 相关日志 | 第 5 章的日志 |
| 引导跳转 | （SSE `guidance`） | 前端接收 |
| Pipeline 计划 | （SSE `pipeline_plan`） | 前端接收 |
| 流结束 | （SSE `done`） | 前端接收 |

## 五、常见问题排查

| 问题 | 可能原因 | 排查方法 |
|:-----|:---------|:---------|
| 规则拦截未生效 | 输入包含多余的标点 | 检查 `_STRIP_TAIL_RE` 正则 |
| LLM 路由返回非法 label | LLM 幻觉 | 检查日志 `unified_chat.llm_route_unknown_label` |
| QA 流式没有 token | QA Agent 生成失败 | 检查 QA 相关日志 |
| guidance 没有 action_url | AgentType 不在 `_GUIDANCE` 中 | 检查 `_GUIDANCE` 字典 |
| pipeline_plan 步骤不对 | `_pipelines` 定义不正确 | 检查 `orchestrator.py` Pipeline 定义 |
