> 对应课件：8.1 系统集成全景
> 前置依赖：第 4~7 章的四个 Agent 源代码

## 一、前四章造了什么，这一章做什么

| 章节 | 造了什么 | 产出文件 |
|:-----|:---------|:---------|
| 第 3 章 | 工程地基 | `logger.py`、`config.py`、`exceptions.py`、`retry.py`、`dependencies.py` |
| 第 4 章 | 简历审查 Agent | `backend/agents/resume/` |
| 第 5 章 | 智能问答 Agent | `backend/agents/qa/` + `core/` |
| 第 6 章 | 试卷批改 Agent | `backend/agents/exam/` |
| 第 7 章 | 模拟面试 Agent | `backend/agents/interview/` |
| **第 8 章** | **系统集成** | `orchestrator.py` + `unified_chat.py` + `router.py` + `main.py` 定稿 |

**第 8 章不造新的 Agent，而是做四件事**：① 编排器（Orchestrator）统一管理四个 Agent 图 ② 统一入口（unified_chat）接收用户输入并路由 ③ 路由聚合（router.py）把所有端点挂到总路由 ④ 工程装配（main.py）把所有零件拼成完整应用。

---

## 二、统一入口的请求生命周期

```
用户输入 → 规则前置拦截（零 Token）→ LLM 路由 → 路由决策 → 分发执行
               ↓ 命中                     ↓ 未命中
         模板回复（不加 LLM）             ↓
                              qa → 流式执行 QA Agent
                              exam/resume/interview → 引导跳转
                              multi_agent → 推送 Pipeline 计划
                              clarify → 追问提示
```

---

## 三、两种执行模式

| 模式 | 说明 | 适用场景 |
|:-----|:-----|:---------|
| 单 Agent 直达 | 直接调用一个 Agent 的 LangGraph 图 | 用户直接提问、批改试卷、审查简历、模拟面试 |
| 多 Agent 串联 Pipeline | 按顺序调用多个 Agent，前序输出注入后序输入 | 求职全链路（先审简历再面试） |
