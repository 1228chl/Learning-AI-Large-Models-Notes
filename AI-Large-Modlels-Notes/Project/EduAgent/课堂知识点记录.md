## 智能体 Agent 核心

- 感知（Perceive）
- 记忆（Memory）
- 决策（Decide）
- 行动（Act）

一个 Agent（智能体）是一个**以大模型为【大脑】、能够感知输入、自主决策、并采取行动来完成目标的系统**。


## Agent 的几种形态

- 单次调用（不算 Agent）
	- 用户 - LLM - 回答
- 固定工作流（流程写死，LLM 嵌在某些步骤里）
	- 用户 - 步骤 A - 步骤 B（含 LLM） - 步骤 C - 结果
- 单 Agent（LLM 自主决定调哪些工具，循环到任务完成）
	- 用户 - LLM 决策 - 调用工具 - 循环 - 用户（继续一个循环）
- 多 Agent 协作（多个专精 Agent，由编排者统一调度）
	- 用户 - 编排者 - Agent1、Agent2、Agent3
