## 2.1 Python异步编程

**核心概念**：`async def` 定义协程，`await` 等待结果，`asyncio.run()` 是总入口。

**asyncio.gather（并发）**：多个协程同时启动一起等，总耗时≈最慢的那个。
```python
results = await asyncio.gather(
    fetch("A", 2), fetch("B", 2), fetch("C", 2)
)
```
**EduAgent应用**：启动时并行预热3个本地模型、简历六维度并行评分、试卷多题并行批改。

**run_in_executor（同步阻塞→异步）**：把同步阻塞函数丢线程池，不阻塞事件循环。
```python
loop = asyncio.get_running_loop()
result = await loop.run_in_executor(None, sync_func, arg)
```
**EduAgent应用**：所有本地模型推理（BGE-M3/Reranker/MiniLM）、PDF解析、Word解析、密码校验。

**create_task（后台任务）**：把协程扔到后台，立即返回。
**GC保护陷阱**：Task无强引用会被回收→模块级set持有引用+done_callback自动移除。
```python
_background_tasks: set[asyncio.Task] = set()
task = asyncio.create_task(background_job())
_background_tasks.add(task)
task.add_done_callback(_background_tasks.discard)
```

**异步上下文管理器 @asynccontextmanager**：yield前=启动逻辑，yield后=清理逻辑。
**EduAgent应用**：main.py的lifespan函数，启动时迁移DB+预热模型，关闭时清理缓存。

## 2.2 Pydantic

**核心用途**：①让大模型输出结构化数据（最重要）②读取配置与接口参数

**BaseModel + Field**：继承BaseModel，类型注解声明字段，自动校验+合理转换。
```python
class Student(BaseModel):
    name: str = Field(description="姓名")  # 必填
    age: int = Field(default=18, description="年龄")  # 可选
```

**description的关键作用**：使用`with_structured_output`时，大模型读取字段名+类型+description作为填空指令。写Pydantic模型=设计大模型输出格式=写提示词的一部分。

**default_factory=list**：列表默认值必须用此写法，避免所有实例共享同一列表。

**嵌套模型**：`list[子模型]`，传字典自动转成子模型对象。
**model_dump()**：模型→字典，存库/返回JSON时使用。
**Enum**：限制字段为固定取值（如面试阶段）。**BaseSettings**：从.env文件读配置。

## 2.3 LangChain

**核心角色**：统一的大模型调用层，用同一套代码调用不同模型。

**创建模型（1.x新写法）**：
```python
llm = init_chat_model(
    model="deepseek-chat", model_provider="openai",
    api_key="...", base_url="https://api.deepseek.com/v1", temperature=0,
)
# 禁止使用 ChatOpenAI(...) 旧写法
# 模型名不能写成 "deepseek/deepseek-chat" 带前缀形式
```

**消息体系**：`SystemMessage`（人设规则）、`HumanMessage`（用户输入）、`AIMessage`（模型回复）。

**调用**：`response = await llm.ainvoke(messages)`，用`response.text`（属性，不加括号）取文本。

**with_structured_output（核心）**：让大模型严格按Pydantic模型填空，直接返回对象。
```python
structured_llm = llm.with_structured_output(PersonInfo, method="function_calling")
result: PersonInfo = await structured_llm.ainvoke(messages)
# 直接 result.name / result.age 访问，不需解析JSON
```
**强制规范**：`method="function_calling"`必须写（DeepSeek不支持json_schema模式）。

**流式astream**：`async for chunk in llm.astream(messages): print(chunk.text, end="")`

## 2.4 LangGraph

**核心**：Agent=一张图，四要素——State(Node共享数据)、Node(处理单元)、Edge(固定边/条件边)、Checkpointer(持久化)。

**实现五步**：
```python
# 1. 定义State
class MyState(TypedDict):
    question: str
    answer: str
# 2. 写节点函数（接收State，返回要更新的字段字典）
def my_node(state: MyState) -> dict:
    return {"answer": "..."}
# 3. 连接边
builder = StateGraph(MyState)
builder.add_node("node1", my_node)
builder.add_edge(START, "node1")  # 入口用 START，禁 set_entry_point
builder.add_edge("node1", END)    # 出口用 END，禁 set_finish_point
# 条件边
builder.add_conditional_edges("classify", router_func, {"concept": "c", "code": "c"})
# 4. 绑定Checkpointer实现记忆
graph = builder.compile(checkpointer=MemorySaver())
# 5. 运行
result = graph.invoke({"question": "..."}, config={"configurable": {"thread_id": "session_1"}})
```

**add_messages**：`Annotated[list, add_messages]`让消息追加而非覆盖，配合MemorySaver实现多轮记忆。

**interrupt/Command**：`interrupt()`暂停图等待外部输入，`Command(resume=...)`恢复执行（HitL，第6章详讲）。

## 2.5 FastAPI

**核心角色**：系统对外的API层，REST API + SSE流式接口。

**关键用法**：
```python
@app.post("/login", response_model=TokenResponse)
async def login(req: LoginRequest, db=Depends(get_db)):
    ...

# 依赖注入——复用通用逻辑
async def get_db(): ...  # yield型：yield前准备连接，yield后提交/回滚
async def get_current_user(): ...  # 校验JWT，失败抛401

# SSE流式
from sse_starlette.sse import EventSourceResponse
async def event_generator():
    yield {"data": json.dumps({"type": "token", "content": char})}
return EventSourceResponse(event_generator())
```

## 2.6 PostgreSQL vs MySQL关键差异

| 特性 | MySQL | PostgreSQL |
|------|-------|-----------|
| 主键自增 | INT AUTO_INCREMENT | UUID DEFAULT gen_random_uuid() |
| 布尔 | TINYINT(1) | BOOLEAN (true/false) |
| JSON | JSON | JSONB（二进制，更快可索引） |
| 自动更新时间 | ON UPDATE CURRENT_TIMESTAMP | TIMESTAMPTZ + 触发器 |
| upsert | INSERT ... ON DUPLICATE KEY UPDATE | INSERT ... ON CONFLICT ... DO UPDATE |
| 插入后拿主键 | LAST_INSERT_ID() | RETURNING id |

## 2.7 SQLAlchemy异步操作

**三件套**：`create_async_engine`（引擎+连接池）→ `async_sessionmaker`（会话工厂）→ `AsyncSession`（会话）

**参数化查询（防SQL注入）**：
```python
result = await db.execute(
    text("SELECT * FROM users WHERE username = :name"),
    {"name": "小明"}

rows = result.mappings().fetchall()  # 推荐：返回字典列表
```

**读取结果**：`fetchone()`取一行、`fetchall()`取所有行、`mappings()`转为字典形式（推荐）

## 2.8 Reducer（状态合并）

**默认规则**：覆盖式合并——节点返回的字段直接覆盖State中同名字段。

**列表字段问题**：多个节点向同一列表追加内容，后一个会覆盖前一个。

**解决方案**：使用`Annotated[类型, 合并函数]`指定Reducer。
- `operator.add`：列表拼接
- `add_messages`：消息追加+自动包装+ID去重（比operator.add更智能）
- 自定义Reducer：普通函数`(current, update) -> new_value`
