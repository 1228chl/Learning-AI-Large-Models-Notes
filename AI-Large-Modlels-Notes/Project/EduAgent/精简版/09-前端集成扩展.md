# 第9章 前端集成扩展

## 9.1 前端技术栈

| 层次 | 技术 | 作用 |
|------|------|------|
| 框架 | Vue 3 + Composition API | 响应式UI |
| UI组件 | Element Plus | 表单、弹窗、布局 |
| HTTP | Axios | 封装所有非流式API请求 |
| 状态管理 | Pinia | 全局存储登录状态（token、user） |
| 路由 | Vue Router 4 | SPA页面切换+鉴权守卫 |
| 构建 | Vite 5 | 开发服务器(:3000)+反向代理 |

## 9.2 前后端通信

**双通道设计**：
- **普通请求**（登录/上传/查询/轮询）：走Vite proxy（`/api`→`localhost:8000`），Axios自动注入JWT
- **SSE流式请求**（QA流式回答/面试对话）：fetch直连后端`http://localhost:8000`，绕过Vite proxy（proxy缓冲响应体导致SSE帧被堆积）

**JWT鉴权自动注入**：Axios请求拦截器从localStorage读token→注入`Authorization: Bearer`头；响应拦截器捕获401→自动跳转登录。

## 9.3 四大功能页面

| 功能 | 前端路由 | 后端API | 通信方式 |
|------|---------|---------|---------|
| 登录 | /login | POST /auth/login | Axios |
| 智能问答 | /qa | POST /qa/chat/stream | SSE直连 |
| 试卷批改-提交 | /exam | POST /exam/submit | Axios |
| 试卷批改-结果 | /exam/:id | GET /exam/my-submissions/:id | Axios |
| 简历审查-上传 | /resume | POST /resume/upload | Axios |
| 简历审查-报告 | /resume/:id | GET /resume/reviews/:id | Axios轮询 |
| 模拟面试-配置 | /interview | POST /interview/sessions | Axios |
| 模拟面试-对话 | /interview/:id | POST /interview/chat/stream | SSE直连 |
| 模拟面试-报告 | /interview/:id | GET /interview/report/:id | Axios |
| 教师批改确认 | /teacher/exam-review | GET /exam/pending-reviews | Axios |

## 9.4 关键设计决策

**Vite Proxy + SSE直连双通道**：普通请求走Vite proxy，SSE流式请求直连后端（proxy缓冲响应体导致SSE帧被堆积）。

**轮询 vs WebSocket**：简历审查/试卷批改状态用轮询（`setInterval`，3秒间隔），一次性等待完成场景，实现简单。

**角色权限路由守卫**：Vue Router的beforeEach导航守卫检查`auth.role`，学生和教师看到不同菜单。后端API层做第二层校验。
