# 第 9 章 前端集成扩展

## 9.1 前端技术栈

| 层次 | 技术 | 作用 |
|------|------|------|
| 框架 | Vue 3 + Composition API | 响应式 UI |
| UI 组件 | Element Plus | 表单、弹窗、布局 |
| HTTP | Axios | 封装所有非流式 API 请求 |
| 状态管理 | Pinia | 全局存储登录状态（token、user） |
| 路由 | Vue Router 4 | SPA 页面切换+鉴权守卫 |
| 构建 | Vite 5 | 开发服务器(:3000)+反向代理 |

## 9.2 前后端通信

**双通道设计**：

- **普通请求**（登录/上传/查询/轮询）：走 Vite proxy（`/api` → `localhost:8000`），Axios 自动注入 JWT
- **SSE 流式请求**（QA 流式回答/面试对话）：fetch 直连后端 `http://localhost:8000`，绕过 Vite proxy（proxy 缓冲响应体导致 SSE 帧被堆积）

**JWT 鉴权自动注入**：Axios 请求拦截器从 localStorage 读 token→注入 `Authorization: Bearer` 头；响应拦截器捕获 401→自动跳转登录。

## 9.3 四大功能页面

| 功能 | 前端路由 | 后端 API | 通信方式 |
|------|---------|---------|---------|
| 登录 | /login | POST /auth/login | Axios |
| 智能问答 | /qa | POST /qa/chat/stream | SSE 直连 |
| 试卷批改-提交 | /exam | POST /exam/submit | Axios |
| 试卷批改-结果 | /exam/:id | GET /exam/my-submissions/:id | Axios |
| 简历审查-上传 | /resume | POST /resume/upload | Axios |
| 简历审查-报告 | /resume/:id | GET /resume/reviews/:id | Axios 轮询 |
| 模拟面试-配置 | /interview | POST /interview/sessions | Axios |
| 模拟面试-对话 | /interview/:id | POST /interview/chat/stream | SSE 直连 |
| 模拟面试-报告 | /interview/:id | GET /interview/report/:id | Axios |
| 教师批改确认 | /teacher/exam-review | GET /exam/pending-reviews | Axios |

## 9.4 关键设计决策

**Vite Proxy + SSE 直连双通道**：普通请求走 Vite proxy，SSE 流式请求直连后端（proxy 缓冲响应体导致 SSE 帧被堆积）。

**轮询 vs WebSocket**：简历审查/试卷批改状态用轮询（`setInterval`，3 秒间隔），一次性等待完成场景，实现简单。

**角色权限路由守卫**：Vue Router 的 beforeEach 导航守卫检查 `auth.role`，学生和教师看到不同菜单。后端 API 层做第二层校验。
