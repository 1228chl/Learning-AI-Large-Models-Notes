# Submit A Full Socre Project

## 一、项目背景

对于字节跳动来说，产品线比较多，但是针对今日头条来说，用户的点击量、订阅量、付费量增长并不明显，所以需要在今日头条 APP 的推荐系统中内嵌一个子任务，将短文本自动进行多分类，然后投送到用户的频道中，使其点击量、订阅量、付费量等有明显增长，因此“投满分项目”应运而生。

一. flask 与 streamlit 框架的区别：flask 是基于 web 应用的 API 框架，前端页面需要自己写，前后端交互需要自己调试，对前后端知识要求较高。streamlit 是前后端一体的，只需要像搭积木一样就能搭建一个能用的页面，方便开发者快速开发与展示，开发者无需掌握任何前后端知识。

二. 基于 flask 框架进行模型部署：引入 flask 包，通过装饰器方法配置接口，并在接口中执行具体的模型方法。但是在实际应用中，只需要通过 codex 等 ai agent 开发工具生成即可，建议口述需求后，再交给大模型优化一遍提示词，再输入提示词给开发工具，这样开发的页面更好。

三. 基于字级别数据构建 fasttext 进行分类：

字级数据获取：1. 读取数据文件与目标文件。2. 根据数据格式进行文本预处理，分成一个一个字，用空格分隔。3. 将分好的数据保存至目标文件。

字级模型训练：1. 传入 fasttext 的有监督式学习方法，并设置 berbose=2 就得到训练后的模型，再调用模型 test 方法传入测试数据评估模型，模型达标后保存模型至本地目录。

模型调用：获取目标文档，用 list+join 方法拆分预处理文本，调用模型 predict 方法传入预处理文本数据就能得到模型结果。

四. 基于词级别数据构建 fasttext 进行分类，跟字级一样，不同点就是文本预处理时字级是切分每个字，词级是用结巴分词切分，以及路径不同、文件名不同、模型名不同等。
