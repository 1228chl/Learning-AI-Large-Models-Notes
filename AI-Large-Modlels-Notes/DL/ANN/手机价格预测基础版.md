## 3. 数据加载与预处理函数 `create_data`

```python
def create_data(csv_path='data/手机价格预测.csv', test_size=0.2, random_state=88):
```

**功能**：从 CSV 文件读取数据，划分训练/验证集，进行标准化，并返回 PyTorch 的 `Dataset` 对象及相关信息。

**参数**：
- `csv_path`：CSV 文件路径，默认 `'data/手机价格预测.csv'`。
- `test_size`：验证集比例，默认 0.2（20%）。
- `random_state`：随机种子，保证划分可重复。

**处理步骤**：

1. **读取数据**：
   ```python
   data = pd.read_csv(csv_path)
   x = data.iloc[:, :-1].values.astype(np.float32)   # 特征：除最后一列外的所有列
   y = data.iloc[:, -1].values.astype(np.int64)      # 标签：最后一列
   ```
   - `x` 的形状为 `(样本数, 特征数)`，类型为 `float32`。
   - `y` 的形状为 `(样本数,)`，类型为 `int64`（分类标签）。

2. **划分训练集和验证集**：
   ```python
   x_train, x_test, y_train, y_test = train_test_split(
       x, y, test_size=test_size, random_state=random_state, stratify=y
   )
   ```
   - 按照 `test_size=0.2` 划分，80%训练，20%验证。
   - `stratify=y`：按标签分层采样，确保训练集和验证集中各类别比例与原数据集一致（对不平衡分类问题很重要）。

3. **标准化**：
   ```python
   scaler = StandardScaler()
   x_train = scaler.fit_transform(x_train)   # 计算训练集的均值和标准差，并标准化训练集
   x_test = scaler.transform(x_test)         # 使用训练集的参数标准化验证集（避免信息泄露）
   ```
   - 标准化公式：`(x - mean) / std`，使每个特征均值为 0、方差为 1。
   - 注意：`fit_transform` 用于训练集，`transform` 仅用于验证集，保证验证集使用与训练集相同的变换参数。

3. **转换为 PyTorch 张量并封装为 `TensorDataset` **：
   ```python
   train_dataset = TensorDataset(torch.from_numpy(x_train), torch.from_numpy(y_train))
   test_dataset = TensorDataset(torch.from_numpy(x_test), torch.from_numpy(y_test))
   ```
   - `TensorDataset` 将特征和标签打包，后续 `DataLoader` 会从中按批次取出 `(x, y)` 对。

5. **返回信息**：
   ```python
   input_dim = x.shape[1]                 # 特征维度（列数）
   num_classes = len(np.unique(y))        # 类别数量（例如4个价格等级）
   return train_dataset, test_dataset, input_dim, num_classes
   ```

## 4. 模型定义 `PhonePriceModel`

```python
class PhonePriceModel(nn.Module):
    def __init__(self, input_dim, num_classes):
        super(PhonePriceModel, self).__init__()
        self.linear1 = nn.Linear(input_dim, 128)
        self.linear2 = nn.Linear(128, 256)
        self.linear3 = nn.Linear(256, num_classes)

    def forward(self, x):
        x = torch.relu(self.linear1(x))
        x = torch.relu(self.linear2(x))
        output = self.linear3(x)   # 注意：CrossEntropyLoss 内部自带 softmax
        return output
```

- 这是一个三层全连接网络（多层感知机）：
  - **第一层**：`input_dim` → 128，激活函数 ReLU。
  - **第二层**：128 → 256，激活函数 ReLU。
  - **第三层**：256 → `num_classes`（输出层，无激活函数）。
- 输出层没有 softmax，因为后面使用的损失函数 `CrossEntropyLoss` 内部会计算 log-softmax 和负对数似然（数学上等价于先 softmax 再计算交叉熵），更数值稳定。
- `forward` 定义了数据前向传播的过程。

## 5. 训练函数 `train`

```python
def train(train_dataset, input_dim, class_num):
    torch.manual_seed(0)   # 再次固定种子，确保模型初始化可重复
    dataloader = DataLoader(train_dataset, shuffle=True, batch_size=8)
    model = PhonePriceModel(input_dim, class_num)
    criterion = nn.CrossEntropyLoss()          # 多分类交叉熵损失
    optimizer = optim.SGD(model.parameters(), lr=1e-3)   # 随机梯度下降，学习率0.001
    num_epoch = 50
```

**训练循环**（`for epoch_idx in range(num_epoch):`）：
- 对于每个 epoch：
  - 记录开始时间 `start = time.time()`。
  - `total_loss` 和 `total_num` 用于累计该 epoch 的总损失和样本数，以便计算平均损失。
  - 遍历 `dataloader`：
    - `output = model(x)`：前向传播。
    - `loss = criterion(output, y)`：计算损失。
    - `optimizer.zero_grad()`：清空上一步的梯度。
    - `loss.backward()`：反向传播，计算梯度。
    - `optimizer.step()`：更新模型参数。
    - 累计损失和样本数。
  - 每个 epoch 结束后打印：epoch 编号、平均损失、耗时。
  - 最后保存模型参数到 `'model/phone.pth'`。

**注意**：
- 训练时模型设置为训练模式（默认是训练模式，无需显式调用 `model.train()`，但一般建议加上）。
- 每轮都保存模型文件（会覆盖），实际应用中可改为保存最佳模型（基于验证集准确率）。

## 6. 评估函数 `test`

```python
def test(test_dataset, input_dim, class_num, model_path='model/phone.pth'):
    model = PhonePriceModel(input_dim, class_num)
    model.load_state_dict(torch.load(model_path))   # 加载训练好的参数
    dataloader = DataLoader(test_dataset, shuffle=False, batch_size=8)
    correct = 0
    for x, y in dataloader:
        model.eval()            # 切换到评估模式（影响 dropout、batch norm 等，这里没有这些层，但习惯加上）
        output = model(x)
        y_pred = torch.argmax(output, dim=1)   # 取概率最大的类别索引
        correct += (y_pred == y).sum().item()
    print('Acc: %.5f' % (correct / len(test_dataset)))
```

- 加载已保存的模型参数。
- `model.eval()`：将模型设为评估模式，关闭 dropout 等训练专用层（虽然本模型没有，但好习惯）。
- 遍历测试集，计算预测正确的数量。
- 输出准确率：`correct / 总样本数`。

## 整体流程总结

1. **数据准备**：读取 CSV → 划分训练/验证集 → 标准化 → 转为 PyTorch 张量。
2. **模型构建**：三层全连接网络（输入→128→256→类别数）。
3. **训练**：使用 SGD 优化器，交叉熵损失函数，训练 50 个 epoch，每个 epoch 后打印平均损失，并保存模型。
4. **评估**：加载保存的模型，在验证集上计算分类准确率。

## 潜在改进点（供扩展理解）

- **过拟合预防**：可以增加 Dropout 层、正则化（如 weight decay）或早停机制。
- **学习率调度**：使用 `torch.optim.lr_scheduler` 动态调整学习率。
- **批次大小**：当前 `batch_size=8` 较小，可适当增大（如 32、64）提高训练稳定性。
- **优化器**：SGD 可能收敛慢，可尝试 Adam。
- **模型保存**：当前每个 epoch 都保存，可能浪费磁盘；应仅保存验证集上效果最好的模型。
- **评估时未关闭梯度计算**：虽然 `model.eval()` 已经固定了 batchnorm/dropout 行为，但为了节省内存和加速，通常还会用 `with torch.no_grad():` 包裹评估循环。
