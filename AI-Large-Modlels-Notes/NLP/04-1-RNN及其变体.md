# RNN 及其变体超详细笔记

## 第一部分：认识 RNN 模型

### 1.1 循环神经网络（RNN）的概念

循环神经网络（Recurrent Neural Network，简称 RNN）是一类以**序列数据**为输入，通过网络内部的结构设计有效捕捉序列之间关系特征的神经网络模型。与全连接网络或卷积网络不同，RNN 引入了**循环**机制：上一时间步的隐藏层输出会作为当前时间步隐藏层输入的一部分。正是这种循环，使得 RNN 能够处理任意长度的序列数据。

**为什么称为“循环”神经网络？**  
因为网络在处理序列时，会反复使用同一个隐藏层单元，将上一时刻的输出“循环”反馈到当前时刻的输入中。这种结构可以看作是对同一网络在时间轴上的多次展开（时间步展开）。

**RNN 的网络结构特点**（以单层 RNN 为例）：

- 由输入层、隐藏层、输出层组成。
- 每个时间步的输入有两个来源：当前时刻的数据端输入 $x_t$，以及上一时间步的隐藏层输出 $h_{t-1}$。
- 每个时间步的输出也有两个去向：当前时刻的数据端输出 $o_t$（通常后续接 softmax 或其他层），以及传递给下一时间步的隐藏状态 $h_t$。

下图描述了 RNN 的循环关系（文字描述）：

- 输入层接收序列的一个元素 $x_t$。
- 隐藏层结合 $x_t$ 和上一时刻的隐藏状态 $h_{t-1}$，通过激活函数（如 tanh）计算出当前隐藏状态 $h_t$。
- 输出层根据 $h_t$ 产生当前时刻的输出 $y_t$（可以是每个时间步都输出，也可以只在最后输出）。

---

### 1.2 RNN 的作用

RNN 非常适合处理具有**连续性**的序列数据，例如自然语言文本、语音信号、时间序列等。在自然语言处理领域，RNN 被广泛应用于文本分类、情感分析、意图识别、机器翻译等任务。

**意图识别示例（N vs 1 结构）**：

用户输入 “What time is it ?”，模型按时间步依次读取每个单词。

1. 首先将单词 “What” 输送给 RNN，产生第一个隐藏输出 $O_1$。
2. 接着输入 “time”，RNN 不仅利用 “time” 的信息，还使用上一层的隐藏输出 $O_1$ 作为输入，产生 $O_2$。
3. 重复此过程，直到处理完最后一个单词 “?”。
4. 最后，将最终的隐藏输出 $O_5$ 经过 softmax 层映射到预定义的 18 个意图类别上（如“查询时间”、“播放音乐”等），完成意图识别。

---

### 1.3 RNN 的分类

RNN 可以从两个角度进行分类：**输入和输出的结构**以及**内部构造**。

---

#### 1.3.1 按输入和输出的结构分类

| 类型 | 输入 | 输出 | 特点 | 应用场景 |
|------|------|------|------|----------|
| **N vs N** | 长度为 N 的序列 | 长度为 N 的序列 | 输入和输出序列等长 | 生成等长度的诗句、对联、词性标注 |
| **N vs 1** | 长度为 N 的序列 | 单个值（通常取最后一个隐层输出或所有隐层输出的聚合） | 输出是一个单独的值，需经过 sigmoid/softmax 处理 | 文本分类、情感分析、意图识别 |
| **1 vs N** | 单个值（可重复作为每个时间步的输入） | 长度为 N 的序列 | 输入一个值，该值作用于每次输出之上 | 图片生成文字（看图说话） |
| **N vs M**（Seq2Seq） | 长度为 N 的序列 | 长度不固定的序列 M | 编码器-解码器架构，中间语义张量 C | 机器翻译、阅读理解、文本摘要 |

---

#### 1.3.2 按内部构造分类

| 类型 | 全称 | 特点 |
|------|------|------|
| 传统 RNN | Recurrent Neural Network | 结构简单，但处理长序列时容易出现梯度消失/爆炸 |
| LSTM | Long Short-Term Memory | 引入门控机制，能有效捕捉长距离依赖 |
| GRU | Gated Recurrent Unit | LSTM 的简化变体，参数量更少，效果相近 |
| Bi‑RNN / Bi‑LSTM / Bi‑GRU | 双向循环网络 | 分别从前向和后向处理序列，将两个方向的结果拼接 |

---

| 概念 | 说明 |
|------|------|

| 按输入输出分类 | N vs N, N vs 1, 1 vs N, N vs M |
| 按内部构造分类 | 传统 RNN, LSTM, GRU, 双向变体 |

## 第二部分：传统 RNN 模型

### 2.1 RNN 内部结构分析

传统 RNN 的核心是一个循环单元，它在每个时间步执行相同的计算。聚焦于单个时间步，其输入有两个部分：

- 当前时间步的输入 $x_t$（向量形式，维度为 `input_size`）
- 上一时间步的隐藏状态 $h_{t-1}$（维度为 `hidden_size`）

这两个输入会在 RNN 单元内部进行**融合**：通常先将 $x_t$ 和 $h_{t-1}$ 拼接成一个更长的向量 $[x_t, h_{t-1}]$，然后通过一个全连接层（线性变换），再经过激活函数（通常是 `tanh`）得到当前时间步的隐藏状态 $h_t$。这个过程可以用数学公式表示为：

$$
h_t = \tanh \left( W_{ih} x_t + b_{ih} + W_{hh} h_{t-1} + b_{hh} \right)
$$

其中：

- $W_{ih}$ 是输入到隐藏层的权重矩阵，形状为 `(hidden_size, input_size)`
- $W_{hh}$ 是隐藏层到隐藏层的权重矩阵（循环权重），形状为 `(hidden_size, hidden_size)`
- $b_{ih}, b_{hh}$ 是偏置项

在 PyTorch 的 `nn.RNN` 实现中，上述公式被统一处理，并且可以选择 `tanh` 或 `relu` 作为激活函数。默认使用 `tanh`。

**激活函数 `tanh` 的作用**：将输出值压缩到 $[-1, 1]$ 区间，有助于维持数值稳定并引入非线性。它能够帮助调节流经网络的值，防止激活值过大或过小。

RNN 的时间步展开过程可以描述为：

- 初始时间步 $t=1$：输入 $x_1$，初始隐藏状态 $h_0$（通常为零向量），计算 $h_1$。
- 时间步 $t=2$：输入 $x_2$，使用上一时间步的 $h_1$，计算 $h_2$。
- 以此类推，直到序列结束。

每个时间步的输出 $o_t$ 通常直接取 $h_t$，也可以再通过一个线性层映射到目标维度。在 PyTorch 中，`nn.RNN` 默认返回每个时间步的隐藏状态作为输出。

---

### 2.2 PyTorch 中 RNN 的 API 详解

`torch.nn.RNN` 的构造函数主要参数如下：

| 参数 | 含义 | 默认值 | 说明 |
|------|------|--------|------|
| `input_size` | 输入 $x_t$ 的特征维度 | 必填 | 每个时间步输入的向量长度 |
| `hidden_size` | 隐藏状态 $h_t$ 的特征维度 | 必填 | 隐层向量的长度 |
| `num_layers` | RNN 层的数量（纵向堆叠） | 1 | 多层 RNN，每层接收上一层的隐藏输出作为输入 |
| `nonlinearity` | 激活函数 | `'tanh'` | 也可设为 `'relu'` |
| `bias` | 是否使用偏置 | `True` | 通常保留 |
| `batch_first` | 输入形状是否为 `(batch, seq, feature)` | `False`（默认是 `(seq, batch, feature)`） | 设为 `True` 更符合直觉 |
| `dropout` | 层间 dropout 概率 | 0 | 仅当 `num_layers > 1` 时有效 |
| `bidirectional` | 是否双向 | `False` | 双向时隐藏状态维度翻倍 |

**前向传播的输入与输出**：

- **输入**：
  - `input`：形状为 `(seq_len, batch, input_size)`（若 `batch_first=True` 则为 `(batch, seq_len, input_size)`）
  - `h_0`（可选）：初始隐藏状态，形状为 `(num_layers * num_directions, batch, hidden_size)`。如果不提供，默认为全零。

- **输出**：
  - `output`：所有时间步的**最后一层**隐藏状态，形状为 `(seq_len, batch, hidden_size * num_directions)`（若 `batch_first=True` 则 `(batch, seq_len, hidden_size * num_directions)`）
  - `h_n`：最后一个时间步的**每一层**隐藏状态，形状为 `(num_layers * num_directions, batch, hidden_size)`。

**重要结论**：

- 当 `num_layers = 1` 时，`output` 和 `h_n` 在数值上相同（但形状可能不同，`output` 包含所有时间步，`h_n` 只包含最后一个时间步）。
- 当 `num_layers > 1` 时，`output` 只包含**最后一层**在所有时间步的输出，而 `h_n` 包含**每一层**在最后一个时间步的输出。

---

### 2.3 API 代码示例与形状解析

#### 2.3.1 单层 RNN：单个样本、单个时间步

```python
import torch
import torch.nn as nn

# 模型参数：input_size=5, hidden_size=6, num_layers=1
rnn = nn.RNN(5, 6, 1)

# 输入：seq_len=1, batch=1, input_size=5
input = torch.randn(1, 1, 5)

# 初始隐藏状态：num_layers=1, batch=1, hidden_size=6
h0 = torch.randn(1, 1, 6)

output, hn = rnn(input, h0)
print("output shape:", output.shape)   # torch.Size([1, 1, 6])
print("hn shape:", hn.shape)           # torch.Size([1, 1, 6])
```

当 `num_layers=1` 且序列长度为 1 时，`output` 和 `hn` 数值相同（仅形状一致）。

---

#### 2.3.2 单层 RNN：单个样本、多个时间步

```python
# 输入：seq_len=11, batch=1, input_size=5
input = torch.randn(11, 1, 5)
h0 = torch.randn(1, 1, 6)

output, hn = rnn(input, h0)
print("output shape:", output.shape)   # torch.Size([11, 1, 6])
print("hn shape:", hn.shape)           # torch.Size([1, 1, 6])
```

此时 `output` 包含所有 11 个时间步的最后一层输出，`hn` 仅包含最后一个时间步的隐藏状态。

---

#### 2.3.3 单层 RNN：多个样本、多个时间步

```python
# 输入：seq_len=11, batch=3, input_size=5
input = torch.randn(11, 3, 5)
h0 = torch.randn(1, 3, 6)

output, hn = rnn(input, h0)
print("output shape:", output.shape)   # torch.Size([11, 3, 6])
print("hn shape:", hn.shape)           # torch.Size([1, 3, 6])
```

`batch` 维度独立处理，每个样本的序列互不影响。

---

#### 2.3.4 多层 RNN（`num_layers=2`）

```python
rnn = nn.RNN(5, 6, num_layers=2)
input = torch.randn(1, 3, 5)   # seq_len=1, batch=3
h0 = torch.randn(2, 3, 6)      # 2 层，每层初始隐藏状态

output, hn = rnn(input, h0)
print("output shape:", output.shape)   # torch.Size([1, 3, 6])  最后一层的输出
print("hn shape:", hn.shape)           # torch.Size([2, 3, 6])  每层最后时间步的隐藏状态
```

**重要结论**：

- `output` 仅包含**最后一层**在所有时间步的输出。
- `hn` 包含**每一层**在最后一个时间步的输出。对于多层 RNN，第一层的输出 $h_t^{(1)}$ 会作为第二层的输入，依此类推。

**图示理解**（文字描述）：

- 第 1 层：按时间步依次计算，输出序列 $h_1^{(1)}, h_2^{(1)}, ..., h_T^{(1)}$。
- 第 2 层：将第 1 层的输出序列作为输入，再按时间步计算，输出 $h_1^{(2)}, h_2^{(2)}, ..., h_T^{(2)}$。最终 `output` 即为这些 $h_t^{(2)}$ 的集合。
- `hn[0]` 是第 1 层最后一个时间步的隐藏状态，`hn[1]` 是第 2 层最后一个时间步的隐藏状态。

---

#### 2.3.5 关于 `batch_first` 和逐个时间步送数的讨论

- ** `batch_first=True` **：输入形状变为 `(batch, seq_len, input_size)`，输出形状变为 `(batch, seq_len, hidden_size)`。这在很多情况下更直观，但需注意 PyTorch 默认 `batch_first=False`。

- **逐个时间步送数 vs 一次送入**：PyTorch 的 RNN 支持一次传入整个序列，内部会自动循环遍历时间步。两种方式结果一致，但一次送入更高效（并行化）。以下代码演示了等价性：

```python
rnn = nn.RNN(5, 6, 1)
# 一次性送入
input_batch = torch.randn(3, 2, 5)   # seq=3, batch=2
h0 = torch.zeros(1, 2, 6)
out_batch, hn_batch = rnn(input_batch, h0)

# 逐个时间步送入
h = h0
for t in range(input_batch.shape[0]):
    x_t = input_batch[t].unsqueeze(0)   # (1, batch, 5)
    out_t, h = rnn(x_t, h)              # out_t shape: (1, batch, 6)
# out_t 的最后一个时间步应与 out_batch[-1] 一致
```

### 2.4 RNN 的优缺点

#### 2.4.1 优点

1. **内部结构简单**：只有简单的线性变换和 `tanh` 激活，参数量相对少。
2. **对计算资源要求低**：相比 LSTM/GRU，RNN 训练和推理速度更快，适合短序列任务。
3. **在短序列上性能优异**：对于几个到几十个时间步的序列，RNN 能够捕获依赖关系。

---

#### 2.4.2 缺点

1. **长序列特征提取效果差**：当序列长度超过一定范围（如 30–50），RNN 难以学习到远距离依赖。这是因为在反向传播中，梯度需要通过连乘的方式传递，导致远距离时间步的梯度指数级衰减（梯度消失）或增长（梯度爆炸）。
2. **梯度消失或爆炸**：在反向传播中，误差信号从第 $t$ 步传递到第 $1$ 步需要乘以若干次循环权重矩阵 $W_{hh}$。若 $W_{hh}$ 的特征值小于 1，则梯度呈指数衰减（梯度消失）；若大于 1，则指数增长（梯度爆炸）。`tanh` 激活函数并不能完全消除这个问题，因为其导数小于 1。梯度消失使得前部时间步的权重几乎不更新；梯度爆炸则导致参数值变得极大，产生 NaN。
3. **不可并行计算**：RNN 必须按时间步依次计算，无法像 Transformer 那样并行处理整个序列。

**梯度消失/爆炸的数学解释**：

在反向传播中，损失函数对 $h_1$ 的梯度包含因子 $\prod_{k=1}^{t-1} \frac{\partial h_{k+1}}{\partial h_k}$。每个因子包含 $W_{hh}^\top$ 乘以激活函数的导数。若激活函数导数的绝对值小于 1，且 $W_{hh}$ 的奇异值小于 1，则连乘结果指数衰减。

---

### 2.5 总结速查表（第二部分）

| 概念 | 说明 |
|------|------|
| RNN 内部计算 | $h_t = \tanh(W_{ih}x_t + b_{ih} + W_{hh}h_{t-1} + b_{hh})$ |
| 激活函数 | tanh（默认）或 ReLU，用于压缩值范围并引入非线性 |
| `nn.RNN` 核心参数 | `input_size`, `hidden_size`, `num_layers`, `batch_first` |
| 输入形状（默认） | `(seq_len, batch, input_size)` |
| 输出 `output` 形状 | `(seq_len, batch, hidden_size * num_directions)`，包含最后一层所有时间步 |
| 输出 `h_n` 形状 | `(num_layers * num_directions, batch, hidden_size)`，包含所有层最后时间步 |
| 优点 | 结构简单，计算快，短序列效果好 |
| 缺点 | 长序列梯度消失/爆炸，不可并行 |

**常见注意事项**：

- 当 `num_layers > 1` 时，`output` 并不包含中间层的隐藏状态，仅最后一层。
- 若未提供 `h0`，PyTorch 会自动初始化为全零。
- 对于可变长度序列，应使用 `pack_padded_sequence` 和 `pad_packed_sequence` 避免填充带来的计算浪费。
- 训练时若损失出现 NaN，很可能是梯度爆炸，可尝试梯度裁剪（`torch.nn.utils.clip_grad_norm_`）。

## 第三部分：LSTM 模型

### 3.1 LSTM 概述

**LSTM**（Long Short-Term Memory，长短时记忆网络）是传统 RNN 的一种重要变体，由 Hochreiter 和 Schmidhuber 在 1997 年提出。它被设计用来解决传统 RNN 在处理长序列时遇到的**梯度消失**和**梯度爆炸**问题。LSTM 通过引入**门控机制**和**细胞状态**（Cell State），使得网络能够选择性地记住或遗忘过去的信息，从而有效捕捉序列中的长距离依赖关系。

与经典 RNN 相比，LSTM 能够有效捕捉长序列之间的语义关联，缓解梯度消失或爆炸现象。因此，它在机器翻译、情感分析、语音识别等需要长期记忆的任务中表现优异。

---

### 3.2 LSTM 内部结构

与标准 RNN 只有一个隐藏状态 $h_t$ 不同，LSTM 在每个时间步维护两个内部状态：

- **细胞状态** $C_t$（Cell State）：负责长期记忆，信息沿着时间轴传递，只进行少量的线性操作。
- **隐藏状态** $h_t$（Hidden State）：负责短期记忆，用于输出和传递到下一时间步。

LSTM 单元内部包含三个门控结构和一个细胞状态更新，所有门控都使用 **sigmoid** 激活函数（输出范围 [0,1]），表示信息流过的比例。具体结构如下：

---

#### 3.2.1 遗忘门（Forget Gate）

遗忘门决定要从上一时刻的细胞状态 $C_{t-1}$ 中丢弃多少信息。它接收当前输入 $x_t$ 和上一时刻隐藏状态 $h_{t-1}$，输出一个 0~1 之间的向量 $f_t$，每个维度对应 $C_{t-1}$ 中一个元素的保留比例。

$$
f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)
$$

其中 $[h_{t-1}, x_t]$ 表示将两个向量拼接，$W_f$ 是权重矩阵，$b_f$ 是偏置。当 $f_t$ 接近 0 时，表示完全遗忘；接近 1 时，表示完全保留。

**作用**：遗忘门作用在上一个时间步细胞状态之上，表示对上一个时间步信息遗忘多少。

---

#### 3.2.2 输入门（Input Gate）

输入门决定当前时刻的新信息有多少要存入细胞状态。它由两部分组成：

- **门控信号** $i_t$：通过 sigmoid 函数计算，控制新信息的流入比例。
- **候选细胞状态** $\tilde{C}_t$：通过 tanh 激活函数计算，产生新的候选值（范围 -1~1），表示当前时间步的新知识。

$$
i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)
$$

$$
\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)
$$

**作用**：输入门作用在当前时间步的输入上，表示对当前时间步输入要使用多少（即记忆多少）。

---

#### 3.2.3 细胞状态更新（Cell State Update）

将遗忘门的输出与上一时刻细胞状态相乘（丢弃部分信息），加上输入门的输出与候选细胞状态相乘（添加新信息），得到更新后的细胞状态 $C_t$：

$$
C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t
$$

这里 $\odot$ 表示逐元素相乘（Hadamard 积）。通过这种线性组合，梯度可以沿着 $C_t$ 路径直接流动而不经过非线性激活，有效缓解梯度消失。

**作用**：细胞状态更新融合了遗忘门和输入门的结果，形成新的长期记忆。

---

#### 3.2.4 输出门（Output Gate）

输出门基于当前细胞状态决定隐藏状态 $h_t$ 的值。首先通过 sigmoid 计算一个门控信号 $o_t$，然后将细胞状态经过 tanh 缩放，再与门控信号相乘：

$$
o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)
$$

$$
h_t = o_t \odot \tanh(C_t)
$$

最终，当前时间步的输出可以直接取 $h_t$，或者再经过一个线性层映射到目标维度。

**作用**：输出门作用在内部细胞状态之上，表示对内部细胞状态要使用多少（即输出多少信息到隐藏状态）。

---

### 3.3 为什么 LSTM 能缓解梯度消失？

原因主要有两点：

1. **细胞状态的加法更新**：在 $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$ 中，对 $C_{t-1}$ 的系数 $f_t$ 是门控值（接近 1 时，梯度几乎直接传递），且右侧包含加法运算，反向传播时梯度可以沿两条路径传播，避免连乘导致的指数衰减。
2. **遗忘门的调节作用**：网络可以学习将遗忘门设为接近 1，从而长时间保留信息；或者设为接近 0 来丢弃无关信息，这相当于自适应地缩短或延长有效记忆长度，减少了不必要的梯度连乘。

然而，LSTM **并不能完全消除**梯度消失或爆炸，只是极大地减轻了长序列训练中的难度。对于超长序列（如数千步），仍然可能出现问题，此时需要结合梯度裁剪或使用 Transformer 等架构。

---

### 3.4 双向 LSTM（Bi‑LSTM）概述

**双向 LSTM**（Bi‑LSTM）不改变 LSTM 单元的内部结构，而是将同一个序列分别按正序和逆序输入两个独立的 LSTM 网络，然后将两个方向在每个时间步得到的隐藏状态进行拼接（或求和/平均），作为该时间步的最终输出。例如，对于句子“我爱中国”，从左到右 LSTM 处理一次，从右到左再处理一次，将两个方向的结果张量拼接作为最终输出。

这种结构能够同时利用**过去**和**未来**的上下文信息，在很多序列标注任务（如命名实体识别、词性标注）中效果显著提升，但模型参数和计算复杂度也随之增加一倍（因为需要两个独立的 LSTM 网络）。一般需要对语料和计算资源进行评估后决定是否使用该结构。

---

### 3.5 PyTorch 中 LSTM 的 API

`torch.nn.LSTM` 的使用方式与 `nn.RNN` 非常相似，主要区别在于 LSTM 除了隐藏状态 $h_t$，还需要维护细胞状态 $C_t$。构造函数参数与 `nn.RNN` 相同：

| 参数 | 含义 | 默认值 |
|------|------|--------|
| `input_size` | 输入特征维度 | 必填 |
| `hidden_size` | 隐藏状态/细胞状态的特征维度 | 必填 |
| `num_layers` | 堆叠的 LSTM 层数 | 1 |
| `bias` | 是否使用偏置 | True |
| `batch_first` | 是否将 batch 放在第一维 | False |
| `dropout` | 层间 dropout 概率（需 `num_layers>1`） | 0 |
| `bidirectional` | 是否双向 | False |

**前向传播**：

- **输入**：
  - `input`：形状 `(seq_len, batch, input_size)` 或 `(batch, seq_len, input_size)`（若 `batch_first=True`）
  - `(h_0, c_0)`（可选）：初始隐藏状态和细胞状态，每个形状为 `(num_layers * num_directions, batch, hidden_size)`。若不提供，默认为全零。
- **输出**：
  - `output`：所有时间步的最后一层隐藏状态（或双向拼接后的结果），形状 `(seq_len, batch, hidden_size * num_directions)`
  - `(h_n, c_n)`：最后一个时间步的每一层隐藏状态和细胞状态，形状均为 `(num_layers * num_directions, batch, hidden_size)`

---

### 3.6 API 代码示例

#### 3.6.1 单层 LSTM，单个样本

```python
import torch
import torch.nn as nn

lstm = nn.LSTM(input_size=5, hidden_size=6, num_layers=1)

# 输入：seq_len=1, batch=1, input_size=5
input = torch.randn(1, 1, 5)

# 初始状态：h0 和 c0 形状均为 (1,1,6)
h0 = torch.zeros(1, 1, 6)
c0 = torch.zeros(1, 1, 6)

output, (hn, cn) = lstm(input, (h0, c0))
print("output shape:", output.shape)   # (1,1,6)
print("hn shape:", hn.shape)           # (1,1,6)
print("cn shape:", cn.shape)           # (1,1,6)
```

---

#### 3.6.2 多层 LSTM，多个样本

```python
lstm = nn.LSTM(5, 6, num_layers=2)      # 2 层 LSTM
input = torch.randn(3, 2, 5)            # seq_len=3, batch=2
h0 = torch.zeros(2, 2, 6)              # 2 层，batch=2
c0 = torch.zeros(2, 2, 6)

output, (hn, cn) = lstm(input, (h0, c0))
print("output shape:", output.shape)   # (3,2,6)  最后一层所有时间步
print("hn shape:", hn.shape)           # (2,2,6)  每层最后时间步的隐藏状态
print("cn shape:", cn.shape)           # (2,2,6)  每层最后时间步的细胞状态
```

---

#### 3.6.3 双向 LSTM

```python
lstm = nn.LSTM(5, 6, num_layers=1, bidirectional=True)
input = torch.randn(3, 2, 5)
h0 = torch.zeros(2, 2, 6)      # 双向时 num_directions=2，故第一维为 2
c0 = torch.zeros(2, 2, 6)

output, (hn, cn) = lstm(input, (h0, c0))
print("output shape:", output.shape)   # (3,2,12)  因为 hidden_size*2 = 12
print("hn shape:", hn.shape)           # (2,2,6)   前向和后向的最后一层状态
print("cn shape:", cn.shape)           # (2,2,6)
```

**注意**：双向 LSTM 的 `hn` 包含两个方向（索引 0 为正向，索引 1 为反向），每个方向形状为 `(num_layers, batch, hidden_size)`。`output` 在每个时间步拼接了正向和反向的隐藏状态，因此最后一维是 `hidden_size * 2`。

---

#### 3.6.4 常见错误纠正

在编写 LSTM 代码时，一个常见的错误是调用方式不正确。正确方式应为：

```python
output, (hn, cn) = lstm(input, (h0, c0))
```

而错误写法是：

```python
output, hn, cn = lstm(input, h0, c0)   # 错误！LSTM 返回一个元组，第二个元素是 (hn, cn)
```

在提供的 PPT 中，有一道题目要求指出程序错误，正是此问题。

---

### 3.7 LSTM 的优缺点

#### 3.7.1 优点

- **有效缓解梯度消失/爆炸**：门控机制和细胞状态路径使得远距离信息更容易传递。
- **长序列处理能力强**：相比传统 RNN，LSTM 能够记忆数十到上百步的依赖。
- **灵活的记忆控制**：遗忘门、输入门、输出门可以自适应决定记忆哪些、丢弃哪些、输出哪些。

---

#### 3.7.2 缺点

- **结构复杂，计算量大**：每个时间步包含 4 个全连接层（三个门 + 一个候选状态），训练和推理速度比 RNN 慢 2~4 倍。
- **依然不能完全杜绝梯度问题**：对于极长序列（如数万字），LSTM 仍可能失效；此外，梯度爆炸仍需梯度裁剪处理。
- **不可并行**：同 RNN，必须按时间步顺序计算。
- **参数量较多**：约为普通 RNN 的 4 倍（每个门都有自己的权重矩阵）。

---

### 3.8 LSTM 门控单元对照速查表

| 门/状态 | 公式 | 作用 |
|---------|------|------|
| 遗忘门 $f_t$ | $\sigma(W_f[h_{t-1}, x_t]+b_f)$ | 决定从 $C_{t-1}$ 中丢弃多少信息 |
| 输入门 $i_t$ | $\sigma(W_i[h_{t-1}, x_t]+b_i)$ | 控制新信息流入细胞状态的比例 |
| 候选状态 $\tilde{C}_t$ | $\tanh(W_C[h_{t-1}, x_t]+b_C)$ | 生成当前时间步的候选记忆 |
| 细胞状态更新 | $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$ | 更新长期记忆 |
| 输出门 $o_t$ | $\sigma(W_o[h_{t-1}, x_t]+b_o)$ | 决定细胞状态的哪些部分输出到 $h_t$ |
| 隐藏状态 | $h_t = o_t \odot \tanh(C_t)$ | 当前时间步的输出（短期记忆） |

---

### 3.9 常见问题与调优建议

1. **是否总是使用 LSTM 而不是 RNN？**  
   对于短序列（如几个 token），RNN 足够且更快；对于中等长度（10–100），LSTM 或 GRU 更优；对于超长序列，考虑 Transformer 或稀疏注意力模型。

2. **LSTM 层数如何选择？**  
   通常 1–3 层已足够，更多层可能带来过拟合且训练变慢。对于复杂语言建模，可尝试 2 层。

3. **如何处理变长序列？**  
   使用 `torch.nn.utils.rnn.pack_padded_sequence` 和 `pad_packed_sequence` 避免填充位置的计算浪费。示例：

   ```python
   from torch.nn.utils.rnn import pack_padded_sequence, pad_packed_sequence
   # 假设 lengths 是每个样本的实际长度
   packed_input = pack_padded_sequence(input, lengths, batch_first=True, enforce_sorted=False)
   packed_output, (hn, cn) = lstm(packed_input)
   output, _ = pad_packed_sequence(packed_output, batch_first=True)
   ```

4. **梯度爆炸处理**：在反向传播前添加梯度裁剪：

   ```python
   torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
   ```

5. **Dropout 使用**：只在 `num_layers>1` 时有效，且仅作用于层间的输出，不会在时间步之间应用 dropout。若需要在时间步间使用，可考虑 `nn.Dropout` 手动添加。

6. **LSTM 中的“门控”单元类型**（常见选择题）：包括输入门（Input Gate）、遗忘门（Forget Gate）、输出门（Output Gate）。记忆门不是标准术语。

## 第四部分：GRU 模型

### 4.1 GRU 概述

**GRU**（Gated Recurrent Unit，门控循环单元）是另一种流行的 RNN 变体，由 Cho 等人于 2014 年提出。与 LSTM 一样，GRU 旨在解决传统 RNN 的梯度消失问题，并捕捉长距离依赖。相比 LSTM，GRU 将遗忘门和输入门合并为单一的**更新门**，并混合了细胞状态和隐藏状态，因此结构更简单，参数量更少，计算效率更高。

GRU 同 LSTM 一样，能够有效捕捉长序列之间的语义关联，缓解梯度消失或爆炸现象。同时，它的结构比 LSTM 简单，比传统 RNN 复杂，是一种折中的优秀选择。

---

### 4.2 GRU 内部结构

GRU 在每个时间步只维护一个隐藏状态 $h_t$（没有独立的细胞状态）。它包含两个门控单元：**更新门**（Update Gate）和**重置门**（Reset Gate）。

---

#### 4.2.1 更新门（Update Gate）

更新门 $z_t$ 决定当前时间步的隐藏状态 $h_t$ 有多少来自上一时间步的隐藏状态 $h_{t-1}$，有多少来自新的候选隐藏状态 $\tilde{h}_t$。它的计算公式与 LSTM 的门类似：

$$
z_t = \sigma(W_z \cdot [h_{t-1}, x_t] + b_z)
$$

其中 $[h_{t-1}, x_t]$ 表示将上一时间步隐藏状态与当前输入拼接。$z_t$ 的范围是 (0,1)。当 $z_t$ 接近 1 时，模型倾向于保留旧状态（即忽略新输入）；当 $z_t$ 接近 0 时，模型倾向于更新状态（使用新信息）。

**作用**：更新门控制着对上一时间步隐藏状态和当前候选隐藏状态的依赖比例。

---

#### 4.2.2 重置门（Reset Gate）

重置门 $r_t$ 决定上一时间步的隐藏状态 $h_{t-1}$ 中有多少信息需要被“重置”（即忽略），用于计算候选隐藏状态 $\tilde{h}_t$：

$$
r_t = \sigma(W_r \cdot [h_{t-1}, x_t] + b_r)
$$

**作用**：重置门决定了上一时间步信息有多少可以被利用（即需要遗忘多少）。

---

#### 4.2.3 候选隐藏状态（Candidate Hidden State）

候选隐藏状态 $\tilde{h}_t$ 的计算与传统 RNN 类似，但加入了重置门的控制：

$$
\tilde{h}_t = \tanh(W_h \cdot [r_t \odot h_{t-1}, x_t] + b_h)
$$

这里 $r_t \odot h_{t-1}$ 表示重置门逐元素乘以上一时间步的隐藏状态。如果 $r_t$ 接近 0，模型会忽略 $h_{t-1}$（相当于从零开始处理当前输入）；如果 $r_t$ 接近 1，模型会保留大部分历史信息。

**作用**：候选隐藏状态是对当前时间步新知识的提取，融合了重置门控制的历史信息。

---

#### 4.2.4 最终隐藏状态更新

最后，更新门 $z_t$ 在旧隐藏状态 $h_{t-1}$ 和候选隐藏状态 $\tilde{h}_t$ 之间进行加权组合，得到当前时间步的输出 $h_t$：

$$
h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t
$$

注意：这与 LSTM 中细胞状态的更新形式非常相似，只是将 $C_{t-1}$ 换成了 $h_{t-1}$，并且没有输出门。因此，GRU 直接将 $h_t$ 作为输出，并传递到下一时间步。

**解释**：

- $z_t \odot \tilde{h}_t$：对当前时间步要使用多少（记忆多少，依赖多少）。
- $(1 - z_t) \odot h_{t-1}$：对上一个时间步要使用多少（记忆多少，依赖多少）。
- 当 $z_t = 0$ 时，$h_t = h_{t-1}$，完全使用上一个隐藏层信息；当 $z_t = 1$ 时，$h_t = \tilde{h}_t$，完全使用本次隐藏层信息。

---

### 4.3 GRU vs LSTM 对比

| 特性 | LSTM | GRU |
|------|------|-----|
| 门控数量 | 3 个（遗忘门、输入门、输出门） | 2 个（更新门、重置门） |
| 内部状态 | 细胞状态 $C_t$ 和隐藏状态 $h_t$ | 仅隐藏状态 $h_t$ |
| 参数量 | 较多（约 GRU 的 1.5 倍） | 较少 |
| 计算速度 | 较慢 | 较快 |
| 表达能力 | 理论上更强（独立门控） | 相近，但在小数据上可能略差 |
| 适用场景 | 长序列、复杂任务 | 资源受限、中等长度序列 |

**经验法则**：GRU 和 LSTM 在多数任务上性能相近，GRU 训练更快，参数量更少；LSTM 在超长序列或需要精细记忆控制的任务中可能略优。实际中可先尝试 GRU，若效果不理想再换 LSTM。

---

### 4.4 双向 GRU（Bi‑GRU）概述

与 Bi‑LSTM 类似，**双向 GRU**（Bi‑GRU）不改变 GRU 单元内部结构，而是分别用正序和逆序处理序列，然后将两个方向的隐藏状态拼接。它能同时利用前后文信息，适用于需要双向上下文的序列标注任务，但模型参数和计算复杂度也随之增加一倍。

---

### 4.5 PyTorch 中 GRU 的 API

`torch.nn.GRU` 的构造函数参数与 `nn.RNN` 完全相同：

| 参数 | 含义 | 默认值 |
|------|------|--------|
| `input_size` | 输入特征维度 | 必填 |
| `hidden_size` | 隐藏状态维度 | 必填 |
| `num_layers` | GRU 层数 | 1 |
| `bias` | 是否使用偏置 | True |
| `batch_first` | 是否 batch 在第一维 | False |
| `dropout` | 层间 dropout 概率（`num_layers>1`） | 0 |
| `bidirectional` | 是否双向 | False |

**前向传播**：

- **输入**：
  - `input`：形状 `(seq_len, batch, input_size)` 或 `(batch, seq_len, input_size)`
  - `h_0`（可选）：初始隐藏状态，形状 `(num_layers * num_directions, batch, hidden_size)`
- **输出**：
  - `output`：所有时间步的最后一层隐藏状态，形状 `(seq_len, batch, hidden_size * num_directions)`
  - `h_n`：最后一个时间步的每一层隐藏状态，形状 `(num_layers * num_directions, batch, hidden_size)`

注意：GRU 没有细胞状态，因此只返回 `(output, h_n)`，而不是 LSTM 的三元组。

---

### 4.6 API 代码示例

#### 4.6.1 单层 GRU，单个样本

```python
import torch
import torch.nn as nn

gru = nn.GRU(input_size=5, hidden_size=6, num_layers=1)

input = torch.randn(1, 1, 5)   # seq_len=1, batch=1, input_size=5
h0 = torch.zeros(1, 1, 6)      # (num_layers, batch, hidden_size)

output, hn = gru(input, h0)
print("output shape:", output.shape)   # (1,1,6)
print("hn shape:", hn.shape)           # (1,1,6)  与 output 相同
```

#### 4.6.2 多层 GRU，多个样本

```python

print("output shape:", output.shape)   # (3,2,6)  最后一层所有时间步
print("hn shape:", hn.shape)           # (2,2,6)  每层最后时间步的隐藏状态
```

---

#### 4.6.3 双向 GRU

```python

print("hn shape:", hn.shape)           # (2,2,6)  正向和反向的最后状态
```

---

### 4.7 GRU 的优缺点

#### 4.7.1 优点

1. **结构比 LSTM 简单**：只有两个门，无独立的细胞状态，参数量减少约 1/3。
2. **训练速度更快**：由于计算量小，在同等算力下比 LSTM 快 20%-30%。
3. **同样能缓解梯度消失**：通过更新门和重置门控制信息流动，效果与 LSTM 接近。
4. **在中小规模数据上表现优异**：许多任务中 GRU 与 LSTM 性能相当，甚至更佳。

---

#### 4.7.2 缺点

1. **表达能力可能弱于 LSTM**：独立输出门缺失，可能对某些需要精细控制输出路径的任务不利。
2. **仍不可并行计算**：必须按时间步顺序处理。
3. **不能完全杜绝梯度消失**：对于极长序列，仍可能出现问题。

---

### 4.8 三种 RNN 模型对比总结

| 模型 | 门控数量 | 内部状态 | 参数量（相对 RNN） | 长序列能力 | 训练速度 | 适用场景 |
|------|----------|----------|--------------------|------------|----------|----------|
| 传统 RNN | 0 | $h_t$ | 1x | 弱 | 最快 | 短序列、简单任务 |
| LSTM | 3 | $C_t, h_t$ | 4x | 强 | 慢 | 长序列、复杂任务 |
| GRU | 2 | $h_t$ | 3x | 较强 | 中等 | 长短序列均可，资源受限 |

**选择建议**：

- 如果序列长度 < 20 且任务简单，传统 RNN 可能足够。
- 对于大多数 NLP 任务（文本分类、情感分析、机器翻译），优先尝试 GRU，因为速度快且效果接近 LSTM。
- 对于极长序列（如文档级别）或需要精细记忆控制的任务，使用 LSTM。
- 若需要同时利用前后文（如 NER、词性标注），采用双向版本（Bi‑LSTM 或 Bi‑GRU）。

---

### 4.9 常见问题与调优建议

1. **GRU 和 LSTM 的精度差异大吗？**  
   在大部分任务中，差异很小（< 1%）。可以用 GRU 快速验证，再用 LSTM 微调。

2. **GRU 的初始化重要吗？**  
   对于门控循环单元，初始 $h_0$ 通常全零即可。但也可尝试小随机数初始化，效果提升有限。

3. **如何防止过拟合？**  
   - 减小 `hidden_size` 或 `num_layers`。
   - 添加 dropout（仅层间，`num_layers>1`）。
   - 在输入到 GRU 之前添加 Dropout 层。
   - 使用权重衰减（L2 正则化）。

4. **梯度爆炸如何处理？**  
   同 LSTM，使用 `clip_grad_norm_`。GRU 也容易出现梯度爆炸，尤其当序列较长时。

5. **GRU 可以处理非常长的序列吗（如 1000+ 时间步）？**  
   理论上可以，但实践中可能仍需梯度裁剪或使用 Transformer。对于超长序列，考虑分段或使用稀疏注意力模型。

---

### 4.10 最终总结：RNN 系列模型速查表

| 模型 | 核心公式简记 | 输入形状（默认） | 输出形状（默认） | 主要应用 |
|------|-------------|-----------------|-----------------|----------|
| RNN | $h_t = \tanh(W_{ih}x_t + W_{hh}h_{t-1})$ | `(seq, batch, input)` | `(seq, batch, hidden)` | 短序列、简单分类 |
| LSTM | 遗忘门+输入门+更新细胞+输出门 | 同上 | `(seq, batch, hidden)` + 细胞状态 | 长序列、翻译、标注 |
| GRU | 更新门+重置门， $h_t = (1-z_t)h_{t-1} + z_t\tilde{h}_t$ | 同上 | `(seq, batch, hidden)` | 通用、资源受限 |

**PyTorch API 快速对比**：

```python
rnn  = nn.RNN( input_size, hidden_size, num_layers )
lstm = nn.LSTM( input_size, hidden_size, num_layers )
gru  = nn.GRU( input_size, hidden_size, num_layers )

# 前向传播
# RNN 和 GRU: output, hn = model(input, h0)
# LSTM: output, (hn, cn) = model(input, (h0, c0))
```

### 5.1 案例一：使用 LSTM 进行情感分类（IMDB 数据集）

#### 5.1.1 任务描述

IMDB 电影评论数据集包含 25000 条训练样本和 25000 条测试样本，每条评论被标记为正面（positive）或负面（negative）。我们将构建一个两层 LSTM 模型，对评论进行情感分类。

---

#### 5.1.2 实现步骤

1. 加载并预处理 IMDB 数据（使用 torchtext 或手动构建词汇表）。
2. 创建数据加载器（DataLoader），对文本序列进行填充和截断。
3. 定义 LSTM 分类模型：嵌入层 + 双层 LSTM + 全连接分类层。
4. 训练模型并评估准确率。

---

#### 5.1.3 完整代码

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, Dataset
from torch.nn.utils.rnn import pad_sequence
from collections import Counter
import re

# -------------------- 1. 数据预处理 --------------------
def load_imdb_data(file_path):
    """读取 IMDB 数据文件，返回 (文本列表, 标签列表)"""
    texts, labels = [], []
    with open(file_path, 'r', encoding='utf-8') as f:
        for line in f:
            # 格式：标签 文本（标签已转换为 _label_1 或 _label_0，此处简化处理）
            # 实际 IMDB 原始数据需调整，此处模拟数据格式：label score text
            parts = line.strip().split(' ', 1)
            if len(parts) < 2:
                continue
            label = int(parts[0])
            text = parts[1].lower()
            # 移除标点符号（简单处理）
            text = re.sub(r'[^\w\s]', '', text)
            texts.append(text)
            labels.append(label)
    return texts, labels

# 为了示例可运行，我们使用少量模拟数据（实际应用请下载真实 IMDB 数据集）
# 此处创建模拟数据用于演示完整流程
sample_texts = [
    "this movie is great and wonderful",
    "i hate this film so boring",
    "amazing acting and beautiful story",
    "terrible waste of time",
    "love it highly recommend"
]
sample_labels = [1, 0, 1, 0, 1]

# 构建词汇表
def build_vocab(texts, min_freq=1):
    counter = Counter()
    for text in texts:
        words = text.split()
        counter.update(words)
    # 保留出现次数 >= min_freq 的词
    vocab = {'<PAD>': 0, '<UNK>': 1}
    for word, freq in counter.items():
        if freq >= min_freq:
            vocab[word] = len(vocab)
    return vocab

vocab = build_vocab(sample_texts, min_freq=1)
vocab_size = len(vocab)

# 文本转向量
def text_to_tensor(text, vocab, max_len=50):
    words = text.split()[:max_len]
    indices = [vocab.get(w, vocab['<UNK>']) for w in words]
    # 填充到 max_len
    if len(indices) < max_len:
        indices += [vocab['<PAD>']] * (max_len - len(indices))
    return torch.tensor(indices, dtype=torch.long)

class IMDBDataset(Dataset):
    def __init__(self, texts, labels, vocab, max_len=50):
        self.texts = texts
        self.labels = labels
        self.vocab = vocab
        self.max_len = max_len

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, idx):
        text = self.texts[idx]
        label = self.labels[idx]
        input_ids = text_to_tensor(text, self.vocab, self.max_len)
        return input_ids, torch.tensor(label, dtype=torch.long)

# 创建 DataLoader
train_dataset = IMDBDataset(sample_texts, sample_labels, vocab, max_len=20)
train_loader = DataLoader(train_dataset, batch_size=2, shuffle=True)

# -------------------- 2. 定义 LSTM 分类模型 --------------------
class LSTMSentimentClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_layers, num_classes, dropout=0.5):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, num_layers, batch_first=True, dropout=dropout)
        self.fc = nn.Linear(hidden_dim, num_classes)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        # x: (batch, seq_len)
        emb = self.embedding(x)                # (batch, seq_len, embed_dim)
        lstm_out, (hn, cn) = self.lstm(emb)    # lstm_out: (batch, seq_len, hidden_dim)
        # 取最后一个时间步的输出
        last_output = lstm_out[:, -1, :]       # (batch, hidden_dim)
        last_output = self.dropout(last_output)
        logits = self.fc(last_output)          # (batch, num_classes)
        return logits

# 超参数
embed_dim = 64
hidden_dim = 128
num_layers = 2
num_classes = 2
learning_rate = 0.001
epochs = 10

model = LSTMSentimentClassifier(vocab_size, embed_dim, hidden_dim, num_layers, num_classes)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=learning_rate)

# -------------------- 3. 训练循环 --------------------
for epoch in range(epochs):
    model.train()
    total_loss = 0
    for batch_inputs, batch_labels in train_loader:
        optimizer.zero_grad()
        outputs = model(batch_inputs)
        loss = criterion(outputs, batch_labels)
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
    print(f'Epoch {epoch+1}, Loss: {total_loss/len(train_loader):.4f}')

# 简单评估（训练集上）
model.eval()
correct = 0
total = 0
with torch.no_grad():
    for inputs, labels in train_loader:
        outputs = model(inputs)
        preds = torch.argmax(outputs, dim=1)
        correct += (preds == labels).sum().item()
        total += labels.size(0)
print(f'Training Accuracy: {correct/total:.4f}')
```

**说明**：

- 实际使用 IMDB 完整数据集时，可借助 `torchtext.datasets.IMDB` 或从文件读取。
- 模型使用最后一个时间步的输出进行分类。也可采用所有时间步输出的池化（如平均池化或最大池化）。
- 嵌入层的 `padding_idx=0` 可使填充位置的梯度始终为零。

### 5.2 案例二：使用 Bi‑LSTM + CRF 进行命名实体识别（NER）

#### 5.2.1 任务描述

命名实体识别要求为文本序列中的每个 token 分配一个标签（如 B-PER、I-PER、O 等）。我们将构建一个双向 LSTM 模型，并在输出层后接一个条件随机场（CRF）层，以捕捉标签之间的转移约束。

---

#### 5.2.2 实现步骤

1. 准备 CoNLL-2003 格式的 NER 数据（每行为“词 标签”，空行分隔句子）。
2. 构建词汇表和标签映射。
3. 定义 Bi‑LSTM + CRF 模型。
4. 训练模型，使用 CRF 的负对数似然损失。
5. 评估模型的 F1 分数。

---

#### 5.2.3 安装依赖

需要安装 `pytorch-crf` 库：

```bash
pip install pytorch-crf
```

---

#### 5.2.4 完整代码（简化版，使用模拟数据）

```python
import torch
import torch.nn as nn
from torchcrf import CRF
from torch.utils.data import Dataset, DataLoader

# -------------------- 1. 模拟数据 --------------------
# 句子（已分词）
sentences = [
    ['我', '爱', '北京', '天安门'],
    ['苹果', '公司', '发布', '新', '手机']
]
# 对应的 NER 标签（BIO 体系）
labels = [
    ['O', 'O', 'B-LOC', 'I-LOC'],
    ['B-ORG', 'I-ORG', 'O', 'O', 'O']
]

# 构建词汇表和标签映射
word2idx = {'<PAD>': 0, '<UNK>': 1}
tag2idx = {'O': 0, 'B-LOC': 1, 'I-LOC': 2, 'B-ORG': 3, 'I-ORG': 4}
idx2tag = {v: k for k, v in tag2idx.items()}

for sent in sentences:
    for word in sent:
        if word not in word2idx:
            word2idx[word] = len(word2idx)

class NERDataset(Dataset):
    def __init__(self, sentences, labels, word2idx, tag2idx):
        self.sentences = sentences
        self.labels = labels
        self.word2idx = word2idx
        self.tag2idx = tag2idx

    def __len__(self):
        return len(self.sentences)

    def __getitem__(self, idx):
        sent = self.sentences[idx]
        tag_seq = self.labels[idx]
        word_ids = [self.word2idx.get(w, self.word2idx['<UNK>']) for w in sent]
        tag_ids = [self.tag2idx[t] for t in tag_seq]
        return torch.tensor(word_ids, dtype=torch.long), torch.tensor(tag_ids, dtype=torch.long)

# 由于句子长度不同，需要填充（使用 collate_fn）
def collate_fn(batch):
    word_ids_list, tag_ids_list = zip(*batch)
    # 填充序列
    word_ids_padded = nn.utils.rnn.pad_sequence(word_ids_list, batch_first=True, padding_value=0)
    tag_ids_padded = nn.utils.rnn.pad_sequence(tag_ids_list, batch_first=True, padding_value=0)
    # 创建掩码（非填充位置为 True）
    mask = (word_ids_padded != 0)
    return word_ids_padded, tag_ids_padded, mask

dataset = NERDataset(sentences, labels, word2idx, tag2idx)
loader = DataLoader(dataset, batch_size=2, collate_fn=collate_fn)

# -------------------- 2. 定义 Bi-LSTM + CRF 模型 --------------------
class BiLSTM_CRF(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_tags, pad_idx=0):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=pad_idx)
        self.lstm = nn.LSTM(embed_dim, hidden_dim // 2, num_layers=1, batch_first=True, bidirectional=True)
        self.hidden2tag = nn.Linear(hidden_dim, num_tags)
        self.crf = CRF(num_tags, batch_first=True)

    def forward(self, x, tags=None, mask=None):
        # x: (batch, seq_len)
        embeds = self.embedding(x)               # (batch, seq_len, embed_dim)
        lstm_out, _ = self.lstm(embeds)          # (batch, seq_len, hidden_dim)
        emissions = self.hidden2tag(lstm_out)    # (batch, seq_len, num_tags)
        if tags is not None:
            # 训练：计算负对数似然损失
            loss = -self.crf(emissions, tags, mask=mask, reduction='mean')
            return loss
        else:
            # 预测：Viterbi 解码
            return self.crf.decode(emissions, mask=mask)

# 超参数
vocab_size = len(word2idx)
embed_dim = 16
hidden_dim = 32
num_tags = len(tag2idx)

model = BiLSTM_CRF(vocab_size, embed_dim, hidden_dim, num_tags)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# -------------------- 3. 训练 --------------------
for epoch in range(20):
    model.train()
    total_loss = 0
    for x, y, mask in loader:
        optimizer.zero_grad()
        loss = model(x, tags=y, mask=mask)
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
    print(f'Epoch {epoch+1}, Loss: {total_loss/len(loader):.4f}')

# -------------------- 4. 预测示例 --------------------
model.eval()
with torch.no_grad():
    for x, y, mask in loader:
        pred_tags = model(x, mask=mask)
        print("预测结果（标签ID）:", pred_tags)
        # 将标签ID转换为标签名称
        for i, seq in enumerate(pred_tags):
            print(f"句子 {i}: {[idx2tag[t] for t in seq if t != 0]}")
        break
```

**关键点说明**：

- CRF 层能够学习标签之间的转移概率（例如 I-LOC 不能出现在 B-LOC 之前），从而得到全局最优的标签序列。
- 训练时 CRF 计算负对数似然损失；预测时使用维特比算法解码。
- 掩码（mask）用于忽略填充位置，避免它们影响 CRF 的计算。

### 5.3 实战总结与扩展建议

| 案例 | 模型 | 核心技术 | 适用任务 |
|------|------|----------|----------|
| 情感分类 | LSTM | 嵌入层 + LSTM + 全连接 | 文本分类、情感分析、意图识别 |
| 命名实体识别 | Bi-LSTM + CRF | 双向 LSTM + 条件随机场 | 序列标注（NER、POS、Chunking） |

**扩展方向**：

- 使用预训练词向量（如 GloVe、FastText）替换随机初始化的嵌入层。
- 增加注意力机制（Attention），使模型关注重要时间步。
- 使用更大的数据集（如 CoNLL-2003 英文 NER 数据集）训练更鲁棒的模型。
- 将 LSTM 替换为 GRU，对比训练速度和精度。
