为什么需要 Transformer？

在 Transformer 出现之前，处理语言的主流方案是 RNN（循环神经网络）和它的改进版 LSTM。它们能工作，但有一个结构性缺陷：顺序处理，无法并行。

📖 想象你在翻译一句话

「我昨天在公园里看到的那只非常可爱的橘猫正在追一只蝴蝶。」

要理解"追"的主语是"橘猫"不是"蝴蝶"，你需要同时把握整句话的结构。但 RNN 像一个只能逐字阅读的人 —— 读到句末时，句首信息已经模糊。这就像传话游戏：信息传递越远，失真越严重。

核心突破

Transformer 摒弃了逐字阅读，让每个词都能直接"看到"句子里的所有其他词。这就是 Self-Attention（自注意力机制）—— Transformer 的灵魂。而且，因为所有词同时处理，它可以充分利用 GPU 的并行计算能力，训练出千亿参数级别的超大模型。

第一步：把文字变成数字

计算机不理解「猫」这个汉字，它只理解数字。所以 Transformer 的第一件事，就是把每个词映射到一个高维向量—— 一串有意义的数字。

🗺️ 想象给每个词一张"身份地图"

把每个词想象成一个城市。城市之间距离越近，语义越相似。「国王」和「王后」很近，「国王」和「披萨」很远。Embedding 层就是把词放到这样一张多维地图上，让语义相近的词靠在一起。

词向量语义空间
悬停文字查看语义关系

这是 128 维词向量压缩到 2D 的投影。语义相近的词自然会聚在一起。

Transformer 使用的 embedding 维度通常是 512（基础版）或 768（BERT-base）。每一个维度捕捉了词的某种抽象属性 —— 比如性别、时态、情感色彩等 —— 虽然我们无法直接解释每个维度，但模型通过训练学会了如何利用它们。

Self-Attention：让每个词"看到"所有词

这是 Transformer 最核心的创新。Self-Attention 计算句子中每对词之间的相关性，让每个词都能从所有其他词那里收集信息。

🔍 想象你在图书馆查资料

你想搞懂「苹果」在文章里是什么意思。你会快速扫视周围的词 —— 看到「iPhone」「库克」就判断是苹果公司；看到「香蕉」「果园」就知道是水果。Self-Attention 做的就是这件事：每个词扫视所有其他词，根据相关性决定关注谁。

注意力的计算可以概括为：越相似的词，注意力分数越高。而「相似度」通过向量点积来衡量 —— 这就是下一节 Q、K、V 的作用。

Q、K、V：注意力的三个角色

Transformer 用三个可学习的线性变换为每个词生成三个向量：Query（查询）、Key（键）、Value（值）。它们共同完成一次注意力计算。

🍽️ 想象你在餐厅点菜

Query = 你的需求：「我想吃辣的、肉类的、预算 50 元以内的」

Key = 菜单标签：每道菜的属性标签 ——「麻辣」「清淡」「牛肉」「甜品」

Value = 菜本身：实际提供的内容。你最终享用的是菜的 Value，而选择依据是 Query 和 Key 的匹配度。

Q · K = 两个向量在每个维度上的乘积之和。正值表示方向相似（相关），负值表示方向相反（不相关），接近零表示正交（无关）。
Attention(Q, K, V) = softmax(QKT / √dk) · V
为什么要除以 √dk？

点积结果会随着向量维度增大而增大。当 dk = 64 时，Q·K 的取值范围可能达到几十甚至上百，经过 Softmax 后会趋近于 0 或 1（丧失区分度）。除以 √dk（约 8）将数值拉回合理范围，让梯度能正常流动。这被称为 Scaled Dot-Product Attention。

多头注意力：多个"视角"同时理解

一组 Q/K/V 只能学到一种关系模式。但语言包含多种关系：主谓搭配、代词指代、修饰关系、因果逻辑…… 怎么办？同时用多组注意力，每组关注不同模式。

为什么用多头？

单头注意力可能会把多个不相关的关系「平均」在一起，导致信息模糊。多头让每个头专门化：一个头专门找主语-谓语关系，另一个头专门找代词指代，再一个头专门看位置相邻关系。

效率很关键

每个头的维度 = 模型维度 ÷ 头数。比如模型维度 512、8 个头，每个头维度是 64。总计算量和单头差不多，但捕捉到的模式丰富得多。原始论文使用了 8 个注意力头。

位置编码：让模型知道词序

Self-Attention 把所有词当作无序集合—— 它看不到「猫吃鱼」和「鱼吃猫」的区别。但语言中，词序显然很重要。解决方案：给每个词加上一个位置信号。

正弦位置编码的巧妙之处

Transformer 使用不同频率的正弦/余弦函数来编码位置：偶数维度用正弦，奇数维度用余弦。高频维度能区分相邻位置（位置 3 和位置 4），低频维度能区分远距离位置（位置 3 和位置 50）。所有维度组合起来，每个位置就有了独一无二的指纹，而且模型可以通过简单的线性变换推断两个位置之间的距离 —— 这是正弦函数的内在属性。

现代变体

GPT 系列只用 Decoder（自回归生成，预测下一个词），BERT 只用 Encoder（双向理解，做分类/问答），T5 用完整 Encoder-Decoder（翻译/摘要）。架构可按任务灵活裁剪 —— 这也是 Transformer 强大的原因之一。

Feed-Forward、残差连接 与 Layer Normalization

注意力之后，每个词还要经过一个前馈网络（FFN）。而架构图中反复出现的「Add & Layer Norm」是保证深层网络能稳定训练的关键。

Feed-Forward Network

FFN 是一个对每个位置独立应用的两层全连接网络：

FFN(x) = W2 · GeLU(W1 · x + b1) + b2

第一层将维度从 dmodel(512) 扩展到 dff(2048)，经过 GeLU 激活函数，再压缩回 512 维。这种 扩展-压缩 结构让网络能学习更复杂的特征变换。

残差连接

每个子层的输出不是直接传递，而是 输入 + 子层输出：

output = LayerNorm(x + Sublayer(x))

这就像在原文基础上修改，而非丢掉重写。它为梯度提供了一条高速公路，让深层网络也能有效训练。

Layer Normalization

对单个样本的所有特征做归一化（均值=0，方差=1），然后通过可学习的缩放/偏移参数调整。相比 Batch Norm（对一批样本的同一特征归一化），Layer Norm 不依赖 batch size，更稳定，特别适合序列长度不固定的 NLP 任务。

训练 vs 推理：两种工作模式

Transformer 在训练和推理（实际使用）时的工作方式有本质区别。理解这个区别，才能真正理解 ChatGPT 等模型是怎么工作的。

下一个 Token 预测模拟
输入上文，模型预测最可能的下一个词（可链式预测）
多样性（Temperature） 0.8 低=确定 高=随机

训练阶段

使用 Teacher Forcing：给模型看完整的输入和输出序列，它尝试预测每个位置的下一个词。因为知道了正确答案，可以并行计算所有位置的预测。损失函数是比较预测和真实下一个词的差距（交叉熵）。

Decoder 中的 Masked Attention 确保预测位置 i 时只能看到位置 1 到 i-1，不能「偷看」未来。

推理阶段（自回归生成）

模型逐词生成：先输出第一个词，然后把这个词追加到输入中，再预测下一个词……重复直到输出结束符或达到最大长度。这个过程是串行的（每步依赖前一步的结果），所以推理比训练慢得多。

这就是为什么 ChatGPT 是一个字一个字吐出来的 —— 它在做自回归生成。

Transformer 如何改变了 AI 世界

2017

「Attention Is All You Need」

Google Brain 团队发表 Transformer 论文，最初用于机器翻译，在 BLEU 分数和训练速度上全面超越当时的 SOTA。

2018

BERT

Google 发布 BERT，用 Transformer Encoder 做双向文本理解。在 11 项 NLP 任务上刷新纪录，引发 NLP 领域的范式转变。

2019-2020

GPT-2 → GPT-3

OpenAI 展示了大模型的涌现能力。GPT-3 的 1750 亿参数展示了少样本学习（few-shot learning）—— 仅凭几个示例就能完成新任务。

2020

Vision Transformer (ViT)

Transformer 进入计算机视觉。把图片切成 16×16 的小块当作「词」，在 ImageNet 上达到与 CNN 相当的效果。

2022-2024

ChatGPT & 多模态

基于 Transformer Decoder 的大语言模型走向大众。GPT-4、Claude 等多模态模型能同时理解文字和图像。Stable Diffusion 中的 U-Net 也采用了 Transformer 块。

ChatGPT、Claude、文心一言 —— 所有大语言模型的核心架构
