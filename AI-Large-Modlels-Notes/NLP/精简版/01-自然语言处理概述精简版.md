# 自然语言处理概述（核心精简版）

## 一、NLP 核心概念

### 1.1 定义

- **NLP**：计算机科学、人工智能与语言学交叉领域，目标是让计算机**理解并生成人类语言**。
- 核心难点：语言的**歧义性**和**上下文依赖**。

### 1.2 两大子领域

| 子领域 | 全称 | 任务 | 典型应用 |
|--------|------|------|----------|
| **NLU** | 自然语言理解 | 从文本/语音中提取意义 | 问答、意图识别、情感分析 |
| **NLG** | 自然语言生成 | 从数据/意义生成自然语言 | 机器翻译、对话回复、摘要 |

### 1.3 常见技术任务

- 语音识别 / 合成
- 机器翻译
- 文本分类 / 情感分析
- 信息抽取（实体、关系）
- 问答系统

### 1.4 典型应用

- 智能客服、搜索引擎、智能家居、语音助手、身份认证（多模态）

## 二、NLP 发展简史（关键阶段）

| 时期 | 主导方法 | 代表工作 | 特点 |
|------|----------|----------|------|
| **1950–1980** | 基于规则（符号主义） | 乔治敦机器翻译、乔姆斯基生成语法 | 小规模有效，难移植，维护成本高 |
| **1980–2013** | 基于统计（经验主义） | HMM 词性标注、IBM 翻译模型、CRF、SVM | 依赖大规模语料，可迁移，概率建模 |
| **2013–2017** | 深度学习前期 | Word2Vec、Seq2Seq、注意力机制 | 词向量、RNN/LSTM、神经机器翻译 |
| **2017–今** | 预训练大模型 | Transformer、BERT、GPT 系列 | 自注意力、预训练+微调、涌现能力 |

### 里程碑事件

- **1950**：图灵测试 → 确立语言智能为 AI 核心目标
- **2013**：Word2Vec → 词向量成为标准输入
- **2017**：Transformer → 彻底改变序列建模
- **2018**：BERT → 开启预训练+微调范式
- **2020**：GPT-3 → 少样本上下文学习
- **2022**：ChatGPT → 大模型对话引爆应用

## 三、关键技术要点

### 3.1 基于规则 vs 基于统计

| 维度 | 基于规则 | 基于统计 |
|------|----------|----------|
| 知识来源 | 语言学家编写 | 从语料学习 |
| 可解释性 | 强 | 弱 |
| 领域迁移 | 困难 | 相对容易 |
| 鲁棒性 | 差 | 好 |
| 数据需求 | 低 | 高 |

### 3.2 统计方法核心模型

- **HMM**（隐马尔可夫模型）：生成式，用于词性标注。假设一阶马尔可夫和观测独立。
- **CRF**（条件随机场）：判别式，允许任意特征函数，序列标注更优。
- **IBM 模型**：统计机器翻译的词对齐基础。

### 3.3 深度学习方法

- **Word2Vec**（CBOW / Skip-gram）：将词映射为稠密向量，语义相似词距离近。
- **RNN / LSTM**：处理序列，Seq2Seq + 注意力成为神经机器翻译标准。
- **Transformer**：完全基于自注意力，并行训练，建模长距离依赖。

### 3.4 预训练大模型

- **BERT**：Encoder only，MLM + NSP，适合 NLU。
- **GPT**：Decoder only，自回归语言模型，适合 NLG。
- **核心范式**：海量无监督预训练 → 下游任务微调 / 提示学习

## 四、典型应用场景（NLP 角色）

| 应用 | NLP 技术 | 说明 |
|------|----------|------|
| **语音助手** | ASR + NLU + DM + NLG + TTS | 意图识别、槽位填充、对话管理 |
| **机器翻译** | Transformer 编码器-解码器 | 条件语言模型，评价指标 BLEU |
| **搜索引擎** | 查询理解、语义向量、相关性排序 | BM25、BERT-based 检索、ANN |
| **智能问答** | 抽取式 QA（BERT 指针）、生成式 QA（RAG） | SQuAD 数据集，答案片段抽取 |
| **情感分析** | 文本分类 | 输出情感极性（正/负/中） |
| **文本摘要** | 抽取式（TextRank）或生成式（BART） | ROUGE 评价 |
| **信息抽取** | 序列标注（BiLSTM-CRF，BERT） | 实体、关系、事件抽取 |

### 多模态案例：雄安新区身份认证

- 融合：文字生成（随机数字） + 语音识别 + 人脸识别 + 姿态表情
- NLP 作用：语音指令理解、动态挑战响应

## 五、挑战与未来方向

### 主要挑战

- 数据稀缺（低资源语言、专业领域）
- 可解释性差
- 缺乏常识推理和因果理解（幻觉问题）
- 多语言、多模态融合
- 伦理与安全（偏见、有害生成）

### 未来趋势

- 更大更强的预训练模型（更长上下文、多模态）
- 高效微调（LoRA, QLoRA）与边缘部署
- 检索增强生成（RAG）减少幻觉
- 自主智能体（Agent）：LLM + 工具调用 + 规划
- 人机协作增强而非替代
