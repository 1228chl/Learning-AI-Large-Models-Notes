# Bert 系列模型（核心精简版）

## 一、BERT

### 1.1 概述

- **全称**：Bidirectional Encoder Representations from Transformers  
- **提出**：Google，2018 年 10 月  
- **架构**：多层 **Transformer Encoder**（无 Decoder）  
- **核心**：深度双向上下文表示，预训练 + 微调范式

### 1.2 输入表示（三种嵌入相加）

- **Token Embedding**：WordPiece 分词，`[CLS]` 用于分类，`[SEP]` 分隔句子  
- **Segment Embedding**：区分句子 A（0）和 B（1）  
- **Position Embedding**：可学习位置编码（不同于 Transformer 的固定正弦）

**最终输入** = token_emb + segment_emb + position_emb，再经过 LayerNorm 和 Dropout。

### 1.3 架构参数（BERT-base）

- 层数：12  
- 隐藏维度：768  
- 注意力头数：12  
- 参数量：约 1.1 亿

### 1.4 预训练任务

1. **MLM（掩码语言模型）**  
   - 随机掩码 15%的 token  
   - 其中 80%替换为 `[MASK]`，10%随机词，10%不变  
   - 目的：学习双向语义 + 纠错能力，缓解预训练-微调差异  
2. **NSP（下一句预测）**  
   - 50%真实下一句（IsNext），50%随机句子（NotNext）  
   - 使用 `[CLS]` 输出做二分类  
   - 目的：理解句子间关系

**总损失** = MLM 损失 + NSP 损失

### 1.5 下游任务微调（四种典型）

| 任务类型 | 微调方式 |
|----------|----------|
| 句子对分类（如 NLI） | `[CLS]` 输出 + 分类层 |
| 单文本分类 | `[CLS]` 输出 + 分类层 |
| 问答（SQuAD） | 编码器输出上接两个线性层，预测答案起始和结束位置 |
| 序列标注（NER） | 每个 token 的输出 + 分类层 |

### 1.6 优势与局限

| 优势 | 局限 |
|------|------|
| 深度双向，理解能力强 | 模型庞大，推理成本高 |
| 统一架构，适配多种 NLU 任务 | 不适合生成任务（无 Decoder） |
| 迁移学习友好，少量微调即 SOTA | `[MASK]` 导致预训练-微调不一致 |
| 在 GLUE、SQuAD 上刷新纪录 | 最大输入长度 512 |

### 1.7 评估基准

- **GLUE**：英文通用语言理解（9 项任务）  
- **CLUE**：中文语言理解基准

## 二、ELMo

### 2.1 概述

- **全称**：Embeddings from Language Models  
- **提出**：华盛顿大学，2018 年 3 月  
- **贡献**：首个**动态词向量**模型，解决一词多义  
- **架构**：**双向双层 LSTM**（前向+后向分开训练，最后拼接）

### 2.2 输入表示

- **字符级 CNN**（CharCNN）：可处理 OOV，利用词形态信息

### 2.3 架构

- 底层：CharCNN → 静态词向量  
- 中间：前向 LSTM（2 层）+ 后向 LSTM（2 层）  
- 顶层：各层表示加权求和（权重任务相关）

### 2.4 预训练任务

- **双向语言模型**：前向 LM 损失 + 后向 LM 损失（独立优化，无参数共享）

### 2.5 优缺点

| 优点 | 缺点 |
|------|------|
| 上下文动态词向量 | 特征提取器 LSTM 弱于 Transformer |
| 字符级 CNN 处理 OOV | 双向仅拼接，非深度融合 |
| 模型轻量 | 被 BERT 全面超越 |

## 三、GPT

### 3.1 概述

- **全称**：Generative Pre-Training  
- **提出**：OpenAI，2018 年上半年（GPT-1）  
- **架构**：Transformer **Decoder**（掩码自注意力 + FFN，**无交叉注意力**）  
- **核心**：自回归生成，只能看到左侧上下文（因果掩码）

### 3.2 关键区别（vs 原始 Decoder）

- 去掉编码器-解码器交叉注意力  
- 堆叠更多层（GPT-1 12 层，GPT-3 96 层）

### 3.3 输入表示

- Token Embedding + 可学习 Position Embedding（无 Segment Embedding）

### 3.4 预训练任务

- **自回归语言模型**：最大化 $P(w_i | w_1,...,w_{i-1})$

### 3.5 优缺点

| 优点 | 缺点 |
|------|------|
| 生成能力强（对话、续写、代码） | 单向，不能利用未来信息 |
| 零样本/少样本提示学习 | 生成速度慢（串行） |
| 参数量可扩展到千亿级 | 理解任务弱于 BERT |

### 3.6 后续发展

- GPT-2（2019）：1.5B 参数，零样本学习  
- GPT-3（2020）：175B 参数，少样本学习  
- GPT-4（2023）：多模态

## 四、三者综合对比

| 维度 | ELMo | GPT | BERT |
|------|------|-----|------|
| 基础架构 | 双向 LSTM | Transformer Decoder | Transformer Encoder |
| 双向性 | 前向+后向独立训练后拼接 | 单向（左→右） | 深度双向（同时看左右） |
| 预训练任务 | 前向 LM + 后向 LM | 自回归 LM | MLM + NSP |
| 擅长领域 | 动态词向量（已落后） | **自然语言生成（NLG）** | **自然语言理解（NLU）** |
| 参数量（典型） | ~94M | 117M ~ 175B | 110M ~ 340M |
| 能否处理 OOV | 是（CharCNN） | 子词 BPE | 子词 WordPiece |
| 最大序列长度 | 数百 | 1024（GPT-2/3） | 512 |

## 五、常见面试简答（重点）

**Q1：BERT 的三种嵌入是什么？**  
Token Embedding + Segment Embedding + Position Embedding（可学习），三者相加。

**Q2：MLM 中“811”规则是什么？为什么？**  
15%的 token 被选中，其中 80%替换为 `[MASK]`，10%随机词，10%不变。  
目的：强制学习双向语义（80%），增加纠错能力（10%），缓解预训练-微调不一致（10%）。

**Q3：BERT 与 ELMo 的双向有何不同？**  
BERT 是 Transformer Encoder，同一层中每个 token 同时看到左右所有 token，**深度融合**。  
ELMo 分别训练前向和后向 LSTM，最后**拼接**，不是真正的双向融合。

**Q4：为什么 BERT 不适合生成任务？**  
BERT 是 Encoder-only，无自回归解码能力；生成需要 Decoder（如 GPT）。

**Q5：GPT 的因果掩码是什么？**  
上三角掩码，位置 i 只能看到 j≤i（过去及自身），防止看到未来词，保证自回归生成。

**Q6：ELMo 如何处理 OOV？**  
使用字符级 CNN，通过字符组合生成向量，无需词典。

**Q7：三个模型的历史顺序？**  
ELMo（2018.03）→ GPT-1（2018 上半年）→ BERT（2018.10）。
