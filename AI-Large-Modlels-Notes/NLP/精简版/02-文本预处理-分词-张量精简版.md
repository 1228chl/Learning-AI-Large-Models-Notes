## 二、文本处理基本方法

### 2.1 分词（Tokenization）

**作用**：将连续文本切分为词序列，是语义理解的最小单元。

#### jieba 分词库（中文）

```python
import jieba

sentence = "我爱自然语言处理"

# 精确模式（默认）
words = jieba.lcut(sentence, cut_all=False)   # ['我', '爱', '自然语言处理']

# 全模式（所有可能词）
words_full = jieba.lcut(sentence, cut_all=True)  # ['我', '爱', '自然', '自然语言', '语言', '处理']

# 搜索引擎模式（长词再切分）
words_search = jieba.lcut_for_search(sentence)   # ['我', '爱', '自然', '语言', '自然语言', '处理']
```

- `lcut()` 返回 list，`cut()` 返回生成器（适合大数据流）。
- **用户自定义词典**：`jieba.load_userdict("userdict.txt")`（每行：词 词频 词性）

#### 停用词过滤

```python
stopwords = set(open("stopwords.txt", encoding="utf-8").read().split())
words = [w for w in jieba.lcut(sentence) if w not in stopwords]
```

### 2.2 词性标注（POS）

```python
import jieba.posseg as pseg

words_pos = pseg.lcut("我爱北京天安门")
for word, flag in words_pos:
    print(f"{word}/{flag}")   # 我/r 爱/v 北京/ns 天安门/ns
```

常用标记：`n` 名词, `v` 动词, `a` 形容词, `nr` 人名, `ns` 地名, `nt` 机构名, `d` 副词, `p` 介词, `c` 连词, `u` 助词, `w` 标点。

### 2.3 命名实体识别（NER）

- **简单方式**：通过词性标记（`nr` / `ns` / `nt`）获取。
- **专业工具**：HanLP、LTP、BERT-NER。

## 三、文本张量表示方法

### 3.1 One-hot 编码

- **表示**：长度 = 词汇表大小，仅一个位置为 1。
- **缺点**：稀疏、维度爆炸、无语义相似度。

```python
from tensorflow.keras.preprocessing.text import Tokenizer

tokenizer = Tokenizer()
tokenizer.fit_on_texts(["周杰伦", "陈奕迅"])
word_index = tokenizer.word_index   # {'周杰伦':1, '陈奕迅':2}

# 生成 one-hot（手动）
one_hot = [0]*len(word_index)
one_hot[word_index["周杰伦"]-1] = 1
```

### 3.2 Word2Vec

**核心思想**：语义相近的词在上下文分布相似，学习稠密向量。

| 模型 | 输入 → 输出 | 特点 |
|------|-------------|------|
| **CBOW** | 上下文词 → 中心词 | 训练快，低频词效果差 |
| **Skip-gram** | 中心词 → 上下文词 | 训练慢，低频词效果好 |

#### 使用 FastText 训练（支持子词，可处理 OOV）

```python
import fasttext

# 训练 CBOW
model = fasttext.train_unsupervised('data.txt', model='cbow', dim=100, epoch=5)

# 训练 Skip-gram
model = fasttext.train_unsupervised('data.txt', model='skipgram', dim=100)

# 常用操作
vec = model.get_word_vector("音乐")                # 获取向量
neighbors = model.get_nearest_neighbors("音乐", k=5) # 最相似词 [(score, word), ...]
model.save_model("model.bin")
loaded = fasttext.load_model("model.bin")
```

### 3.3 Word Embedding（神经网络嵌入层）

- **广义**：所有稠密词向量（Word2Vec、GloVe、FastText）。
- **狭义**：`nn.Embedding` 作为模型的可训练层，随任务更新。

```python
import torch.nn as nn

embedding = nn.Embedding(num_embeddings=10000, embedding_dim=256)
input_ids = torch.tensor([2, 45, 678])   # 词索引
vectors = embedding(input_ids)           # shape (3, 256)
```

| 方法 | 是否动态 | OOV 处理 | 使用方式 |
|------|----------|---------|----------|
| Word2Vec（静态） | 否 | 仅 FastText | 预训练后查表 |
| nn.Embedding | 是（端到端） | 映射到 `<UNK>` | 作为网络第一层 |

## 四、特征处理与数据增强（基础）

### 4.1 特征处理

- **n-gram**：连续的 n 个词作为一个特征，保留局部顺序。
- **TF-IDF**：词频 × 逆文档频率，降低常见词权重。

```python
from sklearn.feature_extraction.text import TfidfVectorizer

vectorizer = TfidfVectorizer(ngram_range=(1,2))
tfidf = vectorizer.fit_transform(["文本1", "文本2"])
```

- **长度规范化**：padding / truncation 到相同长度。

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("bert-base-chinese")
enc = tokenizer(sentences, padding=True, truncation=True, max_length=128, return_tensors="pt")
```

## 五、完整预处理流程（PyTorch + HuggingFace 示例）

```python
from torch.utils.data import Dataset, DataLoader
from transformers import AutoTokenizer

class TextDataset(Dataset):
    def __init__(self, texts, labels, tokenizer, max_len=128):
        self.texts = texts
        self.labels = labels
        self.tokenizer = tokenizer
        self.max_len = max_len

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, idx):
        enc = self.tokenizer(
            self.texts[idx],
            truncation=True,
            padding='max_length',
            max_length=self.max_len,
            return_tensors='pt'
        )
        return {
            'input_ids': enc['input_ids'].flatten(),
            'attention_mask': enc['attention_mask'].flatten(),
            'label': torch.tensor(self.labels[idx])
        }

tokenizer = AutoTokenizer.from_pretrained("bert-base-chinese")
dataset = TextDataset(["我喜欢NLP", "讨厌噪声"], [1, 0], tokenizer)
dataloader = DataLoader(dataset, batch_size=2)
```

## 六、常见面试题速记

- **为什么中文需要分词？** 词间无空格，计算机无法直接识别语义单元。
- **jieba 三种模式区别？** 精确（最细）、全（所有可能）、搜索（长词再分）。
- **one-hot 缺点？** 稀疏、维度爆炸、无语义相似度。
- **CBOW vs Skip-gram？** 预测方向相反；Skip-gram 更擅长低频词。
- **静态 vs 动态词向量？** 静态（Word2Vec）固定，无法处理一词多义；动态（ELMo、BERT）上下文相关。
- **如何处理未登录词（OOV）？** 子词分词（BPE）、FastText 子词、映射到 `<UNK>`。
