# 自然语言处理概述超详细笔记



## 第一部分：自然语言处理概念



### 1.1 什么是自然语言处理

自然语言处理（Natural Language Processing，简称 NLP）是计算机科学、人工智能与语言学交叉形成的一个核心研究领域。其根本目标是：**让计算机能够理解人类语言并生成人类语言**。换句话说，NLP 试图打破人机之间以编程语言为中介的交互壁垒，使计算机能够像人一样读、写、听、说。

从技术实现角度看，NLP 涵盖了一系列使计算机程序能够处理文本或语音数据的任务，包括但不限于：将语音转换为文字（语音识别）、将文字转换为语音（语音合成）、从文本中提取意义（自然语言理解）、用另一种语言表达相同意义（机器翻译）、判断文本的情感倾向（情感分析）以及自动将文档归类（文本分类）等。

NLP 之所以困难，根源在于人类语言的**歧义性**和**上下文依赖性**。同一个词在不同语境下可能有完全不同的含义（例如“苹果”可以指水果或科技公司），同一个意思可以用无数种不同的句式表达。因此，NLP 不仅是编程任务，更需要对世界知识、常识推理和语用规则进行建模。



### 1.2 两大核心子领域：NLU 与 NLG

NLP 通常被划分为两个紧密相连的子领域：

| 子领域 | 全称 | 核心任务 | 典型应用 |
|--------|------|----------|----------|
| **自然语言理解（NLU）** | Natural Language Understanding | 从语言输入中提取结构和意义，包括词义消歧、句法分析、语义角色标注、意图识别、情感分析、实体抽取等 | 问答系统、智能客服、搜索引擎查询理解、自动摘要 |
| **自然语言生成（NLG）** | Natural Language Generation | 根据结构化数据或语义表示，生成符合语法和语用习惯的自然语言文本 | 机器翻译、对话系统回复生成、天气预报自动撰写、报告生成 |

```python
import jieba

sentence = "传智教育是一家上市公司，旗下有黑马程序员品牌。我是在黑马这里学习人工智能"


# 1. 精确模式
words_precise = jieba.lcut(sentence, cut_all=False)
print("精确模式:", words_precise)


# 输出: ['传智', '教育', '是', '一家', '上市公司', '，', '旗下', '有', '黑马', '程序员', '品牌', '。', '我', '是', '在', '黑马', '这里', '学习', '人工智能']


# 2. 全模式
words_full = jieba.lcut(sentence, cut_all=True)
print("全模式:", words_full)


# 输出: ['传', '智', '教育', '是', '一家', '上市', '上市公司', '公司', '', '', '旗下', '下有', '黑马', '程序', '程序员', '品牌', '', '', '我', '是', '在', '黑马', '这里', '学习', '人工', '人工智能', '智能']


# 3. 搜索引擎模式
words_search = jieba.lcut_for_search(sentence)
print("搜索引擎模式:", words_search)

# 输出: ['传智', '教育', '是', '一家', '上市', '公司', '上市公司', '，', '旗下', '有', '黑马', '程序', '程序员', '品牌', '。', '我', '是', '在', '黑马', '这里', '学习', '人工', '智能', '人工智能']
```

**数学视角**：可以将 NLU 看作一个从文本序列 $\mathbf{x} = (x_1, x_2, ..., x_T)$ 到某个语义空间 $\mathcal{Y}$ 的映射函数 $f: \mathcal{X} \rightarrow \mathcal{Y}$ ，例如分类标签、实体集合、依存树等。而 NLG 则是给定某种表示 $\mathbf{z}$ （可能是意图、数据库记录或另一种语言的句子），生成目标序列 $\mathbf{y} = (y_1, ..., y_S)$ 的过程，通常使用条件语言模型 $P(\mathbf{y} \mid \mathbf{z})$ 。

在实际系统中，NLU 和 NLG 往往联合使用。例如一个智能客服机器人：首先使用 NLU 解析用户输入的句子，识别意图和槽位；然后根据对话策略决定要回答什么内容；最后使用 NLG 生成自然语言的回复。



### 1.3 NLP 覆盖的主要技术领域

NLP 的应用非常广泛，以下列出几个经典的技术方向，每个方向都可以看作一个独立的子问题：

| 技术领域 | 描述 | 输入 | 输出 | 评价指标 |
|----------|------|------|------|----------|
| **语音识别** | 将声音信号转换为文字 | 音频波形 | 文本转写 | 词错误率（WER） |
| **语音合成** | 将文字转换为自然的语音 | 文本 | 音频波形 | 平均意见得分（MOS） |
| **机器翻译** | 将一种语言的文本转换为另一种语言的文本 | 源语言句子 | 目标语言句子 | BLEU、TER |
| **文本分类** | 将文本划分到预定义的类别中 | 文档/句子 | 类别标签 | 准确率、F1 值 |
| **情感分析** | 判断文本的情感极向（正面、负面、中性） | 评论文本 | 情感标签 + 强度 | 准确率、宏平均 F1 |
| **信息抽取** | 从非结构化文本中提取结构化信息（实体、关系、事件） | 原始文本 | 实体-关系三元组 | 精确率、召回率、F1 |
| **问答系统** | 根据自然语言问题返回答案 | 问题 + 候选文档/知识库 | 答案短语或段落 | 精确匹配（EM）、F1 |



### 1.4 典型应用场景详解



#### 1.4.1 问答系统

问答系统接收用户用自然语言提出的问题，从结构化的知识库或非结构化的文档集合中找出答案。例如：**“《红楼梦》的作者是谁？”** 系统需要识别出问题中的实体“《红楼梦》”以及关系“作者”，然后检索知识库返回“曹雪芹”。在工业界，智能客服系统是问答系统的重要落地场景——用户向聊天机器人描述问题，机器人先进行意图分类，然后从 FAQ 或知识库中匹配答案，最后生成回复。

```python

sentence = "传智教育是一家上市公司，旗下有黑马程序员品牌。我是在黑马这里学习人工智能"


# 1. 精确模式
words_precise = jieba.lcut(sentence, cut_all=False)
print("精确模式:", words_precise)

words_full = jieba.lcut(sentence, cut_all=True)
```

#### 1.4.2 智能客服

智能客服通常结合了 NLU 和对话管理技术。典型的处理流程：

- **意图识别**：用户说“我想退订会员”，系统识别意图为“取消订阅”。
- **槽位填充**：提取出关键信息，如“会员类型”、“订单号”等。
- **对话状态跟踪**：记录已收集的信息和还需要询问的信息。
- **策略决策**：决定接下来是要求补充信息还是直接执行操作。
- **自然语言生成**：产生如“请提供您的会员订单号”这样的回复。



#### 1.4.3 搜索引擎

现代搜索引擎不仅做关键词匹配，还会利用 NLP 技术理解查询的真实意图。例如用户搜索“苹果股价”，搜索引擎需要识别“苹果”在这里指的是 Apple Inc. 而非水果。这就涉及**实体链接**（Entity Linking）技术：将文本中的提及映射到知识库中的具体实体。此外，搜索引擎还会使用**查询改写**（同义词扩展、拼写纠错）、**相关性排序**（基于 BERT 等模型的语义匹配）等技术。



#### 1.4.4 智能家居

智能音箱（如 Amazon Echo、Google Home、小爱同学）是 NLP 在智能家居中的典型代表。用户通过语音发出指令：“打开客厅的灯”。系统依次完成：

1. **语音识别**：将音频转为文字。
2. **自然语言理解**：识别意图为“控制设备”，槽位为“客厅的灯”，动作为“打开”。
3. **对话管理**：与 IoT 设备控制模块交互。
4. **语音合成**：用语音回复“好的，已为您打开客厅灯”。

### 1.5 数学形式化定义（扩展）

为了更精确地理解 NLP 中的典型问题，这里给出两个基础任务的数学定义：

- **文本分类**：设词汇表为 $V$ ，一篇文档可以表示为一个词序列 $D = (w_1, ..., w_n)$ ，其中 $w_i \in V$ 。分类任务是学习一个函数 $f: D \rightarrow \{c_1, c_2, ..., c_k\}$ ，通常通过最大化后验概率实现： $\hat{c} = \arg\max_{c} P(c \mid D)$ 。在朴素贝叶斯分类器中，利用贝叶斯定理假设特征条件独立： $P(c \mid D) \propto P(c) \prod_{i=1}^n P(w_i \mid c)$ 。

- **词性标注**：给定一个句子 $S = (w_1, ..., w_n)$ 和一组词性标签集合 $T$ ，找出最可能的标签序列 $\mathbf{t} = (t_1, ..., t_n)$ ，使得 $\mathbf{t} = \arg\max_{\mathbf{t}} P(\mathbf{t} \mid S)$ 。隐马尔可夫模型（HMM）将其分解为 $P(\mathbf{t} \mid S) \propto P(t_1) \prod_{i=2}^n P(t_i \mid t_{i-1}) \prod_{i=1}^n P(w_i \mid t_i)$ 。
