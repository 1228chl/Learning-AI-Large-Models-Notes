# 两数之和

Given an array of integers `nums` and an integer `target`, return _indices of the two numbers such that they add up to `target`_. You may assume that each input would have **_exactly_ one solution**, and you may not use the _same_ element twice.

> 给定一个整数数组 `nums` 和一个整数 `target`，返回两个数的下标，使得它们的和等于 `target`。你可以假设每个输入都恰好有一个解，并且不能重复使用同一个元素。

You can return the answer in any order.

> 你可以按任意顺序返回答案。

**Example 1:**

> **Input:** nums = [2,7,11,15], target = 9
> **Output:** [0,1]
> **Explanation:** Because nums[0] + nums[1] == 9, we return [0, 1].

**Example 2:**

> **Input:** nums = [3,2,4], target = 6
> **Output:** [1,2]

**Example 3:**

> **Input:** nums = [3,3], target = 6
> **Output:** [0,1]

**Constraints:**

- `2 <= nums.length <= 104`
- `-109 <= nums[i] <= 109`
- `-109 <= target <= 109`
- **Only one valid answer exists.**

**Follow-up:** Can you come up with an algorithm that is less than `O(n^2)` time complexity?

> 进阶：你能想出一个时间复杂度低于 `O(n^2)` 的算法吗？

**Hint 1**

A really brute force way would be to search for all possible pairs of numbers but that would be too slow. Again, it's best to try out brute force solutions just for completeness. It is from these brute force solutions that you can come up with optimizations.

> 一种非常暴力的方法是搜索所有可能的数对，但这会太慢。同样，为了完整性，最好尝试一下暴力解法。正是从这些暴力解法中，你才能想出优化方案。

**Hint 2**

So, if we fix one of the numbers, say `x`, we have to scan the entire array to find the next number `y` which is `value - x` where value is the input parameter. Can we change our array somehow so that this search becomes faster?

> 所以，如果我们固定其中一个数，比如 `x`，就必须扫描整个数组来找到下一个数 `y`，即 `value - x`，其中 value 是输入参数。我们能否以某种方式改变数组，使这个查找变得更快？

**Hint 3**

The second train of thought is, without changing the array, can we use additional space somehow? Like maybe a hash map to speed up the search?

> 第二种思路是，在不改变数组的情况下，能否以某种方式使用额外空间？比如用哈希映射来加速查找？

**Answer:**

```python
def twoSum(self, nums, target):
    seen = {}
    for i, v in enumerate(nums):
        remaining = target - v
        if remaining in seen:
            return [seen[remaining], i]
        seen[v] = i
    return []
```
