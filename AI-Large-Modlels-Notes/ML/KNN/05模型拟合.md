# 模型拟合问题（Model Fitting）

## 第一部分：拟合的基本概念

### 1.1 拟合的定义

> 拟合（fitting）用在机器学习领域，用来表示模型对样本点的拟合情况。

扩展解释：

- 拟合是指模型通过学习训练数据中的规律，来近似输入与输出之间的真实映射关系。
- 拟合程度反映了模型对训练数据的“模仿”能力，但最终目标是泛化到新数据。

---

### 1.2 拟合的三种状态

| 状态                     | 训练集表现 | 测试集表现 | 原因             |
| ---------------------- | ----- | ----- | -------------- |
| **欠拟合**（Underfitting）  | 差     | 差     | 模型过于简单，未学到数据规律 |
| **过拟合**（Overfitting）   | 好     | 差     | 模型过于复杂，学到了噪声   |
| **良好拟合**（Good Fitting） | 较好    | 较好    | 模型复杂度适中，泛化能力强  |

---

## 第二部分：欠拟合（UnderFitting）

 ### 2.1 定义

 > 模型在训练集上表现**很差**、在测试集表现也**很差**。

 ---

 ### 2.2 本质

 - 模型的能力不足以捕捉数据中的主要规律，甚至连训练数据都无法很好地拟合。

  ---

  ### 2.3 产生原因
  
  - **模型过于简单**：
	  - 例如用线性模型拟合非线性数据
	  - 特征太少
	  - 神经网络层数或神经元太少
	  - 决策树深度太浅

---

### 2.4 示例

- 真实函数是二次曲线 $y=x^2$，训练数据带少量噪声。
- 用一次线性模型 $y=ax+b$ 去拟合 $\to$ 无论怎么调整参数，误差都很大 $\to$ 欠拟合。

---

### 2.5 如何判断欠拟合

- 训练集误差高，验证集/测试集误差也高（两者相近且都高）。
- 模型在训练集上的预测值与真实值偏差大。
- 学习曲线：训练误差和验证误差都居高不下，且随着训练集增大，两者趋于接近但都较高。

---

### 2.6 解决方法

| 方法           | 说明                                  |
| ------------ | ----------------------------------- |
| **增加模型复杂度**  | 增加特征数量、使用多项式特征、增加神经网络层数/神经元、增大决策树深度 |
| **减少正则化强度**  | 若有 L 1/L 2 正则项，降低 $\lambda$         |
| **增加更多有效特征** | 通过特征工程引入与任务相关的特征                    |
| **延长训练时间**   | 对于迭代算法（如梯度下降），增加迭代次数                |
| **选择更复杂的模型** | 例如从线性模型换成决策树或神经网络                   |

> 欠拟合可以通过**增加特征**来解决。

---

## 第三部分：过拟合（OverFitting）

### 3.1 定义

> 模型在训练集上表现**很好**、在测试集表现**很差**。

---

### 3.2 本质

- 模型过于复杂，不仅学习了数据中的普遍规律，还“记住”了训练数据中的**噪声**、**异常点**和**随机波动**，导致对新数据的泛化能力下降。

---

### 3.3 产生原因

- **模型太复杂**（参数数量远多于样本数、树深度过大、神经网络层数过多等）。
- **数据不纯**（训练数据中包含错误标注、噪声、异常值）。
- **训练数据太少**（样本数不足以支撑复杂模型的学习）。

---

### 3.4 示例

- 用高阶多项式（如 10 次）去拟合只有 10 个点的数据 $\to$ 多项式可以完美穿过每一个点（训练误差为 0），但形状剧烈震荡，对新点预测极差 $\to$ 过拟合。

---

### 3.5 如何判断过拟合

- 训练集误差很低（甚至为 0），验证集/测试集误差明显较高。
- 训练误差持续下降，而验证误差先下降后上升（过拟合发生的拐点）。
- 模型参数值非常大（某些权重绝对值极大）。

---

### 3.6 解决方法

| 方法                  | 说明                               |
| ------------------- | -------------------------------- |
| 增加训练数据              | 收集更多样本，或使用数据增强                   |
| 降低模型复杂度             | 减少特征数、降低多项式次数、减少神经网路层数/神经元、减小树深度 |
| 正则化（Regularization） | L 1（Lasso）、L 2（Ridge）正则，限制参数大小   |
| 特征降维                | PCA 等，减少冗余特征                     |
| 特征选择                | 只保留重要特征                          |
| 异常值检测与处理            | 去除异常样本或修正错误标注                    |
| 早停法（Early Stopping） | 在验证异常样本或修正错误标注                   |
| 集成方法                | Bagging（随机森林）、Dropout（神经网络）      |
| 添加噪声（数据增强）          | 对输入添加轻微噪声，提高鲁棒性                  |

> 过拟合可以通过**正则化、异常值检测、特征降维**等方法来解决。
