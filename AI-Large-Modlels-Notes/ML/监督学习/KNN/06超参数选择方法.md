# 超参数选择方法（交叉验证与网格搜索）超详细笔记

## 第一部分：为什么需要超参数选择？

### 1.1 超参数 vs 模型参数

| 类型 | 定义 | 例子 | 获取方式 |
|------|------|------|----------|
| **模型参数** | 模型从数据中自动学习到的参数 | 线性回归的权重 w、偏置 b；KNN 中不存在训练参数 | 通过训练（如梯度下降）自动得到 |
| **超参数** | 训练前需要人工设定的参数 | KNN 的 K 值、距离度量 p 值、正则化系数λ | 人工设定或通过超参数搜索自动寻找 |

### 1.2 超参数调优的重要性

- **KNN 的 K 值**：直接影响模型复杂度（K 小→过拟合，K 大→欠拟合）。
- 手动尝试 K 值（如 1,3,5,7,...）非常低效。
- 需要自动化、系统化的方法来寻找最优超参数组合。

## 第二部分：交叉验证（Cross-Validation）

### 2.1 交叉验证的目的

**PPT 原文**：
> 交叉验证是一种**数据集的分割方法**，目的是为了得到**更加准确可信的模型评分**。

**扩展解释**：
- 常规的单一训练集/验证集划分（如 70%/30%）可能因为划分的偶然性导致评估结果不稳定。
- 交叉验证通过多次划分、多次评估并取平均，减少评估结果的方差，使模型评分更可靠。

### 2.2 K 折交叉验证（K-Fold Cross-Validation）

#### 2.2.1 基本流程

1. 将训练集划分为 **n 份**（n 通常取 5 或 10，PPT 示例中 n=4）。
2. 进行 n 次训练和验证：
   - **第一次**：第 1 份做验证集，其余 n-1 份做训练集。
   - **第二次**：第 2 份做验证集，其余 n-1 份做训练集。
   - ...
   - **第 n 次**：第 n 份做验证集，其余 n-1 份做训练集。
1. 计算 n 次验证得分的**平均值**，作为该模型（超参数组合）的交叉验证得分。

#### 2.2.2 文字描述

> 第一次：把第一份数据做验证集，其他数据做训练。
> 第二次：把第二份数据做验证集，其他数据做训练。
> ... 以此类推，总共训练 4 次，评估 4 次。
> 使用训练集+验证集多次评估模型，取平均值做交叉验证为模型得分。

#### 2.2.3 完整流程（包括最终模型）

后续说明：
> 若 k=5 模型得分最好，再使用**全部训练集**（训练集+验证集）对 k=5 模型再训练一遍，再使用测试集对 k=5 模型做评估。

**解释**：交叉验证只用于**模型选择和超参数调优**，不用于最终模型训练。选定最优超参数后，需要在**完整的训练集**（包括之前用于验证的折）上重新训练最终模型，然后用**独立的测试集**评估泛化能力。

### 2.3 交叉验证的变体

| 类型 | 说明 | 特点 |
|------|------|------|
| **K 折交叉验证** | 将数据均匀分成 K 份，轮流做验证集 | 最常用，K=5 或 10 |
| **留一法（LOOCV）** | K=样本数 N，每次留一个样本做验证 | 计算开销极大，适合小样本 |
| **分层 K 折（StratifiedKFold）** | 保证每一折的类别比例与整体一致 | 用于分类问题，避免类别失衡 |
| **重复 K 折** | 多次重复 K 折，取平均 | 减少随机性，更稳定 |

### 2.4 交叉验证的优点与缺点

| 优点 | 缺点 |
|------|------|
| 评估结果更稳定、可信（减少划分偶然性） | 计算量增加：需要训练 K 次模型（K 通常 5~10） |
| 更充分利用数据（每个样本都被用作验证） | 不适合超大数据集（训练多次开销大） |
| 有助于检测过拟合 | - |

## 第三部分：网格搜索（Grid Search）

### 3.1 网格搜索的目的

**PPT 原文**：
> 为什么需要网格搜索？模型有很多超参数，其能力也存在很大的差异。需要**手动产生很多超参数组合**，来训练模型。每组超参数都采用**交叉验证评估**，最后选出最优参数组合建立模型。

**扩展解释**：
- 手动尝试所有可能的超参数组合非常繁琐且容易遗漏。
- 网格搜索自动遍历用户指定的超参数候选值列表，对所有组合进行交叉验证评估，返回最佳组合。

### 3.2 网格搜索的原理

**PPT 举例**：
> 网格搜索 $\text{[1, 2, 3, 4, 5, 6, 7, 8] * [“uniform”, “distance”]}$ 共 16 种选择的可能。

- 第一个参数 `n_neighbors` 有 8 个候选值：1~8。
- 第二个参数 `weights` 有 2 个候选值：`'uniform'`、`'distance'`。
- 总组合数 = 8 × 2 = 16。
- 网格搜索对每种组合执行交叉验证（如 5 折），得到 16 个交叉验证得分，选择得分最高的组合。

### 3.3 网格搜索 + 交叉验证的强力组合

**PPT 原文**：
> 交叉验证解决模型的数据输入问题（数据集划分），得到更可靠的模型。
> 网格搜索解决超参数的组合。
> 两个组合在一起形成一个模型参数调优的解决方案。

**流程**：
```
候选超参数组合1 → 交叉验证(5折) → 平均得分
候选超参数组合2 → 交叉验证(5折) → 平均得分
...
候选超参数组合N → 交叉验证(5折) → 平均得分
选出得分最高的组合 → 在完整训练集上训练最终模型 → 在测试集上评估
```

## 第四部分：交叉验证网格搜索 API 详解

### 4.1 GridSearchCV 类

**所属库**：`sklearn.model_selection`

**类名**：`GridSearchCV`

**导入方式**：
```python
from sklearn.model_selection import GridSearchCV
```

### 4.2 构造函数参数

```python
GridSearchCV(estimator, param_grid, scoring=None, n_jobs=None, 
             refit=True, cv=None, verbose=0, pre_dispatch='2*n_jobs',
             error_score=np.nan, return_train_score=False)
```

**常用参数详解**：

| 参数 | 类型 | 说明 |
|------|------|------|
| **estimator** | 估计器对象 | 需要调参的模型，如 `KNeighborsClassifier()` |
| **param_grid** | dict 或 list of dict | 超参数候选值。如 `{'n_neighbors': [3,5,7], 'weights': ['uniform','distance']}` |
| **cv** | int, 交叉验证生成器, 默认 5 | 交叉验证折数。如 `cv=5` 表示 5 折交叉验证 |
| **scoring** | str 或 callable | 评估指标。分类默认 `'accuracy'`，回归默认 `'r2'`。可用 `'f1'`、`'roc_auc'` 等 |
| **refit** | bool, 默认 True | 是否在找到最佳参数后，用**全部训练集**重新训练模型。设为 True 后可直接用 `best_estimator_` |
| **n_jobs** | int, 默认 None | 并行任务数。`-1` 表示使用所有 CPU 核心 |
| **verbose** | int | 控制输出详细程度。0=不输出，1=输出部分，2=全部 |
| **return_train_score** | bool, 默认 False | 是否返回训练集得分（用于分析过拟合） |

### 4.3 GridSearchCV 的重要属性

在鸢尾花案例代码中展示了以下属性：

| 属性 | 含义 |
|------|------|
| `best_score_` | 最佳交叉验证得分的平均值 |
| `best_estimator_` | 最佳超参数组合对应的模型对象 |
| `best_params_` | 最佳超参数组合（字典形式） |
| `cv_results_` | 所有超参数组合的详细结果（DataFrame 可用） |

**代码片段**：
```python
print('estimator.best_score_---', estimator.best_score_)
print('estimator.best_estimator_---', estimator.best_estimator_)
print('estimator.best_params_---', estimator.best_params_)
print('estimator.cv_results_---', estimator.cv_results_)
```

### 4.4 cv_results_ 的详细内容（扩展）

`cv_results_` 是一个字典，包含以下常用键：
- `'mean_test_score'`：各组合的交叉验证平均得分
- `'std_test_score'`：得分的标准差
- `'mean_train_score'`（若 `return_train_score=True`）
- `'params'`：对应的超参数字典

可转换为 DataFrame 方便分析：
```python
results_df = pd.DataFrame(estimator.cv_results_)
results_df.to_csv('grid_search_results.csv')
```

## 第五部分：鸢尾花案例中的交叉验证网格搜索完整流程

### 5.1 完整代码

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier

# 1. 获取数据集
mydataset = load_iris()

# 2. 数据基本处理 - 划分数据集
x_train, x_test, y_train, y_test = train_test_split(
    mydataset.data, mydataset.target, test_size=0.2, random_state=22
)

# 3. 数据集预处理 - 数据标准化
transfer = StandardScaler()
x_train = transfer.fit_transform(x_train)
x_test = transfer.transform(x_test)

# 4. 机器学习（模型训练）
estimator = KNeighborsClassifier()
print('estimator-->', estimator)

# 4-2. 使用交叉验证网格搜索
param_grid = {'n_neighbors': [1, 3, 5, 7]}
estimator = GridSearchCV(estimator=estimator, param_grid=param_grid, cv=5)
estimator.fit(x_train, y_train)   # 训练：对每个K值进行5折交叉验证

# 4-3. 交叉验证网格搜索结果查看
print('estimator.best_score_---', estimator.best_score_)
print('estimator.best_estimator_---', estimator.best_estimator_)
print('estimator.best_params_---', estimator.best_params_)
print('estimator.cv_results_---', estimator.cv_results_)

# 4-4. 保存交叉验证结果
myret = pd.DataFrame(estimator.cv_results_)
myret.to_csv(path_or_buf='./mygridsearchcv.csv')

# 5. 模型评估
myscore = estimator.score(x_test, y_test)
print('myscore-->', myscore)
```

### 5.2 代码分步解析

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 加载鸢尾花数据集 | 150 个样本，4 个特征，3 个类别 |
| 2 | 划分训练集(80%)和测试集(20%) | 测试集全程不可参与超参数选择 |
| 3 | 标准化 | 重要：KNN 依赖距离 |
| 4 | 创建 KNN 分类器（未设 K 值） | 默认为 5 |
| 4-2 | 创建 GridSearchCV | `param_grid` 指定 K 候选[1,3,5,7]，`cv=5` 五折交叉验证 |
| 4-2 | `fit(x_train, y_train)` | 自动对每个 K 值进行 5 折 CV，选出最佳 K |
| 4-3 | 输出最佳结果 | `best_score_` 是 CV 平均准确率，`best_params_` 选出最优 K |
| 4-4 | 保存 cv_results_ | 可分析各 K 值下的均值和标准差 |
| 5 | 在测试集上评估 | 使用最佳模型（已用全部训练集重新训练） |

### 5.3 PPT 中关于交叉验证和网格搜索目的的多选题

**题目**：交叉验证和网格搜索的目的是什么？（多选题）

A）为了让被评估的模型更加**准确可信**，一般会使用交叉验证网格搜索去完成任务。  
B）有些算法模型本身自带较多的超参数，无法**高效**的去筛选比较合适的超参数组合。  
C）使用交叉验证和网格搜索可以提升模型的**可信度**和查找最佳参数组合的**效率**。  
D）仅交叉验证功能能够提升模型的准确率。

**正确答案**：A、B、C

**解析**：
- A 正确：交叉验证使评估更稳定。
- B 正确：网格搜索自动化参数组合。
- C 正确：两者结合提升可信度和效率。
- D 错误：交叉验证本身不提升准确率，只是评估更可靠；真正提升准确率的是选择到更好的超参数。

## 第六部分：手写数字识别案例中的超参数选择

PPT 中手写数字识别案例（MNIST）使用了 KNN，但**未在示例代码中展示交叉验证网格搜索**（可能为了简洁而直接设了 `n_neighbors=3`）。实际应用中，对手写数字识别应进行超参数调优。

### 6.1 数据简介

- **数据文件**：`train.csv` 和 `test.csv`
- **图像尺寸**：28×28 像素，共 784 个像素（特征）
- **像素值范围**：0~255（越大颜色越深）
- **训练集**：共 785 列，第一列为标签（0~9），其余 784 列为像素值
- **特征名称**：`pixel 0`, `pixel 1`, ..., `pixel 783`

### 6.2 网格搜索调优示例（扩展）

```python
from sklearn.model_selection import GridSearchCV

param_grid = {
    'n_neighbors': [3, 5, 7, 9],
    'weights': ['uniform', 'distance'],
    'p': [1, 2]   # 曼哈顿 vs 欧氏

knn = KNeighborsClassifier()
grid = GridSearchCV(knn, param_grid, cv=3, n_jobs=-1, verbose=1)
```

## 第七部分：扩展知识

### 7.1 其他超参数搜索方法

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| **网格搜索** | 遍历所有候选组合 | 超参数少、候选值少时精确 |
| **随机搜索**（RandomizedSearchCV） | 随机采样候选组合 | 超参数多、候选范围大时高效 |
| **贝叶斯优化**（Bayesian Optimization） | 用概率模型指导搜索 | 评估代价高（如深度学习） |
| **遗传算法** | 模拟进化 | 复杂搜索空间 |

### 7.2 交叉验证的注意事项

- **数据泄露**：必须在划分训练/测试集**之后**进行交叉验证。绝对不能用测试集的信息来指导超参数选择。
- **分层采样**：分类问题中，使用 `StratifiedKFold` 保持每折类别比例与整体一致。
- **时间序列数据**：不能随机打乱，应使用 `TimeSeriesSplit`。

### 7.3 网格搜索的优缺点

| 优点 | 缺点 |
|------|------|
| 简单、确定、易于并行 | 维数灾难：参数组合数随参数数量和候选值指数增长 |
| 保证找到候选集中的最优组合 | 需要手动指定候选范围，可能遗漏最优值 |

### 7.4 如何选择 K 折数（cv）

- **小数据集**（<1000）：用较大的 K（如 10），甚至留一法。
- **中等数据集**（1000~10000）：K=5 或 10。
- **大数据集**（>10000）：K=3 或 5，因为训练多次开销大，且划分一次验证集已足够代表。

## 第八部分：总结与速查

### 8.1 核心概念

- **交叉验证**：多次划分训练/验证集，评估模型稳定性。
- **网格搜索**：自动遍历超参数组合，结合交叉验证选择最优组合。
- **GridSearchCV**：sklearn 中实现两者结合的类。

### 8.2 标准工作流程

```
原始数据 → 划分测试集(20%) → 剩余作为训练集
训练集 → 交叉验证+网格搜索 → 得到最佳超参数
最佳超参数 + 全部训练集 → 训练最终模型
最终模型在测试集上评估
```

### 8.3 常用代码模板

```python
from sklearn.model_selection import GridSearchCV
from sklearn.neighbors import KNeighborsClassifier

# 定义模型
knn = KNeighborsClassifier()

# 定义超参数候选
param_grid = {'n_neighbors': [3,5,7,9], 'weights': ['uniform','distance']}

# 创建GridSearchCV对象
grid = GridSearchCV(knn, param_grid, cv=5, scoring='accuracy', n_jobs=-1)

# 在训练集上拟合
grid.fit(X_train, y_train)

# 输出最佳参数和分数
print("Best params:", grid.best_params_)
print("Best CV score:", grid.best_score_)

# 评估测试集
print("Test accuracy:", grid.score(X_test, y_test))
```
