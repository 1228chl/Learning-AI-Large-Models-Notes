
# 集成学习完整学习笔记

## 第一部分：集成学习简介

### 1.1 什么是集成学习

**集成学习（Ensemble Learning）** 是机器学习中的一种重要思想，它通过**组合多个模型**（称为“弱学习器”或“基学习器”）来形成一个精度更高的模型。其核心逻辑是：**三个臭皮匠，顶个诸葛亮**——多个模型的集体决策往往优于单个模型。

**定义**：

- 训练阶段：使用训练集依次（或并行）训练出多个弱学习器。
- 预测阶段：对于未知样本，让所有弱学习器分别进行预测，然后通过某种策略（如投票、平均）联合得出最终结果。

**形象比喻**：

- 单一决策树可能判断错误（例如把某棵西瓜判断为不甜）。
- 但如果同时询问 100 棵决策树（每棵树用不同的数据子集和特征子集训练），然后统计“甜”和“不甜”的票数，少数服从多数——结果往往更准确。

---

### 1.2 为什么集成学习有效

集成学习之所以能提升性能，主要归功于两个因素：

| 因素 | 说明 |
|------|------|
| **减少方差（Variance）** | 多个模型的平均（或投票）能够平滑掉单个模型的极端预测，降低过拟合风险。 |
| **减少偏差（Bias）** | 通过串行地修正前一个模型的错误，可以逐步降低偏差。 |
| **克服局部最优** | 不同模型可能陷入不同的局部最优，组合后更容易接近全局最优。 |

---

### 1.3 集成学习的分类

根据弱学习器的**生成方式**和**依赖关系**，集成学习主要分为两类：

| 类型 | 代表算法 | 核心特点 |
|------|----------|----------|
| **Bagging（并行式）** | 随机森林（Random Forest） | 弱学习器并行训练，相互独立；通过有放回抽样生成不同训练集；最终结果采用平权投票或平均 |
| **Boosting（串行式）** | AdaBoost、GBDT、XGBoost、LightGBM | 弱学习器串行训练，每个新学习器重点关注前一个学习器的错误样本；最终结果采用加权投票 |

> **提示**：Bagging 侧重于**降低方差**（防止过拟合），Boosting 侧重于**降低偏差**（提高拟合能力）。

---

## 第二部分：Bagging 思想

### 2.1 Bagging 的基本原理

**Bagging** 全称是 **Bootstrap Aggregating**（自助聚合）。其核心步骤：

1. **有放回抽样（Bootstrap）**：从原始训练集中**有放回**地随机抽取 $m$ 个样本（ $m$ 通常等于原始样本数），形成一个新的训练子集。重复此过程 $T$ 次，得到 $T$ 个不同的训练子集。
2. **并行训练**：在每个训练子集上独立训练一个弱学习器（通常是不剪枝的决策树），各个学习器之间没有依赖关系，可以并行计算。
3. **联合预测**：
   - 分类问题：所有弱学习器进行**平权投票**，得票最多的类别作为最终预测结果。
   - 回归问题：所有弱学习器的预测结果取**算术平均值**。

**图示思想**：

```python
原始数据集
    ↓ (有放回抽样, 重复T次)
子集1   子集2   ...   子集T
  ↓       ↓             ↓
模型1   模型2   ...   模型T
  ↓       ↓             ↓
  └───────┴─────────────┘
            ↓ (投票/平均)
         最终预测
```

---

### 2.2 为什么要用有放回抽样？

如果采用**无放回抽样**，每个训练子集之间没有重叠，那么每个弱学习器学到的数据分布可能差异很大，导致每个模型都“有偏”。而**有放回抽样**使得不同子集之间存在一定重叠（约 63.2%的样本会被抽到，剩余 36.8%未被抽到），这样既保持了差异性，又保留了原始数据的整体分布特性。

**数学特性**：当原始样本数为 $n$ ，有放回抽样 $n$ 次，某个特定样本未被抽到的概率为 $(1 - 1/n)^n \approx 1/e \approx 0.368$ ，即大约 36.8% 的样本不会出现在某个子集中（这些样本称为**袋外数据（Out-Of-Bag, OOB）**，可用于内部验证）。

---

### 2.3 Bagging 的特点

| 特点 | 说明 |
|------|------|
| **并行训练** | 各弱学习器之间无依赖，可同时训练，计算效率高 |
| **降低过拟合** | 平均/投票能平滑掉单个模型的噪声，提升泛化能力 |
| **对异常值鲁棒** | 因为多个模型综合决策，个别模型受异常值影响被削弱 |
| **适合高方差模型** | 尤其适合不剪枝的决策树（容易过拟合），通过集成降低方差 |

---

## 第三部分：Boosting 思想

### 3.1 Boosting 的基本原理

**Boosting**（提升方法）是一种串行集成策略。它通过**迭代地训练弱学习器**，每一轮都**重点关注上一轮被预测错误的样本**，从而逐步提升模型性能。最终将多个弱学习器进行**加权投票**（或加权平均）得到强学习器。

**核心流程**：

1. 初始化样本权重（通常均匀分布）。
2. 对于 $t = 1, 2, \dots, T$ ：
   - 根据当前样本权重分布训练一个弱学习器 $h_t$ 。
   - 计算 $h_t$ 在训练集上的错误率 $\epsilon_t$ 。
   - 计算该学习器的**权重系数** $\alpha_t$ （错误率越低，权重越高）。
   - 更新样本权重：增加被错误分类的样本的权重，减少被正确分类的样本的权重，使下一轮学习器更关注难例。
1. 最终预测：加权投票 $\text{sign}(\sum \alpha_t h_t(x))$ 。

**生活中的比喻**（来自原 PDF）：

> 滚球兽 → 亚古兽 → 暴龙兽 → 机械暴龙兽 → 战斗暴龙兽  
> 随着学习的积累，从弱到强，每次进化都变得更加强大。

---

### 3.2 Boosting 的典型代表算法

| 算法 | 全称 | 特点 |
|------|------|------|
| **AdaBoost** | Adaptive Boosting | 最早的 Boosting 算法，使用指数损失，权重更新简单 |
| **GBDT** | Gradient Boosting Decision Tree | 用损失函数的负梯度拟合残差，可自定义损失函数 |
| **XGBoost** | eXtreme Gradient Boosting | 对 GBDT 的工程优化，支持并行、正则化、缺失值处理 |
| **LightGBM** | Light Gradient Boosting Machine | 基于直方图的决策树算法，训练速度快，内存占用小 |

---

### 3.3 Boosting 的特点

| 特点 | 说明 |
|------|------|
| **串行训练** | 每一轮依赖上一轮的结果，无法并行，训练时间较长 |
| **降低偏差** | 通过不断修正错误，可以显著提升模型的拟合能力 |
| **容易过拟合** | 如果学习率太高或迭代次数过多，可能过拟合 |
| **对异常值敏感** | 异常点会被反复加权，导致模型过度关注噪声 |

---

## 第四部分：Bagging vs Boosting 对比

| 对比维度 | Bagging | Boosting |
|----------|---------|----------|
| **数据采样** | 有放回地随机采样（Bootstrap） | 使用全部训练样本，但调整样本权重 |
| **训练方式** | **并行**，各学习器独立 | **串行**，后一个依赖前一个 |
| **学习器权重** | 平权（所有学习器投票权重相同） | 加权（错误率低的学习器权重高） |
| **目标** | 降低方差，防止过拟合 | 降低偏差，提高拟合能力 |
| **代表算法** | 随机森林 | AdaBoost、GBDT、XGBoost、LightGBM |
| **对异常值敏感度** | 低（通过平均削弱异常影响） | 高（异常点被反复加权） |
| **训练时间** | 短（可并行） | 长（需串行迭代） |
| **适用场景** | 高方差模型（如未剪枝决策树） | 高偏差模型（如浅层决策树） |

## 第五部分：随机森林算法

### 5.1 随机森林的定义

**随机森林（Random Forest）** 是基于 **Bagging 思想**实现的一种集成学习算法，它采用**决策树**作为每一个弱学习器，并在决策树训练过程中**额外引入随机特征选择**，进一步增加多样性。

---

### 5.2 随机森林的构建过程

1. **随机采样训练数据**：从原始数据集中**有放回**地随机抽取 $n$ 个样本（ $n$ 通常等于原始样本数），形成一个训练子集。重复此过程 $T$ 次（ $T$ 为决策树的数量）。
2. **随机选择特征**：对于每棵决策树的**每个节点**，从所有 $M$ 个特征中**随机挑选 $m$ 个特征**（ $m < M$ ），然后从这 $m$ 个特征中选择最佳分裂特征。典型的 $m$ 取值为 $\sqrt{M}$ （分类）或 $M/3$ （回归）。
3. **训练决策树**：使用选定的样本和特征，构建一棵决策树（通常不做剪枝，让其充分生长）。
4. **重复**：重复步骤 1~3，生成 $T$ 棵决策树。
5. **联合预测**：
   - 分类问题：平权投票，多数表决。
   - 回归问题：取所有树预测值的平均值。

---

### 5.3 随机森林的“随机”体现在何处？

| 随机性 | 说明 | 作用 |
|--------|------|------|
| **数据随机** | 有放回抽样（Bootstrap） | 使每棵树训练数据不同，增加差异性 |
| **特征随机** | 节点分裂时随机选取特征子集 | 进一步降低树之间的相关性，防止所有树都依赖同一个强特征 |

---

### 5.4 为什么要随机抽样训练集？

**问题 1：如果不随机抽样，每棵树的训练集都一样，会怎样？**  
→ 所有决策树训练结果完全相同，集成后没有任何改善，等价于单棵树。

**问题 2：为什么要有放回地抽样？**  
→ 如果采用无放回抽样，每棵树使用的样本完全不同（无交集），每棵树学到的数据分布差异过大，无法有效投票（因为每棵树都在自己不同分布的数据上训练，投票基准不一致）。有放回抽样使得不同子集之间约有 63%的重叠，既保持了差异性，又保留了整体分布。

---

### 5.5 随机森林的特点

| 优点 | 说明 |
|------|------|
| **高准确性** | 集成多棵树，通常比单棵决策树准确率高很多 |
| **抗过拟合能力强** | 随机抽样+特征随机，增加了泛化能力 |
| **能处理高维数据** | 可以处理成千上万个特征，且能输出特征重要性 |
| **鲁棒性好** | 对异常值和噪声不敏感 |
| **可并行训练** | 树之间独立，可充分利用多核 CPU |

| 缺点 | 说明 |
|------|------|
| **模型较大** | 需要存储多棵树，内存占用较高 |
| **预测速度较慢** | 相比单棵决策树，预测时需要运行所有树 |
| **可解释性差** | 不如单棵决策树直观（但可分析特征重要性） |

## 第六部分：随机森林 API 介绍

Scikit-learn 提供了随机森林分类器和回归器，位于 `sklearn.ensemble` 模块。

---

### 6.1 分类 API：RandomForestClassifier

```python
from sklearn.ensemble import RandomForestClassifier
```

**构造函数与主要参数**：

```python
RandomForestClassifier(
    n_estimators=100,           # 决策树的数量（默认100）
    criterion='gini',           # 分裂指标：'gini' 或 'entropy'
    max_depth=None,             # 树的最大深度（None表示不限）
    min_samples_split=2,        # 内部节点再划分所需最小样本数
    min_samples_leaf=1,         # 叶子节点最少样本数
    max_features='sqrt',        # 每个节点随机选取的特征数
    bootstrap=True,             # 是否使用有放回抽样（默认True）
    oob_score=False,            # 是否使用袋外数据计算泛化误差
    n_jobs=None,                # 并行数（-1表示所有CPU核心）
    random_state=None,          # 随机种子
    verbose=0,                  # 控制训练过程输出
    warm_start=False,           # 是否增量训练
    class_weight=None,          # 类别权重（处理不平衡）
    ccp_alpha=0.0               # 剪枝参数
)
```

**重要参数详解**：

| 参数 | 作用 | 典型值 |
|------|------|--------|
| `n_estimators` | 森林中树的数量 | 越大性能越好，但训练/预测越慢。常用 100~500 |
| `max_features` | 每个节点随机选取的特征数 | 分类：`'sqrt'`（ $\sqrt{M}$ ）；回归：`'log2'` 或 `M/3` |
| `max_depth` | 单棵树的最大深度 | 默认 None（充分生长），可设 10~30 控制复杂度 |
| `min_samples_split` | 节点分裂最小样本数 | 默认 2，可增大至 5~20 防过拟合 |
| `bootstrap` | 是否使用有放回抽样 | True（随机森林标准做法） |
| `oob_score` | 是否使用袋外数据评估 | True 时可在训练后查看 `oob_score_` |
| `n_jobs` | 并行核心数 | -1 使用全部核心 |

---

### 6.2 回归 API：RandomForestRegressor

参数与分类器基本一致，唯一区别是 `criterion` 默认为 `'squared_error'`（MSE）。

## 第七部分：泰坦尼克号案例（决策树 vs 随机森林）

以下代码演示使用单一决策树和随机森林对泰坦尼克号数据集进行生存预测，并对比两者效果。同时展示使用网格搜索优化随机森林的超参数。

---

### 7.1 数据预处理（同决策树案例）

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV
from sklearn.metrics import accuracy_score, classification_report

# 加载数据
df = pd.read_csv("/data/titanic/train.csv")

# 选择特征
X = df[['Pclass', 'Age', 'Sex']]
y = df['Survived']

# 缺失值处理
X['Age'].fillna(X['Age'].mean(), inplace=True)

# One-hot 编码性别
X = pd.get_dummies(X, columns=['Sex'])

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=33)

print(f"训练集样本数: {X_train.shape[0]}")
print(f"测试集样本数: {X_test.shape[0]}")
```

---

### 7.2 单一决策树训练与评估

```python
# 决策树
dtc = DecisionTreeClassifier(random_state=42)
dtc.fit(X_train, y_train)
dtc_pred = dtc.predict(X_test)
dtc_acc = accuracy_score(y_test, dtc_pred)
print(f"单一决策树准确率: {dtc_acc:.4f}")
```

---

### 7.3 随机森林训练与评估

```python
# 随机森林（设定 max_depth=6 防止过拟合）
rfc = RandomForestClassifier(max_depth=6, random_state=9, n_estimators=50)
rfc.fit(X_train, y_train)
rfc_pred = rfc.predict(X_test)
rfc_acc = accuracy_score(y_test, rfc_pred)
print(f"随机森林准确率: {rfc_acc:.4f}")
```

**预期结果**：随机森林的准确率通常高于单一决策树（例如决策树 75% → 随机森林 80%+）。

---

### 7.4 随机森林 + 网格搜索调优

```python
# 定义参数网格
param_grid = {
    'n_estimators': [40, 50, 60, 70],
    'max_depth': [2, 4, 6, 8, 10],
    'random_state': [9]
}

# 实例化随机森林
rfc_base = RandomForestClassifier()

# 网格搜索（2折交叉验证，可适当增大cv）
grid_search = GridSearchCV(
    estimator=rfc_base,
    param_grid=param_grid,
    cv=2,           # 数据量不大时可用2~5折
    scoring='accuracy',
    n_jobs=-1
)
grid_search.fit(X_train, y_train)

# 最优参数及测试集准确率
print("最佳参数:", grid_search.best_params_)
best_rfc = grid_search.best_estimator_
y_pred = best_rfc.predict(X_test)
final_acc = accuracy_score(y_test, y_pred)
print(f"网格搜索后随机森林准确率: {final_acc:.4f}")

# 查看最佳模型
print("最佳模型:", grid_search.best_estimator_)
```

---

### 7.5 结果分析与对比

| 模型 | 准确率 | 特点 |
|------|--------|------|
| 单一决策树 | ~75% | 简单，易过拟合 |
| 随机森林（默认参数） | ~80% | 泛化能力更强 |
| 随机森林（网格搜索） | ~82% | 通过调参进一步提升 |

### 8.1 集成学习核心思想

| 方法 | 采样方式 | 训练方式 | 投票方式 | 代表算法 |
|------|----------|----------|----------|----------|
| Bagging | 有放回采样（Bootstrap） | 并行 | 平权投票 | 随机森林 |
| Boosting | 全量数据，调整权重 | 串行 | 加权投票 | AdaBoost, GBDT, XGBoost |

### 8.2 随机森林关键点

| 项目 | 内容 |
|------|------|
| **基学习器** | 决策树（通常不剪枝） |
| **数据随机性** | 有放回抽样（Bootstrap） |
| **特征随机性** | 每个节点随机选择部分特征（`max_features`） |
| **预测方式** | 分类：平权投票；回归：平均值 |
| **主要超参数** | `n_estimators`、`max_depth`、`max_features`、`min_samples_split` |
| **是否需标准化** | 不需要（决策树基于比较，非距离） |
| **特征重要性** | 可通过 `model.feature_importances_` 获取 |

### 8.4 练习

**题目 1**：Bagging 是什么意思，下面说法正确的是（）

A 一个精度比较高的分类器  
B 从数据集中随机采样出多个子集，每个子集训练一个弱分类器，然后将这些弱分类器组合成一个强分类器  
C 从特征集中随机选择多个特征，使用这些特征训练一个弱分类器，然后将多个弱分类器组合成一个强分类器  
D 以上都不是  

**正确答案**：**B、C**（B 描述数据随机，C 描述特征随机，都是 Bagging 的变体，但严格意义上 Bagging 主要指数据随机；随机森林同时包含两者）

**题目 2**：请对下列随机森林的构建方法进行排序：  
A）重复采样，构建出多颗决策树

C）如果是分类场景则采用平权投票的方式决定最终随机森林的预测结果，如果是回归场景则采用简单平均法获取最终结果

**正确答案**：**B → A → D → C**
