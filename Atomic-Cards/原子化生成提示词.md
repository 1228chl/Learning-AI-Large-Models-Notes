## 卡片格式要求

每张卡片为一个独立的 Markdown 文件，严格遵循以下模板：

### Frontmatter（YAML 元数据）

```yaml
---
author: "XunZong"
created: "2026-07-06"
tags: ["一级标签", "二级标签", "核心概念"]
aliases: ["别名1", "别名2", "English Term"]
---
```

- `tags`：至少 2 个，第一个为所属模块，第二个为核心概念
- `aliases`：包含中文名和英文术语的别名

### 正文结构

每张卡片应包含以下内容的** 2-4 个**，不必全部包含，按知识点特性选择最合适的：

#### 1. 定义（必备）
用一段严谨但易懂的文字定义该概念，包含其数学形式（若适用）。**必须给出数学公式**（使用 LaTeX，行内用 `$...$`，块级用 `$$...$$`）。

#### 2. 核心公式 / 分类表（若适用）
使用 Markdown 表格列出关键公式、分类或对比信息。表格列包括：名称、公式（LaTeX）、含义/几何意义、ML 应用（若适用）。

#### 3. 直观理解 / 几何意义（若适用）
用一句话或一段话解释该概念的直觉意义，帮助理解而非死记硬背。

#### 4. ML / DL 中的具体出现位置（重要，必选）
以表格或列表形式说明该概念在机器学习和深度学习中的具体应用场景，包括对应的数学形式。例如：

| 应用场景 | 数学形式 | 说明 |
|----------|----------|------|
| Transformer Attention | $\text{softmax}(QK^T/\sqrt{d})V$ | 点积衡量查询与键的匹配程度 |

### 引用链接

每张卡片末尾必须有一行引用，链接到相关的其他原子卡片：

```markdown

```

**规则：**
- 引用的卡片必须写完整的文件名（含编号前缀），如 `[[12-向量范数]]`，不能写成 `[[向量范数]]`
- 引用 2-4 张直接相关的卡片
- 形成一个可双向导航的知识网络

### 格式约束

- **不使用任何图标**（如 ✅、📝、🔗、💡 等）
- **不使用 emoji**
- 使用纯 Markdown 格式：标题（`#` / `##`）、表格、列表、LaTeX 公式
- 代码块使用 ` ``` ` 包裹
- 文件命名规则：`<两位序号>-<概念中文名>.md`，如 `01-向量基础.md`

### LaTeX 在表格中的注意事项

Markdown 表格中，管道符 `|` 会被识别为表格分隔符。LaTeX 公式在表格单元格内部时，必须替换管道符：

| LaTeX 符号 | 表格中的写法 | 含义 |
|------------|-----------|------|
| `\|` | `\Vert` 或 `\lVert` / `\rVert` | 双竖线（范数、条件概率分隔符） |
| `\vert` 或 `\mid` | `\vert` 或 `\mid` | 单竖线（绝对值、集合描述） |
| `{ \| ...}` | 不可用，改用其他表达 | 集合构造式 |

**错误示例**（表格内会断行）：
```latex
$P(A|B)$       ← | 被解析为表格分隔符
$\|x\|$        ← | 被解析为表格分隔符
```

**正确写法**：
```latex
$P(A\vert B)$   ← 表格内条件概率
$\Vert x \Vert$  ← 表格内范数
$\lVert x \rVert$ ← 更清晰的左右区分
```
