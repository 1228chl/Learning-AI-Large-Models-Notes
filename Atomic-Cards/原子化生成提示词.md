## 卡片格式要求

### Frontmatter（YAML 元数据）

```yaml
---
author: "XunZong"
created: "2026-07-06"
tags: ["所属分类", "二级标签", "核心概念"]
aliases: ["中文名", "English Term"]
---
```

- `tags`：至少 2 个，第一个为所属分类，第二个为具体标签
- `aliases`：包含中文名和常用英文术语

### 正文结构

每张卡片选择包含以下 **2-4 个部分**（定义必选）：

#### 1. 定义（必备）

严谨易懂的定义，包含数学形式。**必须有 LaTeX 公式**（行内 `$...$`，块级 `$$...$$`）。

#### 2. 核心公式 / 分类表（若适用）

Markdown 表格列出公式/分类/对比，含名称、公式（LaTeX）、含义/几何意义、应用。

#### 3. 直观理解 / 几何意义（若适用）

一句话解释直觉含义，帮助理解。

#### 4. ML/DL 应用场景（重要，必选）

表格或列表说明概念在 AI 领域的具体出现位置及数学形式：

| 应用场景 | 数学形式 | 说明 |
|----------|----------|------|

### 引用链接

卡片末尾必须有：

```markdown
> 参见 [[01-相关卡片]]、[[02-相关卡片]]
```

**规则**：

- 文件名必须含编号前缀：`[[12-向量范数]]`，不能写成 `[[向量范数]]`
- 引用 **2-4 张** 直接相关的卡片
- 引用目标必须在对应目录下确实存在

### 格式约束

- **不使用图标**（如 ✅、📝、🔗、💡 等）和 **emoji**
- 纯 Markdown：标题 `#`/`##`、表格、列表、LaTeX 公式
- Python 代码块用 ` ```python ` 包裹
- 文件名：`<两位序号>-<概念名>.md`

### LaTeX 在表格中的注意事项

表格内的 LaTeX 禁止使用 `|` 管道符：

| 场景   | 错误          | 正确                |     |     |           |                   |
| ---- | ----------- | ----------------- | --- | --- | --------- | ----------------- |
| 范数 ` |             | x                 |     | `   | `$\|x\|$` | `$\Vert x \Vert$` |
| 条件概率 | `$P(A\|B)$` | `$P(A\vert B)$`   |     |     |           |                   |
| 绝对值  | `$\|x\|$`   | `$\vert x \vert$` |     |     |           |                   |

### 面试问答（可选补充）

每张卡片可在末尾附加面试问答板块，用于应对技术面试中的层层追问。格式：

```markdown
> **面试追问**
>
> Q1（基础）：[核心概念的理解]
> 回答要点：...
>
> Q2（深挖）：[原理/优缺点/对比]
> 回答要点：...
>
> Q3（实战）：[项目中的应用场景]
> 回答要点：...
>
> Q4（边界）：[极端情况/失效场景/优化方向]
> 回答要点：...
```

问答以 Q1-Q4 由浅入深排列，每题附简洁回答要点，不展开长篇论述。

## 输出要求

1. 如果知识点属于已有分类 → 写入对应目录，编号为当前最大编号 + 1
2. 如果知识点属于全新分类 → 新建目录，从 01 开始编号
3. 生成完成后，执行一次引用断链检查：所有 `[[xx-名称]]` 必须能找到同名文件
4. 多张卡片可并行写入，但注意引用链完整性
