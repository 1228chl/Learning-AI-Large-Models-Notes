# 链表

## 定义

链表（Linked List）是一种线性数据结构，元素存储在**分散的内存节点**中，每个节点包含**数据**和指向下一节点的**指针**。通过指针将节点串联起来，链表的长度可以动态变化。

## 三种类型

```python
# 单向链表节点
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# 双向链表节点
class DoublyListNode:
    def __init__(self, val=0, prev=None, next=None):
        self.val = val
        self.prev = prev
        self.next = next
```

| 类型 | 指针方向 | 特点 |
|------|----------|------|
| **单向链表** | 每个节点指向下一个 | 最简结构，只能单向遍历 |
| **双向链表** | 每个节点指向前后 | 可双向遍历，删除更灵活 |
| **循环链表** | 尾节点指向头节点 | 环形结构，适合轮询 |

## 核心操作复杂度

| 操作 | 数组 | 单向链表 |
|------|:----:|:--------:|
| **随机访问** | $O(1)$ | $O(n)$ |
| **头部插入** | $O(n)$ | $O(1)$ |
| **头部删除** | $O(n)$ | $O(1)$ |
| **尾部插入（有尾指针）** | $O(1)$ | $O(1)$ |
| **已知节点后插入** | $O(n)$ | $O(1)$ |
| **查找值** | $O(n)$ | $O(n)$ |

```python
# 构建链表 1 → 2 → 3
node3 = ListNode(3)
node2 = ListNode(2, node3)
head = ListNode(1, node2)

# 头插 O(1)
new_head = ListNode(0, head)

# 遍历 O(n)
cur = head
while cur:
    print(cur.val)
    cur = cur.next
```

## 链表的变体应用

| 变体 | 结构 | 典型用途 |
|------|------|----------|
| **跳表（Skip List）** | 多层链表索引 | Redis Sorted Set 底层实现 |
| **LRU 缓存** | 双向链表 + 哈希表 | 最近最少使用淘汰策略 |
| **邻接表** | 数组 + 链表 | 图的稀疏存储 |

## ML 中的链表

原生 ML 计算（矩阵乘法、卷积）中链表使用较少（因内存不连续不利 GPU 计算），但在以下场景发挥作用：

| 场景 | 使用方式 |
|------|----------|
| **稀疏矩阵** | 每个节点的非零元素链接起来 |
| **计算图（Graph）** | 节点间的前驱/后继关系 |
| **Transformer 中间变量** | 计算图中的梯度传播路径 |
| **数据流水线** | 生产者-消费者队列结构 |
