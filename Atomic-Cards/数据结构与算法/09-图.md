# 图

## 定义

图（Graph）由**顶点（Vertex）** 和**边（Edge）** 组成 $G = (V, E)$。图是最灵活的数据结构，树、链表都是图的特例。

| 分类 | 定义 | 示例 |
|------|------|------|
| **有向图 vs 无向图** | 边是否有方向 | 单向关注 / 好友关系 |
| **有权图 vs 无权图** | 边是否有权重 | 距离 / 社交连接 |
| **连通图 vs 非连通图** | 是否任意两点可达 | 网络图 / 孤立聚类 |
| **稀疏图 vs 稠密图** | 边数远小于/接近完全图 | 社交网络 / 电路图 |

## 存储方式

```python
# 1. 邻接矩阵（适合稠密图）
graph = [[0, 1, 1],
         [1, 0, 0],
         [1, 0, 0]]
# 查询边：O(1)，空间：O(V²)

# 2. 邻接表（适合稀疏图，更常用）
graph = {
    'A': ['B', 'C'],
    'B': ['A'],
    'C': ['A'],
}
# 查询边：O(度)，空间：O(V + E)
```

| 对比 | 邻接矩阵 | 邻接表 |
|------|:--------:|:------:|
| 查询边 | $O(1)$ | $O(\deg(v))$ |
| 遍历所有邻边 | $O(V)$ | $O(\deg(v))$ |
| 空间 | $O(V^2)$ | $O(V+E)$ |
| 适用 | 稠密图 | 稀疏图（实际更常见） |

## 图的遍历

```python
# DFS（栈/递归）— 深入到底再回溯
def dfs(graph, node, visited=set()):
    if node in visited: return
    visited.add(node)
    print(node)
    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)

# BFS（队列）— 层层推进
from collections import deque
def bfs(graph, start):
    visited = {start}
    q = deque([start])
    while q:
        node = q.popleft()
        print(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                q.append(neighbor)
```

## 最短路径算法

| 算法 | 适用 | 时间复杂度 | 说明 |
|------|------|:----------:|------|
| **Dijkstra** | 非负权图 | $O((V+E)\log V)$ | 单源最短路径（堆优化） |
| **Bellman-Ford** | 任意权图（可检测负环） | $O(VE)$ | DP 思想 |
| **Floyd-Warshall** | 所有点对 | $O(V^3)$ | DP 动态规划 |
| **A\*** | 有启发信息 | 优于 Dijkstra | 地图导航 |
