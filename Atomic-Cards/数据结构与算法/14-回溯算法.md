# 回溯算法

## 定义

回溯算法（Backtracking）是一种通过**遍历所有可能的候选解**来寻找所有解的算法。当发现当前候选解不可能是有效解时，就**回溯**（撤销选择）尝试其他可能。本质是**深度优先搜索（DFS）+ 剪枝**。

参考：[Hello 算法 第13章](https://www.hello-algo.com/chapter_backtracking/)

## 通用框架

```python
def backtrack(state, choices, res):
    """回溯算法框架"""
    # 判断是否为解
    if is_solution(state):
        record_solution(state, res)   # 记录解
        return
    # 遍历所有选择
    for choice in choices:
        # 剪枝：判断选择是否合法
        if is_valid(state, choice):
            # 尝试：做出选择，更新状态
            make_choice(state, choice)
            backtrack(state, choices, res)  # 递归
            # 回退：撤销选择，恢复到之前的状态
            undo_choice(state, choice)
```

## 全排列

```python
# 无重复元素的全排列
def permutations_i(nums):
    n = len(nums)
    res = []
    selected = [False] * n

    def backtrack(state):
        if len(state) == n:
            res.append(state[:])      # 深拷贝
            return
        for i, choice in enumerate(nums):
            if not selected[i]:       # 剪枝：不重复选元素
                selected[i] = True
                state.append(choice)
                backtrack(state)
                selected[i] = False   # 回退
                state.pop()

    backtrack([])
    return res

# 含重复元素的排列（额外用 duplicated set 剪枝）
def permutations_ii(nums):
    n = len(nums)
    res = []
    selected = [False] * n

    def backtrack(state):
        if len(state) == n:
            res.append(state[:])
            return
        duplicated = set()
        for i, choice in enumerate(nums):
            if not selected[i] and choice not in duplicated:
                duplicated.add(choice)   # 同层相同值剪枝
                selected[i] = True
                state.append(choice)
                backtrack(state)
                selected[i] = False
                state.pop()

    backtrack([])
    return res
```

## 子集与组合

```python
# 子集（元素不可重复选取）
def subsets(nums):
    res = []
    def backtrack(start, state):
        res.append(state[:])           # 记录所有中间状态
        for i in range(start, len(nums)):
            state.append(nums[i])
            backtrack(i + 1, state)    # i+1 保证不重复取
            state.pop()
    backtrack(0, [])
    return res

# 组合 C(n, k)
def combine(n, k):
    res = []
    def backtrack(start, path):
        if len(path) == k:
            res.append(path[:])
            return
        # 剪枝：剩余元素不够时提前结束
        for i in range(start, n - (k - len(path)) + 2):
            path.append(i)
            backtrack(i + 1, path)
            path.pop()
    backtrack(1, [])
    return res
```

## N 皇后

```python
def n_queens(n):
    state = [['#' for _ in range(n)] for _ in range(n)]
    cols = [False] * n               # 列冲突
    diags1 = [False] * (2 * n - 1)   # 主对角线冲突（row - col + n - 1）
    diags2 = [False] * (2 * n - 1)   # 副对角线冲突（row + col）
    res = []

    def backtrack(row):
        if row == n:
            res.append([list(r) for r in state])
            return
        for col in range(n):
            d1 = row - col + n - 1
            d2 = row + col
            if not cols[col] and not diags1[d1] and not diags2[d2]:
                state[row][col] = 'Q'
                cols[col] = diags1[d1] = diags2[d2] = True
                backtrack(row + 1)
                state[row][col] = '#'
                cols[col] = diags1[d1] = diags2[d2] = False

    backtrack(0)
    return res
```

## 回溯问题对比

| 问题 | 剪枝策略 | 状态空间 | 典型复杂度 |
|------|----------|----------|:----------:|
| 全排列（无重复） | `selected[]` 避免重复选元素 | $n!$ | $O(n! \cdot n)$ |
| 全排列（有重复） | `selected[]` + 同层 `duplicated` set | $\frac{n!}{m!}$ | $O(n! \cdot n)$ |
| 子集 | `start` 控制遍历起点 | $2^n$ | $O(2^n)$ |
| 组合 C(n,k) | `start` + 剩余元素数剪枝 | $C(n,k)$ | $O(C(n,k))$ |
| N 皇后 | `cols[]` + `diags1[]` + `diags2[]$` | $n^n$ → 剪枝后 $O(n!)$ | $O(n!)$ |
