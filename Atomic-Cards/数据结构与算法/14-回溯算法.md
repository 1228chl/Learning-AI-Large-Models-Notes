# 回溯算法

## 定义

回溯算法（Backtracking）是一种通过**遍历所有可能的候选解**来寻找所有解的算法。当发现当前候选解不可能是有效解时，就**回溯**（撤销选择）尝试其他可能。本质是**深度优先搜索（DFS）+ 剪枝**。

参考：[Hello 算法 第13章](https://www.hello-algo.com/chapter_backtracking/)

## 通用框架

```python
def backtrack(state, choices, res):
    """回溯算法框架：通过递归遍历所有可能的选择，寻找问题的所有解"""
    # 判断是否为解
    if is_solution(state):               # 检查当前状态是否满足题目的解条件
        record_solution(state, res)      # 若满足则记录当前解
        return                           # 记录后停止当前分支，回溯到上一层继续搜索
    # 遍历所有选择
    for choice in choices:               # 在当前状态下枚举所有可用的候选选择
        # 剪枝：判断选择是否合法
        if is_valid(state, choice):      # 提前排除不合法分支，大幅减少无效搜索
            # 尝试：做出选择，更新状态
            make_choice(state, choice)   # 选择当前候选，将问题推进到新状态
            backtrack(state, choices, res)  # 递归：在新状态下继续深入搜索下一层
            # 回退：撤销选择，恢复到之前的状态
            undo_choice(state, choice)   # 撤销选择使状态还原，以便尝试下一个候选
```

## 全排列

```python
# 无重复元素的全排列
def permutations_i(nums):

    n = len(nums)                             # 数组长度，即排列的元素总数

    res = []                                  # 存储所有排列结果

    selected = [False] * n                    # 标记每个元素是否已被选取，避免同一元素被重复使用

    def backtrack(state):

        if len(state) == n:                   # 已选够所有元素，得到一个完整排列
            res.append(state[:])              # 深拷贝当前排列并记录，避免后续修改影响已存结果
            return
        for i, choice in enumerate(nums):     # 遍历所有候选元素
            if not selected[i]:               # 剪枝：跳过已选元素，保证每个元素在排列中只出现一次

                selected[i] = True            # 尝试：标记当前元素为已选状态
                state.append(choice)          # 将元素加入当前排列
                backtrack(state)              # 递归：基于当前排列继续选取下一个位置的元素

                selected[i] = False           # 回退：取消标记，恢复元素可用状态
                state.pop()                   # 回退：移除刚加入的元素，还原状态尝试其他排列

    backtrack([])                             # 从空排列开始递归构建
    return res

# 含重复元素的排列（额外用 duplicated set 剪枝）
def permutations_ii(nums):

    n = len(nums)                             # 数组长度

    res = []                                  # 存储所有排列结果

    selected = [False] * n                    # 标记每个元素是否已被选取

    def backtrack(state):

        if len(state) == n:                   # 所有元素已选完，得到一个完整排列
            res.append(state[:])
            return

        duplicated = set()                    # 记录当前递归层已用过的值，同层相同值只取一次
        for i, choice in enumerate(nums):
            if not selected[i] and choice not in duplicated:
                duplicated.add(choice)        # 剪枝：同一深度下相同值只取第一个，避免生成重复排列

                selected[i] = True            # 尝试：标记元素为已选
                state.append(choice)          # 加入当前排列
                backtrack(state)              # 递归：继续选取下一个位置的元素

                selected[i] = False           # 回退：恢复元素可用状态
                state.pop()                   # 回退：移除刚加入的元素

    backtrack([])
    return res
```

## 子集与组合

```python
# 子集（元素不可重复选取）
def subsets(nums):

    res = []                                 # 存储所有子集
    def backtrack(start, state):             # start控制遍历起点，防止回头重复选取
        res.append(state[:])                 # 记录当前子集（包含空集和所有中间状态）
        for i in range(start, len(nums)):    # 从start开始，避免之前元素被重复选取
            state.append(nums[i])            # 尝试：将当前元素加入子集
            backtrack(i + 1, state)          # 递归：i+1保证后续只取后面元素，组合不重复
            state.pop()                      # 回退：移除当前元素，尝试下一个候选
    backtrack(0, [])                         # 从空集和索引0开始构建
    return res

# 组合 C(n, k)
def combine(n, k):

    res = []                                 # 存储所有组合结果
    def backtrack(start, path):

        if len(path) == k:                   # 已选够k个元素，得到一个完整组合
            res.append(path[:])
            return
        # 剪枝：剩余元素不够时提前结束，减少无效递归
        for i in range(start, n - (k - len(path)) + 2):  # 确保剩余元素充足
            path.append(i)                   # 尝试：将当前数字加入组合
            backtrack(i + 1, path)           # 递归：下一个从i+1开始，防止重复
            path.pop()                       # 回退：移除当前数字，尝试下一个候选
    backtrack(1, [])                         # 从1开始选取（题目范围1到n）
    return res
```

## N 皇后

```python
def n_queens(n):
    # 初始化n×n棋盘，'#'表示空位，'Q'表示皇后
    state = [['#' for _ in range(n)] for _ in range(n)]

    cols = [False] * n                     # 列冲突检测：cols[c]为True表示第c列已有皇后

    diags1 = [False] * (2 * n - 1)         # 主对角线冲突：row-col为常数，加n-1映射到非负索引

    diags2 = [False] * (2 * n - 1)         # 副对角线冲突：row+col为常数

    res = []                               # 存储所有合法的棋盘布局

    def backtrack(row):                    # 按行逐层放置皇后

        if row == n:                       # 所有行都成功放置，找到一个合法解
            res.append([list(r) for r in state])  # 深拷贝当前棋盘并记录
            return
        for col in range(n):               # 尝试当前行的每一列

            d1 = row - col + n - 1         # 计算主对角线编号（row-col为常数，偏移保证非负）

            d2 = row + col                 # 计算副对角线编号（row+col为常数）
            if not cols[col] and not diags1[d1] and not diags2[d2]:

                state[row][col] = 'Q'      # 尝试：在(row, col)放置皇后

                cols[col] = diags1[d1] = diags2[d2] = True  # 标记列和对角线为占用
                backtrack(row + 1)         # 递归：继续放置下一行皇后

                state[row][col] = '#'      # 回退：移除皇后

                cols[col] = diags1[d1] = diags2[d2] = False  # 回退：解除占用标记，尝试下一列

    backtrack(0)                           # 从第0行开始放置
    return res
```

## 回溯问题对比

| 问题 | 剪枝策略 | 状态空间 | 典型复杂度 |
|------|----------|----------|:----------:|
| 全排列（无重复） | `selected[]` 避免重复选元素 | $n!$ | $O(n! \cdot n)$ |
| 全排列（有重复） | `selected[]` + 同层 `duplicated` set | $\frac{n!}{m!}$（$m$ 为重复元素个数） | $O(n! \cdot n)$ |
| 子集 | `start` 控制遍历起点 | $2^n$ | $O(2^n)$ |
| 组合 C(n,k) | `start` + 剩余元素数剪枝 | $C(n,k)$ | $O(C(n,k))$ |
| N 皇后 | `cols[]` + `diags1[]` + `diags2[]$` | $n^n$ → 剪枝后 $O(n!)$ | $O(n!)$ |

## 面试追问

**Q1（基础）**：回溯算法的"选择→递归→撤销"三段式框架中，每一步的作用是什么？为什么撤销（undo）这一步必不可少？
**回答要点**：

1. 选择——在当前状态尝试一种候选，更新状态；递归——基于新状态继续搜索下一层；撤销——恢复状态到选择前的样子，以便尝试下一个候选。
2. 撤销必不可少：若不撤销，状态会被"污染"，后续分支的搜索基于错误的中间状态，导致解遗漏或无效。
3. 这正体现了"回溯"的核心——试探后回退。

**Q2（深挖）**：回溯和动态规划都能解决组合优化问题，两者的本质区别是什么？什么情况下回溯会被 DP 取代？
**回答要点**：

1. 回溯是"遍历所有可能解"（暴力搜索 + 剪枝），DP 是"最优子问题递推"（缓存子问题解）。
2. 回溯不依赖最优子结构，适用于求所有解或只需一个解的场景；DP 要求最优子结构，只适用于求最优解。
3. 当问题有重叠子问题且只需求最优值时，DP 指数级快于回溯（如 01 背包：回溯 O(2^n)，DP O(nW)）。

**Q3（实战）**：N 皇后问题中如何用三个数组（cols、diags1、diags2）实现 O(1) 的冲突判断？每条对角线如何用行、列坐标唯一标记？
**回答要点**：

1. cols[col] 标记列是否被占；diags1[row - col + n - 1] 标记主对角线（行减列为常数，加 n-1 保证非负下标）；diags2[row + col] 标记副对角线（行加列为常数）。
2. 每次放置皇后时 O(1) 检查三个数组，放置后更新，回溯时恢复。
3. 这种用空间换时间的方式将冲突判断从 O(n) 降为 O(1)。

**Q4（边界）**：回溯算法面临"组合爆炸"时（如大规模数独、复杂排班），有哪些加速策略？什么时候应放弃精确解？
**回答要点**：

1. 核心加速策略包括：强剪枝（约束传播、前向检查，提前排除无效分支）。
2. 启发式搜索（优先探索可能性最少的分支——最小剩余值启发式）；对称性破缺（避免等价解重复搜索）；并行搜索。
3. 当问题规模大到即使强剪枝也无法在可接受时间内求解时（如大规模 TSP），应放弃精确回溯，改用近似算法（贪心、局部搜索、模拟退火、遗传算法）来获取足够好的可行解。
