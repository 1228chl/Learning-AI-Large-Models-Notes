# 动态规划

## 定义

动态规划（Dynamic Programming, DP）是一种解决**多阶段决策问题**的方法。核心思想：将复杂问题分解为重叠子问题，通过**记忆化**（Memorization）或**填表**（Tabulation）避免重复计算。

## DP 问题的两个关键特征

| 特征 | 含义 | 例子 |
|------|------|------|
| **最优子结构**（Optimal Substructure） | 问题的最优解包含子问题的最优解 | 最短路径的子路径也是最短路 |
| **重叠子问题**（Overlapping Subproblems） | 不同决策路径会重复遇到相同子问题 | 斐波那契数列 |

## DP 解题四步法

```python
# 1. 定义状态（DP 数组的含义）
# 2. 确定递推关系（状态转移方程）
# 3. 初始化（边界条件）
# 4. 确定遍历顺序

# 示例：爬楼梯（每次爬 1 或 2 阶，到 n 阶有几种方法）
def climb_stairs(n):
    if n <= 2: return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2           # 初始化
    for i in range(3, n + 1):     # 遍历顺序
        dp[i] = dp[i-1] + dp[i-2] # 状态转移
    return dp[n]
```

## 常见 DP 类型

| 类型 | 状态定义 | 经典题目 |
|------|----------|----------|
| **线性 DP** | `dp[i]` 表示前 i 个元素的最优解 | 最长递增子序列、最大子数组和 |
| **区间 DP** | `dp[i][j]` 表示区间 [i, j] 的最优解 | 矩阵链乘、回文子串 |
| **背包 DP** | `dp[i][w]` 表示前 i 个物品容量 w 的最大价值 | 01 背包、完全背包 |
| **树形 DP** | `dp[node]` 表示以 node 为根的子树 | 二叉树最大路径和 |
| **状态压缩 DP** | 用 bitmask 表示状态 | 旅行商问题、集合覆盖 |

## 典型问题：01 背包

```python
# 有 W 容量，n 个物品（重量 wt[i]，价值 val[i]），求最大价值
def knapsack(W, wt, val):
    n = len(wt)
    dp = [[0] * (W + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(1, W + 1):
            if wt[i-1] > w:
                dp[i][w] = dp[i-1][w]            # 装不下
            else:
                dp[i][w] = max(
                    dp[i-1][w],                              # 不装
                    dp[i-1][w - wt[i-1]] + val[i-1]          # 装
                )
    return dp[n][W]
```

## ML 中的 DP 思想

| 场景 | DP 体现 |
|------|----------|
| **Beam Search** | 局部束 DP：每一步保留 K 个最优路径 |

| **BiLSTM-CRF** | 命名实体识别的序列标注 |
