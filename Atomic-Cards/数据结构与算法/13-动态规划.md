# 动态规划

## 定义

动态规划（Dynamic Programming, DP）是一种解决**多阶段决策问题**的方法。核心思想：将复杂问题分解为重叠子问题，通过**记忆化**（Memorization）或**填表**（Tabulation）避免重复计算。

## DP 问题的两个关键特征

| 特征 | 含义 | 例子 |
|------|------|------|
| **最优子结构**（Optimal Substructure） | 问题的最优解包含子问题的最优解 | 最短路径的子路径也是最短路 |
| **重叠子问题**（Overlapping Subproblems） | 不同决策路径会重复遇到相同子问题 | 斐波那契数列 |

## DP 解题四步法

```python
# 1. 定义状态（DP 数组的含义）
# 2. 确定递推关系（状态转移方程）
# 3. 初始化（边界条件）
# 4. 确定遍历顺序

# 示例：爬楼梯（每次爬 1 或 2 阶，到 n 阶有几种方法）
def climb_stairs(n):
    if n <= 2: return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2           # 初始化
    for i in range(3, n + 1):     # 遍历顺序
        dp[i] = dp[i-1] + dp[i-2] # 状态转移
    return dp[n]
```

## 常见 DP 类型

| 类型 | 状态定义 | 经典题目 |
|------|----------|----------|
| **线性 DP** | `dp[i]` 表示前 i 个元素的最优解 | 最长递增子序列、最大子数组和 |
| **区间 DP** | `dp[i][j]` 表示区间 [i, j] 的最优解 | 矩阵链乘、回文子串 |
| **背包 DP** | `dp[i][w]` 表示前 i 个物品容量 w 的最大价值 | 01 背包、完全背包 |
| **树形 DP** | `dp[node]` 表示以 node 为根的子树 | 二叉树最大路径和 |
| **状态压缩 DP** | 用 bitmask 表示状态 | 旅行商问题、集合覆盖 |

## 典型问题：01 背包

```python
# 有 W 容量，n 个物品（重量 wt[i]，价值 val[i]），求最大价值
def knapsack(W, wt, val):
    n = len(wt)
    dp = [[0] * (W + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(1, W + 1):
            if wt[i-1] > w:
                dp[i][w] = dp[i-1][w]            # 装不下
            else:
                dp[i][w] = max(
                    dp[i-1][w],                              # 不装
                    dp[i-1][w - wt[i-1]] + val[i-1]          # 装
                )
    return dp[n][W]
```

## 面试追问

**Q1（基础）**：DP 的两个关键特征——最优子结构和重叠子问题——分别是什么意思？斐波那契数列满足这两个特征吗？

**回答要点**：最优子结构指问题的最优解可以由子问题的最优解推导出来（如最长递增子序列的 dp[i] 由前面所有 dp[j] 决定）；重叠子问题指不同路径会重复遇到相同的子问题（如 fib(5) 需要 fib(4) 和 fib(3)，而 fib(4) 又需要 fib(3) 和 fib(2)，fib(3) 被重复计算）。斐波那契数列满足两个特征，因此可用 DP 优化。

**Q2（深挖）**：DP 的"状态定义"为什么是最关键的一步？同一个问题（如最长递增子序列）如果状态定义不同，复杂度可能差多少？

**回答要点**：状态定义决定了转移方程的复杂度和最终解法维度。LIS 若定义 dp[i] = 以 nums[i] 结尾的 LIS 长度，则需遍历前面所有小于 nums[i] 的位置， $O(n^2)$ ；若定义 dp[i] = 长度为 i 的递增子序列的最小末尾值，配合二分查找可将复杂度降为 $O(n\log n)$ 。状态定义是从问题到解法的桥染，好的状态定义让转移自然高效。

**Q3（实战）**：01 背包问题的状态转移方程 `dp[i][w] = max(dp[i-1][w], dp[i-1][w-wt[i-1]] + val[i-1])` 各部分的含义是什么？空间如何优化为一维数组？

**回答要点**：dp[i][w] 表示前 i 个物品在容量 w 下的最大价值。对第 i 个物品有两种选择：不装（继承 dp[i-1][w]）或装（价值为 dp[i-1][w-wt[i-1]] + val[i-1]），取最大值。优化为一维 dp[w] 时需要倒序遍历 w 确保每个物品只选一次（否则正序会覆盖上一行数据导致重复选取）。

**Q4（边界）**：DP 在什么情况下不是最优解法？你会如何判断一个问题是否适合用 DP 求解？

**回答要点**：如果子问题不重叠（如二分查找、快排的分治），DP 对比递归没有优势（记忆化徒增空间）；如果最优子结构不成立（如最长简单路径在图中），DP 无效。判断方法：① 是否可分解为子问题且子问题最优可组合为原问题最优；② 不同路径是否共享子问题；③ 问题规模是否在可接受范围内（状态数量是否爆炸）。若状态空间过大（如 TSP 的状态压缩 DP 中 $2^n$ 种状态），需考虑近似或贪心。
