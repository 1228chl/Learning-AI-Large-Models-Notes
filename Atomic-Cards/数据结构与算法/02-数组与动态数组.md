# 数组与动态数组

## 定义

数组（Array）是一种线性数据结构，将相同类型的元素存储在**连续的内存空间**中。通过**索引**（Index）可以在 $O(1)$ 时间内随机访问任意元素。

**动态数组**（如 Python 的 `list`、C++ 的 `vector`）在底层仍是连续数组，但在容量不足时自动**扩容**（通常倍增）。

## 核心操作复杂度

| 操作 | 数组 | 动态数组（均摊） | 说明 |
|------|:----:|:----------------:|------|
| **随机访问** | $O(1)$ | $O(1)$ | 连续内存 + 索引计算 |
| **插入（末尾）** | — | $O(1)$ | 通常 $O(1)$，扩容时 $O(n)$ |
| **插入（中间/头部）** | $O(n)$ | $O(n)$ | 后续元素需要后移 |
| **删除（末尾）** | — | $O(1)$ | 直接减少 size |
| **删除（中间/头部）** | $O(n)$ | $O(n)$ | 后续元素需要前移 |
| **查找** | $O(n)$ | $O(n)$ | 线性扫描（无序时） |

## Python 示例

```python
# 静态数组（初始化固定长度）
arr = [0] * 5                          # [0, 0, 0, 0, 0]

# 动态数组（自动扩容）
nums = [1, 2, 3]
nums.append(4)                         # 末尾 O(1)
nums.insert(0, 0)                      # 头部 O(n)
nums.pop()                             # 末尾删除 O(1)
nums.pop(0)                            # 头部删除 O(n)

# 随机访问 O(1)
x = nums[2]
```

## 数组 vs 链表

| 对比 | 数组 | 链表 |
|------|:----:|:----:|
| 内存 | **连续** | 分散 |
| 随机访问 | $O(1)$ | $O(n)$ |
| 插入/删除 | $O(n)$ | $O(1)$（已知位置） |
| 缓存友好 | ✅ 高（空间局部性） | ❌ 低 |
| 内存开销 | 低 | 高（额外指针） |

## ML 中的数组

| 场景 | 形式 |
|------|------|
| **特征矩阵** | `X.shape = (n_samples, n_features)` — 二维数组 |
| **图像张量** | `img.shape = (H, W, C)` — 三维数组 |
| **权重参数** | `W.shape = (d_in, d_out)` — 矩阵连续存储 |
| **批量数据** | `DataLoader` 返回的 tensor 基于连续内存 |
| **GPU 加速** | GPU 对连续内存访问有极致优化（合并访问） |

> NumPy 的 `ndarray` 和 PyTorch 的 `Tensor` 底层都是连续数组，配合 SIMD 和 GPU 实现高性能计算。
