# 搜索算法

## 二分查找（Binary Search）

在**有序数组**中查找目标值，每次将搜索范围缩小一半：

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

| 性质 | 值 |
|------|:--:|
| 时间复杂度 | $O(\log n)$ |
| 空间复杂度（迭代） | $O(1)$ |
| 空间复杂度（递归） | $O(\log n)$ |
| 前提条件 | 数组必须有序 |

**变种**：查找左边界、右边界、最接近目标值的元素。

## 线性搜索（Linear Search）

```python
def linear_search(nums, target):
    for i, v in enumerate(nums):
        if v == target:
            return i
    return -1
```

时间复杂度：$O(n)$，空间复杂度：$O(1)$。适用于**无序数据**或**小规模数据**。

## 搜索算法对比

| 算法 | 前提 | 时间复杂度 | 空间复杂度 | 应用 |
|------|------|:----------:|:----------:|------|
| **线性搜索** | 无 | $O(n)$ | $O(1)$ | 无序小数据集 |
| **二分搜索** | 有序数组 | $O(\log n)$ | $O(1)$ | 有序数据查找 |
| **哈希查找** | 键的映射 | $O(1)$ | $O(n)$ | 精确等值查询 |
| **二叉搜索树** | 有序树 | $O(\log n)$ | $O(n)$ | 动态数据查找 |
| **跳表查找** | 有序多层索引 | $O(\log n)$ | $O(n\log n)$ | Redis Sorted Set |
