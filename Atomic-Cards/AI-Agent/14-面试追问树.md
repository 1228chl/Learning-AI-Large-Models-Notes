# 面试追问树

## 定义

面试追问树从核心知识点出发，沿**深度和广度**展开追问链路，帮助构建完整的知识体系并应对面试中的层层深入提问。

## RNN 追问树

```
RNN 是什么？
  ├─ 为什么 RNN 适合序列数据？
  │   └─ 参数共享、循环连接
  ├─ RNN 有什么局限？
  │   ├─ 梯度消失 → 为什么？(连乘 < 1)
  │   │   └─ 如何解决？→ LSTM（门控机制）
  │   └─ 梯度爆炸 → 如何解决？→ 梯度裁剪
  ├─ LSTM 比 RNN 好在哪里？
  │   ├─ 遗忘/输入/输出门
  │   └─ 细胞状态（加法梯度流）
  ├─ GRU 和 LSTM 的区别？
  │   └─ 参数更少，效果相当
  └─ 现在为什么不用 RNN 了？
      └─ Transformer 并行 + 长距离
```

## Transformer 追问树

```
Transformer 的核心创新？
  ├─ 自注意力是什么？
  │   ├─ Q, K, V 分别是啥？
  │   ├─ 为什么要除以 √dₖ？→ 防止 softmax 饱和
  │   └─ 多头注意力的作用？→ 多种关系模式
  ├─ 为什么需要位置编码？
  │   ├─ 自注意力是排列不变的
  │   └─ Sinusoidal vs RoPE 的区别？
  ├─ 为什么用 LayerNorm 不用 BatchNorm？
  │   └─ 序列变长、不依赖 batch
  ├─ 残差连接的作用？
  │   └─ 梯度直通、深层训练
  └─ Transformer 计算复杂度？
      └─ O(n²·d) → 长序列怎么优化？→ Flash Attention / 稀疏注意力
```

## BERT vs GPT 追问树

```
BERT 和 GPT 的区别？
  ├─ 架构：编码器 vs 解码器
  ├─ 注意力：双向 vs 掩码自注意力
  ├─ 训练任务：MLM vs 下一个词预测
  ├─ 适合：理解 vs 生成
  ├─ 为什么 GPT 能 zero-shot？→ 自回归 = 语言模型
  └─ 为什么 BERT 微调效果好？→ 双向编码 = 更丰富表示
```

## ML 基础追问树

```
过拟合是什么？如何解决？
  ├─ 原因：模型太复杂 / 数据太少 / 噪声
  ├─ 诊断：训练误差低，验证误差高
  ├─ 解决：
  │   ├─ 增加数据 / 数据增强
  │   ├─ 降低模型复杂度
  │   ├─ 正则化（L1/L2/Dropout）
  │   └─ 早停（Early Stopping）
  └─ 欠拟合是什么？→ 模型太简单
```

## 面试准备建议

| 层级 | 准备重点 | 常见问题 |
|:----:|:--------|:--------|
| **基础** | 概念清晰，公式能写 | "什么是梯度消失？" |
| **深入** | 比优劣，说为什么 | "为什么用 ReLU 不用 Sigmoid？" |
| **实战** | 结合项目和场景 | "你怎么解决数据不平衡？" |
| **前沿** | 关注最新进展 | "LLaMA 用了什么技巧？" |
