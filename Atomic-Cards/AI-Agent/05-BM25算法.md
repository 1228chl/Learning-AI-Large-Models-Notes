# BM25 算法

## 定义

BM25（Best Matching 25）是一种**稀疏检索**算法，基于**词袋模型**和**TF-IDF**改进而来。它计算查询与文档之间的相关性分数，是 RAG 系统中与稠密向量检索互补的经典方法。

**核心公式**：

$$\text{Score}(Q, D) = \sum_{i=1}^n \text{IDF}(q_i) \cdot \frac{f(q_i, D) \cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot (1 - b + b \cdot \frac{|D|}{\text{avgdl}})}$$

其中：
- $f(q_i, D)$：词 $q_i$ 在文档 $D$ 中的频率
- $|D|$：文档长度；$\text{avgdl}$：平均文档长度
- $k_1$：控制词频饱和（默认 1.2~2.0）
- $b$：控制长度归一化（默认 0.75）

## BM25 vs TF-IDF

| 对比 | TF-IDF | BM25 |
|:----:|:------|:----|
| **词频影响** | 线性增长 | **非线性饱和**（$k_1$ 控制） |
| **文档长度** | 不考虑 | 考虑（$b$ 控制） |
| **长文档惩罚** | ❌ 不惩罚，越长 TF 越高 | ✅ 合理惩罚长文档 |
| **效果** | 基准 | **更好，业界标准** |

## Python 实现

```python
import math
from collections import Counter
import jieba

class BM25:
    def __init__(self, documents, k1=1.5, b=0.75):
        self.documents = documents
        self.k1 = k1
        self.b = b
        self.avgdl = sum(len(doc) for doc in documents) / len(documents)
        self.doc_freqs = [Counter(doc) for doc in documents]
        self.idf = self._compute_idf()

    def _compute_idf(self):
        n_docs = len(self.documents)
        idf = {}
        for doc in self.doc_freqs:
            for word in doc:
                idf[word] = idf.get(word, 0) + 1
        return {word: math.log(1 + (n_docs - freq + 0.5) / (freq + 0.5))
                for word, freq in idf.items()}

    def score(self, query, doc_idx):
        score = 0
        doc_len = len(self.documents[doc_idx])
        for q in query:
            if q in self.idf:
                f = self.doc_freqs[doc_idx].get(q, 0)
                score += self.idf[q] * (f * (self.k1 + 1)) / (
                    f + self.k1 * (1 - self.b + self.b * doc_len / self.avgdl)
                )
        return score
```

## BM25 参数调优

| 参数 | 作用 | 调高 | 调低 |
|:----:|:----|:----|:----|
| $k_1$ | 词频饱和速度 | 高估高频词重要性 | 忽略高频词 |
| $b$ | 文档长度惩罚 | 更偏向短文档 | 不惩罚长文档 |
| 默认 | $k_1 = 1.2 \sim 2.0$，$b = 0.75$ | — | — |

| 维度 | BM25（稀疏） | Embedding（稠密） |
|:----:|:-----------:|:----------------:|
| **匹配方式** | 精确关键词匹配 | 语义相似度匹配 |
| **同义词** | ❌ 不匹配 | ✅ 能匹配 |
| **罕见专业词** | ✅ 精确命中 | ⚠️ 可能丢失 |
| **适用** | 术语多、需要精确命中的场景 | 泛化语义搜索 |
