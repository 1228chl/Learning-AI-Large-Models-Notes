# 文本分类全流程

## 定义

文本分类是 NLP 中最基础也最实用的任务。一个完整的文本分类项目包含从**数据获取到模型部署**的完整流水线。

## 项目全流程

```
数据获取 → 数据探索(EDA) → 预处理 → 特征工程 → 模型训练 → 评估 → 部署
```

```python
import jieba
from sklearn.feature_extraction.text import TfidfVectorizer

# 中文预处理

    text = text.replace('\n', ' ').strip()
    words = jieba.lcut(text)            # 分词
```
