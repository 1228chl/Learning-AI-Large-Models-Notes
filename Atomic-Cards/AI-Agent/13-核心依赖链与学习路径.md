# 核心依赖链与学习路径

## 定义

核心依赖链将全部知识点按**前置依赖关系**排列为有向无环图（DAG），揭示"为什么先学 A 才能学 B"的逻辑必然性。

## 全景依赖链

```
层级0（数学地基）── 线性代数 ── 概率统计 ── 微积分 ── 优化理论
    │                    │            │            │
    └────────────────────┴────────────┴────────────┘
                              │
                              ↓
层级1（编程实现）── Python ── NumPy ── Pandas ── PyTorch
                              │
                              ↓
层级2（模型基础）── 线性回归 ── 逻辑回归 ── 神经网络
                              │
                              ↓
层级3（深度模型）── CNN ── RNN/LSTM ── Transformer
                              │
                              ↓
层级4（NLP应用）── 词嵌入 ── BERT ── GPT ── LLM
                              │
                              ↓
层级5（工程应用）── RAG ── Agent ── 模型压缩 ── 部署
```

## 各层级核心知识

| 层级 | 名称 | 核心知识点 | 重要度 |
|:----:|:----|:----------|:------:|
| **0** | 数学地基 | 向量、矩阵、概率、导数 | ⭐⭐⭐⭐⭐ |
| **1** | 编程实现 | Python、NumPy、PyTorch 张量 | ⭐⭐⭐⭐⭐ |
| **2** | 模型基础 | 回归、梯度下降、反向传播 | ⭐⭐⭐⭐⭐ |
| **3** | 深度模型 | CNN、RNN、LSTM、Transformer | ⭐⭐⭐⭐⭐ |
| **4** | NLP 应用 | BERT、GPT、微调、提示词 | ⭐⭐⭐⭐⭐ |
| **5** | 工程应用 | RAG、Agent、部署、压缩 | ⭐⭐⭐⭐ |

## 学习路径建议

```yaml
第一阶段（数学 + 编程）:
  线性代数 → Python → NumPy → 概率统计 → 微积分

第二阶段（ML 基础）:
  机器学习概论 → 线性回归 → 逻辑回归 → KNN → 决策树 → 集成学习 → 评估

第三阶段（深度学习）:
  PyTorch → 反向传播 → CNN → RNN/LSTM → Transformer

第四阶段（NLP + LLM）:
  词嵌入 → BERT → GPT → 提示词工程 → RAG → Agent

第五阶段（工程）:
  特征工程 → 模型调优 → Docker → 模型压缩 → 部署
```
