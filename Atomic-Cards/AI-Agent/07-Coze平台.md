# Coze 平台

## 定义

Coze（扣子）是字节跳动推出的**低代码 AI Agent 开发平台**，以 SaaS 方式提供服务，让非技术人员也能搭建智能体应用。

| 版本 | 网址 | 说明 |
|:----:|:----|:----|
| **国内版** | www.coze.cn | 适配国内大模型（豆包等） |
| **国际版** | www.coze.com | 适配 GPT、Claude 等 |
| **开源版** | Coze Studio | 可私有化部署 |

## 核心功能

```
Agent = LLM + 知识库 + 插件 + 工作流 + 对话记忆
```

| 功能 | 说明 | 技术实现 |
|:----|:----|:--------|
| **LLM 配置** | 选择底层大模型 | 豆包、GPT、Claude、MiniMax |
| **知识库** | 上传私有文档让 Agent 学习 | RAG + 向量数据库 |
| **插件** | 扩展 Agent 能力 | 搜索、日历、邮件、代码执行 |
| **工作流** | 拖拽式编排多步骤任务 | 条件分支、循环、并行 |
| **对话记忆** | 跨轮上下文保持 | 短期 + 长期记忆 |
| **发布渠道** | 嵌入到各平台使用 | 飞书、微信、网页嵌入 |

## Agent 构建流程

```yaml
1. 设定角色: "你是电商客服助手"
2. 配置 LLM: 选择模型、设置温度
3. 添加知识库: 上传产品手册、FAQ
4. 配置插件: 查询物流、查询库存
5. 发布测试: 在预览窗口测试对话
6. 部署上线: 发布到飞书/微信等渠道
```

## Coze vs Dify

| 对比 | Coze | Dify |
|:----:|:----|:----|
| **开发方** | 字节跳动 | 开源社区 |
| **部署方式** | SaaS（云端） | 开源可自部署 |
| **适用人群** | 非技术人员 | 开发者 |
| **大模型** | 豆包、GPT 等 | OpenAI、Claude、本地模型 |
| **知识库** | 内置 | 支持多种向量库 |
| **工作流** | 拖拽式 | 拖拽 + API |
| **扩展性** | 平台插件 | 自定义工具 + API |

## ML 中的 Coze

| 应用场景 | 使用方式 |
|:--------:|:--------|
| **企业客服** | 上传产品文档，配置查询订单插件 |
| **个人助手** | 连接日历、邮件、待办事项 |
| **内容创作** | 配置写作工作流 + 知识库 |
| **教育辅导** | 上传教材作为知识库，设定教学角色 |
