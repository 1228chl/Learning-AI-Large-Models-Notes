# 中文递归文本分割器

## 定义

中文递归文本分割器（Chinese Recursive Text Splitter）是一种针对中文文档特点定制的递归文本切分工具，在 LangChain 的 `RecursiveCharacterTextSplitter` 基础上增加了中文自然语言分隔符（句号、问号、感叹号、冒号、分号等），使切分结果更符合中文句法和语义单元，避免在中文词汇中间硬切导致语义断裂。

### 核心问题

标准 `RecursiveCharacterTextSplitter` 的默认分隔符优先级为 `["\n\n", "\n", " ", ""]`，其中空格 `" "` 在英文中作为单词边界，但在中文中**空格并非天然的分隔符**——中文词之间没有空格。这导致默认配置处理中文时，分块边界常常切在句子中间甚至词汇中间，破坏语义完整性。

### 形式化定义

中文递归分割器定义了带优先级的字符级分隔符集合 $\mathcal{S}$，按优先级从高到低依次尝试分割，直到所有子块小于目标块大小 $L$：

$$
\mathcal{S} = [\text{"\n\n"}, \text{"\n"}, \text{"。"}, \text{"！"}, \text{"？"}, \text{"；"}, \text{":"}, \text{"，"}, \text{"、"}, \text{" "}, \text{""}]
$$

分割过程是一个递归函数 $\text{Split}(t, L, \mathcal{S})$：

$$
\text{Split}(t, L, \mathcal{S}) = \begin{cases}
[t], & \text{if } |t| \leq L \\
\bigcup_{s \in \mathcal{S}} \text{Split}(t_i, L, \mathcal{S}_{\text{next}}), & \text{for each chunk } t_i
\end{cases}
$$

- $t$：待分割的文本
- $L$：目标 chunk size（如 200 字符）
- $\mathcal{S}$：按优先级排序的分隔符列表
- $t_i$：用当前优先级分隔符分割后得到的第 $i$ 个子文本块
- $\mathcal{S}_{\text{next}}$：下一个优先级的分隔符（递归降级）
- $|t|$：文本 $t$ 的长度

## 标准分割器 vs 中文分割器对比

| 对比维度 | 标准递归分割器默认配置 | 中文递归分割器 |
|:--------|:---------------------|:--------------|
| **分隔符优先级** | `["\n\n", "\n", " ", ""]` | `["\n\n", "\n", "。", "！", "？", "；", "：", "，", "、", " ", ""]` |
| **中文句号** | 不作为分隔符 | 作为高优先级分隔符 |
| **中文逗号** | 不作为分隔符 | 作为中优先级分隔符 |
| **段落切分** | 依赖空行 `\n\n` | 同样依赖空行 |
| **句子完整性** | ❌ 常从词中间断开 | ✅ 优先在句尾/逗号处断开 |
| **Overlap 边界** | 字符级硬切 | 在标点附近自然对齐 |

## 完整实现

```python
from langchain.text_splitter import RecursiveCharacterTextSplitter

class ChineseRecursiveTextSplitter(RecursiveCharacterTextSplitter):
    """
    中文递归文本分割器：
    在 LangChain RecursiveCharacterTextSplitter 基础上，增加中文分隔符。

    分隔符优先级（从高到低）：
    1. 段落: "\n\n"
    2. 行: "\n"
    3. 句尾: "。"、"！"、"？"
    4. 句内: "；"、"："
    5. 词间: "，"、"、"
    6. 英文空格: " "（处理中英文混排时保留）
    7. 字符级: ""（兜底，保证所有块都小于 chunk_size）
    """

    def __init__(
        self,
        chunk_size: int = 200,       # 子块目标大小（字符数）
        chunk_overlap: int = 50,     # 相邻块重叠字符数
        **kwargs
    ):
        # 中文字符分隔符列表，优先级从高到低
        chinese_separators = [
            "\n\n",   # 段落
            "\n",     # 行
            "。",      # 句号
            "！",      # 感叹号
            "？",      # 问号
            "；",      # 分号
            "：",      # 冒号
            "，",      # 逗号
            "、",      # 顿号
            " ",       # 空格（中英文混排保留）
            "",        # 字符级兜底
        ]

        super().__init__(
            chunk_size=chunk_size,
            chunk_overlap=chunk_overlap,
            separators=chinese_separators,  # 覆盖默认分隔符
            **kwargs
        )


# ===== 使用示例 =====

# 1. 创建中文分割器
splitter = ChineseRecursiveTextSplitter(
    chunk_size=200,       # 每个子块最多 200 个字符
    chunk_overlap=50      # 块间重叠 50 字符，防止语义断裂
)

# 2. 分割中文文本
text = """
深度学习是机器学习的一个分支领域，它基于人工神经网络模拟人类大脑的学习过程。
深度学习的"深度"指的是网络中包含多个隐藏层，这些层能够自动学习数据的层次化特征表示。

在图像识别任务中，浅层网络学习边缘和纹理等低级特征，深层网络则将这些低级特征组合成更抽象的高级语义概念。
这种层次化学习能力使得深度学习在计算机视觉和自然语言处理等领域取得了突破性进展。
常见的深度学习架构包括卷积神经网络（CNN）、循环神经网络（RNN）和 Transformer 等。
"""

chunks = splitter.split_text(text)

for i, chunk in enumerate(chunks):
    print(f"--- Chunk {i+1} ({len(chunk)} chars) ---")
    print(chunk)
    print()

# 预期输出：每个 chunk 在句号或逗号处断开，语义完整
# 第一个 chunk 约 200 字符，以句号结束
```

### 在父子分块流程中使用

```python
# 父块分割器：按段落切，保留语义完整性
parent_splitter = ChineseRecursiveTextSplitter(
    chunk_size=800,
    chunk_overlap=100
)

# 子块分割器：按句子切，细粒度检索
child_splitter = ChineseRecursiveTextSplitter(
    chunk_size=200,
    chunk_overlap=50
)

# 分步执行：先切父块，再在每个父块内切子块
def split_parent_child(text: str):
    """中文文档的父子分块"""
    parent_chunks = parent_splitter.split_text(text)
    result = []

    for p_idx, parent in enumerate(parent_chunks):
        # 在父块内切子块
        child_chunks = child_splitter.split_text(parent)
        for c_idx, child in enumerate(child_chunks):
            result.append({
                "parent_id": f"p{p_idx:04d}",
                "child_id": f"p{p_idx:04d}_c{c_idx:04d}",
                "parent_text": parent,
                "child_text": child,
            })

    return result
```

## 分割过程演示

```
输入文本（300 字符）:
"深度学习是机器学习的分支。它基于神经网络。深度学习包含多个隐藏层。"

分割过程（chunk_size=100）:

第1轮：用 "\n\n" 分割 → 无段落分隔，整段作为一个块（>100 chars）
第2轮：用 "\n" 分割 → 无换行，整段作为一个块（>100 chars）
第3轮：用 "。" 分割 → 得到 3 句子块：
  ["深度学习是机器学习的分支。", "它基于神经网络。", "深度学习包含多个隐藏层。"]
  每个块 < 100 chars → 分割完成 ✓

结果：
  Chunk1: 深度学习是机器学习的分支。
  Chunk2: 它基于神经网络。
  Chunk3: 深度学习包含多个隐藏层。

对比（标准分割器默认分隔符）：
  在第3步使用 " " 分割 → 中文无空格，跳过
  在第4步使用 "" 字符级分割 → 从字符中间硬切：
  Chunk1: 深度学习是机器学  ← 语义断裂
```

## ML/DL 应用场景

| 应用场景 | 分割器配置 | 说明 |
|:--------|:----------|:-----|
| **RAG 子块检索** | chunk_size=200, overlap=50 | 细粒度句子级检索，精确匹配用户问题 |
| **RAG 父块上下文** | chunk_size=800, overlap=100 | 段落级上下文，给 LLM 提供完整语义 |
| **代码文档处理** | 加 `def `, `class ` 等代码分隔符 | 在函数定义处优先分割 |
| **长文档摘要** | chunk_size=1000, overlap=200 | 较大分块，保留段落完整性便于摘要 |

## 面试追问

**Q1（基础）**：为什么标准 RecursiveCharacterTextSplitter 在处理中文时效果不好？
**回答要点**：

1. 标准分隔符优先级包含空格 `" "`，但中文文本中词与词之间没有空格，空格分隔符对中文无效
2. 缺少中文句号 `。`、逗号 `，` 等标点作为分隔符，导致回退到字符级硬切，在词中间断开
3. 英文空格在中文语境下相当于"没有分隔符"，最终兜底的字符级切分产生大量语义碎片

**Q2（深挖）**：中文递归分割器的分隔符顺序为什么选择"句号 > 逗号 > 顿号 > 空格 > 字符级"？
**回答要点**：

1. 句号/问号/感叹号代表完整语义单元的结束，最高优先级保证每个 chunk 以完整句子结束
2. 逗号/顿号代表语义停顿，优先级中等，当一个句子超长时在逗号处分断比在字符中间断开好
3. 空格处理中英文混排：当文本包含英文术语（如 "Transformer 架构"）时，空格作为兜底前的最后一级分隔
4. 字符级兜底确保任何文本都能被分割到指定 chunk_size 以内

**Q3（实战）**：在 EduRAG 项目中，如何将中文递归分割器集成到父子分块流程中？
**回答要点**：

1. 定义两个分割器实例：父块分割器（chunk_size=800）和子块分割器（chunk_size=200）
2. 先对整个文档用父块分割器切分，得到段落级别的父块
3. 对每个父块使用子块分割器进一步切分，得到句子级别的子块
4. 将父块原文存入 `parent_text` 字段，子块存入 `text` 字段，通过 `parent_id` 建立关联

**Q4（边界）**：中文递归分割器在处理代码文档或中英文混排文本时有什么特殊处理？
**回答要点**：

1. 代码文档：可以扩展分隔符列表加入代码特定分隔符（`def `、`class `、`{`、`}`），使分割点在函数定义处
2. 中英文混排：保留空格分隔符处理英文单词边界；Excel/CSV 格式文本需考虑换行符 `\n` 的优先级
3. Markdown 文档：可加入 `#`、`##` 等标题分隔符，使分割点与文档结构对齐
4. 长表格/公式：此类结构化内容不适合递归文本分割，应使用专门的表格/公式分割器预处理
