# 模型压缩（量化 / 剪枝 / 蒸馏）

## 定义

模型压缩将大型模型"瘦身"为适合部署的小模型，在尽量保持精度的前提下减小模型大小、降低推理延迟。

## 三大技术

```python
# 压缩效果概览
# 量化:   FP32 → INT8, 模型大小 4x 减小, 速度 2-4x 提升
# 剪枝:   移除不重要连接, 稀疏度 50-90%
# 蒸馏:   小模型学习大模型, 保留 95%+ 精度
```

| 技术 | 原理 | 压缩比 | 精度损失 | 适用阶段 |
|:----:|:----|:------:|:--------:|:--------:|
| **量化** | 降低参数精度（FP32→INT8） | 4x | 小（<1%） | 训练后 |
| **剪枝** | 移除不重要连接或通道 | 2-10x | 中 | 训练后/训练中 |
| **蒸馏** | 小模型模仿大模型输出 | 取决于学生模型 | 小 | 训练时 |

## 量化（Quantization）

```python
import torch

# 动态量化（最简单，适合 LLM）
model_int8 = torch.ao.quantization.quantize_dynamic(
    model, {torch.nn.Linear}, dtype=torch.qint8
)

# 静态量化（需校准数据，适合 CNN）
model.qconfig = torch.ao.quantization.get_default_qconfig('fbgemm')
model_prepared = torch.ao.quantization.prepare(model, calibration_data)
model_int8 = torch.ao.quantization.convert(model_prepared)
```

| 量化类型 | 精度 | 速度 | 适用 |
|:--------:|:----:|:----:|:----|
| **动态量化** | FP32 的 99%+ | 2-3x | LLM 推理 |
| **静态量化** | FP32 的 99%+ | 3-4x | CNN |
| **INT8 量化** | FP32 的 98-99% | 4x | 通用 |
| **FP16（半精度）** | 几乎无损 | 2x | GPU 训练/推理 |

## 剪枝（Pruning）

```python
import torch.nn.utils.prune as prune

# 非结构化剪枝（逐权重）
prune.random_unstructured(module, name="weight", amount=0.3)

# 结构化剪枝（逐通道）
prune.ln_structured(module, name="weight", amount=0.3, n=2, dim=0)

# LLM 剪枝：SparseGPT / Wanda
```

| 剪枝类型 | 粒度 | 硬件加速 | 压缩比 |
|:--------:|:----:|:--------:|:------:|
| **非结构化** | 单个权重 | ❌ 通用 GPU 不支持 | 高 |
| **结构化**（通道/层） | 整通道 | ✅ | 中 |
| **注意力头剪枝** | 整个头 | ✅ | 中 |

## 知识蒸馏（Knowledge Distillation）

```
教师模型（大）: 输出 soft labels（软标签，带温度 T 的 softmax）
                   ↓
学生模型（小）: 学习拟合 soft labels + hard labels

Loss = α * KL(教师输出 || 学生输出) + (1-α) * CrossEntropy(学生输出, 真实标签)
```

```python
def distillation_loss(student_logits, teacher_logits, labels, T=4.0, alpha=0.7):
    soft_loss = KL_div(
        F.log_softmax(student_logits / T, dim=-1),
        F.softmax(teacher_logits / T, dim=-1)
    ) * T * T
    hard_loss = F.cross_entropy(student_logits, labels)
    return alpha * soft_loss + (1 - alpha) * hard_loss
```

## ML 中的模型压缩

| 应用场景 | 压缩方案 | 成果 |
|:--------:|:--------|:----|
| **BERT 部署** | 蒸馏 + 量化 | TinyBERT（<50% 大小，95%+ 精度）|
| **LLaMA 本地运行** | 4-bit 量化（GGML/GPTQ） | 13B 模型只需 8GB 显存 |
| **YOLO 边缘部署** | 剪枝 + INT8 量化 | Jetson Nano 实时推理 |
| **Whisper 语音** | FP16 量化 | 推理加速 2x |
