# 特征值与特征向量

## 定义

对于方阵 $A \in \mathbb{R}^{n \times n}$，若非零向量 $\mathbf{v}$ 和标量 $\lambda$ 满足：

$$A\mathbf{v} = \lambda \mathbf{v}$$

则 $\lambda$ 是 $A$ 的特征值（Eigenvalue），$\mathbf{v}$ 是对应的特征向量（Eigenvector）。

**几何含义**：特征向量是在 $A$ 作用下**方向保持不变**（仅缩放 $\lambda$ 倍）的特殊方向。这正是理解矩阵行为的关键——找到那些被线性变换"最简单地作用"的方向。

## 求解方法

通过特征方程求解 $\lambda$：$\det(A - \lambda I) = 0$

展开后得到 $\lambda$ 的 $n$ 次多项式（特征多项式），其根即为特征值。对于每个 $\lambda$，求解 $(A - \lambda I)\mathbf{v} = \mathbf{0}$ 得到对应的特征向量。

## 关键性质

| 性质 | 公式 |
|------|------|
| 迹等于特征值之和 | $\text{tr}(A) = \sum_i \lambda_i$ |
| 行列式等于特征值之积 | $\det(A) = \prod_i \lambda_i$ |
| 对称矩阵的特征值 | 均为实数 |
| 半正定矩阵的特征值 | $\lambda_i \geq 0$ |
| 可逆矩阵的特征值 | $\lambda_i \neq 0$ |

## ML 应用

| 应用 | 原理 |
|------|------|
| **PCA** | 数据协方差矩阵的特征向量指向最大方差方向 |
| **谱聚类** | 拉普拉斯矩阵的特征向量包含图的结构信息 |
| **特征面（Eigenfaces）** | 人脸图像协方差矩阵的特征向量作为"基脸" |
| **收敛性分析** | 梯度下降的收敛速度取决于 Hessian 矩阵的特征值分布 |
| **图神经网络** | 图拉普拉斯的特征分解用于谱图卷积 |

> **面试追问**
> 
> Q1（基础）：特征值和特征向量的定义 $A\mathbf{v}=\lambda\mathbf{v}$ 的几何含义是什么？为什么说特征向量代表了矩阵的"特殊方向"？
> 回答要点：特征向量 $A$ 作用后方向保持不变仅缩放 $\lambda$ 倍；这些方向是线性变换的"主轴"，矩阵在这些方向上的作用最简单（仅拉伸/压缩）；找到特征向量相当于找到了理解矩阵行为的最佳坐标系。
> 
> Q2（深挖）：为什么对称矩阵的特征值一定是实数？这个性质对 PCA 为什么至关重要？
> 回答要点：对称矩阵 $A=A^T$ 满足谱定理，可正交对角化 $A=Q\Lambda Q^T$；特征值实数保证了 PCA 中主成分的方差是正实数可排序的；协方差矩阵是对称的，因此 PCA 一定能得到有意义的实值主成分方向。
> 
> Q3（实战）：在 PCA 中我们保留最大的几个特征值对应的特征向量，这背后的数学原理和直觉是什么？
> 回答要点：特征值大小表示对应特征向量方向上的数据方差大小；丢弃小特征值方向相当于忽略变化小的噪声维度；Eckart-Young 定理保证截断后的重构误差（Frobenius 范数）最小。
> 
> Q4（边界）：特征值分解在什么条件下无法进行？此时应该使用什么替代方法？
> 回答要点：非方阵无法进行 EVD；可对角化条件是矩阵必须有 $n$ 个线性无关的特征向量（亏秩矩阵或 Jordan 块结构时无法对角化）；奇异值分解（SVD）是 EVD 的通用替代，适用于任意矩阵且数值更稳定。
