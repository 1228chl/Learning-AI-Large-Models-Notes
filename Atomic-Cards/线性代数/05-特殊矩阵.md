# 特殊矩阵

## 类型与性质

| 矩阵类型 | 定义 | 关键性质 | ML 典型应用 |
|----------|------|----------|------------|
| **对称矩阵** | $A = A^T$ | 特征值为实数，可正交对角化 | 协方差矩阵、Hessian 矩阵、核矩阵 |
| **正交矩阵** | $Q^TQ = I$ | $Q^{-1} = Q^T$，保范数（等距变换） | PCA 旋转矩阵、RNN 的酉初始化 |
| **对角矩阵** | $a_{ij}=0\;(i \neq j)$ | 特征值在对角线上，求逆 $O(n)$ | 缩放操作、BatchNorm |
| **单位矩阵** | $I_{ii}=1$，其余为 0 | 乘法单位元：$AI = IA = A$ | 恒等映射、残差连接 |
| **稀疏矩阵** | 大部分元素为 0 | 可压缩存储，加速计算 | One-hot 编码、图邻接矩阵 |
| **三角矩阵** | 对角线一侧全为 0 | 行列式 = 对角元乘积，求逆 $O(n^2)$ | LU 分解、Cholesky 分解 |

## 半正定矩阵

对称矩阵 $A$ 满足 $\mathbf{x}^T A \mathbf{x} \geq 0$ 对所有 $\mathbf{x}$ 成立时称为半正定（Positive Semi-Definite, PSD）。这是协方差矩阵、核矩阵、Gram 矩阵的共同性质，也是凸优化中保证 Hessian 矩阵性质的关键条件。

> **面试追问**
> 
> Q1（基础）：正交矩阵 $Q$ 满足 $Q^TQ=I$，它有哪些重要性质？为什么在数值计算中正交矩阵特别稳定？
> 回答要点：$Q^{-1}=Q^T$ 求逆即转置无需计算；保范数 $\|Q\mathbf{x}\|=\|\mathbf{x}\|$ 不会放大输入误差；列向量构成标准正交基，数值稳定性极好。
> 
> Q2（深挖）：为什么协方差矩阵一定是半正定的（PSD）？这个性质对机器学习算法有什么重要意义？
> 回答要点：$\Sigma=(X-\bar{X})^T(X-\bar{X})$ 可推出 $\mathbf{x}^T\Sigma\mathbf{x}=\|(X-\bar{X})\mathbf{x}\|^2\geq 0$；PSD 性质保证 Cholesky 分解可行、马氏距离中矩阵可逆、核矩阵满足 Mercer 定理等。
> 
> Q3（实战）：在 RNN 的酉初始化或神经网络的权重正交初始化中，为什么希望权重矩阵接近正交？
> 回答要点：正交矩阵保持输入信号的范数，前向传播中激活值不会爆炸或消失；反向传播中梯度范数也保持稳定，缓解梯度消失/爆炸问题；正交初始化在深层网络和 RNN/LSTM 训练中被广泛使用。
> 
> Q4（边界）：稀疏矩阵表示在 GPU 上计算时是否一定比稠密矩阵更快？实际工程中可能遇到什么问题？
> 回答要点：不一定——稀疏矩阵的不规则非零模式导致 GPU 线程束发散和缓存不友好；需要专用稀疏矩阵存储格式（CSR/COO）和计算核；当稀疏度不够高时，稠密矩阵的规则访问反而更快。
>
