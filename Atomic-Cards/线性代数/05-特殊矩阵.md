# 特殊矩阵

## 类型与性质

| 矩阵类型 | 定义 | 关键性质 | ML 典型应用 |
|----------|------|----------|------------|
| **对称矩阵** | $A = A^T$ | 特征值为实数，可正交对角化 | 协方差矩阵、Hessian 矩阵、核矩阵 |
| **正交矩阵** | $Q^TQ = I$ | $Q^{-1} = Q^T$，保范数（等距变换） | PCA 旋转矩阵、RNN 的酉初始化 |
| **对角矩阵** | $a_{ij}=0\;(i \neq j)$ | 特征值在对角线上，求逆 $O(n)$ | 缩放操作、BatchNorm |
| **单位矩阵** | $I_{ii}=1$，其余为 0 | 乘法单位元：$AI = IA = A$ | 恒等映射、残差连接 |
| **稀疏矩阵** | 大部分元素为 0 | 可压缩存储，加速计算 | One-hot 编码、图邻接矩阵 |
| **三角矩阵** | 对角线一侧全为 0 | 行列式 = 对角元乘积，求逆 $O(n^2)$ | LU 分解、Cholesky 分解 |

## 半正定矩阵

对称矩阵 $A$ 满足 $\mathbf{x}^T A \mathbf{x} \geq 0$ 对所有 $\mathbf{x}$ 成立时称为半正定（Positive Semi-Definite, PSD）。这是协方差矩阵、核矩阵、Gram 矩阵的共同性质，也是凸优化中保证 Hessian 矩阵性质的关键条件。
