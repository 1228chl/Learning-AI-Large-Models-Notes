# 向量范数

## 定义

向量范数（Vector Norm）是将向量映射为非负实数的函数 $\|\cdot\|: \mathbb{R}^n \to \mathbb{R}_{\geq 0}$ ，满足：

1. **非负性**： $\|\mathbf{v}\| \geq 0$ ，且 $\|\mathbf{v}\| = 0 \iff \mathbf{v} = \mathbf{0}$
2. **齐次性**： $\|\alpha\mathbf{v}\| = |\alpha| \|\mathbf{v}\|$
3. **三角不等式**： $\|\mathbf{u} + \mathbf{v}\| \leq \|\mathbf{u}\| + \|\mathbf{v}\|$

## 常用范数

| 范数        | 公式                                                         | 特点               | ML 应用                   |
| --------- | ---------------------------------------------------------- | ---------------- | ----------------------- |
| **L0 范数** | $\Vert\mathbf{v}\Vert_0 = \#\{i: v_i \neq 0\}$             | 向量中非零元素个数（非真正范数） | 稀疏性度量（NP 难）             |
| **L1 范数** | $\Vert\mathbf{v}\Vert_1 = \sum_i \vert v_i\vert$           | 曼哈顿距离，诱导稀疏解      | Lasso 回归、特征选择           |
| **L2 范数** | $\Vert\mathbf{v}\Vert_2 = \sqrt{\sum_i v_i^2}$             | 欧氏距离，旋转不变性       | Ridge 回归、权重衰减、归一化       |
| **L∞ 范数** | $\Vert\mathbf{v}\Vert_\infty = \max_i \vert v_i\vert$      | 最大分量绝对值          | 对抗样本约束（ $\epsilon$ -ball） |
| **Lp 范数** | $\Vert\mathbf{v}\Vert_p = (\sum_i \vert v_i\vert^p)^{1/p}$ | 一般形式（$p$ 为范数阶数） | 理论统一框架                  |

## 范数在 ML 中的角色

| 角色 | 说明 |
|------|------|
| **正则化** | 在损失函数中添加 $\lambda\Vert\mathbf{w}\Vert_1$ 或 $\lambda\Vert\mathbf{w}\Vert_2^2$ 防止过拟合，其中 $\lambda$ 为正则化强度，$\mathbf{w}$ 为权重向量 |
| **梯度裁剪** | 梯度范数过大时按比例缩放： $\mathbf{g} \leftarrow \mathbf{g} \cdot \frac{\text{clip}}{\Vert\mathbf{g}\Vert}$，其中 $\mathbf{g}$ 为梯度向量，$\text{clip}$ 为裁剪阈值 |
| **模型压缩** | 权重范数小的连接可被剪枝移除 |
| **归一化** | LayerNorm / BatchNorm 中对向量进行归一化 $\hat{\mathbf{x}} = \frac{\mathbf{x} - \mu}{\sigma}$，其中 $\mathbf{x}$ 为输入向量，$\mu$ 为均值，$\sigma$ 为标准差 |
| **对抗攻击** | 在 $\Vert\delta\Vert_p < \epsilon$ 的约束下寻找微小扰动 $\delta$ |

## 面试追问

**Q1（基础）**：向量范数必须满足哪三个公理？L1 和 L2 范数在数学定义和几何形状上有什么本质差异？
**回答要点**：

1. 向量范数必须满足三个公理：非负性 $\|\mathbf{v}\|\geq 0$、齐次性 $\|\alpha\mathbf{v}\|=|\alpha|\|\mathbf{v}\|$、三角不等式 $\|\mathbf{u}+\mathbf{v}\|\leq\|\mathbf{u}\|+\|\mathbf{v}\|$
2. L1 等值面是菱形（有尖角），L2 是圆形（光滑）；L1 对坐标轴方向敏感，L2 具有旋转不变性
3. L1 在坐标尖角处易产生稀疏解，L2 的解均匀分布在各方向

**Q2（深挖）**：为什么 L1 正则化倾向于产生稀疏解而 L2 正则化不会？请从几何优化角度解释。
**回答要点**：

1. L1 约束区域 $\|\mathbf{w}\|_1\leq t$ 是菱形，尖角位于坐标轴上
2. 最优解在菱形尖角处与等值线相切时特征权重正好为零，产生稀疏性
3. L2 约束区域 $\|\mathbf{w}\|_2^2\leq t$ 是圆形无尖角，最优解落在坐标轴上的概率为零，只缩小权重但不置零

**Q3（实战）**：训练大规模语言模型时为什么需要梯度裁剪？为什么通常基于 L2 范数进行裁剪？
**回答要点**：

1. 梯度爆炸会导致参数更新步长过大，训练不稳定甚至发散
2. 梯度裁剪 $\mathbf{g}\leftarrow \mathbf{g}\cdot\frac{\text{clip}}{\|\mathbf{g}\|_2}$ 将梯度 L2 范数限制在阈值内
3. L2 范数反映梯度的整体大小，选择 clip 值为梯度的某个高分位数（如 1.0）

**Q4（边界）**：L1 正则化在高维特征选择中虽然能产生稀疏性，但它有哪些固有局限性？
**回答要点**：

1. 当特征间高度相关时 L1 会随机选择其中一个而非全选，导致不稳定性
2. L1 无法处理特征分组结构（如一组特征应同时选入或排除）
3. Elastic Net（L1+L2）或 $L_{0.5}$ 可在某些场景下克服这些问题，但 L0 正则化仍是 NP 难的
