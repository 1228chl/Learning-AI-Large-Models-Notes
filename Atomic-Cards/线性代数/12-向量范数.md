# 向量范数

## 定义

向量范数（Vector Norm）是将向量映射为非负实数的函数 $\|\cdot\|: \mathbb{R}^n \to \mathbb{R}_{\geq 0}$，满足：

1. **非负性**：$\|\mathbf{v}\| \geq 0$，且 $\|\mathbf{v}\| = 0 \iff \mathbf{v} = \mathbf{0}$
2. **齐次性**：$\|\alpha\mathbf{v}\| = |\alpha| \|\mathbf{v}\|$
3. **三角不等式**：$\|\mathbf{u} + \mathbf{v}\| \leq \|\mathbf{u}\| + \|\mathbf{v}\|$

## 常用范数

| 范数 | 公式 | 特点 | ML 应用 |
|------|------|------|---------|
| **L0 范数** | $\|\mathbf{v}\|_0 = \#\{i: v_i \neq 0\}$ | 向量中非零元素个数（非真正范数） | 稀疏性度量（NP 难） |
| **L1 范数** | $\|\mathbf{v}\|_1 = \sum_i \vert v_i\vert$ | 曼哈顿距离，诱导稀疏解 | Lasso 回归、特征选择 |
| **L2 范数** | $\|\mathbf{v}\|_2 = \sqrt{\sum_i v_i^2}$ | 欧氏距离，旋转不变性 | Ridge 回归、权重衰减、归一化 |
| **L∞ 范数** | $\|\mathbf{v}\|_\infty = \max_i \vert v_i\vert$ | 最大分量绝对值 | 对抗样本约束（$\epsilon$-ball） |
| **Lp 范数** | $\|\mathbf{v}\|_p = (\sum_i \vert v_i\vert^p)^{1/p}$ | 一般形式 | 理论统一框架 |

## 范数在 ML 中的角色

| 角色 | 说明 |
|------|------|
| **正则化** | 在损失函数中添加 $\lambda\|\mathbf{w}\|_1$ 或 $\lambda\|\mathbf{w}\|_2^2$ 防止过拟合 |
| **梯度裁剪** | 梯度范数过大时按比例缩放：$\mathbf{g} \leftarrow \mathbf{g} \cdot \frac{\text{clip}}{\|\mathbf{g}\|}$ |
| **模型压缩** | 权重范数小的连接可被剪枝移除 |
| **归一化** | LayerNorm / BatchNorm 中对向量进行归一化 $\hat{\mathbf{x}} = \frac{\mathbf{x} - \mu}{\sigma}$ |
| **对抗攻击** | 在 $\|\delta\|_p < \epsilon$ 的约束下寻找微小扰动 $\delta$ |
