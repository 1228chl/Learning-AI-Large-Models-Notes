# 期望与方差

## 定义

**期望**（Expectation / Mean）是随机变量的"加权平均"，衡量分布的**中心位置**：

| 类型 | 公式 |
|------|------|
| 离散型 | $E[X] = \sum_{i} x_i P(X=x_i)$ |
| 连续型 | $E[X] = \int_{-\infty}^{\infty} x f_X(x) dx$ |
| 函数的期望 | $E[g(X)] = \sum_i g(x_i)P(X=x_i)$ |

**方差**（Variance）衡量随机变量取值围绕期望的**分散程度**：

$$\text{Var}(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2$$

**标准差**（Standard Deviation）：$\sigma_X = \sqrt{\text{Var}(X)}$，与 $X$ 同量纲。

## 关键性质

| 性质 | 期望 | 方差 |
|------|------|------|
| 线性 | $E[aX + b] = aE[X] + b$ | $\text{Var}(aX + b) = a^2\text{Var}(X)$ |
| 独立变量的和 | $E[X + Y] = E[X] + E[Y]$ | $\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)$ |
| 一般情形 | 期望运算总是线性的 | $\text{Var}(X+Y) = \text{Var}(X) + \text{Var}(Y) + 2\text{Cov}(X,Y)$ |

## 在 ML 中的核心角色

| 应用 | 公式 | 直觉 |
|------|------|------|
| **MSE 损失** | $L = \mathbb{E}[(y - \hat{y})^2]$ | 最小化预测误差的期望平方 |
| **偏差-方差分解** | $\text{Err} = \text{Bias}^2 + \text{Variance} + \text{Noise}$ | 泛化误差 = 偏差平方 + 方差 + 噪声 |
| **BatchNorm** | $\hat{x} = \frac{x - \mu_B}{\sigma_B}$ | 将激活值归一化为 0 均值 1 方差 |
| **Dropout** | $E[\text{Dropout}(x)] = p \cdot x$ | 训练时随机丢弃，测试时取期望 |
| **风险最小化** | $R(\theta) = \mathbb{E}_{(x,y)\sim P_{\text{data}}}[L(y, f_\theta(x))]$ | 在数据分布上最小化期望损失 |

## 面试追问

**Q1（基础）**：期望和方差分别衡量随机变量的什么性质？写出各自的数学定义。
**回答要点**：① 期望 $E[X]$ 是概率加权平均，衡量分布的**中心位置**；② 方差 $\text{Var}(X)=E[(X-E[X])^2]$ 衡量取值围绕期望的**分散程度**；③ 离散型用求和，连续型用积分，函数的期望 $E[g(X)]$ 直接套用 $g(x)$ 加权计算。

**Q2（深挖）**：推导方差公式 $\text{Var}(X)=E[X^2]-(E[X])^2$，并说明它的计算优势。
**回答要点**：① $\text{Var}(X)=E[(X-\mu)^2]=E[X^2-2\mu X+\mu^2]=E[X^2]-2\mu E[X]+\mu^2$；② 代入 $\mu=E[X]$ 得 $E[X^2]-2(E[X])^2+(E[X])^2=E[X^2]-(E[X])^2$；③ 优势：只需计算 $E[X]$ 和 $E[X^2]$，避免先减均值再平方的中间步骤。

**Q3（实战）**：偏差-方差分解 $\text{Err} = \text{Bias}^2 + \text{Variance} + \text{Noise}$ 如何指导模型选择中的权衡？
**回答要点**：① 高偏差对应欠拟合（模型过于简单），高方差对应过拟合（模型太复杂）；② 增加模型复杂度通常降低偏差但提高方差，最优复杂度在总误差最低点；③ 正则化（L1/L2）通过限制模型自由度来降低方差，以可接受的偏差增加换取方差的大幅减少。

**Q4（边界）**：柯西分布为什么没有期望？这在实际应用中意味着什么？
**回答要点**：① 柯西分布 $f(x)=\frac{1}{\pi(1+x^2)}$ 的尾部衰减太慢（$1/x^2$），积分 $\int_{-\infty}^{\infty}|x|f(x)dx$ 发散；② 这意味着样本均值不是真实中心的稳定估计量，随样本量增加不收敛；③ 在 ML 中，若数据呈厚尾分布需谨慎使用 MSE 损失，应考虑 Huber 损失等稳健替代。
