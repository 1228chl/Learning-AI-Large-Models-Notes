# 条件概率与贝叶斯公式

## 条件概率

事件 $B$ 发生条件下事件 $A$ 发生的概率：

$$P(A \vert B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0$$

**直观理解**：已知 $B$ 已经发生，样本空间从 $\Omega$ 缩小为 $B$，$A$ 在缩小后的空间中所占的比例。

## 全概率公式

若 $B_1, B_2, \dots, B_n$ 构成样本空间的一个划分（互斥且全覆盖），则：

$$P(A) = \sum_{i=1}^n P(A \vert B_i) P(B_i)$$

## 贝叶斯公式

贝叶斯公式是条件概率的最重要推论，描述了如何根据观测数据更新对某个假设的信念：

$$P(B_i \vert A) = \frac{P(A \vert B_i) P(B_i)}{P(A)} = \frac{P(A \vert B_i) P(B_i)}{\sum_j P(A \vert B_j) P(B_j)}$$

| 成分 | 名称 | 含义 |
|------|------|------|
| $P(B_i)$ | **先验概率**（Prior） | 在看到数据前对假设 $B_i$ 的信念 |
| $P(A \vert B_i)$ | **似然**（Likelihood） | 假设 $B_i$ 下观测到数据 $A$ 的概率 |
| $P(B_i \vert A)$ | **后验概率**（Posterior） | 看到数据后对假设 $B_i$ 更新的信念 |
| $P(A)$ | **证据**（Evidence） | 数据出现的总概率（归一化常数） |

## ML 中的关键应用

| 应用 | 贝叶斯形式 | 说明 |
|------|-----------|------|
| **朴素贝叶斯分类器** | $P(y\vert \mathbf{x}) \propto P(y) \prod_i P(x_i\vert y)$ | 条件独立假设下的贝叶斯分类 |
| **贝叶斯推断** | $P(\theta \vert \mathcal{D}) \propto P(\mathcal{D} \vert \theta) P(\theta)$ | 参数的后验分布估计 |
| **最大后验估计（MAP）** | $\hat{\theta}_{\text{MAP}} = \arg\max P(\mathcal{D}\vert\theta)P(\theta)$ | 在 MLE 基础上加入先验 |
| **贝叶斯神经网络** | $P(y\vert x, \mathcal{D}) = \int P(y\vert x, \theta) P(\theta\vert\mathcal{D}) d\theta$ | 对预测不确定性建模 |

> 贝叶斯公式统一了"先验知识"和"观测数据"，是机器学习的概率论基石。交叉熵损失的最小化等价于最大似然估计，L2 正则化等价于高斯先验下的 MAP 估计。
