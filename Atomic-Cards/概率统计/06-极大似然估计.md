# 极大似然估计

## 定义

极大似然估计（Maximum Likelihood Estimation, MLE）是估计概率模型参数的最常用方法。其核心思想：**选择使观测数据出现概率最大的参数**。

给定独立同分布的数据 $\mathcal{D} = \{x_1, x_2, \dots, x_N\}$ 和参数化的概率模型 $P(x\vert\theta)$ ：

$$
\hat{\theta}_{\text{MLE}} = \arg\max_\theta P(\mathcal{D} \vert \theta) = \arg\max_\theta \prod_{i=1}^N P(x_i \vert \theta)
$$

取对数后（乘积变求和，便于优化）：

$$
\hat{\theta}_{\text{MLE}} = \arg\max_\theta \sum_{i=1}^N \log P(x_i \vert \theta)
$$

## 与损失函数的关系

MLE 提供了**损失函数设计的概率论基础**：

| 模型假设 | 似然函数 | 等价损失函数 |
|----------|----------|-------------|
| 高斯噪声 $y \sim \mathcal{N}(f_\theta(x), \sigma^2)$ | $\prod \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(y_i - f_\theta(x_i))^2}{2\sigma^2}}$ | **MSE 损失** $\sum (y_i - \hat{y}_i)^2$ |
| 伯努利分布（二分类） | $\prod \hat{y}_i^{y_i} (1-\hat{y}_i)^{1-y_i}$ | **二元交叉熵** $-\sum [y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)]$ |
| Categorical 分布（多分类） | $\prod \prod_k (\hat{y}_{ik})^{y_{ik}}$ | **分类交叉熵** $-\sum_i \sum_k y_{ik} \log \hat{y}_{ik}$ |

## MLE vs MAP

| 方法 | 目标 | 先验 | 等价正则化 |
|------|------|------|-----------|
| **MLE** | $\arg\max P(\mathcal{D}\vert\theta)$ | 无 | 无 |
| **MAP（最大后验）** | $\arg\max P(\mathcal{D}\vert\theta)P(\theta)$ | 有（ $P(\theta)$ ） | 高斯先验 $\to$ L2 正则化；拉普拉斯先验 $\to$ L1 正则化 |

## 性质

| 性质 | 说明 |
|------|------|
| **一致性** | 样本量 $N \to \infty$ 时， $\hat{\theta}_{\text{MLE}}$ 收敛到真实参数 |
| **渐近正态性** | $\hat{\theta}_{\text{MLE}}$ 的分布趋近正态分布 |
| **渐近有效性** | 在正则条件下，MLE 的方差达到 Cramér-Rao 下界 |
| **不变性** | 若 $\hat{\theta}$ 是 $\theta$ 的 MLE，则 $g(\hat{\theta})$ 是 $g(\theta)$ 的 MLE |

## 面试追问

**Q1（基础）**：MLE 的核心思想是什么？写出从独立同分布数据 $ \mathcal{D}$ 估计参数 $\theta$ 的优化目标。

**回答要点**：① 选择使观测数据出现概率最大的参数 $\hat{\theta}_{\text{MLE}} = \arg\max_\theta P(\mathcal{D}|\theta)$ ；② 独立同分布下似然函数为 $\prod_i P(x_i|\theta)$ ，优化时常取对数转化为 $\sum_i \log P(x_i|\theta)$ ；③ 取对数将乘积变求和，简化求导且数值更稳定。

**Q2（深挖）**：MLE 和 MAP（最大后验估计）的根本区别是什么？这种区别在正则化中如何体现？

**回答要点**：① MLE 仅最大化似然 $P(\mathcal{D}|\theta)$ ，MAP 额外乘上先验 $P(\theta)$ ，即 $\arg\max P(\mathcal{D}|\theta)P(\theta)$ ；② 高斯先验 $\theta\sim\mathcal{N}(0,\lambda^{-1})$ 等价于 L2 正则化（权重衰减）；③ 拉普拉斯先验等价于 L1 正则化（套索），产生稀疏解。

**Q3（实战）**：从 MLE 的角度解释：为什么在回归问题中使用 MSE 损失函数是合理的？为什么分类问题使用交叉熵？

**回答要点**：① 回归假设噪声服从高斯分布 $y\sim\mathcal{N}(f_\theta(x),\sigma^2)$ ，MLE 推导出的负对数似然恰好是 MSE $\sum(y_i-\hat{y}_i)^2$ ；② 二分类假设输出服从伯努利分布，MLE 导出二元交叉熵 $-\sum[y_i\log\hat{y}_i+(1-y_i)\log(1-\hat{y}_i)]$ ；③ 这说明损失函数的选择本质上就是不同概率分布假设下的 MLE 等价形式。

**Q4（边界）**：MLE 在小样本场景下存在什么固有问题？有哪些应对策略？

**回答要点**：① **过拟合**：小样本下 MLE 容易学到噪声而非真实模式（如抛 3 次硬币全正面则估计 $p=1$ ）；② **无不确定性量化**：MLE 只给出点估计，不提供参数的不确定性范围；③ 应对策略：加入先验做 MAP 估计、使用贝叶斯方法得到完整后验分布、或引入 Bootstrap 估计置信区间。
