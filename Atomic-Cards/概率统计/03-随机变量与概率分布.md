# 随机变量与概率分布

## 定义

**随机变量**（Random Variable）是将随机试验的结果映射为实数的函数 $X: \Omega \to \mathbb{R}$ 。分为两类：

| 类型 | 取值 | 概率表示 | 例子 |
|------|------|----------|------|
| **离散型** | 可数有限或无限个值 | $P(X = x_k) = p_k$ | 掷骰子、分类标签 |
| **连续型** | 不可数无穷个值 | $f_X(x)$ （概率密度函数） | 身高、温度、权重 |

## 核心概念

**概率质量函数（PMF）**：离散随机变量取特定值的概率 $p(x) = P(X = x)$

**概率密度函数（PDF）**：连续随机变量的密度 $f(x)$ ，满足 $P(a \leq X \leq b) = \int_a^b f(x) dx$

**累积分布函数（CDF）**： $F(x) = P(X \leq x) = \sum_{t \leq x} p(t)$ 或 $\int_{-\infty}^x f(t) dt$

## 常用概率分布

| 分布 | 类型 | 概率函数 / 密度函数 | 参数 | ML 应用 |
|------|------|--------------------|------|---------|
| **伯努利分布** | 离散 | $P(X=k) = p^k(1-p)^{1-k}$ | $p$ | 二分类输出层 |
| **Categorical 分布** | 离散 | $P(X=x_k) = p_k$ | $\mathbf{p}$ | 多分类 softmax 输出 |
| **正态分布（高斯）** | 连续 | $f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu, \sigma^2$ | 权重初始化、噪声建模 |
| **均匀分布** | 连续 | $f(x) = \frac{1}{b-a}$ | $a, b$ | 随机采样初始化 |
| **指数分布** | 连续 | $f(x) = \lambda e^{-\lambda x}$ | $\lambda$ | 等待时间建模 |

## 为什么 ML 需要概率分布

| 角色 | 说明 |
|------|------|
| **数据假设** | 假设数据服从某个分布（如高斯噪声）来推导损失函数 |
| **不确定性量化** | 用概率分布表示预测的不确定性（如 Dropout 作为贝叶斯近似） |
| **生成模型** | 学习数据分布 $P(\mathbf{x})$ 来生成新样本（VAE, GAN） |
| **输出层设计** | 分类任务用 softmax 输出 Categorical 分布，回归用高斯分布 |

## 面试追问

**Q1（基础）**：离散型随机变量和连续型随机变量的核心区别是什么？分别用什么函数描述其概率？

**回答要点**：① 离散型取值可数，用概率质量函数（PMF） $P(X=x_k)=p_k$ 描述；② 连续型取值不可数，用概率密度函数（PDF） $f(x)$ 描述，单点概率为零；③ 两者都可用累积分布函数（CDF） $F(x)=P(X \leq x)$ 统一表示。

**Q2（深挖）**：概率密度函数 $f(x)$ 在单点上的值可以大于 1 吗？这违反概率公理吗？

**回答要点**：① 可以大于 1，如 $\text{Uniform}(0,0.5)$ 的密度 $f(x)=2$ ；② 不违反公理——密度值不是概率，对密度的积分（面积）才等于概率；③ 连续分布的 $P(X=a)=0$ ，PDF 在单点取值无概率含义。

**Q3（实战）**：为什么分类问题通常用 softmax 输出 Categorical 分布，而回归问题用高斯分布假设输出？

**回答要点**：① 分类标签是离散的，Categorical 分布是自然的概率模型，softmax 保证输出和为 1 构成合法概率；② 回归误差通常由多个独立微小因素叠加而成，中心极限定理指向高斯分布；③ 不同分布假设直接导出不同的损失函数：高斯 → MSE，Categorical → 交叉熵。

**Q4（边界）**：中心极限定理要求样本独立同分布且方差有限——当数据存在时间依赖（如股票收益率）时，CLT 还成立吗？

**回答要点**：① 对平稳时间序列，若依赖随滞后衰减足够快（如混合条件），仍有类似 CLT 成立（如鞅差 CLT）；② 但长记忆过程（如分数布朗运动）或厚尾分布（如 Cauchy）不满足条件，CLT 失效；③ 实践中需检查残差是否近似正态，而非盲目假设 CLT 适用。
