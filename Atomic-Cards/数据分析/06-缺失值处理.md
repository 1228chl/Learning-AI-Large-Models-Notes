# 缺失值处理

## 定义

缺失值处理是数据预处理的核心环节。缺失数据根据其产生机制分为三种类型，处理策略的选择取决于缺失类型和数据特性：

- **MCAR（完全随机缺失）**：缺失概率与任何变量无关，如传感器偶发故障。此时删除缺失样本不会引入偏差
- **MAR（随机缺失）**：缺失概率与其他观测变量有关，但与缺失值本身无关。如"收入"字段缺失概率与"职业"有关，这是现实中最常见的缺失类型
- **MNAR（非随机缺失）**：缺失概率与缺失值本身有关，如"高收入者更倾向不填收入"。此时需要领域知识建模缺失机制，否则任何插补都有偏

## 处理策略

**删除法**：`dropna()` 快速删除缺失样本，适用于 MCAR 且缺失率 < 5% 的场景。但缺失率 > 5% 时删除会导致大量信息损失，且非 MCAR 场景会引入选择性偏差。

**均值/中位数插补**：用 `mean()` 或 `median()` 填充缺失值，是最简单的数值插补。中位数比均值对异常值更稳健，适用于偏态分布。但该方法会降低方差，削弱变量间的相关性。

**KNN 插补**：寻找 $k$ 个最近邻样本，用其对应特征值的加权平均填充缺失值。$k$ 通常取 3-5，距离度量用欧氏距离。KNN 插补保留了数据分布结构，但计算复杂度为 $O(n^2)$，在大型数据集上效率低。

**MICE（链式方程多重插补）**：对每个含缺失值的特征建立回归模型，迭代 5-10 轮逐步收敛。第 $t$ 轮迭代公式：

$$x_i^{(t)} \sim P(x_i \mid x_{-i}^{(t-1)}, \hat{\theta})$$

其中 $x_{-i}$ 表示除特征 $i$ 外的所有特征。每轮更新一个特征的插补值，依次迭代直至收敛。

## ML/DL 应用场景

| 应用场景 | 推荐策略 | 说明 |
|:--------:|:--------|:------|
| **树模型训练** | 中位数/众数插补 | 树模型对缺失值有一定鲁棒性，简单插补足够，可使用 `SimpleImputer(strategy='median')` |
| **线性模型/神经网络** | KNN 或 MICE 插补 | 线性模型对缺失值敏感，精准插补能减少估计偏差，避免影响权重学习 |
| **时间序列数据** | 前向/后向填充 | 使用 `ffill()` 或 `bfill()` 利用时序连续性，比随机插补更合理 |
| **高缺失率特征（>50%）** | 直接删除 | 超过半数数据缺失的列，任何插补都会引入较大偏差，删除并记录删除原因 |

## 面试追问

**Q1（基础）**：MCAR、MAR、MNAR 三种缺失机制的区别是什么？为什么理解缺失机制很重要？
**回答要点**：

1. MCAR 缺失完全随机，删除无偏；MAR 缺失依赖其他观测变量，需考虑插补策略；MNAR 缺失与变量本身有关，最难处理
2. 理解缺失机制决定了选择删除还是插补，以及插补方法是否会产生有偏估计
3. 现实中大部分缺失是 MAR，MNAR 需要领域知识建模，MCAR 相对少见

**Q2（深挖）**：均值插补虽然简单，但会引入什么问题？为什么 KNN 插补比均值插补更好？
**回答要点**：

1. 均值插补将所有缺失值填充为同一值，人为压缩了变量方差，削弱了变量间相关性
2. KNN 插补利用完整样本的信息，生成与原始分布更接近的插补值，保留数据结构
3. KNN 插补的代价是计算量大（$O(n^2)$），且 $k$ 值选择影响插补效果，需要通过交叉验证确定

**Q3（实战）**：在 ML 流水线中如何正确实现缺失值处理，避免数据泄露？
**回答要点**：

1. 必须在训练集上计算插补参数（均值、中位数、KNN 模型），然后应用到测试集
2. 使用 `sklearn` 的 `Pipeline` 和 `ColumnTransformer` 确保插补器在交叉验证中只在训练 fold 上 fit
3. 在测试集上只用 `transform()` 不用 `fit()`，避免测试集信息泄露到训练过程

**Q4（边界）**：当数据集中缺失值比例较高（如 30% 的样本有至少一个缺失字段）时，直接删除样本和插补各自的代价是什么？
**回答要点**：

1. 删除代价：30% 的样本被丢弃，样本量大幅减少，可能导致模型欠拟合，且非 MCAR 时引入严重偏差
2. 插补代价：MICE 或 KNN 插补需要大量计算，且插补值本身带有不确定性，多次插补后取平均可缓解
3. 最佳实践：先做 EDA 分析缺失模式，缺失率低（<5%）用简单插补，缺失率高但变量重要用 MICE，缺失率极高（>50%）直接删除该变量
