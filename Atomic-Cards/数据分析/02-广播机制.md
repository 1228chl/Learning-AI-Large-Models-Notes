# 广播机制

## 定义

广播（Broadcasting）是 NumPy（和 PyTorch/TensorFlow）中的一种机制，允许**不同形状的数组**进行算术运算。它自动将较小的数组扩展到与较大数组兼容的形状，而无需显式复制数据。

```python
import numpy as np

# 标量与数组
a = np.array([1, 2, 3])
a + 5                     # [6, 7, 8] — 标量 5 广播到 [5, 5, 5]

# 1D + 2D
matrix = np.ones((3, 3))          # 3×3
row = np.array([1, 2, 3])         # 1D (3,) → 广播到 3×3
matrix + row                      # 每行加 [1, 2, 3]

# 列向量 + 行向量
col = np.array([[1], [2], [3]])   # (3, 1)
row = np.array([10, 20, 30])      # (3,)
col + row                         # (3, 3) — 列和行同时广播
```

## 广播规则

NumPy 从**尾部维度**开始比较，维度兼容需满足：

1. 维度相等
2. 其中一个维度为 1

```python
# 形状兼容性判断
A = (3, 1, 5)     # 原始
B = (    4, 5)    # 尾部对齐 → (3, 4, 5) ✅

A = (3, 2, 5)
B = (    4, 5)    # 维度 2 ≠ 4，且没有 1 → ❌ 不兼容
```

## ML 中的广播

```python
# 标准化：均值/标准差沿特征维度计算
X = np.random.randn(100, 10)         # 100 样本 × 10 特征
mean = X.mean(axis=0)                # (10,) — 每个特征的均值
std = X.std(axis=0)                  # (10,) — 每个特征的标准差
X_norm = (X - mean) / std            # 广播：(100,10) - (10,) → (100,10)

# 添加偏置项
X @ w + b                           # b 广播到每个样本

# 图像归一化
img = np.random.rand(224, 224, 3)   # (H, W, C)
mean = np.array([0.485, 0.456, 0.406])
std = np.array([0.229, 0.224, 0.225])
img_norm = (img - mean) / std       # 通道维度广播
```

| 应用场景 | 运算 | 形状变化 |
|:--------:|:----|:---------|
| **特征标准化** | `X - mean` | $(n,d) - (d,) \to (n,d)$ |
| **添加偏置** | `X @ w + b` | $(n,d) @ (d,1) + (1,) \to (n,1)$ |
| **Batch 归一化** | `(X - μ) / σ` | $(n,d) - (d,) / (d,) \to (n,d)$ |
| **图像归一化** | `(img - μ) / σ` | $(H,W,3) - (3,) / (3,) \to (H,W,3)$ |

## 面试追问

**Q1（基础）**：什么是 NumPy 的广播机制？一个形状为 (3, 1) 的数组与一个形状为 (1, 4) 的数组相加时，广播如何工作？

**回答要点**：广播自动将较小数组扩展到兼容形状而不实际复制数据；NumPy 从尾部维度开始比较，兼容条件为维度相等或其中一方维度为 1；(3, 1) 与 (1, 4) 广播后各自虚拟扩展为 (3, 4)，逐元素相加。

**Q2（深挖）**：广播机制底层如何实现"虚拟扩展"？相比 `np.tile()` 显式扩展有何性能优势？

**回答要点**：广播通过设置步长（strides）为 0 实现虚拟扩展，实际不复制数据；`np.tile()` 会物理复制数据并占用额外内存，当数组维度大时易 OOM；计算效率上两者接近，但广播内存效率远优于 tile，代码也更简洁。

**Q3（实战）**：在 ML 中广播常用于哪些场景？请结合特征标准化和偏置项说明广播如何简化代码。

**回答要点**：特征标准化 `(X - mean) / std` 中 mean 形状 (d,) 广播到 (n, d)；线性回归添加偏置 `X @ w + b` 中 b 广播到所有样本；图像归一化 `(H, W, 3) - (3,)` 沿通道维广播；省去手动循环或 `np.tile()` 扩展维度的冗余代码。

**Q4（边界）**：广播在什么情况下可能产生不易察觉的问题或内存风险？

**回答要点**：维度不兼容时报 `ValueError` 但错误信息可能不够直观；广播后参与运算的结果数组占用实际内存，无意中广播到极大形状可能 OOM；高维数组与标量运算时可能意外广播到非预期维度；建议用 `.reshape()` 显式管理维度并用断言检查形状一致性。
