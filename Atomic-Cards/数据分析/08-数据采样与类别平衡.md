# 数据采样与类别平衡

## 定义

数据采样是调整数据集样本分布的过程，包括**随机采样**（从总体中抽取子集）和**类别平衡**（处理分类问题中的类别不均衡）。类别不平衡是 ML 中的常见问题：当正负样本比例悬殊（如 1:1000），模型会偏向多数类，导致少数类几乎不被预测。

### 采样策略

**简单随机采样**：从总体中均匀抽取样本，每个样本被选中的概率相等。适用于数据量太大需要缩减的情况，但可能引入采样偏差（如稀有类被完全遗漏）。

**分层采样**：按类别比例分别采样，确保子集中各类别比例与总体一致。`train_test_split(stratify=y)` 在训练/测试切分中维持类别比例，是分类任务的标准做法。

**欠采样**：从多数类中随机删除样本，使多数类与少数类数量相当。优点是降低数据量和训练时间，缺点是会丢弃大量可能有信息量的多数类样本。

**过采样**：从少数类中随机复制样本，使少数类达到与多数类相同的数量。简单复制会增加模型对少数类过拟合的风险，因为复制的样本没有提供新信息。

**SMOTE**：在少数类样本之间插值生成新样本，而非简单复制。对每个少数类样本 $x_i$，随机选择 $k$ 近邻中的一个 $x_j$，生成新样本：

$$x_{\text{new}} = x_i + \lambda \cdot (x_j - x_i), \quad \lambda \in [0, 1]$$

其中 $\lambda$ 是 [0,1] 之间的随机数。SMOTE 在特征空间中生成合理的合成样本，比简单过采样泛化能力更强。

## ML/DL 应用场景

| 应用场景 | 平衡策略 | 说明 |
|:--------:|:--------|:------|
| **欺诈检测** | SMOTE + 类别权重 | 欺诈样本通常 < 1%，SMOTE 生成合成欺诈样本，配合 `class_weight='balanced'` 双重处理 |
| **医疗诊断** | 过采样 + 集成学习 | 罕见病数据极稀疏，单纯过采样不够，需结合 Bagging 或 EasyEnsemble 多模型投票 |
| **文本分类** | 分层采样 + 加权损失函数 | 长尾标签分布下，用 `weighted cross-entropy` 替代简单重采样，避免生成不自然的文本样本 |
| **推荐系统** | 负采样（Negative Sampling） | 正样本（点击）远少于负样本（未点击），按曝光数量比例进行负采样，控制正负比在 1:10~1:20 |

## 面试追问

**Q1（基础）**：什么是类别不平衡问题？为什么它对模型训练有害？
**回答要点**：

1. 类别不平衡指分类任务中各类别样本数量差异悬殊，如欺诈检测中正样本仅占 0.1%
2. 模型会偏向多数类，因为"全部预测为多数类"就能获得 99.9% 的准确率
3. 危害：准确率虚高但实际上模型完全没学到少数类的模式，在少数类上的召回率接近 0

**Q2（深挖）**：SMOTE 相比简单过采样有什么优势？它有什么潜在问题？
**回答要点**：

1. SMOTE 在少数类样本间插值生成新样本，提供更多样化的训练数据，减少过拟合风险
2. SMOTE 的问题是：在高维特征空间中，近邻也可能很远，生成的点可能跨过决策边界混入多数类区域
3. 改进版 Borderline-SMOTE 只在决策边界附近的少数类样本上生成合成数据，避免在远离边界的安全区域生成冗余样本

**Q3（实战）**：在医疗诊断（正样本 0.5%）任务中，你同时使用 SMOTE 和类别权重，为什么要双重处理？它们各自解决什么问题？
**回答要点**：

1. SMOTE 解决数据层面问题：增加少数类样本数量，让模型有更多样本学习决策边界
2. 类别权重解决损失函数层面问题：加大少数类误分类的惩罚，让优化器更关注少数类
3. 双重处理的原因：SMOTE 生成的数据可能包含噪声，类别权重作为兜底机制确保模型仍重视真实少数类样本

**Q4（边界）**：在时间序列预测中能直接使用 SMOTE 吗？为什么？如何处理时序数据的类别不平衡？
**回答要点**：

1. 不能直接使用 SMOTE，因为时序数据有时间依赖性，随机插值会破坏时间顺序
2. SMOTE 在时序中生成的点可能位于过去和未来之间，导致数据泄露（未来信息泄露到训练集）
3. 替代方案：使用时序感知的采样（只使用过去样本）、调整分类阈值、使用加权损失函数、或对少数类事件做时域增强（平移、缩放）
