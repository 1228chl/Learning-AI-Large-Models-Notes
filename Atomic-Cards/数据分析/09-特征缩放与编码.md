# 特征缩放与编码

## 定义

特征缩放与编码是数据预处理中**将原始数据转换为模型可接受的数值输入**的步骤。数值特征需要统一尺度，分类特征需要转换为数值形式。缩放方法的选择取决于模型类型和特征分布，编码方法的选择取决于类别数量和是否有序。

### 特征缩放

**标准化（Z-score Normalization）**：将特征转换为均值为 0、标准差为 1 的分布：

$$x_{\text{scaled}} = \frac{x - \mu}{\sigma}$$

适用于数据近似正态分布的场景，是 SVM、线性回归、神经网络等需要梯度下降的模型的默认选择。`sklearn` 中对应 `StandardScaler`。

**Min-Max 归一化**：将特征缩放到 [0, 1] 区间：

$$x_{\text{scaled}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$$

适用于已知特征上下界的场景，或需要保持稀疏性（如 0 值在归一化后仍是 0）。对异常值敏感，因为极端值会压缩正常值的缩放范围。对应 `MinMaxScaler`。

**稳健缩放（Robust Scaling）**：使用中位数和 IQR 进行缩放：

$$x_{\text{scaled}} = \frac{x - \text{median}}{\text{IQR}}$$

对异常值最稳健，不假设数据分布，适用于含大量异常值的特征。对应 `RobustScaler`。

### 分类特征编码

**独热编码（One-hot Encoding）**：将 $k$ 个类别展开为 $k$ 个二进制特征，每个样本在对应类别位置为 1 其余为 0。适合无序类别且类别数较少（通常 < 20）的场景。当类别数过多时会导致维度灾难。

**标签编码（Label Encoding）**：将 $k$ 个类别映射为 0 到 $k-1$ 的整数。适合有序类别（如 `low < medium < high`），或树模型中的类别变量。但在线性模型中，标签编码会引入人为的数值大小关系。

**目标编码（Target Encoding）**：用目标变量在各类别上的均值替代类别本身：

$$x_{\text{enc}} = \frac{n_{\text{class\_pos}} + \text{prior}}{n_{\text{class}} + 1}$$

其中 prior 是全局先验概率。需要交叉验证编码避免过拟合，适合高基数类别（> 100 个类别）的特征。

## ML/DL 应用场景

| 应用场景 | 推荐方法 | 说明 |
|:--------:|:--------|:------|
| **神经网络** | Z-score 标准化 + One-hot 编码 | 神经网络对输入尺度敏感，不同尺度的特征会导致梯度更新不稳定，收敛缓慢 |
| **树模型（XGBoost/LightGBM）** | 无需缩放 + 标签编码 | 树模型基于阈值分裂，对尺度不敏感；标签编码对树模型无损，且比 One-hot 更节省内存 |
| **线性模型（LR/SVM）** | Z-score 标准化 + One-hot 编码 | 线性模型依赖特征间距离和权重，标准化后系数可比，有助于正则化 |
| **高基数类别特征（>100 类）** | 目标编码 | One-hot 会导致维度爆炸，目标编码用单列代替百列，且保留与目标变量的关联信息 |

## 面试追问

**Q1（基础）**：标准化（Z-score）和归一化（Min-Max）的区别是什么？如何选择？
**回答要点**：

1. 标准化输出均值为 0、标准差为 1，无固定范围；归一化缩放到 [0, 1]，有固定范围
2. 标准化对异常值更稳健（但不如 RobustScaler）；归一化受异常值影响大，会压缩正常值的缩放范围
3. 选择：不知道特征分布时默认用标准化；特征有明确上下界（如像素值 0-255）用归一化；含大量异常值用 RobustScaler

**Q2（深挖）**：为什么树模型不需要特征缩放，而神经网络需要？背后的数学原理是什么？
**回答要点**：

1. 树模型基于阈值分裂，分裂点只考虑特征排序，不依赖特征尺度，缩放不会改变树的结构
2. 神经网络通过梯度下降更新权重，更新量 $\Delta w = \eta \cdot \frac{\partial L}{\partial w}$ 正比于输入特征值，大尺度特征导致该维度权重更新更快，需要更长收敛时间
3. 此外，未缩放的特征在 L1/L2 正则化中受到不一致的惩罚，特征值越大其权重的惩罚项占比越小

**Q3（实战）**：在线性回归中，如果特征 A 取值 0-1，特征 B 取值 0-1000000，不做缩放会怎样？如何处理？
**回答要点**：

1. 不做缩放时，特征 B 的系数会非常小（约特征 A 系数的百万分之一），梯度下降收敛极慢
2. 且 L1/L2 正则化会对特征 A 产生过大惩罚，导致模型偏向使用特征 B
3. 处理：对特征 A 和 B 统一做 Z-score 标准化，使它们均值 0 方差 1，系数可比较，正则化公平

**Q4（边界）**：One-hot 编码在类别数很多时（如 10000 个城市）会有什么问题？如何处理？
**回答要点**：

1. 10000 个类别 → 10000 列，数据矩阵极度稀疏，存储和计算开销巨大，且每个类别样本量极少
2. 解决方案：目标编码（用目标均值替代）、计数编码（用频次替代）、嵌入（Embedding，如 NN 中 `nn.Embedding` 层）
3. 最实用的方法：频次阈值压缩（出现次数 < 10 次的类别统一归为"other"类），将有效类别数降至可接受范围
