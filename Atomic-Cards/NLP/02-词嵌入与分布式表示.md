# 词嵌入与分布式表示

## 定义

词嵌入（Word Embedding）将离散的词汇映射到低维稠密向量空间中，使得**语义相近的词在向量空间中距离相近**。这是分布式表示（Distributional Representation）的核心思想——"You shall know a word by the company it keeps."

```python
import torch.nn as nn

# 嵌入层：词表大小 10000，每个词映射为 256 维向量
embedding = nn.Embedding(num_embeddings=10000, embedding_dim=256)

# 输入：token IDs，形状 (N, L)
input_ids = torch.randint(0, 10000, (2, 10))
output = embedding(input_ids)          # (2, 10, 256)
```

## 独热编码 vs 词嵌入

| 对比 | One-Hot | 词嵌入 (Embedding) |
|:----:|:--------:|:------------------:|
| 维度 | 词表大小 $V$ | 可自定义 $d$ （常为 50-1024） |
| 稀疏性 | ✅ 稀疏（只有一个 1） | ❌ 稠密（所有值非零） |
| 语义关系 | ❌ 无法表示 | ✅ 可表示类比关系 |
| 参数量 | $V$ | $V \times d$ （可训练） |
| 示例 | `[0,0,1,0,...,0]` | `[0.23, -0.15, 0.67, ...]` |

## Word2Vec

Word2Vec 是 2013 年由 Google 提出的经典词嵌入训练方法，两种架构：

| 架构 | 输入→输出 | 目标 | 类比 |
|:----:|:--------:|:----:|:----:|
| **CBOW** | 上下文词 → 目标词 | 根据周围词预测中心词 | 完形填空 |
| **Skip-gram** | 目标词 → 上下文词 | 根据中心词预测周围词 | 词汇联想 |

**经典类比结果**： $\text{vec(king)} - \text{vec(man)} + \text{vec(woman)} \approx \text{vec(queen)}$

| 方法 | 年份 | 特点 | 说明 |
|:----:|:----:|:----|------|
| **Word2Vec** | 2013 | 静态词向量 | 每个词只有一个固定向量 |
| **GloVe** | 2014 | 基于全局共现统计 | 结合矩阵分解和 Word2Vec 优点 |
| **FastText** | 2016 | 子词信息 | 可处理 OOV，多语言 |
| **BERT** | 2018 | **上下文相关**动态表示 | 同一词在不同语境有不同向量 |
| **GPT** | 2018 | 上下文相关 + 生成式 | 自回归语言模型 |

## ML 中的词嵌入

| 应用场景 | 使用方式 | 说明 |
|----------|----------|------|
| **文本分类** | 嵌入层 + CNN/RNN/Transformer | 将 token IDs 转换为向量序列 |
| **命名实体识别** | 嵌入层 + BiLSTM + CRF | 序列标注 |
| **机器翻译** | 编码器嵌入 + 解码器嵌入 | 跨语言映射 |
| **推荐系统** | Item embedding 作为特征 | 用户-物品协同过滤 |
| **图嵌入** | Node embedding 学习节点表示 | GraphSAGE、Node2Vec |

## 面试追问

**Q1（基础）**：词嵌入（Word Embedding）的核心思想是什么？它与独热编码的根本区别在哪里？

**回答要点**：基于分布式假设——"由同伴认识一个词"；低维稠密向量可表示语义相似度；独热编码高维稀疏、无语义关系、参数量为 V 而非 V×d。

**Q2（深挖）**：Word2Vec 的 CBOW 和 Skip-gram 两种架构有什么区别？在实际训练中如何选择？

**回答要点**：CBOW 用上下文预测中心词，训练快、对高频词效果好；Skip-gram 用中心词预测上下文，训练慢但对低频词和小数据集效果更好；Skip-gram 生成的词向量质量通常更高。

**Q3（实战）**：在一个垂直领域（如医疗或法律）的 NLP 项目中，你会选择使用预训练词向量还是从头训练？具体怎么决策？

**回答要点**：垂直领域术语多且通用词向量覆盖差时，应从头训练或领域语料继续训练（continue training）；通用领域可直接加载 GloVe/FastText 预训练向量；实践中常用"预训练初始化 + 领域微调"的混合方案。

**Q4（边界）**：静态词向量（如 Word2Vec）的根本局限是什么？为什么 BERT 的上下文动态表示能超越它？

**回答要点**：静态词向量给每个词唯一的固定向量，无法处理一词多义（如 "bank" 在河岸 vs 银行的含义相同）；BERT 根据上下文生成不同的向量表示，解决了多义词歧义问题。
