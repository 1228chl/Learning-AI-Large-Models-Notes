# 注意力机制

## 定义

注意力机制（Attention Mechanism）让模型在生成每个输出时**动态关注输入序列的特定位置**，打破了 Seq2Seq 模型中固定长度上下文向量的"信息瓶颈"。

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

注意力本质是一个**加权求和**——模型根据查询 $Q$ 与键 $K$ 的相似度，对值 $V$ 进行加权组合。

## 注意力计算方式

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V):
    """缩放点积注意力"""
    scores = Q @ K.transpose(-2, -1) / (K.size(-1) ** 0.5)
    weights = F.softmax(scores, dim=-1)
    return weights @ V
```

| 注意力类型 | 公式 | 复杂度 | 特点 |
|:---------:|:----:|:------:|------|
| **加性（Additive/Bahdanau）** | $v^T \tanh(W_1 Q + W_2 K)$ | $O(n^2 \cdot d)$ | 早期 RNN 注意力 |
| **点积（Dot-Product/Luong）** | $Q^T K$ | $O(n^2)$ | 简单快速 |
| **缩放点积（Scaled Dot-Product）** | $\frac{Q^T K}{\sqrt{d_k}}$ | $O(n^2)$ | **默认首选**，梯度稳定 |

## Bahdanau Attention vs Luong Attention

| 对比 | Bahdanau（加性，2014） | Luong（点积，2015） |
|:----:|:---------------------:|:------------------:|
| **计算方式** | 加性 $v^T \tanh(W[q; h])$ | 点积 $q^T h$ |
| **Decoder 对齐** | 上一时间步隐状态计算 | 当前时间步隐状态计算 |
| **计算量** | 大（需训练 $W$ 和 $v$） | 小 |
| **RNN 匹配度** | 天然适合 | 需更多 Trick |

## 注意力的核心作用

```
不带注意力：       "I love cats" → [固定向量 C] → "我 爱 猫"
带注意力：         "I love cats"
                     ↑  ↑  ↑
                    [0.1, 0.8, 0.1]  ← 当前步对各输入词的关注权重
                       ↓
                    "爱" ← 当前步输出
```

| 作用 | 说明 |
|:----|------|
| **对齐（Alignment）** | 找到输入中与当前输出最相关的部分 |
| **信息选择** | 从输入中提取相关信息，忽略无关信息 |
| **可解释性** | 注意力权重可视化展示模型关注点 |

## ML 中的注意力

| 应用场景 | 注意力形式 | 说明 |
|:--------:|:---------:|------|
| **机器翻译（Seq2Seq+Attn）** | Encoder-Decoder Attention | 翻译时关注原句对应位置 |
| **Transformer** | 自注意力 + 交叉注意力 | 编码器自注意，解码器交叉注意 |
| **图像 Captioning** | 图像区域注意力 | 生成每个词时关注不同图像区域 |
| **视觉问答（VQA）** | 问题和图像的双向注意力 | 根据问题关注图像相关区域 |
| **推荐系统** | 用户行为序列注意力 | 关注历史行为中重要的交互 |
