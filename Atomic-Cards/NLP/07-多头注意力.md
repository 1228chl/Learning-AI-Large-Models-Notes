# 多头注意力

## 定义

多头注意力（Multi-Head Attention）将 $Q, K, V$ 投影到 $h$ 个不同的子空间，在每个子空间独立计算注意力，然后将结果拼接并投影回原始维度。

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O$$

$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

```python
import torch.nn as nn

# PyTorch 多头注意力
mha = nn.MultiheadAttention(
    embed_dim=512,     # 模型总维度
    num_heads=8,       # 注意力头数（512 / 8 = 64 每头）
    batch_first=True
)

# 输入形状: (N, L, d)
output, weights = mha(query, key, value)
# output: (N, L, 512), weights: (N, 8, L, L)
```

## 为什么需要多头？

```
单头注意力：所有信息混合在一个注意力模式中
           "这只猫在追那只狗，它跑得很快"
                               ↑
                         "它"关注了 "猫"？还是"狗"？
                         → 只能聚焦一个关系

多头注意力：8个独立的注意力模式
           头1: 语法关系（动词-主语）
           头2: 语义关系（代词-指代）
           头3: 位置关系（远近）
           ...
           → 每个头学习不同类型的关系
```

| 特性 | 单头注意力 | 多头注意力 |
|:----:|:---------:|:----------:|
| 表达能力 | 一种关系模式 | $h$ 种不同关系模式 |
| 并行性 | 单个注意力 | 每个头独立计算，可并行 |
| 参数 | 少 | $h$ 组 $W^Q, W^K, W^V$ |
| 可解释性 | — | 可分析每个头关注什么 |

## 注意力头的角色

通过分析预训练模型（如 BERT）的各注意力头，发现不同头学习不同的语言模式：

| 注意力头类型 | 关注模式 | 示例 |
|:-----------:|:--------:|:----|
| **语法头** | 词性依赖 | 动词 → 主语、形容词 → 名词 |
| **位置头** | 相邻词 | 关注左右邻词 |
| **语义头** | 远距离指代 | 代词 → 其指代的名词 |
| **特殊头** | [CLS] / [SEP] | 关注特殊标记 |

## ML 中的多头注意力

| 模型 | 注意力配置 | 说明 |
|:----:|:---------:|------|
| **BERT-base** | 12 层 × 12 头 | $d_{head} = 768 / 12 = 64$ |
| **BERT-large** | 24 层 × 16 头 | $d_{head} = 1024 / 16 = 64$ |
| **GPT-3** | 96 层 × 96 头 | $d_{head} = 12288 / 96 = 128$ |
| **LLaMA** | 32 层 × 32 头 | 使用分组查询注意力（GQA） |
