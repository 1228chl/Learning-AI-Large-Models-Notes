# 位置编码

## 定义

位置编码（Positional Encoding）为 Transformer 注入**序列中词的位置信息**。自注意力本身是**排列不变**的——它将输入视为无序的集合，改变词序不会影响输出。位置编码弥补了这一缺陷。

## 直观理解

### 为什么 Transformer 需要位置编码？

自注意力机制中，每个 token 通过 $QK^T$ 与其他所有 token 计算相似度。如果不加位置信息，"猫追狗"和"狗追猫"在自注意力中的表示将完全相同——因为语义内容相同，只是顺序不同。位置编码的作用是**在 token 的表示中注入"我在第几个位置"的信息**，打破置换不变性。

### 正弦位置编码的原理

Transformer 原版的正弦位置编码使用不同频率的正弦和余弦函数：
- 低频维度（sin/cos 周期长）：编码大范围的绝对位置信息
- 高频维度（sin/cos 周期短）：编码相邻位置的相对差异
- 不同维度的组合形成了每个位置的独特"坐标"

这种编码的关键性质：$PE_{pos+k}$ 可以通过 $PE_{pos}$ 的线性变换得到，使模型可以学会"位置偏移量"的概念。

## 三角位置编码（Sinusoidal）

原版 Transformer 使用固定频率的正余弦函数：

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d}}\right)$$
$$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

其中 $pos$ 是位置，$i$ 是维度索引，$d$ 为模型维度（d_model）。

```python
import torch
import math

# 生成正弦波位置编码矩阵，为序列每个位置分配唯一的频率编码
# 自注意力本身无位置概念，位置编码弥补这一缺陷
def sinusoidal_positional_encoding(seq_len, d_model):
    # 初始化全零的位置编码矩阵，形状为 (seq_len, d_model)
    pe = torch.zeros(seq_len, d_model)
    # 生成位置索引 [0, 1, ..., seq_len-1] 并转为列向量，便于与频率向量广播计算
    position = torch.arange(0, seq_len).unsqueeze(1).float()
    # 计算不同维度的频率系数：偶数维使用 sin，奇数维使用 cos
    # dim 越小频率越高（捕捉局部模式），dim 越大频率越低（捕捉全局模式）
    div_term = torch.exp(torch.arange(0, d_model, 2).float() * 
                         -(math.log(10000.0) / d_model))
    # 偶数维度索引 (2i) 使用正弦函数编码位置信息
    pe[:, 0::2] = torch.sin(position * div_term)
    # 奇数维度索引 (2i+1) 使用余弦函数编码位置信息
    pe[:, 1::2] = torch.cos(position * div_term)
    # 返回形状为 (seq_len, d_model) 的编码矩阵，直接与词嵌入相加输入模型
    return pe
```

## 位置编码类型对比

| 类型 | 实现方式 | 代表模型 | 特点 |
|:----:|:---------|:--------:|------|
| **Sinusoidal**（固定） | 正余弦函数 | 原版 Transformer | 固定，可外推到更长序列 |
| **可学习嵌入** | 作为参数训练 | BERT、GPT | 灵活，但限最大长度 |
| **相对位置编码** | 位置差作为偏置 | T5、DeBERTa | 关注相对距离而非绝对位置 |
| **RoPE（旋转编码）** | 旋转矩阵变换 | LLaMA、PaLM | 相对编码 + 绝对编码优点 |
| **ALiBi** | 按距离线性衰减 | BLOOM | 简单高效，可外推 |

## RoPE（旋转位置编码）

LLaMA 等最新大模型使用的编码方式，将位置信息通过**旋转矩阵**作用于 $Q$ 和 $K$：

$$f_q(x_m, m) = (x_m W_q) \cdot e^{im\theta}$$
$$f_k(x_n, n) = (x_n W_k) \cdot e^{in\theta}$$

其中：
- $x_m$、$x_n$：第 $m$、$n$ 个位置的输入向量
- $W_q$：查询（Query）权重矩阵
- $W_k$：键（Key）权重矩阵
- $\theta$：旋转频率（基频角度）

**核心性质**：$Q$ 和 $K$ 的点积仅依赖于它们的**相对位置差** $m-n$，而非绝对位置。

$$
\text{score}(m, n) = Q(x_m, m)^T \cdot K(x_n, n) = f(x_m, x_n, m-n)
$$

## ML 中的位置编码

| 模型 | 位置编码 | 最大长度 |
|:----:|:--------:|:--------:|
| **Transformer** | Sinusoidal | 512 |
| **BERT** | 可学习嵌入 | 512 |
| **GPT-3** | 可学习嵌入 | 2048 |
| **LLaMA** | RoPE | 2048（可外推至更长） |
| **BLOOM** | ALiBi | 2048（可外推至 >200K） |

## 面试追问

**Q1（基础）**：为什么 Transformer 需要位置编码？如果去掉位置编码会怎样？
**回答要点**：

1. 自注意力是置换不变的（permutation invariant），它将输入视为无序集合
2. 改变词序不改变输出，"我打你"与"你打我"会得到相同表示
3. 位置编码是注入序列顺序信息的唯一方式

**Q2（深挖）**：Sinusoidal（固定正余弦）位置编码与可学习位置嵌入各有什么优缺点？哪种更适合外推到更长序列？
**回答要点**：

1. Sinusoidal 固定无参数、可利用三角恒等式表达相对位置、可外推至更长的序列
2. 可学习嵌入更灵活但受限于训练时的最大长度
3. Sinusoidal 和 RoPE 更适合超出训练长度的推理场景

**Q3（实战）**：你想训练一个能处理 8192 长度上下文的模型，而预训练模型最大只支持 512。你会选择哪种位置编码方案？具体怎么改造？
**回答要点**：

1. RoPE 或 ALiBi 是首选，它们天然支持长度外推
2. 如果使用绝对位置编码，可通过插值（position interpolation）来扩展
3. 需在下游任务数据上继续训练几步适应新的位置范围

**Q4（边界）**：绝对位置编码（如可学习嵌入）有哪些根本性局限？RoPE（旋转位置编码）是如何克服这些局限的？
**回答要点**：

1. 绝对位置编码赋予每个位置固定 ID，注意力得分仅依赖绝对位置
2. RoPE 通过旋转矩阵编码位置，使 Q 和 K 的点积仅依赖于相对位置差 $m-n$
3. 相对编码更好泛化、支持外推、不受 max_seq_len 硬约束
