# 位置编码

## 定义

位置编码（Positional Encoding）为 Transformer 注入**序列中词的位置信息**。自注意力本身是**排列不变**的——它将输入视为无序的集合，改变词序不会影响输出。位置编码弥补了这一缺陷。

## 三角位置编码（Sinusoidal）

原版 Transformer 使用固定频率的正余弦函数：

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d}}\right)$$
$$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

其中 $pos$ 是位置，$i$ 是维度索引。

```python
import torch
import math

def sinusoidal_positional_encoding(seq_len, d_model):
    pe = torch.zeros(seq_len, d_model)
    position = torch.arange(0, seq_len).unsqueeze(1).float()
    div_term = torch.exp(torch.arange(0, d_model, 2).float() * 
                         -(math.log(10000.0) / d_model))
    pe[:, 0::2] = torch.sin(position * div_term)
    pe[:, 1::2] = torch.cos(position * div_term)
    return pe
```

## 位置编码类型对比

| 类型 | 实现方式 | 代表模型 | 特点 |
|:----:|:---------|:--------:|------|
| **Sinusoidal**（固定） | 正余弦函数 | 原版 Transformer | 固定，可外推到更长序列 |
| **可学习嵌入** | 作为参数训练 | BERT、GPT | 灵活，但限最大长度 |
| **相对位置编码** | 位置差作为偏置 | T5、DeBERTa | 关注相对距离而非绝对位置 |
| **RoPE（旋转编码）** | 旋转矩阵变换 | LLaMA、PaLM | 相对编码 + 绝对编码优点 |
| **ALiBi** | 按距离线性衰减 | BLOOM | 简单高效，可外推 |

## RoPE（旋转位置编码）

LLaMA 等最新大模型使用的编码方式，将位置信息通过**旋转矩阵**作用于 $Q$ 和 $K$：

$$f_q(x_m, m) = (x_m W_q) \cdot e^{im\theta}$$
$$f_k(x_n, n) = (x_n W_k) \cdot e^{in\theta}$$

**核心性质**：$Q$ 和 $K$ 的点积仅依赖于它们的**相对位置差** $m-n$，而非绝对位置。

```python
# RoPE 使注意力得分只依赖于位置差
score(m, n) = Q(x_m, m)^T \cdot K(x_n, n) = f(x_m, x_n, m-n)
```

## ML 中的位置编码

| 模型 | 位置编码 | 最大长度 |
|:----:|:--------:|:--------:|
| **Transformer** | Sinusoidal | 512 |
| **BERT** | 可学习嵌入 | 512 |
| **GPT-3** | 可学习嵌入 | 2048 |
| **LLaMA** | RoPE | 2048（可外推至更长） |
| **BLOOM** | ALiBi | 2048（可外推至 >200K） |
