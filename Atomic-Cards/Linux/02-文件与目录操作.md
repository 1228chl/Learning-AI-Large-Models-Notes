# 文件与目录操作

## 命令格式

```bash
command [选项] [参数]
```

- 短选项：`-l`、`-a`，可合并为 `-la`
- 长选项：`--help`、`--all`

## 目录操作

| 命令 | 作用 | 常用示例 |
|------|------|----------|
| `pwd` | 显示当前工作目录绝对路径 | `pwd` → `/home/user` |
| `cd` | 切换目录 | `cd ..`（上级）、`cd ~`（家目录）、`cd -`（上次） |
| `mkdir` | 创建目录 | `mkdir -p a/b/c`（递归创建） |
| `rmdir` | 删除空目录 | `rmdir dir`（只能删空目录） |

## 文件操作

| 命令 | 作用 | 常用示例 |
|------|------|----------|
| `ls` | 列出目录内容 | `ls -l`（详情）、`ls -a`（含隐藏）、`ls -lh`（可读大小） |
| `touch` | 创建空文件 / 更新修改时间 | `touch file.txt` |
| `cp` | 复制文件或目录 | `cp -r src/ dst/`（递归复制目录） |
| `mv` | 移动或重命名 | `mv old new` |
| `rm` | 删除文件或目录 | `rm -rf dir/`（递归强制删除，谨慎!） |
| `find` | 查找文件 | `find / -name "*.py"`、`find . -size +100M` |

## 通配符

| 通配符 | 含义 | 示例 |
|--------|------|------|
| `*` | 匹配任意字符（含空） | `*.txt` 匹配所有 `.txt` 文件 |
| `?` | 匹配单个字符 | `file?.txt` 匹配 `file1.txt` |
| `[]` | 匹配括号内任一字符 | `file[0-9].txt` 匹配 `file0.txt` ~ `file9.txt` |

## ML 使用场景

```bash
# 清理训练过程中产生的 checkpoint（保留最新 3 个）
ls -lt checkpoints/*.pt | tail -n +4 | xargs rm

# 递归查找所有模型配置文件
find . -name "*.yaml" -o -name "*.json" | grep config

# 统计代码行数
find . -name "*.py" | xargs wc -l

# 查看数据集大小
du -sh /data/dataset/

# 创建项目目录结构
mkdir -p project/{data/{raw,processed},models,configs,logs}
```

## 面试追问

**Q1（基础）**：列举 5 个日常最常用的文件目录操作命令及其核心功能。

**回答要点**：1）`ls -l` 列出文件详情（权限、大小、修改时间）；2）`cp -r` 递归复制目录；3）`mv` 移动或重命名文件/目录；4）`rm -rf` 递归强制删除（需谨慎）；5）`find` 按名称/大小/时间查找文件。

**Q2（深挖）**：Shell 通配符（glob pattern）与正则表达式（regex）有何区别？各在什么场景下使用？

**回答要点**：1）通配符由 Shell 展开，用于匹配文件名—— `*` 匹配任意字符、`?` 匹配单个字符、`[abc]` 匹配集合中的字符；2）正则表达式由工具（grep/awk/sed）解释，用于匹配文本内容—— `.*` 表示任意字符重复、`[0-9]+` 表示一位以上数字、支持量词和分组；3）通配符用于命令行文件操作（rm *.txt），正则需要用引号包裹（grep '^ERROR' log）。

**Q3（实战）**：你用 find + xargs 组合解决过什么实际问题？请举例说明。

**回答要点**：1）批量清理旧 checkpoint：`find . -name "*.pt" -mtime +7 | xargs rm`；2）统计项目代码行数：`find . -name "*.py" | xargs wc -l`；3）批量替换配置文件参数：`find configs/ -name "*.yaml" | xargs sed -i 's/batch_size: 32/batch_size: 64/g'`；4）注意点：文件名含空格时需加 `-print0` 与 `xargs -0` 组合以避免分割错误。

**Q4（边界）**：`rm -rf` 命令在什么场景下可能造成严重损失？如何防止误删除？

**回答要点**：1）危险场景：在自动化脚本中使用 `rm -rf $DIR/*` 且 `$DIR` 为空时相当于 `rm -rf /*`；软链接到关键目录后误删源文件；2）预防措施：先用 `ls` 确认路径；用 `rm -i` 交互确认；脚本中加 `set -u` 阻止未定义变量；重要数据使用版本控制（git）或定期备份；考虑使用 `trash-cli` 替代直接删除。
