# 文本处理三剑客

## grep — 文本搜索

根据模式搜索文件内容，返回匹配的行：

```bash
grep [选项] "模式" 文件

# 常用用法
grep "error" train.log              # 搜索包含 error 的行
grep -i "warning" train.log         # 忽略大小写
grep -r "import torch" ./src/       # 递归搜索目录
grep -n "accuracy" train.log        # 显示行号
grep -c "epoch" train.log           # 统计匹配次数
grep -A 3 -B 2 "loss:" train.log    # 显示匹配行前后 N 行
grep -v "DEBUG" train.log           # 反向匹配（排除）
```

## sed — 流编辑器

对文本进行替换、删除、插入等操作，常用于批处理：

```bash
sed 's/旧/新/g' file.txt              # 全局替换
sed -i 's/learning_rate: 0.01/learning_rate: 0.001/g' config.yaml  # 原地替换
sed -n '10,20p' train.log            # 打印 10-20 行
sed '/^$/d' file.txt                 # 删除空行
```

## awk — 文本分析工具

按列处理结构化文本，默认按空格/Tab 分割：

```bash
awk '{print $1, $NF}' file.txt        # 打印第一列和最后一列
awk '$3 > 90 {print $1, $3}' score.txt # 条件过滤
awk '{sum+=$1} END {print sum/NR}'   # 计算第一列平均值

# ML 日志分析：提取每个 epoch 的 loss
grep "Epoch" train.log | awk '{print $3, $7}'
```

## ML 中的黄金组合

```bash
# 1. 提取 loss 曲线数据（接 TensorBoard 或 matplotlib）
grep "Train Loss:" train.log | awk '{print $NF}' > train_loss.txt

# 2. 统计错误类型
grep "Error:" train.log | awk '{print $2}' | sort | uniq -c | sort -nr

# 3. 过滤训练日志中的关键指标
grep -E "(Epoch|Test Acc|Best)" train.log

# 4. 批量替换配置文件参数
find configs/ -name "*.yaml" -exec sed -i 's/batch_size: 32/batch_size: 64/g' {} +

# 5. 查看最大的 checkpoint 文件
ls -lh checkpoints/*.pt | awk '{print $5, $NF}' | sort -h

# 6. 从 tensorboard 日志提取标量数据
grep "step_value" events.out.tfevents.* | awk '{print $2, $4}'
```
