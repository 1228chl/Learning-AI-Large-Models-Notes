# 网络与系统监控

## 远程连接与文件传输

```bash
# SSH 远程登录
ssh user@192.168.1.100               # 基本登录
ssh -p 2222 user@host                # 指定端口
ssh -i ~/.ssh/id_rsa user@host       # 密钥登录
ssh -L 8888:localhost:8888 user@host # 端口转发（远程 Jupyter）

# SCP 文件传输
scp file.txt user@host:/remote/path/           # 本地→远程
scp user@host:/remote/path/file.txt ./         # 远程→本地
scp -r data_dir/ user@host:/remote/dir/        # 递归传输目录

# rsync（增量同步，大型数据传输推荐）
rsync -avz data/ user@host:/remote/data/       # 只传输差异部分
rsync -avz --progress data/ user@host:/data/   # 显示进度
```

## 网络请求与下载

```bash
# curl（HTTP 请求工具，调试 API 接口）
curl http://localhost:8000/api/health           # GET 请求
curl -X POST -H "Content-Type: application/json" \
  -d '{"text":"hello"}' http://localhost:8000/predict  # POST

# wget（文件下载）
wget https://huggingface.co/bert-base-uncased/resolve/main/pytorch_model.bin
wget -c https://...                              # 断点续传
```

## 磁盘与内存监控

```bash
# 磁盘
df -h                   # 查看磁盘分区使用情况（人类可读格式）
du -sh /data/           # 查看目录总大小
du -h --max-depth=1 .   # 查看当前目录下一级子目录大小

# 内存
free -h                 # 查看内存使用情况（-h 人类可读）
free -m                 # 以 MB 为单位

# 系统负载
uptime                  # 查看系统运行时间和平均负载
```

## GPU 监控

```bash
# 最常用：查看 GPU 状态
nvidia-smi              # GPU 型号、显存、温度、进程
watch -n 1 nvidia-smi   # 每秒刷新（Ctrl+C 退出）

# 进阶监控工具（需安装）
gpustat                 # 更友好的 GPU 状态查看
nvtop                   # GPU 版的 htop
nvitop                  # 更全面的 GPU 进程管理
```

## ML 运维常用组合

```bash
# 1. 检查训练环境
nvidia-smi && python -c "import torch; print(torch.cuda.is_available())"

# 2. 空间不足时快速清理
du -sh /tmp/* | sort -hr | head -10     # 找到最大的临时文件
find . -name "*.pt" -size +1G           # 找到大于 1G 的 checkpoint

# 3. 后台训练 + 资源监控
nohup python train.py > train.log 2>&1 &
watch -n 30 nvidia-smi                  # 每 30 秒检查 GPU 状态
tail -f train.log                       # 同时查看日志

# 4. 端口冲突排查
lsof -i :8888                           # 查看端口占用
kill -9 $(lsof -ti :8888)               # 杀掉占用端口的进程

# 5. 多 GPU 训练设置
export CUDA_VISIBLE_DEVICES=0,1,2,3     # 指定可见 GPU
python -m torch.distributed.launch --nproc_per_node=4 train.py
```
