# 进程管理

## 进程查看

```bash
# 查看当前终端进程
ps

# 查看所有进程（BSD 风格）
ps aux                      # a=所有用户, u=用户格式, x=包含无终端的进程
ps aux | grep python        # 查找 Python 相关进程

# 查看进程树
ps -ef --forest

# 动态监控（类任务管理器）
top                         # 实时进程监控，按 q 退出
htop                        # top 的增强版（需安装）
```

`top` 输出关键字段：`PID`（进程ID）、`%CPU`（CPU 使用率）、`%MEM`（内存使用率）、`COMMAND`（命令名）

## 进程信号与终止

```bash
kill -15 PID                # SIGTERM：优雅终止（默认）
kill -9 PID                 # SIGKILL：强制杀死（无法捕获）
kill -2 PID                 # SIGINT：等同于 Ctrl+C

pkill python                # 按名称杀死所有 python 进程
killall train.py            # 杀死所有同名进程
```

| 信号 | 编号 | 含义 | 触发方式 |
|------|------|------|----------|
| SIGHUP | 1 | 挂起 | 终端断开时触发 |
| SIGINT | 2 | 中断 | `Ctrl+C` |
| SIGTERM | 15 | 终止 | `kill PID`（默认） |
| SIGKILL | 9 | 强制杀死 | `kill -9 PID`（无法阻塞） |
| SIGSTOP | 19 | 暂停 | `Ctrl+Z` |

## 后台运行

```bash
# 1. & 后台运行
python train.py &

# 2. nohup：终端关闭后继续运行
nohup python train.py > train.log 2>&1 &

# 3. screen/tmux：会话保持
screen -S train             # 创建会话
# 运行训练脚本，然后 Ctrl+A, D 分离
screen -r train             # 重新连接会话

tmux new -s train           # tmux 版本
tmux attach -t train
```

## systemctl — 服务管理

```bash
systemctl start docker              # 启动服务
systemctl stop docker               # 停止服务
systemctl restart docker            # 重启服务
systemctl status docker             # 查看状态
systemctl enable docker             # 开机自启
systemctl disable docker            # 关闭开机自启
```

## ML 进程管理场景

```bash
# 1. 启动长时间训练任务（断开 SSH 也不中断）
nohup python train.py --config config.yaml > logs/train_$(date +%Y%m%d).log 2>&1 &
echo $! > pid.txt                   # 记录 PID

# 2. 查看 GPU 使用情况和对应进程
nvidia-smi
ps -f -p $(nvidia-smi | grep python | awk '{print $5}')

# 3. 杀死占用 GPU 的僵尸进程
kill -9 $(nvidia-smi | grep -E "^| [0-9]+ " | awk '{print $3}')

# 4. 查看端口占用
lsof -i :8888                       # 查看 8888 端口被哪个进程占用
netstat -tlnp | grep 8888

# 5. 限制进程资源（使用 nice/renice）
nice -n 10 python train.py          # 降低优先级，让其他任务优先
```
