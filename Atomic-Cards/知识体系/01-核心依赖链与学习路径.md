# 核心依赖链与学习路径

## 定义

核心依赖链将全部知识点按**前置依赖关系**排列为有向无环图（DAG），揭示"为什么先学 A 才能学 B"的逻辑必然性。

## 全景依赖链

```
层级0（数学地基）── 线性代数 ── 概率统计 ── 微积分 ── 优化理论
    │                    │            │            │
    └────────────────────┴────────────┴────────────┘
                              │
                              ↓
层级1（编程实现）── Python ── NumPy ── Pandas ── PyTorch
                              │
                              ↓
层级2（模型基础）── 线性回归 ── 逻辑回归 ── 神经网络
                              │
                              ↓
层级3（深度模型）── CNN ── RNN/LSTM ── Transformer
                              │
                              ↓
层级4（NLP应用）── 词嵌入 ── BERT ── GPT ── LLM
                              │
                              ↓
层级5（工程应用）── RAG ── Agent ── 模型压缩 ── 部署
```

## 各层级核心知识

| 层级 | 名称 | 核心知识点 | 重要度 |
|:----:|:----|:----------|:------:|
| **0** | 数学地基 | 向量、矩阵、概率、导数 | ⭐⭐⭐⭐⭐ |
| **1** | 编程实现 | Python、NumPy、PyTorch 张量 | ⭐⭐⭐⭐⭐ |
| **2** | 模型基础 | 回归、梯度下降、反向传播 | ⭐⭐⭐⭐⭐ |
| **3** | 深度模型 | CNN、RNN、LSTM、Transformer | ⭐⭐⭐⭐⭐ |
| **4** | NLP 应用 | BERT、GPT、微调、提示词 | ⭐⭐⭐⭐⭐ |
| **5** | 工程应用 | RAG、Agent、部署、压缩 | ⭐⭐⭐⭐ |

## 学习路径建议

```yaml
第一阶段（数学 + 编程）:
  线性代数 → Python → NumPy → 概率统计 → 微积分

第二阶段（ML 基础）:
  机器学习概论 → 线性回归 → 逻辑回归 → KNN → 决策树 → 集成学习 → 评估

第三阶段（深度学习）:
  PyTorch → 反向传播 → CNN → RNN/LSTM → Transformer

第四阶段（NLP + LLM）:
  词嵌入 → BERT → GPT → 提示词工程 → RAG → Agent

第五阶段（工程）:
  特征工程 → 模型调优 → Docker → 模型压缩 → 部署
```


## 面试追问

**Q1（基础）**：核心依赖链为什么用 DAG（有向无环图）来组织知识点？这种结构解决了什么核心问题？
回答要点：①DAG 天然表达前置依赖关系——A 指向 B 表示 A 是 B 的前置知识；②无环特性保证学习路径不会出现「学 C 需要先学 D，但学 D 又需要先学 C」的死循环；③让学习者能快速定位当前知识点的所有上游依赖和下游应用。

**Q2（深挖）**：为什么数学地基（线性代数、概率统计）被放在层级 0，而不是直接从编程或模型开始？缺少这些数学基础会带来什么具体障碍？
回答要点：①线性代数是神经网络矩阵运算的底层语言（张量、权重矩阵、SVD 降维）；②概率统计是损失函数（交叉熵、最大似然）、评估指标（AUC、置信区间）的理论根基；③缺少数学基础会导致对梯度消失/爆炸、正则化原理、注意力机制公式等核心概念只能死记硬背，无法真正理解和调优。

**Q3（实战）**：在你的学习或项目中，如何利用这张依赖链来排定学习优先级？如果时间有限，哪些层级的「跳过」风险最大？
回答要点：①按层级 0→5 逐层递进，遇到知识点卡壳时沿着依赖链回溯查找缺失的前置知识；②层级 0（数学）和层级 2（模型基础）跳过风险最大——它们是后续所有模型和工程的上游根基；③层级 5（工程）在非部署场景下可做减法，但至少需要理解 RAG 和 Agent 的应用场景。

**Q4（边界）**：这张依赖链是否存在过度简化的问题？在实际学习中，哪些场景下需要突破这个线性顺序？
回答要点：①不同背景的学习者起点不同——数学专业可直接从层级 2 开始，CS 专业可先补概率统计再进入层级 1；②许多概念可以并行学习（如学习 CNN 的同时巩固线性代数中的卷积运算），不必严格串行；③依赖链未考虑实践与理论的交替迭代——实际中「做项目 → 发现知识盲区 → 回补理论」的循环往往比一次性学完所有理论更高效。
