# 梯度与方向导数

## 定义

**方向导数**（Directional Derivative）是多元函数沿某个方向 $\mathbf{d}$ 的变化率：

$$D_{\mathbf{d}} f(\mathbf{x}) = \lim_{h \to 0} \frac{f(\mathbf{x} + h\mathbf{d}) - f(\mathbf{x})}{h}$$

**梯度**（Gradient）是偏导数组成的向量，指向函数值增加最快的方向：

$$\nabla f = \left[ \frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_n} \right]^T$$

方向导数与梯度的关系：$D_{\mathbf{d}} f(\mathbf{x}) = \nabla f(\mathbf{x}) \cdot \mathbf{d}$

## 几何意义

| 性质 | 含义 |
|------|------|
| **梯度方向** | 函数值**增加**最快的方向 |
| **负梯度方向** | 函数值**减小**最快的方向 |
| **梯度大小** $\|\nabla f\|$ | 函数变化的最大速率 |
| **等高线垂直** | 梯度垂直于函数的等高线/等值面 |
| **零梯度** | $\nabla f = \mathbf{0}$ 处为驻点（极值或鞍点） |

## 梯度在 ML 中的核心地位

梯度是连接**微积分**与**机器学习模型训练**的桥梁：

| 场景 | 数学形式 | 直觉 |
|------|----------|------|
| **梯度下降** | $\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$ | 沿负梯度方向走下山坡 |
| **梯度裁剪** | $\mathbf{g} \leftarrow \mathbf{g} \cdot \frac{\text{clip}}{\|\mathbf{g}\|}$ | 防止梯度爆炸 |
| **梯度累积** | $\mathbf{g}_{\text{total}} = \sum_{i=1}^{B} \nabla L_i$ | 模拟大批量训练 |
| **自然梯度** | $\Delta \theta = -F^{-1}\nabla L(\theta)$ | 考虑参数空间曲率 |

> 梯度向量本身是 $\mathbb{R}^n$ 中的向量，梯度的方向就是损失函数增长最快的方向，而**我们想要的是损失下降最快的方向——即负梯度方向**。这正是梯度下降法的全部数学基础。
