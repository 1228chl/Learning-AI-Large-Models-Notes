# 导数与偏导数

## 定义

**导数**（Derivative）描述单变量函数在某一点的变化率，是微积分中最核心的概念：

$$
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
$$

**偏导数**（Partial Derivative）将导数的概念推广到多元函数，表示函数沿某个坐标轴方向的变化率：

$$
\frac{\partial f}{\partial x_i} = \lim_{h \to 0} \frac{f(x_1, \dots, x_i+h, \dots, x_n) - f(x_1, \dots, x_n)}{h}
$$

## 几何意义

| 概念 | 几何含义 |
|------|----------|
| 导数 $f'(x)$ | 函数曲线在 $x$ 处的切线斜率 |
| 偏导数 $\frac{\partial f}{\partial x_i}$ | 曲面上沿 $x_i$ 方向的切线斜率 |
| 导数 $>0$ | 函数在该点递增 |
| 导数 $=0$ | 驻点（可能是极值点或鞍点） |
| 导数 $<0$ | 函数在该点递减 |

## 基本求导法则

| 法则 | 公式 |
|------|------|
| 常数法则 | $(c)' = 0$ |
| 幂法则 | $(x^n)' = nx^{n-1}$ |
| 乘积法则 | $(uv)' = u'v + uv'$ |
| 商法则 | $(\frac{u}{v})' = \frac{u'v - uv'}{v^2}$ |
| 链式法则 | $\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$ |

## ML 中的关键出现位置

| 场景 | 形式 | 说明 |
|------|------|------|
| 梯度下降 | $\theta_{t+1} = \theta_t - \eta \cdot \nabla L(\theta_t)$ | 用一阶导数信息（梯度）更新参数 |
| 反向传播 | $\frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial \mathbf{a}^{(L)}} \cdots \frac{\partial \mathbf{a}^{(l)}}{\partial W^{(l)}}$ | 逐层计算损失对每个参数的偏导数 |
| 激活函数求导 | $\sigma'(x) = \sigma(x)(1-\sigma(x))$ | Sigmoid 的导数用于反向传播 |
| 牛顿法 | $\theta_{t+1} = \theta_t - H^{-1}\nabla L(\theta_t)$ | 用一阶导 + 二阶导加速收敛 |

## 面试追问

**Q1（基础）**：导数的极限定义是什么？偏导数与一元导数的核心区别在哪里？

**回答要点**：导数定义为 $f'(x) = \lim_{h\to 0} \frac{f(x+h)-f(x)}{h}$ ，衡量单变量函数的变化率；偏导数将这一概念推广到多元函数，固定其他变量后对单个变量求导，衡量沿坐标轴方向的变化率。

**Q2（深挖）**：乘积法则 $(uv)' = u'v + uv'$ 与链式法则 $\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$ 在使用场景上的本质区别是什么？二者能否互相替代？

**回答要点**：乘积法则用于两个独立函数相乘的求导，链式法则用于复合函数（函数嵌套）的求导。二者不可互相替代，但在复合函数中出现乘积时可能需要结合使用。混淆二者的典型错误是将 $f(g(x))$ 误用乘积法则。

**Q3（实战）**：在神经网络的反向传播中，损失函数对某个权重 $W_{ij}^{(l)}$ 的偏导数是如何计算的？请沿着计算图简述过程。

**回答要点**：利用链式法则，将损失函数对权重所在层输出的偏导 $\partial L / \partial a_i^{(l)}$ 与激活对该权重的偏导 $\partial a_i^{(l)} / \partial W_{ij}^{(l)}$ 相乘。实际计算中， $\partial L / \partial a_i^{(l)}$ 从上层反向传播获得， $\partial a_i^{(l)} / \partial W_{ij}^{(l)} = a_j^{(l-1)}$ （即前一层的激活值）。因此权重的梯度 = 上层传来的误差 $\times$ 前层激活值。

**Q4（边界）**：导数或偏导数在什么情况下会不存在或无定义？在 ML 优化的场景下如何处理这些情况？

**回答要点**：在间断点、尖点（如 $f(x)=|x|$ 在 $x=0$ 处）、垂直切线处导数不存在。ReLU 激活函数在 $x=0$ 处不可导，实践中通过指定次梯度（通常取 0 或 1）解决。另一个常见场景是 L1 正则化中的 $|w|$ 项在 $w=0$ 处不可导，采用次梯度法或近端梯度法处理。
