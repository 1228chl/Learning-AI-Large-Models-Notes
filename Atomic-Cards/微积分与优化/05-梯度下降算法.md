# 梯度下降算法

## 定义

梯度下降（Gradient Descent）是最核心的迭代优化算法。其思想直观而简洁：沿**负梯度方向**更新参数，因为该方向是函数值下降最快的方向。

$$
\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)
$$

- $\theta_t$ ：第 $t$ 步的参数
- $\eta$ ：学习率（步长）
- $\nabla L(\theta_t)$ ：损失函数在 $\theta_t$ 处的梯度

## 几何直觉

### 梯度下降 = 盲人下山

想象一个盲人在山谷中（损失函数曲面）寻找最低点（最优参数）。他用手杖探测地面坡度——最陡的方向就是负梯度方向。他朝这个方向迈一步（学习率 $\eta$ 决定步长），在新位置重新探测坡度，重复直到到达谷底。

### 学习率 = 步长

- **学习率过大**：一步跨过山谷跳到对面山坡，甚至越跳越高（发散）
- **学习率过小**：每一步都挪动极小距离，走到天黑还没到山脚（收敛极慢）
- **理想学习率**：刚好在陡坡处大步快走，在谷底附近小步慢走

### 条件数问题 = 狭长山谷

当损失函数在某方向陡峭、另一方向平缓时（条件数大），等值面呈狭长椭圆。梯度下降会在陡峭方向来回震荡，沿平缓方向缓慢推进——如同在狭长山谷中 zigzag 前进。Adam/RMSProp 通过为每个参数调整步长来缓解这一问题：陡峭方向用小步，平缓方向用大步。

### 鞍点 = 高原

在高维空间中，鞍点（某些方向是极小值、另一些方向是极大值的点）远比局部极小值更常见。在鞍点处梯度为零，普通梯度下降会停滞。动量的作用如同"惯性"——即使当前梯度为零，历史累积的动量仍能推动参数穿越鞍点区域。

## 三种变体

| 变体 | 更新公式 | 每轮数据量 | 特点 |
|------|----------|-----------|------|
| **批量梯度下降（BGD）** | $\theta = \theta - \eta \nabla J(\theta)$ | 全部 $n$ 个样本 | 准确但慢，不适合大数据 |
| **随机梯度下降（SGD）** | $\theta = \theta - \eta \nabla L_i(\theta)$ | 1 个样本 | 快但震荡大，可逃离局部最优 |
| **小批量梯度下降（Mini-batch）** | $\theta = \theta - \eta \nabla J_B(\theta)$ | $B$ 个样本（通常 32-512） | 折中，最常用 |

## 优化挑战

| 问题 | 表现 | 解决思路 |
|------|------|----------|
| **学习率难选** | 太大不收敛，太小收敛慢 | 学习率调度、自适应方法 |
| **陷入鞍点** | 梯度为 0 但不是极小值 | 动量法、SGD 噪声 |
| **条件数大** | 某个方向陡峭、某个方向平缓 | Adam、RMSProp |
| **局部最优** | 非凸函数的局部极小点 | 多组初始化、模拟退火 |

## 主流优化器对比

| 优化器 | 核心思想 | 更新公式特点 |
|--------|----------|-------------|
| **SGD** | 原始梯度下降 | $\theta_{t+1} = \theta_t - \eta g_t$（$g_t$ 为第 $t$ 步的梯度） |
| **SGD + Momentum** | 累积历史梯度方向 | $v_t = \gamma v_{t-1} + \eta g_t$（$v_t$ 为动量项，$\gamma$ 为动量衰减系数） |
| **AdaGrad** | 自适应学习率（参数级） | $\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{G_t + \epsilon}} g_t$（$G_t$ 为累积梯度平方和，$\epsilon$ 为数值稳定常数） |
| **RMSProp** | 滑动平均梯度平方 | $\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{v_t + \epsilon}} g_t$（$\epsilon$ 为数值稳定常数） |
| **Adam** | 动量 + 自适应学习率 | $m_t, v_t$ 一阶/二阶矩估计 |

## ML 中的梯度下降

| 应用场景 | 具体形式 | 说明 |
|----------|----------|------|
| 神经网络训练 | SGD + 反向传播 | 所有深度学习模型的训练方式 |
| 微调（Fine-tuning） | 小学习率 SGD / Adam | 预训练模型在特定任务上继续训练 |
| 对抗训练 | $\theta_{t+1} = \theta_t - \eta \nabla(L + \lambda L_{\text{adv}})$ | 提升模型鲁棒性（$\lambda$ 为对抗损失权重，$L_{\text{adv}}$ 为对抗损失） |
| 联邦学习 | 各客户端本地梯度下降，服务器聚合 | 分布式隐私保护的训练方式 |

## 面试追问

**Q1（基础）**：梯度下降的核心迭代公式是什么？学习率 $\eta$ 的作用是什么？如果学习率设置过大或过小分别会怎样？
**回答要点**：

1. 核心公式为 $\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$，学习率 $\eta$ 控制每一步沿负梯度方向迈出的步长大小
2. 学习率过大会导致参数越过极值点来回震荡甚至发散，无法收敛
3. 学习率过小会导致收敛极其缓慢，容易陷入局部最优点或停滞在平缓区域

**Q2（深挖）**：BGD（批量梯度下降）、SGD（随机梯度下降）和 Mini-batch GD 的优缺点分别是什么？为什么 Mini-batch 是实际中最常用的方案？
**回答要点**：

1. BGD 使用全量数据计算精确梯度，收敛稳定但计算代价高，无法支持在线学习
2. SGD 每步仅用一个样本，计算快但梯度方差大、震荡剧烈，不过噪声可帮助逃离局部最优
3. Mini-batch 使用 32-512 个样本计算梯度估计，方差与计算效率的平衡最好，且能充分利用 GPU 矩阵并行计算能力

**Q3（实战）**：在实际项目中，你如何选择 SGD+Momentum 和 Adam？二者的核心差异在哪里？
**回答要点**：

1. SGD+Momentum 累积历史梯度方向以减小震荡，收敛到极值点附近更精确、泛化性能更好，适合 CV 任务和需要精调的场景
2. Adam 结合 Momentum 与 RMSProp 自动调整每参数学习率，收敛更快、对超参数不敏感，适合 NLP、Transformer 模型和快速原型开发
3. 实践中常先用 Adam 快速热身达到较好区域，再切换到 SGD 进行精调以获取更好泛化性能

**Q4（边界）**：在大规模深度学习（如 LLM 预训练）中，基础的 Adam 遇到了哪些挑战？业界有哪些改进方案？
**回答要点**：

1. Adam 需存储一阶矩 $m_t$ 和二阶矩 $v_t$，内存占用达模型参数的两倍，对数十亿参数的 LLM 负担极大
2. 改进方案包括 AdamW（解耦权重衰减）、Adafactor（因式分解二阶矩）、8-bit Adam（块级量化）、Lion（仅存动量）等
3. 学习率预热（Warmup）和余弦退火（Cosine Decay）调度在 LLM 训练中几乎成为标配
