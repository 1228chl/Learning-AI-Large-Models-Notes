# UV 包管理器

## 定义

UV 是 **Astral** 公司（Ruff 的作者）用 Rust 开发的极速 Python 包管理器和项目管理器。它旨在替代 pip、pip-tools、poetry、conda 等工具，提供**统一且极速**的体验——安装速度比 pip 快 10-100 倍。

## 核心特性对比

| 对比维度 | pip | Conda | UV |
|----------|:---:|:-----:|:--:|
| **语言** | Python | Python | **Rust** |
| **安装速度** | 基准 | 慢 | **10-100x 更快** |
| **依赖解析** | 弱（线性） | 强（SAT 求解器） | **强（SAT 求解器 + Rust）** |
| **虚拟环境** | 需 venv 配合 | 内置 | **内置** |
| **lock 文件** | 不支持（需 pip-tools） | 不支持 | **支持** |
| **项目管理** | 不支持（需 poetry） | 不支持 | **支持（pyproject.toml）** |
| **Python 版本管理** | 不支持 | 不支持 | **内置（uv python install）** |

## 安装与虚拟环境

```bash
# 安装 UV
curl -LsSf https://astral.sh/uv/install.sh | sh   # Mac/Linux

# 创建虚拟环境
uv venv                     # 默认创建 .venv
uv venv --python 3.11       # 指定 Python 版本

# 激活（与标准 venv 相同）
source .venv/bin/activate    # Mac/Linux
.venv\Scripts\Activate.ps1   # Windows
```

## 包管理（兼容 pip）

```bash
# 安装包（速度比 pip 快 10x+）
uv pip install torch transformers datasets

# 从 requirements 安装
uv pip install -r requirements.txt

# 导出依赖
uv pip freeze > requirements.txt
```

## 项目依赖管理

UV 最大的亮点是原生支持 `pyproject.toml` 项目规范：

```bash
uv init my_project           # 初始化项目（创建 pyproject.toml）
cd my_project

uv add torch                 # 添加依赖
uv add pytest --dev          # 添加开发依赖
uv remove torch              # 移除依赖

uv lock                      # 生成 uv.lock（精确锁定所有依赖版本）
uv sync                      # 根据 lock 文件同步环境
uv sync --upgrade            # 升级所有依赖
```

## Python 版本管理

```bash
# 无需手动安装 Python！UV 可以自动管理
uv python install 3.12       # 下载并安装指定 Python
uv python list               # 列出可用版本
uv run script.py             # 自动使用正确 Python 版本运行
```

## ML 团队协作场景

```bash
# 团队成员统一操作
git clone project
cd project

uv sync                      # 一行命令：创建环境 + 安装所有依赖
uv run train.py              # 在环境中运行训练脚本

# CI/CD 中直接使用
uv sync --frozen             # 仅使用 lock 文件，不解析
uv run pytest                # 运行测试
```

| UV 命令 | 等价的传统组合 |
|---------|---------------|
| `uv add requests` | `pip install requests && pip freeze > requirements.txt` |
| `uv sync` | `python -m venv .venv && pip install -r requirements.txt` |
| `uv lock` | `pip-tools` 的 `pip-compile` |
| `uv run` | 激活环境后运行脚本 |
