# 类与对象

## 定义

**类**（Class）是一类具有相似特征和行为的事物的抽象模板；**对象**（Instance / Object）是类的一个具体实例。Python 中一切皆对象。

```python
class Dog:
    # 类的文档字符串：描述这个类是什么
    """类的定义"""
    # __init__ 是构造方法，创建实例时自动调用，用于初始化实例属性
    def __init__(self, name, age):
        # self 指向当前创建的实例，self.name 是实例独有的属性
        self.name = name      # 实例属性：每只狗有自己的名字

        self.age = age        # 实例属性：每只狗有自己的年龄

    # 实例方法：第一个参数必须是 self，通过它访问当前实例的数据
    def bark(self):            # 实例方法
        # 使用 f-string 将实例属性嵌入字符串
        print(f"{self.name} is barking")

# 调用类名 Dog(…) 就是在执行 __init__，返回一个新的实例对象
dog = Dog("Buddy", 3)         # 创建对象（实例化）
# 通过点号调用实例方法，self 会自动传入当前实例 dog
dog.bark()                    # 调用方法
```

## 面向对象 vs 面向过程

| 对比维度 | 面向过程 | 面向对象 |
|----------|----------|----------|
| **视角** | 按步骤拆解问题 | 抽象出对象，让对象交互完成任务 |
| **中心** | 函数/过程为中心 | 对象（数据+方法）为中心 |
| **数据与操作** | 分离 | 封装在一起 |
| **适用** | 简单脚本、一次性任务 | 复杂业务、大型项目、框架 |
| **可扩展性** | 差 | 强（通过继承和多态） |

## 核心概念对照

| 概念 | 说明 | 代码体现 |
|------|------|----------|
| **类属性** | 所有实例共享 | 直接定义在类体中 |
| **实例属性** | 每个实例独有 | `self.xxx = val`（一般在 `__init__` 中） |
| **实例方法** | 操作实例数据 | 第一个参数为 `self` |
| **类方法** | 操作类级别的数据 | `@classmethod`，第一个参数为 `cls` |
| **静态方法** | 与类相关但不依赖实例/类数据 | `@staticmethod`，无特殊参数 |
| ** `__init__` ** | 构造函数，创建实例时自动调用 | 初始化实例属性 |
| ** `__str__` ** | 字符串表示，`print(obj)` 时调用 | 返回用户可读的字符串 |

## 魔术方法（特殊方法）

| 方法 | 触发时机 | 用途 |
|------|----------|------|
| `__init__(self, ...)` | `obj = Class()` | 初始化 |
| `__str__(self)` | `print(obj)` / `str(obj)` | 用户可读描述 |
| `__repr__(self)` | 交互式环境直接输入 `obj` | 开发者可读描述 |
| `__len__(self)` | `len(obj)` | 返回长度 |
| `__eq__(self, other)` | `obj == other` | 相等性判断 |
| `__call__(self, ...)` | `obj()` | 使对象可调用 |

## ML 中的类与对象

| 应用场景 | 类定义 | 说明 |
|----------|--------|------|
| **PyTorch 模型定义** | `class MyModel(nn.Module)` | 所有神经网络模型通过继承 `nn.Module` 定义 |
| **自定义 Dataset** | `class MyDataset(Dataset)` | 实现 `__len__` 和 `__getitem__` 加载数据 |
| **自定义 Loss** | `class MyLoss(nn.Module)` | 通过继承实现自定义损失函数 |
| **配置管理** | `class Config:` | 用类封装实验超参数 |
| **Callback / Hook** | `class TrainerCallback:` | 训练过程中的回调接口 |

## 面试追问

**Q1（基础）**：类属性和实例属性有什么区别？各自如何定义和访问？
**回答要点**：

1. 定义位置不同：类属性直接定义在类体中，实例属性在 `__init__` 中用 `self.xxx` 定义
2. 共享范围不同：类属性所有实例共享，实例属性每个实例独有
3. 访问方式不同：类属性可通过类名或实例访问，实例属性只能通过实例访问

**Q2（深挖）**：`@classmethod`、`@staticmethod` 和普通实例方法三者的区别及应用场景是什么？
**回答要点**：

1. 实例方法：第一个参数为 `self`，依赖实例数据，用于操作实例属性
2. 类方法：用 `@classmethod` 装饰，第一个参数为 `cls`，可访问类属性，适合工厂模式
3. 静态方法：用 `@staticmethod` 装饰，无特殊参数，仅与类命名空间关联，适合工具函数

**Q3（实战）**：在 PyTorch 中自定义 `Dataset` 类时必须实现哪两个方法？为什么 `DataLoader` 能自动迭代它们？
**回答要点**：

1. 必须实现 `__len__`（返回数据集大小）和 `__getitem__`（根据索引返回样本）
2. `DataLoader` 内部通过迭代器协议自动调用这两个方法
3. 支持批处理、打乱和多进程加载，用户无需手动调用

**Q4（边界）**：Python 中 `__new__` 和 `__init__` 有什么区别？什么场景下需要重写 `__new__`？
**回答要点**：

1. `__new__` 是真正的构造函数，负责创建并返回实例，在 `__init__` 之前调用
2. `__init__` 仅做初始化，不返回实例
3. 重写 `__new__` 的场景：单例模式、不可变类型子类化（如 `tuple`）、自定义对象创建流程
