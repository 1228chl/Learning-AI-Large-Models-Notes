# 继承与多态

Python 面向对象三大特性——封装、继承、多态——的概览，详细内容见各独立卡片：

| 概念 | 核心思想 | 详细卡片 |
|:----:|:---------|:--------:|
| **封装** | 数据+方法绑定，对外隐藏实现细节 | [[11-封装(Encapsulation)]] |
| **继承** | 子类复用父类代码，MRO 解决多继承查找顺序 | [[12-继承与MRO]] |
| **多态** | 同一接口不同实现，Python 基于鸭子类型 | [[13-多态与鸭子类型]] |

## 封装 (Encapsulation)

数据+方法绑定，对外隐藏实现细节。Python 通过命名约定（`_name` 受保护、`__name` 私有）和 `@property` 实现可控访问。 → [[11-封装(Encapsulation)]]

## 继承与 MRO

子类复用父类代码，支持单/多/多层继承。C3 线性化算法解决多继承的方法查找顺序（`__mro__`）。 → [[12-继承与MRO]]

## 多态与鸭子类型

同一接口不同实现，Python 不检查类型只检查方法存在性。"如果它像鸭子一样叫，那它就是鸭子。" → [[13-多态与鸭子类型]]

## ML 中的继承与多态

| 应用场景 | 体现 | 说明 |
|----------|------|------|
| **模型家族** | `BERT(nn.Module)`、`GPT2(nn.Module)` | 不同模型共享 `nn.Module` 接口，统一训练流程 |
| **多种优化器** | `SGD`、`Adam`、`AdamW` 都继承 `Optimizer` | PyTorch 统一优化器接口 |
| **数据集加载** | `ImageFolder(Dataset)`、`TensorDataset(Dataset)` | 不同数据格式统一为 Dataset 协议 |
| **Hook 机制** | `register_forward_hook` | 不修改类定义即可扩展功能（装饰器模式） |
