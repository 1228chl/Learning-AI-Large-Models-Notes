# 继承与多态

## 封装（Encapsulation）

将数据和操作数据的方法绑定在类内部，对外隐藏实现细节。Python 中通过命名约定控制访问权限：

| 命名方式 | 访问级别 | 示例 |
|----------|----------|------|
| `name` | 公有，到处可访问 | `self.name` |
| `_name` | 受保护（约定，不自强制） | `self._internal` |
| `__name` | 私有（名字修饰为 `_Class__name`） | `self.__secret` |

```python
class BankAccount:
    def __init__(self, owner):
        self.owner = owner          # 公有
        self._balance = 0           # 受保护（约定）
        self.__pin = "1234"         # 私有（名字修饰）

    def deposit(self, amount):      # 公有接口
        self._balance += amount
```

## 继承（Inheritance）

子类自动获得父类的所有公有属性和方法，实现代码复用：

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        pass

class Dog(Animal):                 # 单继承
    def speak(self):               # 方法重写（Override）
        return f"{self.name} says Woof!"

class Cat(Animal):                 # 另一个子类
    def speak(self):
        return f"{self.name} says Meow!"
```

| 继承类型 | 说明 | 适用场景 |
|----------|------|----------|
| **单继承** | 一个子类继承一个父类 | 简单的 is-a 关系 |
| **多继承** | 一个子类继承多个父类 | 需要组合多个类的能力 |
| **多层继承** | A → B → C 的链式继承 | 层次化抽象 |

## MRO（Method Resolution Order）

多继承时的方法查找顺序。Python 使用 **C3 线性化算法**（`__mro__` 属性查看）：

```python
class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass

print(D.__mro__)  # D → B → C → A → object
```

## 多态（Polymorphism）

不同类的对象对同一消息（方法调用）做出不同响应——**同一个接口，不同实现**：

```python
def make_sound(animal):     # 不关心具体类型，只关心有无 speak 方法
    print(animal.speak())

make_sound(Dog("Buddy"))    # Buddy says Woof!
make_sound(Cat("Kitty"))    # Kitty says Meow!
```

Python 的多态是**鸭子类型**（Duck Typing）：不检查对象的类型，只检查对象是否有需要的方法或属性。"如果它走路像鸭子、叫起来像鸭子，那它就是鸭子。"
