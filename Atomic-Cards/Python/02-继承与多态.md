# 继承与多态

## 封装（Encapsulation）

将数据和操作数据的方法绑定在类内部，对外隐藏实现细节。Python 中通过命名约定控制访问权限：

| 命名方式 | 访问级别 | 示例 |
|----------|----------|------|
| `name` | 公有，到处可访问 | `self.name` |
| `_name` | 受保护（约定，不自强制） | `self._internal` |
| `__name` | 私有（名字修饰为 `_Class__name`） | `self.__secret` |

```python
class BankAccount:
    def __init__(self, owner):
        self.owner = owner          # 公有
        self._balance = 0           # 受保护（约定）
        self.__pin = "1234"         # 私有（名字修饰）

    def deposit(self, amount):      # 公有接口
        self._balance += amount
```

## 继承（Inheritance）

子类自动获得父类的所有公有属性和方法，实现代码复用：

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        pass

class Dog(Animal):                 # 单继承
    def speak(self):               # 方法重写（Override）
        return f"{self.name} says Woof!"

class Cat(Animal):                 # 另一个子类
    def speak(self):
        return f"{self.name} says Meow!"
```

| 继承类型 | 说明 | 适用场景 |
|----------|------|----------|
| **单继承** | 一个子类继承一个父类 | 简单的 is-a 关系 |
| **多继承** | 一个子类继承多个父类 | 需要组合多个类的能力 |
| **多层继承** | A → B → C 的链式继承 | 层次化抽象 |

## MRO（Method Resolution Order）

多继承时的方法查找顺序。Python 使用 **C3 线性化算法**（`__mro__` 属性查看）：

```python
class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass

print(D.__mro__)  # D → B → C → A → object
```

## 多态（Polymorphism）

不同类的对象对同一消息（方法调用）做出不同响应——**同一个接口，不同实现**：

```python
def make_sound(animal):     # 不关心具体类型，只关心有无 speak 方法
    print(animal.speak())

make_sound(Dog("Buddy"))    # Buddy says Woof!
make_sound(Cat("Kitty"))    # Kitty says Meow!
```

Python 的多态是**鸭子类型**（Duck Typing）：不检查对象的类型，只检查对象是否有需要的方法或属性。"如果它走路像鸭子、叫起来像鸭子，那它就是鸭子。"

## ML 中的继承与多态

| 应用场景 | 体现 | 说明 |
|----------|------|------|
| **模型家族** | `BERT(nn.Module)`、`GPT2(nn.Module)` | 不同模型共享 `nn.Module` 接口，统一训练流程 |
| **多种优化器** | `SGD`、`Adam`、`AdamW` 都继承 `Optimizer` | PyTorch 统一优化器接口 |
| **数据集加载** | `ImageFolder(Dataset)`、`TensorDataset(Dataset)` | 不同数据格式统一为 Dataset 协议 |
| **Hook 机制** | `register_forward_hook` | 不修改类定义即可扩展功能（装饰器模式） |

## 面试追问

**Q1（基础）**：Python 中 `_name`、`__name` 和 `name` 三种命名方式的访问权限有什么区别？
**回答要点**：`name` 为公有，到处可访问；`_name` 为受保护（约定俗成，非强制）；`__name` 为私有，触发名字修饰（Name Mangling）变为 `_ClassName__name`，子类无法直接访问。

**Q2（深挖）**：Python 多继承时方法查找顺序（MRO）的规则是什么？如何查看？
**回答要点**：MRO 使用 C3 线性化算法，保证单调性（优先从左到右、从子到父），可通过 `类名.__mro__` 或 `类名.mro()` 查看；遵循"子类优先、父类从左到右、所有父类只出现一次"的原则。

**Q3（实战）**：在使用 PyTorch 时，`nn.Module` 的继承体现了哪些面向对象设计原则？
**回答要点**：体现了封装（参数和 forward 逻辑封装在模块内）、继承（自定义模型继承 `nn.Module` 获得参数管理能力）、多态（不同模型统一调用 `forward()`）；`nn.Sequential` 则体现了组合优于继承。

**Q4（边界）**：鸭子类型（Duck Typing）在什么场景下会失效或者带来隐患？
**回答要点**：当对象意外拥有同名方法但语义不同时，会静默执行错误逻辑且不报错；缺乏显式类型约束导致 IDE 补全受限和代码可读性下降；可通过 `Protocol`（Python 3.8+）定义显式接口来弥补鸭子类型的不足。
