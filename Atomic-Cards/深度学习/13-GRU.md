# GRU

## 定义

门控循环单元（GRU, Gated Recurrent Unit）是 LSTM 的简化变体，由 Cho 等人于 2014 年提出。它将 LSTM 的三个门**合并为两个门**，去掉独立的细胞状态 $C$，参数量更少，计算更快，效果与 LSTM 相当。

$$z_t = \sigma(W_z \cdot [h_{t-1}, x_t]) \quad \text{更新门}$$
$$r_t = \sigma(W_r \cdot [h_{t-1}, x_t]) \quad \text{重置门}$$
$$\tilde{h}_t = \tanh(W_h \cdot [r_t \odot h_{t-1}, x_t]) \quad \text{候选状态}$$
$$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t \quad \text{最终状态}$$

```python
import torch.nn as nn

gru = nn.GRU(input_size=100, hidden_size=256, num_layers=2, batch_first=True)
output, h_n = gru(x)

# 与 LSTM 的对比
lstm = nn.LSTM(100, 256)     # params = 4 × (100×256 + 256×256 + 256) ≈ 365K
gru = nn.GRU(100, 256)       # params = 3 × (100×256 + 256×256 + 256) ≈ 274K
```

## GRU vs LSTM

| 对比 | LSTM | GRU |
|:----:|:----:|:----:|
| **门数量** | 3（遗忘/输入/输出） | **2**（更新/重置） |
| **细胞状态** | 有 $C_t$ | **无**（仅 $h_t$） |
| **参数量** | 多（4 组权重） | **少**（3 组权重） |
| **计算速度** | 慢 | **快** |
| **过拟合** | 易过拟合 | **鲁棒** |
| **数据量要求** | 大数据集 | **小数据集友好** |

## 更新门 vs 重置门

| 门 | 公式 | 当值为 0 | 当值为 1 |
|:--:|:----:|:---------:|:---------:|
| **更新门 $z_t$** | $\sigma(W_z[h_{t-1}, x_t])$ | 完全忽略新信息（保持旧状态） | 完全使用新信息 |
| **重置门 $r_t$** | $\sigma(W_r[h_{t-1}, x_t])$ | 完全忽略过去状态 | 完全考虑过去状态 |

**直观理解**：
- **更新门**：决定过去状态保留多少，新信息加入多少（LSTM 的遗忘门 + 输入门）
- **重置门**：决定如何将过去状态与当前输入结合

## 三种 RNN 选择指南

```python
# 数据量小时：GRU（参数少，不易过拟合）
# 数据量大且需要长程记忆：LSTM
# 简单序列任务：普通 RNN（但需控制层数）
```

| 场景 | 推荐 | 原因 |
|:----:|:----:|------|
| **小数据集** | GRU | 参数少，鲁棒 |
| **大数据集、长序列** | LSTM | 更强的长期记忆 |
| **计算资源受限** | GRU | 更快，更省显存 |
| **需要可解释性** | GRU | 结构更简单 |
| **简单序列任务** | RNN | 够用且快 |
