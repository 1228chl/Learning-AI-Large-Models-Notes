# 语言模型发展史

## 定义

**语言模型（Language Model）** 是计算一个词序列出现概率的数学模型，其核心公式为：

$$
P(S) = P(W_1, W_2, \dots, W_n) = P(W_1) \times P(W_2 \mid W_1) \times \cdots \times P(W_n \mid W_1, \dots, W_{n-1})
$$

其中 $S$ 为词序列， $W_i$ 为序列中第 $i$ 个词， $P(W_i \mid W_1, \dots, W_{i-1})$ 表示给定前 $i-1$ 个词时第 $i$ 个词出现的条件概率。语言模型经历了四个发展阶段：**统计语言模型（Statistical LM）**、**神经语言模型（Neural LM）**、**预训练语言模型（Pre-trained LM）** 和**大语言模型（LLM）**，每一阶段都在建模能力、泛化性能和计算效率上实现质的飞跃。

## 四大发展阶段对比

| 阶段 | 核心架构 | 参数规模 | 建模方式 | 代表模型 | 核心局限 |
|:----:|:--------:|:--------:|:--------:|:--------:|:--------:|
| **统计 LM** | N-gram + 马尔可夫假设 | 百万级 | 频次统计 + 平滑 | N-gram, KenLM | 参数空间爆炸、数据稀疏严重 |
| **神经 LM** | 全连接层 + tanh + softmax | 千万级 | 词向量 + 浅层网络 | NNLM (Bengio 2003) | 长序列建模能力有限（梯度消失） |
| **预训练 LM** | Transformer 编码器/解码器 | 亿级 | 自监督预训练 + 微调 | BERT, GPT-2, T5 | 预训练成本高、领域适配需微调 |
| **大语言模型 (LLM)** | 深度 Transformer 缩放 | 千亿级 | Scaling Law + 涌现能力 | GPT-3, LLaMA, PaLM | 推理成本高、幻觉问题、对齐挑战 |

## 核心公式体系

### 1. 统计语言模型（N-gram）

基于马尔可夫假设：一个词的出现只与前 $n-1$ 个词有关。

$$
P(W_i \mid W_1, \dots, W_{i-1}) \approx P(W_i \mid W_{i-n+1}, \dots, W_{i-1})
$$

$$
P(W_i \mid W_{i-1}, \dots, W_{i-n+1}) = \frac{C(W_{i-n+1} \dots W_i)}{C(W_{i-n+1} \dots W_{i-1})}
$$

其中 $C(\cdot)$ 为词序列在训练语料中的出现频次， $n$ 为 N-gram 阶数（通常 $n \leq 5$）， $W_{i-n+1} \dots W_i$ 为连续 $n$ 个词的组合（n-gram）。

**数据稀疏问题**：当 $n$ 增大时，参数空间呈指数增长 $|V|^n$（ $|V|$ 为词典大小），大量 n-gram 在训练语料中从未出现，需要平滑技术（如加一平滑、Kneser-Ney 平滑）处理。

### 2. 神经语言模型

使用浅层神经网络替代计数统计，输入为词向量拼接，经过全连接层 + tanh 激活 + softmax 输出下一个词的概率分布：

$$
\text{输入} = [e(W_{i-n+1}); e(W_{i-n+2}); \dots; e(W_{i-1})]
$$

$$
h = \tanh(W_h \cdot \text{输入} + b_h)
$$

$$
P(W_i \mid W_{i-1}, \dots, W_{i-n+1}) = \text{softmax}(W_o \cdot h + b_o)
$$

其中 $e(W)$ 为词 $W$ 的稠密向量表示（词嵌入）， $[ \cdot ; \cdot ]$ 表示向量拼接， $W_h$ 和 $b_h$ 为隐藏层权重和偏置， $W_o$ 和 $b_o$ 为输出层权重和偏置， $h$ 为隐藏层表示。词嵌入在学习过程中自动捕获语义和语法信息，使模型具备比 N-gram 更好的泛化能力。

**关键局限**：固定上下文窗口长度（仍受 N-gram 范围限制），串行计算导致训练效率低，梯度消失问题使得长距离依赖难以建模。

### 3. 预训练语言模型

基于 Transformer 架构，从大规模无监督语料中学习通用语言表示，采用"预训练 + 微调"范式：

$$
\text{目标} = \begin{cases}
\text{MLM: } \displaystyle \mathbb{E}_{x \sim \mathcal{D}} \sum_{i \in \text{mask}} \log P(x_i \mid x_{\backslash i}) & \text{(BERT, 双向编码器)} \\
\text{AR: } \displaystyle \sum_{i=1}^n \log P(x_i \mid x_{<i}) & \text{(GPT, 自回归解码器)} \\
\text{Span Corruption: } \displaystyle \sum_{s \in \text{spans}} \log P(s \mid \text{context}) & \text{(T5, Encoder-Decoder)}
\end{cases}
$$

其中 $\mathcal{D}$ 为预训练语料分布， $\text{MLM}$ 为掩码语言模型（Masked Language Model）， $\text{AR}$ 为自回归（Auto-Regressive）， $\text{Span Corruption}$ 为跨度破坏任务（T5 的预训练目标）。预训练阶段使用海量无标注数据（如维基百科、书籍、网页）学习通用语义和语法知识，微调阶段在具体任务上使用少量标注数据适配。

**核心优势**：Transformer 的自注意力机制支持并行计算并直接建模长距离依赖，大规模预训练使模型具备丰富的语义理解能力，一次预训练多任务微调显著降低下游任务对标注数据的依赖。

### 4. 大语言模型（LLM）

当模型参数量跨越千亿级别（如 GPT-3 1750 亿参数）时，出现两个关键现象：

**Scaling Law**：模型性能与参数量 $N$、数据量 $D$、计算量 $C$ 之间存在幂律关系：

$$
L(N, D) \approx \left(\frac{N_c}{N}\right)^{\alpha_N} + \left(\frac{D_c}{D}\right)^{\alpha_D}
$$

其中 $L$ 为损失值， $N_c, D_c$ 为饱和常数， $\alpha_N, \alpha_D$ 为缩放指数（通常约 0.07-0.09）。这意味着增加参数量和训练数据量可稳定提升模型性能，且存在最优分配比例（Chinchilla 法则: 约 20 tokens 参数）。

**涌现能力（Emergent Abilities）**：当模型规模超过某个阈值后，自动具备小模型不具备的能力，包括：

- **上下文学习（In-Context Learning, ICL）**：无需梯度更新，仅通过提示中的示例即可完成新任务
- **思维链推理（Chain-of-Thought, CoT）**：展示中间推理步骤解决复杂问题
- **指令遵循（Instruction Following）**：理解并执行自然语言指令

## 代码示例：N-gram 频次统计与困惑度计算

```python
import math
from collections import defaultdict, Counter

class NgramLM:
    """简单的 N-gram 统计语言模型实现"""

    def __init__(self, n: int = 3):
        self.n = n                     # N-gram 阶数
        self.ngram_counts = defaultdict(Counter)  # 条件频次计数
        self.context_counts = Counter()           # 上下文计数
        self.vocab_size = 0                       # 词典大小（用于平滑）

    def train(self, corpus: list[list[str]]) -> None:
        """在语料上统计 N-gram 频次"""
        vocab = set()
        for sentence in corpus:
            # 添加句子开始/结束标记
            tokens = ["<s>"] * (self.n - 1) + sentence + ["</s>"]
            vocab.update(tokens)
            for i in range(self.n - 1, len(tokens)):
                context = tuple(tokens[i - self.n + 1: i])
                word = tokens[i]
                self.ngram_counts[context][word] += 1
                self.context_counts[context] += 1
        self.vocab_size = len(vocab)

    def prob(self, word: str, context: tuple[str, ...]) -> float:
        """计算 P(word | context)，使用加一平滑"""
        numerator = self.ngram_counts[context].get(word, 0) + 1
        denominator = self.context_counts[context] + self.vocab_size
        return numerator / denominator

    def perplexity(self, sentence: list[str]) -> float:
        """计算句子困惑度（越低越好）"""
        tokens = ["<s>"] * (self.n - 1) + sentence + ["</s>"]
        log_prob = 0.0
        N = len(tokens) - (self.n - 1)   # 有效词数
        for i in range(self.n - 1, len(tokens)):
            context = tuple(tokens[i - self.n + 1: i])
            word = tokens[i]
            p = self.prob(word, context)
            log_prob += math.log2(p)
        return 2 ** (-log_prob / N)

# ---------- 使用示例 ----------
corpus = [
    ["我", "喜欢", "学习", "自然", "语言"],
    ["自然", "语言", "处理", "非常", "有趣"],
    ["我", "喜欢", "深度", "学习"],
]
model = NgramLM(n=3)
model.train(corpus)

test_sentence = ["我", "喜欢", "学习"]
ppl = model.perplexity(test_sentence)
print(f"句子 '{' '.join(test_sentence)}' 的困惑度: {ppl:.2f}")
# 困惑度越低说明模型对该序列越"自信"
```

## ML/DL 应用场景

| 应用场景 | 典型模型 | 说明 |
|:--------:|:--------:|:----|
| **文本生成** | GPT-4, LLaMA, Claude | 给定前缀生成连贯文本，用于写作辅助、代码生成、对话系统 |
| **机器翻译** | T5, NLLB | 编码器读取源语言，解码器生成目标语言，跨语言语义建模 |
| **文本分类** | BERT, RoBERTa | 预训练模型微调后用于情感分析、主题分类、意图识别 |
| **信息检索** | BERT (Dense Retrieval), 双塔模型 | 使用预训练模型编码查询和文档，语义匹配替代关键词匹配 |
| **语音识别** | Whisper, 基于 Transformer 的 LAS | 声学特征序列到文本序列的映射，语言模型提供先验知识 |
| **蛋白质建模** | ESM, ProtGPT | 将氨基酸序列视为"语言"，用预训练语言模型学习蛋白质结构 |
| **代码生成** | Codex, StarCoder | 在代码语料上预训练，理解编程语言语法和语义，实现自然语言到代码的转换 |

## 面试追问

**Q1（基础）**：N-gram 统计语言模型和神经语言模型在建模原理上有哪些本质区别？
**回答要点**：

1. N-gram 基于频次计数直接计算条件概率，神经语言模型通过神经网络学习词序列的概率分布
2. N-gram 使用离散表示（one-hot），参数空间为 $|V|^n$，随阶数指数增长；神经语言模型使用稠密词向量，参数共享缓解稀疏问题
3. 神经语言模型学习到的词嵌入具有语义相似性（如"猫"和"狗"的向量距离近），N-gram 无法捕获语义相似性
4. 神经语言模型通过连续空间表示获得更好的泛化能力，对未见过的 n-gram 也能给出合理概率

**Q2（深挖）**：为什么 Transformer 架构能够取代 RNN 成为预训练语言模型的标准架构？它的核心优势是什么？
**回答要点**：

1. 自注意力机制直接建模所有位置对的依赖关系，一步到位解决 RNN 的长距离遗忘问题，不受序列长度限制
2. 完全并行化计算，训练效率远高于 RNN 的串行计算方式，使得大规模预训练成为可能
3. 残差连接和 LayerNorm 解决了深层网络的训练稳定性问题，使模型可以堆叠到数十层甚至上百层
4. 多头注意力机制让模型在不同子空间同时学习不同类型的关系，丰富语义表示

**Q3（实战）**：假设你需要在资源受限的场景下部署一个文本生成模型，你会如何选择不同阶段的语言模型？
**回答要点**：

1. 若资源极度受限（如嵌入式设备），使用统计语言模型（N-gram + 高效平滑）或小型神经语言模型，参数量在百万级
2. 若资源中等（如手机端），使用蒸馏后的预训练语言模型（如 DistilBERT、TinyLLaMA），参数量在亿级，量化到 INT8
3. 若资源充足（云端），使用大语言模型，配合 KV Cache、Flash Attention 等推理优化技术
4. 核心原则：根据任务精度要求、延迟约束和硬件资源选择最简模型，优先使用预训练 + 微调范式，避免从头训练

**Q4（边界）**：大语言模型的涌现能力（Emergent Abilities）是真实存在的还是由评测指标导致的假象？
**回答要点**：

1. 涌现能力表现为模型性能在某个规模阈值后突然跃升，但部分研究发现这种"突现"可能来源于评测指标的非连续性（如选择题的准确率是离散的 0/1 指标）
2. 使用连续指标（如交叉熵损失）观察时，模型性能随规模平滑提升，不存在突现拐点
3. 但上下文学习（ICL）能力确实在特定规模以上才稳定出现，这可能与模型注意力头数增加后对长程模式识别的能力跃升有关
4. 当前共识：部分涌现现象是评测指标的离散性导致的假象，但 ICL 和 CoT 等能力确实存在规模驱动的质变，其机制仍是开放研究问题
