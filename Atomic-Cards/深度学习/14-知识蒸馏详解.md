# 知识蒸馏详解

## 定义

知识蒸馏（Knowledge Distillation）让**小模型（学生）** 学习**大模型（教师）** 的知识，在保持较高精度的同时显著减少参数量和推理成本。由 Hinton 于 2015 年提出。

## 三种蒸馏方式

### 1. 硬标签蒸馏（Hard-label Distillation）

学生模型直接模仿教师模型的**最终预测结果**（one-hot 硬标签）：

```python
# 教师模型输出的软概率分布，经 argmax 转为 one-hot 硬标签（仅保留最大概率类别）
教师输出: [0.9, 0.1, 0.0] → argmax → [1, 0, 0]（硬标签）
# 学生模型通过交叉熵损失拟合硬标签，只学习最终决策而丢失类间相似性信息
学生: 学习拟合硬标签 → 交叉熵损失
```

| 特点 | 说明 |
|:----|:----|
| **知识** | 教师最终的"答案"决策 |
| **信息量** | 最少（丢失了类间相似性信息） |
| **优点** | 简单，计算开销小 |
| **缺点** | 效果差，损失了"暗知识" |

### 2. 软标签蒸馏（Soft-label Distillation）— 最经典

使用**温度系数 T** 软化教师和学生的输出概率分布，让学生学习教师输出中蕴含的类间关系：

$$
q_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}
$$

```python

def distillation_loss(student_logits, teacher_logits, labels, T=4.0, alpha=0.7):
    # 软损失：学生 vs 教师（都用温度 T 软化）
    # 使用 KL 散度衡量学生分布与教师分布之间的差异，值越小两者越接近
    # 乘 T*T 补偿温度缩放造成的梯度尺度变化，使不同温度下的梯度量级一致
    soft_loss = KL_div(

        F.log_softmax(student_logits / T, dim=1),  # 学生对数概率分布（经温度软化后）

        F.softmax(teacher_logits / T, dim=1)       # 教师概率分布（经温度软化后，作为目标分布）
    ) * T * T

    # 硬损失：学生输出与真实标签之间的交叉熵，确保模型不偏离真实标注信息
    hard_loss = F.cross_entropy(student_logits, labels)

    # 加权融合：alpha 控制软标签暗知识的比重，(1-alpha) 控制真实标签的约束力度
    return alpha * soft_loss + (1 - alpha) * hard_loss
```

| 温度 T | 效果 |
|:------:|:----|
| T=1 | 标准 softmax，原始概率分布 |
| T > 1 | **软化**概率，非最大类也有可观概率 |
| T → ∞ | 所有类别概率趋近相等 |

**核心价值**：软标签揭示了类间相似性（"猫"和"狗"比"猫"和"汽车"更相似），这是硬标签丢失的关键信息。

### 3. 中间层蒸馏（Intermediate-layer Distillation）

让学生模仿教师**中间层的特征表示**，而不仅仅是最终输出：

| 子类型 | 蒸馏对象 | 说明 |
|:------|:--------|:----|
| **特征图蒸馏** | 中间层输出的特征图 | 让学生特征图与教师相似 |
| **注意力图蒸馏** | 注意力权重图 | 让学生关注相同的区域 |
| **关系蒸馏** | 特征之间的关系（Gram 矩阵） | 保持特征间的关系结构 |

## 三种方式对比

| 对比 | 硬标签蒸馏 | 软标签蒸馏 | 中间层蒸馏 |
|:----:|:----------:|:----------:|:----------:|
| **知识形式** | 最终决策 | 类间关系（暗知识） | 特征提取能力 |
| **信息量** | 最少 | 丰富 | 最丰富 |
| **实现难度** | 简单 | 中等（需调温度 T） | 复杂（需对齐层） |
| **效果** | 一般 | **好（经典方法）** | **最好（但实现复杂）** |
| **计算开销** | 低 | 中 | 高 |
| **适用** | 快速实验 | **通用推荐** | 高精度要求 |

## ML 中的知识蒸馏

| 应用场景 | 教师→学生 | 说明 |
|:--------:|:---------|:----|
| **BERT → TinyBERT** | BERT-base（110M）→ 6 层 Transformer（15M） | 保留 BERT 约 95%+ 精度 |
| **DistilBERT** | BERT-base（110M）→ 6 层（66M） | 40% 参数，97% 精度 |
| **HuggingFace 蒸馏** | 用教师 logits 训练学生 | `Trainer` 支持蒸馏 |
| **目标检测（YOLO）** | 大模型 → 轻量模型 | 边缘设备部署 |

## 面试追问

**Q1（基础）**：知识蒸馏中"软标签"为什么比"硬标签"包含更多信息？

**回答要点**：硬标签只给出最终类别（如"猫"），丢失了类间相似性信息；软标签保留了概率分布，如"猫 0.8、狗 0.15、汽车 0.05"，蕴含了教师对类别相似性的判断（猫与狗更像）；这种"暗知识"是学生学到泛化能力的关键。

**Q2（深挖）**：温度系数 T 在知识蒸馏中起什么作用？T 过大或过小分别有什么问题？

**回答要点**：T > 1 软化概率分布，放大非最大类别的相对差异，暴露类间相似性；T 过小（接近 1）软标签接近硬标签，丢失暗知识；T 过大各类概率趋近相等，软标签变成均匀分布，提供无效信息；通常 T=2~8 间调参。

**Q3（实战）**：教师和学生模型结构差异大时，如何设计有效的蒸馏方案？

**回答要点**：仅用软标签蒸馏可能不够，需结合中间层蒸馏（特征对齐）；对教师中间层输出做 MLP 投影适配学生维度；分层蒸馏策略——让不同学生层匹配教师对应层的语义特征；动态调整蒸馏损失和硬损失的权重 alpha。

**Q4（边界）**：什么情况下知识蒸馏效果不佳？如果教师模型本身很差怎么办？

**回答要点**：教师模型过拟合或精度不高时，蒸馏会传递错误知识给学生；教师与学生能力差距过大（如 100B→1B），学生难以模仿；解决方案：用集成模型或更强的教师、在线蒸馏（教师学生同步训练）、自蒸馏（学生做自己的教师）避免崩溃。
