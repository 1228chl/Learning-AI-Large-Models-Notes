# 完整模型训练流程（PyTorch 实践）

## 定义

完整模型训练流程是从原始数据到可部署模型的标准操作序列，涵盖**数据加载 → 模型创建 → 损失函数 → 优化器 → 训练循环 → 评估 → 保存**七个环节。该流程是深度学习工程化的核心模式，所有深度学习项目都遵循这一基本框架。

### 数据流形式化定义

训练流程可表示为数据 $D$ 经过多个阶段的变换，最终输出训练好的模型参数 $\theta^*$：

$$
\theta^* = \arg\min_{\theta} \frac{1}{N} \sum_{i=1}^N \mathcal{L}(f_{\theta}(x_i), y_i)
$$

通过如下流程实现：

$$
D \xrightarrow{\text{DataLoader}} \{(x_i, y_i)\} \xrightarrow{\text{Model}} f_{\theta}(x_i) \xrightarrow{\text{Loss}} \mathcal{L}_i \xrightarrow{\text{Backward}} \nabla_\theta \mathcal{L} \xrightarrow{\text{Optimizer}} \theta_{t+1}
$$

- $D$：原始数据集
- $(x_i, y_i)$：第 $i$ 个样本的输入和标签
- $f_{\theta}$：模型，由参数 $\theta$ 定义的神经网络
- $\mathcal{L}$：损失函数，衡量模型预测 $f_{\theta}(x_i)$ 与真实标签 $y_i$ 的差距
- $\nabla_\theta \mathcal{L}$：损失函数对模型参数的梯度
- $\theta_t$：第 $t$ 步迭代的模型参数

## 完整代码实现

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

# ==================== 1. 数据加载 ====================
class CustomDataset(Dataset):
    """
    自定义数据集类，继承 PyTorch Dataset。
    必须实现 __len__ 和 __getitem__ 两个方法。
    """
    def __init__(self, X, y):
        self.X = torch.FloatTensor(X)       # 特征：转为 FloatTensor
        self.y = torch.LongTensor(y)        # 标签：分类任务用 LongTensor

    def __len__(self):
        return len(self.y)                  # 返回数据集总样本数

    def __getitem__(self, idx):
        return self.X[idx], self.y[idx]    # 返回单个样本 (特征, 标签)

# 创建 DataLoader：自动实现批量化、打乱、并行加载
dataloader = DataLoader(
    dataset=train_dataset,
    batch_size=64,          # 每批 64 个样本
    shuffle=True,           # 每个 epoch 打乱顺序，防止模型记住数据排列
    num_workers=4           # 4 个子进程并行加载数据，加速数据读取
)

# ==================== 2. 模型创建 ====================
class NeuralNet(nn.Module):
    """三层全连接神经网络分类器"""
    def __init__(self, input_dim, hidden_dim, num_classes):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),     # 输入层 → 隐藏层
            nn.ReLU(),                             # 激活函数：引入非线性
            nn.Linear(hidden_dim, hidden_dim),    # 隐藏层
            nn.ReLU(),
            nn.Linear(hidden_dim, num_classes)    # 隐藏层 → 输出层
        )

    def forward(self, x):
        return self.net(x)                        # 前向传播：输入 → 输出

model = NeuralNet(input_dim=784, hidden_dim=256, num_classes=10)

# 有 GPU 则使用 GPU 加速
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = model.to(device)

# ==================== 3. 损失函数与优化器 ====================
criterion = nn.CrossEntropyLoss()              # 分类任务：交叉熵损失
optimizer = optim.Adam(
    model.parameters(),
    lr=0.001,                  # 学习率：控制每步参数更新的步长
    weight_decay=1e-5          # 权重衰减：L2 正则化，防止过拟合
)

# 学习率调度器：训练过程中动态调整学习率
scheduler = optim.lr_scheduler.StepLR(
    optimizer,
    step_size=10,              # 每 10 个 epoch 调整一次
    gamma=0.1                  # 学习率乘以 0.1（衰减为原来的 1/10）
)

# ==================== 4. 训练循环 ====================
num_epochs = 50                # 训练轮数

for epoch in range(num_epochs):
    model.train()               # 切换到训练模式（启用 Dropout/BatchNorm）
    running_loss = 0.0

    for batch_idx, (inputs, labels) in enumerate(dataloader):
        # 将数据移动到 GPU
        inputs, labels = inputs.to(device), labels.to(device)

        # ---- 核心 5 步 ----
        optimizer.zero_grad()                # 1. 清零梯度：防止梯度累加
        outputs = model(inputs)               # 2. 前向传播：计算模型输出
        loss = criterion(outputs, labels)     # 3. 计算损失：衡量预测与标签差距
        loss.backward()                       # 4. 反向传播：计算梯度
        optimizer.step()                      # 5. 参数更新：沿梯度反方向调整参数

        running_loss += loss.item()

    # 更新学习率
    scheduler.step()

    # 每个 epoch 打印训练状态
    avg_loss = running_loss / len(dataloader)
    current_lr = optimizer.param_groups[0]["lr"]
    print(f"Epoch [{epoch+1}/{num_epochs}] Loss: {avg_loss:.4f} LR: {current_lr:.6f}")

# ==================== 5. 评估与保存 ====================
model.eval()                    # 切换到评估模式（关闭 Dropout/BatchNorm 的随机性）
correct = 0
total = 0

with torch.no_grad():           # 禁用梯度计算：评估阶段不需要梯度，节省内存
    for inputs, labels in test_loader:
        inputs, labels = inputs.to(device), labels.to(device)
        outputs = model(inputs)
        _, predicted = torch.max(outputs, 1)  # 取最大概率的类别作为预测结果
        total += labels.size(0)
        correct += (predicted == labels).sum().item()

accuracy = 100 * correct / total
print(f"测试集准确率: {accuracy:.2f}%")

# 保存模型权重（推荐方式）
torch.save(model.state_dict(), "model_weights.pth")

# 保存完整模型（包含架构，便于部署）
torch.save(model, "model_complete.pth")
```

## 优化器对比与选型

优化器的核心差异在于**如何利用历史梯度信息**来更高效地更新参数：

| 优化器 | 核心思想 | 更新公式（简化） | 适用场景 | 推荐学习率 |
|:-------|:---------|:-----------------|:---------|:----------:|
| **SGD** | 沿当前梯度反方向更新 | $\theta = \theta - \eta g_t$ | 简单任务、需精细调参 | 0.01~0.1 |
| **Momentum** | 加入历史梯度动量，加速收敛 | $v_t = \beta v_{t-1} + g_t$，$\theta = \theta - \eta v_t$ | 梯度震荡明显时 | 0.01 |
| **Adagrad** | 自适应学习率：频繁更新的特征学习率小 | $\theta = \theta - \frac{\eta}{\sqrt{G_t + \epsilon}} g_t$ | 稀疏特征场景 | 0.01 |
| **RMSprop** | 使用梯度平方的指数移动平均调整学习率 | $v_t = \beta v_{t-1} + (1-\beta)g_t^2$，$\theta = \theta - \frac{\eta}{\sqrt{v_t + \epsilon}} g_t$ | 非平稳目标、RNN | 0.001 |
| **Adam** | Momentum + RMSprop 结合，加偏差校正 | $m_t, v_t$ 分别指数移动平均梯度及其平方 | **通用首选** | **0.001** |
| **AdamW** | Adam + 解耦权重衰减（weight decay 不参与自适应调整） | 同 Adam，但权重衰减与学习率独立 | Transformer 训练 | 0.001~0.0001 |

**选型经验法则**：
- **默认首选 Adam**（lr=0.001）：几乎任何任务都能快速收敛，无需精细调参
- **追求极致精度选 SGD + Momentum**：在充分调参 + 学习率调度下，SGD 的泛化能力通常优于 Adam（如 ResNet 论文）
- **大模型/Transformer 训练选 AdamW**：解耦权重衰减避免正则化与自适应学习率的冲突
- **RNN 训练优先 RMSprop**：缓解梯度爆炸和长期依赖问题
- 学习率是最重要的超参数——**先用 Adam(lr=0.001) 确定模型能收敛，再调优**

```python
import torch.optim as optim

# 四种常用优化器的构造对比
model_params = model.parameters()

sgd = optim.SGD(model_params, lr=0.01)                              # 带动量的 SGD 最常用
sgd_momentum = optim.SGD(model_params, lr=0.01, momentum=0.9)       # momentum: 历史梯度衰减系数，0.9 表示保留 90% 的上一步动量
adam = optim.Adam(model_params, lr=0.001)                            # Adam: 自适应学习率 + 动量，betas=(0.9, 0.999) 默认
adamw = optim.AdamW(model_params, lr=0.001, weight_decay=0.01)      # AdamW: Adam + 解耦权重衰减，适合 Transformer 类模型
rmsprop = optim.RMSprop(model_params, lr=0.001)                     # RMSprop: 梯度平方 EMA + 自适应学习率
```

## 各环节功能对比

| 环节 | 作用 | 关键选择 | 常见错误 |
|:-----|:-----|:---------|:---------|
| **DataLoader** | 数据批量化、打乱、并行加载 | batch_size / shuffle / num_workers | batch_size 过大导致 OOM |
| **Model** | 定义网络结构 | 层数 / 激活函数 / 初始化方式 | 输入输出维度不匹配 |
| **Loss** | 衡量预测与真实值的差距 | CrossEntropy（分类）/ MSE（回归） | 任务与损失函数不匹配 |
| **Optimizer** | 更新模型参数 | Adam（通用）/ SGD（需精细调参） | 学习率过大导致发散 |
| **Scheduler** | 动态调整学习率 | StepLR / CosineAnnealing / ReduceLROnPlateau | 衰减过快导致训练停滞 |
| **Training Loop** | 零梯度→前向→损失→反向→更新 | 顺序固定不可调换 | 遗忘 `zero_grad()` 导致梯度累加 |
| **Evaluation** | 评估模型泛化性能 | 准确率 / F1 / 混淆矩阵 | 未切换 `model.eval()` 和 `torch.no_grad()` |

## ML/DL 应用场景

| 应用场景 | 流程定制 | 说明 |
|:--------|:---------|:-----|
| **图像分类** | 加入数据增强（随机翻转/裁剪） | 提升模型泛化能力，防止过拟合 |
| **NLP 文本分类** | 加入梯度裁剪（gradient clipping） | 防止 RNN/Transformer 梯度爆炸 |
| **BERT 微调** | 使用 warmup 学习率调度 | 预训练模型需要小学习率逐步适应下游任务 |
| **GAN 训练** | 双优化器（生成器 + 判别器）交替训练 | 特殊的对抗训练流程 |
| **LLM 预训练** | 分布式训练（DP/DDP）+混合精度（AMP） | 大规模训练需多 GPU + FP16 加速 |

## 面试追问

**Q1（基础）**：训练循环中 `optimizer.zero_grad()` 的作用是什么？忘记调用会怎样？
**回答要点**：

1. 每次 `loss.backward()` 计算的梯度会**累加**到参数的 `.grad` 属性中
2. `zero_grad()` 将上一步的梯度清零，确保当前 batch 的梯度不受历史影响
3. 忘记调用会导致梯度来自多个 batch 的累加，参数更新方向错误，模型无法收敛

**Q2（深挖）**：`model.train()` 和 `model.eval()` 对模型行为有什么影响？为什么评估时必须调用？
**回答要点**：

1. `model.train()` 启用 Dropout（随机丢弃神经元）和 BatchNorm（使用 batch 统计量）
2. `model.eval()` 关闭 Dropout（使用全部神经元），BatchNorm 使用全局均值和方差
3. 评估时不调用 `model.eval()`，Dropout 持续生效导致预测结果随机，不可重复
4. `torch.no_grad()` 禁用梯度计算，减少内存消耗并加速推理

**Q3（实战）**：如果训练时损失不下降，你会从哪些环节排查问题？
**回答要点**：

1. 数据层：检查数据是否有正确的标签、是否做了归一化、是否有 NaN
2. 模型层：检查输入输出维度是否匹配、权重初始化是否合理
3. 损失函数：检查任务与损失函数是否匹配（分类用 CrossEntropy，回归用 MSE）
4. 优化器：学习率过大（发散）或过小（不收敛），可先用 0.001 的 Adam 测试
5. 训练循环：确认 `zero_grad()` 被调用、`backward()` 和 `step()` 的顺序正确

**Q4（边界）**：什么是梯度累积（Gradient Accumulation）？在什么场景下使用？
**回答要点**：

1. 梯度累积是将多个 batch 的梯度累加后再更新参数，变相增大 batch_size
2. 适用场景：GPU 显存不足以容纳目标 batch_size（如大模型训练），通过累积 K 个小 batch 模拟大 batch
3. 实现：每 K 步才调用 `optimizer.step()`，中间只做 `backward()` 不做 `step()`
4. 注意：需将累计后的梯度除以 K，保持梯度量级与直接使用大 batch 一致
