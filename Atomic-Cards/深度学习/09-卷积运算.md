# 卷积运算

## 定义

卷积（Convolution）是一种**滑动窗口**运算。一个卷积核（Filter / Kernel）在输入上滑动，在每个位置计算核与覆盖区域的**逐元素乘积之和**，生成**特征图（Feature Map）**。

$$
(I * K)_{ij} = \sum_{m} \sum_{n} I_{i+m, j+n} \cdot K_{m, n}
$$

```python
import torch.nn as nn

# 2D 卷积层
conv = nn.Conv2d(  # 实例化2D卷积层，对输入图像进行卷积运算提取局部特征
    in_channels=3,           # 输入通道数（RGB = 3）
    out_channels=64,         # 输出通道数（卷积核数量）
    kernel_size=3,           # 卷积核大小 3×3
    stride=1,                # 步长
    padding=1,               # 填充（保持尺寸）
    dilation=1               # 空洞率
)
```

## 核心参数

```python
# 输出尺寸公式
output_size = (input_size - kernel_size + 2 * padding) // stride + 1  # 计算卷积后特征图的空间尺寸
```

| 参数 | 作用 | 常用值 | 说明 |
|------|------|:------:|------|
| `kernel_size` | 感受野大小 | 3, 5, 7 | 越小参数越少，越大感受野越广 |
| `stride` | 滑动步长 | 1, 2 | > 1 时可下采样 |
| `padding` | 边缘填充 | `same` (保持尺寸), 0 | 保持边界信息不被丢失 |
| `dilation` | 空洞间隔 | 1, 2, 4 | 扩大感受野不增加参数 |

| 填充模式 | 输入→输出 | 说明 |
|----------|:---------:|------|
| **Valid**（无填充） | $n \to n - k + 1$ | 尺寸缩小 |
| **Same**（保持尺寸） | $n \to n$ | $p = (k-1)/2$ |
| **Full**（最大填充） | $n \to n + k - 1$ | 极少使用 |

## ML 中的卷积

| 应用场景 | 典型结构 | 说明 |
|----------|----------|------|
| **图像分类** | Conv + ReLU + Pool → 全连接 | 逐层提取特征 |
| **目标检测** | CNN 主干 + 检测头 | YOLO、Faster R-CNN |
| **语义分割** | 编码器-解码器（转置卷积） | U-Net、DeepLab |
| **图像生成** | 转置卷积（反卷积）上采样 | GAN 生成器 |
| **1D 卷积** | 文本 / 时序 Conv1d | NLP 特征提取 |

## 面试追问

**Q1（基础）**：卷积的局部连接和参数共享分别带来了什么好处？

**回答要点**：局部连接捕捉空间局部特征（边缘、纹理），符合图像的空间相关性；参数共享使同一卷积核在所有位置复用，大幅减少参数量并引入平移等变性；两者共同使 CNN 比全连接网络在图像任务上参数效率高几个数量级。

**Q2（深挖）**：空洞卷积（Dilated Convolution）如何在扩大感受野的同时不增加参数量？

**回答要点**：标准 3×3 卷积感受野是 3×3；空洞率为 d 的 3×3 卷积感受野为 (2d+1)×(2d+1)；但参数量仍为 9（3×3），与普通卷积相同；通过 skip 采样点实现稀疏计算，d 越大感受野越大。

**Q3（实战）**：设计 CNN 网络时，如何选择 kernel size、stride 和 padding 的组合？

**回答要点**：常用 3×3 kernel + padding=1 + stride=1 保持尺寸不变；下采样用 stride=2 的卷积或池化；堆叠多个小 kernel（如 3×3）比单个大 kernel（7×7）参数更少、非线性更强；根据输入尺寸和期望输出尺寸反推各层参数。

**Q4（边界）**：在 Transformer/ViT 时代，CNN 还有哪些不可替代的优势？

**回答要点**：CNN 内置平移等变性/局部性归纳偏置，小数据量下比 ViT 泛化更好；计算效率高，推理速度快，适合边缘部署；在底层视觉任务（超分、去噪、光流）中仍占主导；ViT 需要大量数据和计算才能超越 CNN。
