# 权重初始化策略

## 定义

权重初始化（Weight Initialization）决定模型训练开始时的参数值。初始化不当会导致梯度消失/爆炸、收敛慢甚至不收敛。

```python
import torch.nn as nn

# PyTorch 默认初始化（Kaiming Uniform）
linear = nn.Linear(256, 128)

# 显式设置初始化
def init_weights(m):
    if isinstance(m, nn.Linear):
        nn.init.xavier_uniform_(m.weight)
        nn.init.zeros_(m.bias)

model.apply(init_weights)
```

## 常见初始化方法

| 方法 | 分布 | 方差 $\text{Var}(w)$ | 适用激活函数 |
|------|------|:--------------------:|-------------|
| **零初始化** | 常数 $0$ | $0$ | ❌ 不可用（对称性破坏失败） |
| **随机小值** | $\text{Uniform}(-0.01, 0.01)$ | $\approx 3\times10^{-5}$ | 简单网络 |
| **Xavier（Glorot）** | $\mathcal{U}(-\sqrt{\frac{6}{n_{in}+n_{out}}}, +\sqrt{\frac{6}{n_{in}+n_{out}}})$ | $\frac{2}{n_{in}+n_{out}}$ | Sigmoid, Tanh |
| **Kaiming（He）** | $\mathcal{N}(0, \sqrt{\frac{2}{n_{in}}})$ | $\frac{2}{n_{in}}$ | **ReLU**, PReLU |
| **正交初始化** | 正交矩阵 | $1$ | RNN, LSTM |

## 核心原理：方差保持

好的初始化使**每层输出的方差保持稳定**，避免逐层放大或衰减：

$$Y = WX + b$$

$$\text{Var}(Y) = n_{in} \cdot \text{Var}(W) \cdot \text{Var}(X)$$

**Xavier 初始化**：令 $\text{Var}(W) = \frac{1}{n_{in}}$，使 $\text{Var}(Y) \approx \text{Var}(X)$

**Kaiming 初始化**：考虑 ReLU 将一半神经元置零，方差加倍 $\text{Var}(W) = \frac{2}{n_{in}}$

```python
# 不同激活函数的初始化选择
nn.init.xavier_uniform_(w)       # Tanh / Sigmoid
nn.init.kaiming_uniform_(w, mode='fan_in', nonlinearity='relu')  # ReLU
nn.init.orthogonal_(w)           # RNN / LSTM
```

## ML 中的初始化策略

| 应用场景 | 推荐初始化 | 原因 |
|----------|-----------|------|
| **MLP / CNN（ReLU）** | Kaiming He | 适配 ReLU 的非线性 |
| **MLP（Tanh）** | Xavier Glorot | 信号在 Tanh 饱和区前保持稳定 |
| **RNN / LSTM** | 正交初始化 | 保持长期依赖的梯度流 |
| **ResNet** | Kaiming + BN | BN 在前，初始化影响减弱 |
| **Transformer** | $\mathcal{N}(0, \sqrt{d_{model}})$ | 特定缩放（Attention is All You Need） |
