# 梯度消失与梯度爆炸

## 定义

在深层网络中，梯度通过**链式法则连乘**。如果每层的梯度 $<1$ ，连乘后趋近于 0（**梯度消失**）；如果每层梯度 $>1$ ，连乘后指数增长（**梯度爆炸**）。

$$
\nabla_{\theta^{(1)}} L = \nabla_{\mathbf{a}^{(L)}} L \cdot \prod_{l=2}^{L} \underbrace{\frac{\partial \mathbf{a}^{(l)}}{\partial \mathbf{a}^{(l-1)}}}_{\text{Jacobian 连乘}}
$$

## 原因与表现

| 问题 | 原因 | 表现 | 后果 |
|------|------|------|------|
| **梯度消失** | Sigmoid/Tanh 导数 $<1$ ，连乘指数衰减 | 浅层梯度 $\approx 0$ | 浅层参数不更新，无法训练深层 |
| **梯度爆炸** | 权重初始化过大 / RNN 长期依赖 | 梯度 NaN | 参数发散，训练崩溃 |

```python
# 监控梯度的常用方式
total_norm = torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)  # 计算并裁剪所有参数梯度的L2范数（限制在max_norm内），返回裁剪前的总梯度范数
# total_norm 过大 → 梯度爆炸
# total_norm 过小（接近 0）→ 梯度消失
```

## 解决方案

| 方案 | 解决梯度消失 | 解决梯度爆炸 | 原理 |
|:----:|:-----------:|:-----------:|------|
| **ReLU 激活函数** | ✅ | ❌ | $x>0$ 时导数为 1，不衰减 |
| **权重初始化（Kaiming）** | ✅ | ✅ | 保持方差稳定 |
| **Batch Normalization** | ✅ | ✅ | 将激活值拉回标准范围 |
| **残差连接（ResNet）** | ✅ | ❌ | $y = x + F(x)$ ，梯度直通 |
| **梯度裁剪** | ❌ | ✅ | 限制梯度范数上限 |
| **LSTM 门控机制** | ✅ | ✅ | 遗忘门控制梯度流 |
| **Layer Normalization** | ✅ | ✅ | Transformer 中使用 |

```python
# 1. 梯度裁剪（防爆炸）— 最常用
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)        # 对模型所有参数的梯度进行L2范数整体裁剪，防止梯度爆炸导致训练崩溃

# 2. 梯度裁剪（按值裁剪）
torch.nn.utils.clip_grad_value_(model.parameters(), clip_value=0.5)     # 按值裁剪：将每个梯度元素限制在[-clip_value, clip_value]范围内

# 3. 监控梯度范数
for name, param in model.named_parameters():                             # 遍历模型所有命名参数及其对应的梯度
    if param.grad is not None:                                           # 仅当参数有梯度（未被冻结或无梯度）时才打印，避免None.grad报错
        print(f"{name}: grad_norm = {param.grad.norm():.6f}")           # 打印参数名称及其梯度的L2范数，用于判断梯度是否异常（过大/过小）
```

## 梯度消失的经典案例：Sigmoid + 深层网络

```python
# Sigmoid导数在0点处最大为0.25，深层网络连乘后梯度呈指数衰减
Sigmoid 导数最大: σ'(0) = 0.25

# 最浅层（靠近输入层）的梯度 = 最深层的梯度 × 0.25^L，L越大衰减越严重
层1 (最浅): ∇L₁ = ∇L_L × 0.25^L  →  L=10 时 ≈ ∇L_L × 1e-6
# 最深层（靠近输出层）的梯度直接计算，不受连乘衰减影响
层L (最深): ∇L_L = ∇L_L          →  正常

# 结论：网络越深，浅层梯度越小，参数几乎无法更新，导致深层网络难以训练
→ 深层网络的浅层几乎无梯度可更新！
```

## ML 中的梯度问题

| 应用场景 | 易发问题 | 常用解决方案 |
|----------|----------|-------------|
| **深层 CNN（>20 层）** | 梯度消失 | ReLU + BN + 残差连接（ResNet） |
| **RNN / LSTM** | 两者都易发 | LSTM 门控 + 正交初始化 + 梯度裁剪 |
| **Transformer** | 梯度消失（深层） | Pre-LN + 残差连接 |
| **GAN 训练** | 梯度消失（判别器太强） | 改进损失（WGAN）、标签平滑 |
| **强化学习（PPO）** | 梯度爆炸 | 梯度裁剪（标准做法） |

## 面试追问

**Q1（基础）**：梯度消失和梯度爆炸产生的根本原因是什么？

**回答要点**：链式法则导致梯度为各层 Jacobian 的连乘；每层导数 < 1 时连乘指数衰减至 0（消失），每层导数 > 1 时连乘指数增长（爆炸）；深层网络中这一效应被放大，浅层梯度要么消失要么爆炸。

**Q2（深挖）**：残差连接为什么能缓解梯度消失？从梯度传播路径解释。

**回答要点**：残差块 y = x + F(x)，反向传播时 ∂L/∂x = ∂L/∂y × (1 + ∂F/∂x)；梯度通过"捷径"直接传播到浅层，即使 ∂F/∂x 很小，仍有 ∂L/∂y 的直通路径；加法操作确保梯度不会指数衰减，信号可传播到任意浅层。

**Q3（实战）**：训练 RNN 时 loss 突然变成 NaN，你怎么排查和修复？

**回答要点**：NaN 通常由梯度爆炸导致，首先检查输入数据是否有 NaN 或异常值；立即添加梯度裁剪 clip_grad_norm_，max_norm 从 1.0 开始调；降低学习率、使用正交初始化、检查是否有除零等数值错误。

**Q4（边界）**：梯度裁剪的阈值如何选择？设置不当会有什么后果？

**回答要点**：阈值过大会裁剪失效，仍会发生梯度爆炸；阈值过小会过度限制正常梯度，导致收敛变慢或无法收敛；通常先监控梯度范数分布，取梯度范数的 90%-95% 分位数作为初始阈值，再微调。
