# 生成对抗网络（GAN）

## 定义

生成对抗网络（Generative Adversarial Network, GAN）由 Ian Goodfellow 于 2014 年提出，核心思想是 **两个网络相互博弈**：生成器（Generator）试图生成逼真的假数据，判别器（Discriminator）试图区分真假数据，两者在对抗训练中共同提升。

目标函数是**极小化极大博弈**：

$$
\min_{G} \max_{D} V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]
$$

其中：
- $G$ 为生成器，输入随机噪声 $z \sim p_z$（通常为高斯分布或均匀分布），输出假样本 $G(z)$
- $D$ 为判别器，输入样本 $x$，输出其为真实样本的概率 $D(x) \in [0, 1]$
- $p_{\text{data}}$ 为真实数据分布
- $\mathbb{E}_{x \sim p_{\text{data}}}$ 表示从真实数据分布中采样计算期望
- 生成器 $G$ 的目标是**最小化** $\log(1 - D(G(z)))$（让判别器无法区分真假）
- 判别器 $D$ 的目标是**最大化** $\log D(x) + \log(1 - D(G(z)))$（正确区分真假）

## 对抗训练过程

```
随机噪声 z
    │
    ▼
生成器 G ──→ 假样本 G(z) ──┐
                             ├──→ 判别器 D ──→ 真/假
真实数据 x ──────────────────┘
```

训练循环（交替进行）：

1. **训练判别器**：固定生成器，用真实数据（标签=1）和生成数据（标签=0）训练判别器
2. **训练生成器**：固定判别器，更新生成器使生成的样本被判别器判为"真"
3. 重复 1-2 步直至收敛

```python
import torch
import torch.nn as nn

# 生成器：将随机噪声映射为图像
class Generator(nn.Module):
    """从 100 维随机噪声生成 28×28 的灰度图像（如 MNIST 手写数字）"""
    def __init__(self, noise_dim=100):
        super().__init__()
        self.model = nn.Sequential(
            nn.Linear(noise_dim, 256),          # 100维噪声 → 256维隐藏层
            nn.ReLU(),
            nn.Linear(256, 512),                 # 隐藏层扩展
            nn.ReLU(),
            nn.Linear(512, 784),                 # 512 → 28×28=784 像素
            nn.Tanh()                            # 输出归一化到 [-1, 1]，与图像预处理一致
        )

    def forward(self, z):
        # z: (batch_size, noise_dim)，随机噪声输入
        return self.model(z).view(-1, 1, 28, 28)  # reshape 为图像张量

# 判别器：判断输入图像是真实（1）还是生成（0）
class Discriminator(nn.Module):
    """二分类器：输入图像，输出为真实样本的概率"""
    def __init__(self):
        super().__init__()
        self.model = nn.Sequential(
            nn.Linear(784, 512),                 # 28×28 图像展平为 784 维向量
            nn.LeakyReLU(0.2),                    # LeakyReLU 防止判别器梯度消失
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 1),                   # 输出单个值：真实概率
            nn.Sigmoid()                          # 压缩到 [0, 1] 概率区间
        )

    def forward(self, x):
        return self.model(x.view(x.size(0), -1))  # 展平图像后输入
```

## GAN 的演进

| 变体 | 核心改进 | 提出年份 | 意义 |
|:-----|:---------|:--------:|:------|
| **原始 GAN** | 基础对抗框架 | 2014 | 开创性工作 |
| **DCGAN** | 用卷积替代全连接 | 2015 | 稳定 CNN 架构的 GAN 训练 |
| **Conditional GAN (cGAN)** | 加入条件输入 $y$（如类别标签） | 2014 | 可控生成 |
| **Pix2Pix** | 图像到图像的翻译 | 2016 | 有监督的图像生成 |
| **CycleGAN** | 无需成对数据的图像翻译 | 2017 | 无监督跨域转换 |
| **StyleGAN** | 样式控制 + 渐进式训练 | 2018 | 高质量人脸生成 |
| **BigGAN** | 大规模训练 + 谱归一化 | 2018 | 高质量 ImageNet 生成 |

## 训练难点与技巧

GAN 的训练以不稳定著称，以上技巧在实践中被广泛使用：

| 问题 | 表现 | 缓解方法 |
|:-----|:-----|:---------|
| **模式坍塌** | 生成器只学会生成少数几种样本 | 小批量判别（Mini-batch Discrimination）、Unrolled GAN |
| **不收敛** | 生成器和判别器的 loss 持续震荡 | 交替训练步数调优、标签平滑（Label Smoothing） |
| **梯度消失** | 判别器太强，生成器学不到 | 使用 LSGAN（最小二乘损失）、WGAN（Wasserstein 距离） |
| **梯度爆炸** | 生成器更新过大 | 梯度裁剪（Gradient Clipping）、谱归一化 |

## ML/DL 应用场景

| 应用场景 | 使用的 GAN 变体 | 说明 |
|:---------|:----------------|:------|
| 图像超分辨率 | SRGAN | 将低分辨率图像重建为高分辨率，感知损失提升视觉质量 |
| 图像修复 | Pix2Pix / EdgeConnect | 填充图像中缺失或损坏的区域 |
| 风格迁移 | CycleGAN | 将照片转换为特定艺术风格（如梵高风格） |
| 数据增强 | DCGAN | 为少样本分类任务生成额外的训练数据 |
| 人脸生成 | StyleGAN | 生成逼真的人脸图像，用于虚拟角色创作 |
| 医学影像增强 | cGAN | 从 CT 图像生成对应的 MRI 图像，辅助诊断 |

## 面试追问

**Q1（基础）**：GAN 的 Generator 和 Discriminator 分别是什么？它们对抗训练的目标是什么？
**回答要点**：

1. 生成器 G 从随机噪声 $z$ 生成假样本 $G(z)$，目标是让判别器无法区分真假样本。
2. 判别器 D 接收真实样本和生成样本，输出其为真实的概率 $D(x)$，目标是正确区分。
3. 两者形成极小化极大博弈：$D$ 最大化 $\log D(x) + \log(1-D(G(z)))$，$G$ 最小化 $\log(1-D(G(z)))$。纳什均衡时 $D$ 无法区分真假（$D(x)=0.5$）。

**Q2（深挖）**：原始 GAN 为什么训练困难？WGAN 做了哪些改进？
**回答要点**：

1. 原始 GAN 使用 JS 散度（Jensen-Shannon Divergence）衡量真实分布和生成分布的差异。当两个分布不重叠时，JS 散度为常数，梯度为零，生成器无法学习。
2. WGAN 用 Wasserstein 距离（Earth Mover 距离）替代 JS 散度，即使分布不重叠也能提供有意义的梯度信号。
3. WGAN 的改进：移除判别器的 Sigmoid（输出 logit 而非概率）、权重裁剪（Weight Clipping）/ 梯度惩罚（Gradient Penalty, WGAN-GP）、更稳定的训练过程。

**Q3（实战）**：你在训练 GAN 发现生成结果全是相同的图像（模式坍塌），会如何诊断和修复？
**回答要点**：

1. 模式坍塌的表现：生成器陷入局部最优，只学会了数据集中某一种模式，缺乏多样性。
2. 诊断：计算生成样本的多样性指标（如 pairwise 距离方差），如果方差明显小于真实数据，确认模式坍塌。
3. 修复策略：尝试小批量判别（让判别器同时看一个 batch 的样本）、增加生成器的噪声输入维度、使用 Unrolled GAN（让生成器看到判别器的多步更新）、或尝试 LSGAN / WGAN-GP 替代原始 GAN。

**Q4（边界）**：GAN 和扩散模型（Diffusion Models）相比有哪些优势和劣势？
**回答要点**：

1. GAN 的优势：生成速度快（单次前向传播），适合实时应用；在低分辨率图像上质量优异。
2. 扩散模型的优势：生成质量更优（尤其在多样性和细节上），训练更稳定，不存在模式坍塌问题。
3. 扩散模型的劣势：推理速度慢（需要多步去噪），计算成本高。当前趋势是扩散模型逐步取代 GAN 成为主流生成范式（如 DALL-E 3、Stable Diffusion），但 GAN 在实时应用和低资源场景仍有价值。
