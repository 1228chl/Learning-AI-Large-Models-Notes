# 数据增强

## 定义

数据增强（Data Augmentation）是在不收集新数据的前提下，**通过对原始训练数据施加随机变换，生成更多多样化的训练样本**的技术。核心目标是提升模型的泛化能力，减少过拟合。

数学视角：数据增强相当于在训练数据的经验分布上施加一个**先验变换分布** $T$，模型在每个 epoch 看到的都是经过随机变换后的样本：

$$
\tilde{D} = \{T(x_i), y_i \mid T \sim \mathcal{T}, (x_i, y_i) \in D\}
$$

其中 $D$ 为原始训练数据集，$\mathcal{T}$ 为变换分布族（随机翻转、旋转、裁剪等），每轮训练对每个样本采样不同的 $T$，等效于从连续分布中无限采样。

## 为什么要做数据增强

| 问题 | 数据增强的解决方式 |
|:-----|:-------------------|
| **数据量不足** | 一张图片通过增强可产生数十张变体，变相扩大数据集 |
| **过拟合** | 模型在更多样化的数据上训练，泛化能力更强 |
| **类别不平衡** | 对少数类样本做更强增强，缓解类别分布不均 |
| **模型鲁棒性** | 模拟真实世界的扰动（光照、遮挡、噪声），提升模型在测试时的稳定性 |

**直觉**：你只有 10 张猫的照片，但通过翻转、旋转、裁剪、调色，可以生成 100 张看起来不同的猫图——模型学到的是"猫的本质特征"而非"这张照片的像素分布"。

## 图像数据增强方法

### 几何变换

| 方法 | 操作 | 适用场景 | 是否保持标签 |
|:-----|:-----|:---------|:------------:|
| **随机翻转** | 水平/垂直翻转 | 对称性数据（自然场景） | 是 |
| **随机旋转** | $\pm 30^\circ$ 小角度旋转 | 通用 | 是（小角度） |
| **随机裁剪** | 裁剪后缩放到原尺寸 | 物体在图像中位置多变 | 是 |
| **随机缩放** | 放大/缩小后裁剪 | 物体尺度变化大 | 是 |
| **随机仿射变换** | 平移 + 旋转 + 缩放 | OCR / 文本识别 | 是 |

### 色彩变换

| 方法 | 操作 | 说明 |
|:-----|:-----|:------|
| **亮度调整** | 随机增减图像亮度 | 模拟不同光照条件 |
| **对比度调整** | 随机增强/降低对比度 | 模拟雾气/阴影 |
| **饱和度调整** | 随机调整颜色饱和度 | 模拟褪色或鲜艳 |
| **色相偏移** | 随机改变色调 | 模拟不同色温 |
| **高斯噪声** | 添加随机高斯噪声 | 模拟传感器噪声，增强鲁棒性 |
| **模糊** | 高斯模糊/均值模糊 | 模拟失焦或运动模糊 |

### 高级增强方法

| 方法 | 核心思想 | 说明 |
|:-----|:---------|:------|
| **Mixup** | 随机两张图按比例混合：$\tilde{x} = \lambda x_i + (1-\lambda) x_j$，标签也按比例混合 $\tilde{y} = \lambda y_i + (1-\lambda) y_j$ | 强制模型学习样本间的线性插值行为 |
| **Cutout** | 随机将图像的矩形区域置零（遮挡） | 强迫模型关注非遮挡区域的特征 |
| **CutMix** | Cutout 升级版：遮挡区域填入另一张图的对应区域，标签按面积比例混合 | 结合 Mixup 和 Cutout 的优势 |
| **RandAugment** | 从增强策略池中随机采样 N 个操作 + 幅度 | 自动化增强策略搜索，无需人工设计 |

```python
import torchvision.transforms as transforms
from torchvision.transforms import autoaugment

# ==================== 基础增强组合（通用图像分类） ====================
basic_augmentation = transforms.Compose([
    transforms.RandomResizedCrop(224),                   # 随机裁剪并缩放到 224x224，模拟尺度变化 + 裁剪多样性
    transforms.RandomHorizontalFlip(p=0.5),              # 50% 概率水平翻转，引入镜像对称多样性
    transforms.RandomRotation(degrees=15),               # 随机旋转 ±15 度，容忍拍摄角度偏差
    transforms.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2, hue=0.1),  # 调色抖动
    transforms.ToTensor(),                               # PIL 图像 → PyTorch Tensor，像素值缩放到 [0,1]
    transforms.Normalize(mean=[0.485, 0.456, 0.406],     # ImageNet 均值（RGB 三通道）
                         std=[0.229, 0.224, 0.225])      # ImageNet 标准差，将像素值标准化到 N(0,1) 附近
])

# ==================== 高级增强（强增强方案） ====================
strong_augmentation = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.08, 1.0)), # scale=0.08: 可只保留原图的 8%，模拟大尺度变化
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.RandAugment(num_ops=2, magnitude=9),       # RandAugment: 自动从 14 种增强策略中随机选 2 个操作
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
])

# ==================== Mixup 实现（自定义） ====================
def mixup_data(x, y, alpha=1.0):
    """Mixup: 将 batch 内的随机两张图片按比例混合，标签也做线性插值"""
    if alpha > 0:
        lam = torch.distributions.Beta(alpha, alpha).sample().item()  # 从 Beta 分布采样混合系数
    else:
        lam = 1  # alpha=0 退化为无增强

    batch_size = x.size(0)
    index = torch.randperm(batch_size)               # 随机打乱 batch 内样本顺序用于配对混合

    mixed_x = lam * x + (1 - lam) * x[index, :]      # 两张图按 λ 比例混合：新图 = λ * 图A + (1-λ) * 图B
    mixed_y = lam * y + (1 - lam) * y[index]          # 标签也按相同 λ 比例混合：新标签 = λ * 标签A + (1-λ) * 标签B
    return mixed_x, mixed_y
```

## 文本数据增强方法

| 方法 | 操作 | 说明 |
|:-----|:-----|:------|
| **回译** | 将文本 A → 翻译成另一种语言 → 翻译回原语言 | 保持语义不变但句式改变 |
| **同义词替换** | 随机替换词为同义词 | WordNet / 同义词表 |
| **随机插入** | 在句子中随机插入同义词 | 增加句子长度，引入冗余 |
| **随机删除** | 以概率 p 随机删除词 | 模拟 OCR 字符丢失 |
| **EDA** | 上述四种方法的组合 | Easy Data Augmentation 综合方案 |

## ML/DL 应用场景

| 应用场景 | 增强方法 | 说明 |
|:---------|:---------|:------|
| 图像分类 | RandomResizedCrop + HorizontalFlip + RandAugment | 通用图像分类的标配增强管线 |
| 目标检测 | Mosaic + MixUp + 随机缩放 | YOLOv4 使用 Mosaic 增强大幅提升检测性能 |
| 语义分割 | 同步增强（图像和标签一起做相同的几何变换） | 分割任务要求图像与标签的几何变换一致 |
| 人脸识别 | 随机光照 + 遮挡（Cutout） | 模拟现实中的变化光照和遮挡 |
| 文本分类 | EDA（同义词替换 + 随机插入/删除） | 小样本文本分类的简单有效增强 |
| 自监督学习 | SimCLR 多视角增强组合 | 正样本对的强增强 + 负样本对的对比学习 |

## 面试追问

**Q1（基础）**：数据增强为什么能防止过拟合？它改变的是训练集还是验证集？
**回答要点**：

1. 数据增强在每轮训练中生成不同的样本变体，模型每次看到的都是"新"数据，等效于扩大了训练集的规模和多样性，减少了模型记住特定样本的能力。
2. 数据增强通常只作用于训练集，验证集和测试集不增强（保持数据原始分布，确保评估的公正性）。
3. 测试集不做增强的原因是：我们需要评估模型在真实、未修改的数据上的表现。

**Q2（深挖）**：为什么有些增强操作（如旋转 90 度）对某些数据集有害？如何选择合适的增强策略？
**回答要点**：

1. 增强操作必须保持标签不变性——旋转 90 度会使"6"变成"9"（数字识别）、"猫竖起来"不再是合理图片，因此增强策略应与数据集的对称性相匹配。
2. 选择策略：理解数据的先验知识（自然图像对翻转不变、文字识别对旋转敏感）、从简单增强开始逐步增加、用验证集性能验证每个增强操作的收益。
3. 当前最佳实践：使用自动化增强搜索（AutoAugment / RandAugment），让算法从数据中学习最优增强组合和幅度。

**Q3（实战）**：在一个医学影像分类项目中，训练集只有 500 张，你会如何设计数据增强方案？
**回答要点**：

1. 基础增强：随机旋转（±10°，医学图像通常有方向的，不能大角度）、随机缩放、弹性变形（模拟组织变形）、高斯噪声（模拟设备噪声）。
2. 领域特定增强：模拟不同造影剂浓度（对比度调整）、模拟不同切片厚度（模糊/锐化）、模拟设备噪声模式。
3. 避免破坏标签的操作：不水平翻转（左右对应身体不同部位）、不改变宽高比（保持解剖比例）。
4. 组合策略：从弱增强开始，用验证集监控过拟合进度，必要时再增加 Mixup / CutMix。

**Q4（边界）**：数据增强是否总有效？在什么场景下可能带来副作用？
**回答要点**：

1. 增强操作破坏了标签不变性时有害——如手写数字识别中旋转 90 度使 6/9 混淆，医学图像中水平翻转使左右器官颠倒。
2. 过度增强会使训练分布偏离真实测试分布——增强后的图像过于离谱（如过度色彩扭曲），模型学到的是"虚假的鲁棒性"。
3. 数据量已经很大时，增强的边际收益递减——ImageNet 级别的数据集有 1400 万张图片，基础翻转/裁剪够用，复杂增强收益不大。
4. 某些任务对原始像素的保真度要求高（如人脸识别中的特征比对），过度增强会降低特征的可区分性。
