# 损失函数

## 定义

损失函数（Loss Function）衡量模型预测 $\hat{y}$ 与真实标签 $y$ 之间的差距。训练过程就是最小化损失函数。

## 直观理解

### 损失函数的代价曲面形状

不同损失函数对误差的惩罚方式不同，几何上表现为不同的"代价曲面"形状：

- **MSE（L2）**：误差越大，惩罚以平方增长。这意味着 MSE 对异常值极度敏感——一个离群点就能主导整个损失函数。其梯度与误差成正比，大误差处大步修正，小误差处小步精调。
- **MAE（L1）**：误差与惩罚成正比增长。对异常值更鲁棒（不会平方放大），但梯度恒定，小误差处仍用相同步长，收敛末期可能围绕最优点震荡。
- **Huber Loss**：$\delta$ 分界点以内用 MSE（小误差处精细），以外用 MAE（大误差处鲁棒），兼得两者优点。$\delta$ 控制切换点——$\delta \to \infty$ 退化为 MSE，$\delta \to 0$ 退化为 MAE。
- **交叉熵**：预测概率与真实标签的 KL 散度。当预测完全错误时（真实类概率接近 0），梯度极大，能快速纠偏；当预测接近正确时，梯度趋近于 0 实现精细收敛。这是交叉熵比 MSE 更适合分类的根本原因——MSE 在错误分类时梯度反而可能很小（Sigmoid 饱和）。

## 分类损失

```python
import torch.nn.functional as F

# 二分类交叉熵（输出层用 Sigmoid）
loss = F.binary_cross_entropy(y_pred, y_true)  # 二分类交叉熵：衡量两个概率分布之间的差异，值越小预测越准

# 多分类交叉熵（输出层用线性，内部计算 Softmax）
loss = F.cross_entropy(logits, y_true)     # 推荐！数值稳定

# 手动拆开
loss = F.nll_loss(F.log_softmax(logits, dim=1), y_true)  # 手动组合 log_softmax + nll_loss，等价于交叉熵
```

| 损失 | 公式 | 适用 | 特点 |
|------|------|:----:|------|
| **交叉熵（Cross-Entropy）** | $-\sum y_i \log \hat{y}_i$ | 分类 | **默认首选**，梯度大，收敛快 |
| **Hinge Loss（合页损失）** | $\sum \max(0, 1 - y_i \hat{y}_i)$ | SVM 分类 | 最大化间隔 |
| **Focal Loss** | $-(1-\hat{y}_t)^\gamma \log \hat{y}_t$ | 类别不平衡 | 降低易分样本权重 |

注：表中 $y_i$ 为类别 $i$ 的真实标签，$\hat{y}_i$ 为类别 $i$ 的预测概率，$\hat{y}_t$ 为真实类别的预测概率，$\gamma$ 为聚焦参数。

## 回归损失

```python
# MSE（均方误差）
loss = F.mse_loss(y_pred, y_true)           # MSE(L2损失)：计算预测值与真实值之间的平方差，对大误差惩罚更重

# MAE（平均绝对误差 / L1 Loss）
loss = F.l1_loss(y_pred, y_true)            # MAE(L1损失)：计算预测值与真实值之间的绝对差，对异常值更鲁棒

# Huber Loss（MSE + MAE 混合）— 详细解析见 [光滑损失函数](../模型压缩/16-光滑损失函数.md)
loss = F.huber_loss(y_pred, y_true)         # Huber损失：小误差用MSE，大误差用MAE，兼具两者优点
```

| 损失 | 公式 | 对异常值 | 梯度 | 特点 |
|------|------|:--------:|:----:|------|
| **MSE（L2 Loss）** | $\frac{1}{n}\sum(y-\hat{y})^2$ | 敏感 | 随误差增大 | 放大大误差 |
| **MAE（L1 Loss）** | $\frac{1}{n}\sum\vert y-\hat{y}\vert$ | **鲁棒** | 恒定 | 对小误差同等待遇 |
| **Huber Loss** | $\begin{cases} \frac{1}{2}(y-\hat{y})^2 & \vert d\vert<\delta \\ \delta\vert d\vert-\frac{1}{2}\delta^2 & \text{else} \end{cases}$ | 折中 | 自适应 | 综合 MSE 和 MAE 优点 |

注：$n$ 为样本数量，$d = y - \hat{y}$ 为残差，$\delta$ 为 Huber Loss 的分界阈值。

## 损失函数选择指南

| 任务 | 输出层激活 | 损失函数 |
|------|-----------|----------|
| 二分类 | Sigmoid | `BCEWithLogitsLoss` |
| 多分类 | Softmax | `CrossEntropyLoss` |
| 多标签分类 | Sigmoid（每个类别独立） | `BCEWithLogitsLoss` |
| 回归 | 恒等（无激活） | `MSELoss` |
| 回归（含异常值） | 恒等 | `HuberLoss` |
| 对比学习 | — | `ContrastiveLoss` / `InfoNCE` |

## ML 中的损失函数

| 应用场景 | 损失函数 | 说明 |
|----------|----------|------|
| 图像分类（ResNet） | CrossEntropyLoss | 标准多分类 |
| 目标检测（YOLO） | 定位（MSE）+ 分类（BCE）+ 置信度 | 多任务联合损失 |
| 图像生成（GAN） | 生成器： $-\log D(G(z))$ ；判别器： $\log D(x) + \log(1-D(G(z)))$ | 对抗损失；$D$ 为判别器，$G$ 为生成器，$z$ 为随机噪声，$x$ 为真实样本 |
| 自监督学习 | InfoNCE（对比损失） | SimCLR、MoCo |
| 语言模型（GPT） | CrossEntropyLoss（下一个 token 预测） | 自回归生成 |

## 面试追问

**Q1（基础）**：为什么分类任务通常用交叉熵而不是 MSE？
**回答要点**：

1. 交叉熵配合 Softmax 的梯度形式为 (p-y)，与误差成正比，收敛快
2. MSE 配合 Sigmoid 的梯度含 σ'(z) 项，在饱和区梯度极小导致收敛慢
3. 交叉熵的损失平面更平滑，优化更高效

**Q2（深挖）**：Focal Loss 如何解决类别不平衡问题？它的设计思路是什么？
**回答要点**：

1. 在交叉熵基础上引入调制因子 (1-p_t)^γ
2. 易分样本（p_t 接近 1）的权重被大幅降低，难分样本（p_t 小）的权重相对提升
3. γ 控制衰减速率，α 平衡正负样本，两者配合解决极度不平衡

**Q3（实战）**：在多任务学习中同时优化分类和回归损失，你怎么平衡？
**回答要点**：

1. 直接加权求和（手动调权重或使用不确定性加权）
2. 确保各损失数值尺度相近，必要时归一化
3. 监控各任务梯度的量级，避免某个任务主导训练；实际项目中常用 grid search 或 GradNorm 自动调节

**Q4（边界）**：交叉熵在标签噪声大的数据集上有什么问题？如何改进？
**回答要点**：

1. 交叉熵会强行拟合错误标签，导致过拟合噪声、泛化下降
2. 改进方案包括标签平滑（Label Smoothing）、对称交叉熵（Symmetric CE）、使用 MAE/L1 损失对噪声更鲁棒
3. 实际中标签平滑最常用，简单有效
