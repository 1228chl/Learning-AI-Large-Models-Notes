# 对比学习

## 定义

对比学习（Contrastive Learning）是一种**自监督学习**范式：**不依赖标注数据**，通过让模型区分"相似"和"不相似"的样本对来学习数据的有效表示。核心思想是**拉近正样本对（同类），推远负样本对（异类）**。

对比损失（InfoNCE）的数学形式：

$$
\mathcal{L} = -\frac{1}{N} \sum_{i=1}^{N} \log \frac{\exp(\text{sim}(z_i, z_i^+) / \tau)}{\sum_{j=1}^{N} \exp(\text{sim}(z_i, z_j^-) / \tau)}
$$

其中：
- $z_i$ 为锚点样本的嵌入向量
- $z_i^+$ 为正样本（同一张图的不同增强视图）
- $z_j^-$ 为负样本（batch 中其他样本）
- $\text{sim}(u, v) = u^T v / \|u\| \|v\|$ 为余弦相似度
- $\tau$ 为温度参数，控制分布的锐度——$\tau$ 越小，模型对相似度差异越敏感

## 核心思想

**正样本对**：同一张图像经过两种不同的数据增强（随机裁剪、翻转、颜色抖动等）得到的两个视图。

**负样本对**：batch 中不同图像的增强视图之间互为负样本。

```
图像 A ──→ 增强1 ──→ 视图 A1 ──┐
                                 ├── 正样本对（拉近）
图像 A ──→ 增强2 ──→ 视图 A2 ──┘

图像 A ──→ 视图 A1 ──┐
                       ├── 负样本对（推远）
图像 B ──→ 视图 B1 ──┘
```

## 代表模型

### SimCLR（Google, 2020）

核心框架：数据增强 → 编码器 → 投影头 → 对比损失

```python
import torch
import torch.nn as nn
import torchvision.transforms as T

# SimCLR 的核心组件
class SimCLR(nn.Module):
    """SimCLR: 简单对比学习框架"""
    def __init__(self, backbone, projection_dim=128):
        super().__init__()
        self.backbone = backbone                         # 编码器（如 ResNet-50），提取特征
        self.projector = nn.Sequential(                   # 投影头：将特征映射到对比空间
            nn.Linear(backbone.feat_dim, 512),            # 编码器输出 → 512 维隐藏层
            nn.ReLU(),
            nn.Linear(512, projection_dim)                # 512 → 128 维投影空间
        )

    def forward(self, x):
        h = self.backbone(x)                              # 特征向量
        z = self.projector(h)                             # 投影向量（用于对比损失）
        return nn.functional.normalize(z, dim=1)          # L2 归一化，使余弦相似度退化为内积

# SimCLR 使用的数据增强（关键创新：强增强组合）
simclr_augmentation = T.Compose([
    T.RandomResizedCrop(224, scale=(0.08, 1.0)),         # 随机裁剪，保留 8%~100% 的区域
    T.RandomHorizontalFlip(p=0.5),                        # 随机水平翻转
    T.ColorJitter(0.4, 0.4, 0.4, 0.1),                   # 颜色抖动：亮度、对比度、饱和度、色相
    T.RandomGrayscale(p=0.2),                             # 随机灰度化，强制模型学习形状特征
    T.GaussianBlur(kernel_size=23),                       # 高斯模糊，消除纹理细节干扰
    T.ToTensor(),
])
```

**关键发现**：
- 更强的数据增强显著提升表示质量（投影头移除后保留有用信息）
- 更大的 batch_size（4096）提供更多负样本，效果更好
- 投影头（projection head）在训练后需要移除，用编码器输出做下游任务

### MoCo（Momentum Contrast）

MoCo 使用动量编码器 + 队列维护负样本，解决 SimCLR 对大批量的依赖：

- **动量编码器**：参数是编码器的指数移动平均，缓慢更新，保证负样本表示的一致性
- **负样本队列**：维护一个队列存储历史 batch 的编码表示，提供大量负样本而无需大 batch

### BYOL（Bootstrap Your Own Latent）

BYOL 不使用负样本，仅用正样本对训练——用动量编码器的输出作为目标网络，预测器网络拟合目标输出，有效避免了表示坍塌。

## SimCLR vs MoCo vs BYOL

| 维度 | SimCLR | MoCo v2 | BYOL |
|:-----|:------:|:-------:|:----:|
| 是否用负样本 | ✅ 是 | ✅ 是 | ❌ 否 |
| 大批量依赖 | 高（4096） | 低（256） | 低（256） |
| 动量编码器 | ❌ 否 | ✅ 是 | ✅ 是 |
| ImageNet 线性探针 | 76.5% | 77.4% | 79.6% |
| 训练稳定性 | 稳定 | 稳定 | 对 batch norm 敏感 |

## ML/DL 应用场景

| 应用场景 | 使用方法 | 说明 |
|:---------|:---------|:------|
| 无监督预训练 | SimCLR / MoCo 在无标签数据上预训练 | 学到的表示可迁移到下游分类/检测任务 |
| 多模态表示学习 | CLIP 的图文对比学习 | 文本和图像在共享嵌入空间中对齐 |
| 图节点表示 | GraphSAGE 的对比学习变体 | 拉近邻接节点，推远非邻接节点 |
| 推荐系统 | 用户行为序列的对比学习 | 同一用户的不同行为序列为正样本 |

## 面试追问

**Q1（基础）**：对比学习为什么不需要标注数据？正样本对和负样本对如何构造？
**回答要点**：

1. 对比学习的正样本对来自同一数据点经过不同增强得到的两个视图（如一张图做裁剪+翻转 vs 颜色抖动），无需人工标注。
2. 负样本对来自同一 batch 中不同数据点的增强视图，利用"自然"的类别差异（假设不同图像属于不同类别）。
3. 这种构造方式称为"实例判别"（Instance Discrimination）——将每个样本视为一个单独的类，让模型区分不同样本。

**Q2（深挖）**：SimCLR 为什么需要大 batch？MoCo 如何解决这个问题？
**回答要点**：

1. SimCLR 的负样本来自当前 batch 内的其他样本，batch 越大负样本越多，对比学习效果越好。batch_size=4096 时负样本达 8190 个。
2. MoCo 用动量编码器 + 队列机制：队列存储历史 batch 的编码表示，可提供大量负样本（如 65536 个）而不增加 batch_size。
3. 动量编码器确保队列中负样本的表示一致性——如果直接用普通编码器，历史编码与当前编码不匹配，损失函数失去意义。

**Q3（实战）**：在只有 1 万张无标签医疗影像数据的情况下，你如何用对比学习训练一个有用的表示模型？
**回答要点**：

1. 选择 MoCo 或 BYOL 而非 SimCLR：小数据量下 SimCLR 的 batch_size 受限，负样本不足。
2. 设计领域特定的数据增强：合理的弹性变形、灰度变换（模拟不同造影剂浓度）、局部遮挡（模拟病灶遮挡），不破坏图像诊断意义的变换。
3. 下游适配：在学到的编码器上接一个简单的分类头，用少量标注样本微调，通常比从零训练好得多。

**Q4（边界）**：BYOL 为什么不需要负样本也不会坍塌？它和 SimCLR 的本质区别是什么？
**回答要点**：

1. BYOL 不需要负样本是因为它使用不对称的网络结构——在线网络（有预测器）和目标网络（无预测器，动量更新）。预测器阻止了坍塌：如果所有表示都坍塌到同一个点，预测器无法准确预测目标输出。
2. 本质区别：SimCLR 通过"推远负样本"来防止坍塌（排斥力），BYOL 通过"预测器 + 动量目标网络"的架构设计来防止坍塌（隐式正则化）。
3. BYOL 对 batch norm 的实现细节非常敏感——不正确的 BN 实现会导致隐式坍塌（使用 batch norm 时模型实际上仍然依赖了隐式的负样本信息）。
