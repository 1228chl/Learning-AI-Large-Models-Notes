# 权重初始化策略

## 定义

权重初始化（Weight Initialization）决定模型训练开始时的参数值。初始化不当会导致梯度消失/爆炸、收敛慢甚至不收敛。

```python
import torch.nn as nn

# PyTorch 默认初始化（Kaiming Uniform）
linear = nn.Linear(256, 128)                              # 创建线性层：输入256维、输出128维，默认使用Kaiming均匀初始化

# 显式设置初始化
def init_weights(m):                                       # 定义权重初始化函数，接收模型的一个子模块作为参数
    if isinstance(m, nn.Linear):                           # 仅对线性层进行初始化，跳过卷积层等其他模块
        nn.init.xavier_uniform_(m.weight)                  # 使用Xavier均匀分布初始化权重，使信号在前向和反向传播中方差保持稳定
        nn.init.zeros_(m.bias)                             # 将偏置项初始化为0，偏置通常不需要随机初始化

model.apply(init_weights)                                  # 将init_weights函数递归应用到模型的所有子模块
```

## 常见初始化方法

| 方法 | 分布 | 方差 $\text{Var}(w)$ | 适用激活函数 |
|------|------|:--------------------:|-------------|
| **零初始化** | 常数 $0$ | $0$ | ❌ 不可用（对称性破坏失败） |
| **随机小值** | $\text{Uniform}(-0.01, 0.01)$ | $\approx 3\times10^{-5}$ | 简单网络 |
| **Xavier（Glorot）** | $\mathcal{U}(-\sqrt{\frac{6}{n_{in}+n_{out}}}, +\sqrt{\frac{6}{n_{in}+n_{out}}})$ | $\frac{2}{n_{in}+n_{out}}$ | Sigmoid, Tanh |
| **Kaiming（He）** | $\mathcal{N}(0, \sqrt{\frac{2}{n_{in}}})$ | $\frac{2}{n_{in}}$ | **ReLU**, PReLU |
| **正交初始化** | 正交矩阵 | $1$ | RNN, LSTM |

其中 $n_{in}$ 和 $n_{out}$ 分别表示该层的输入神经元数量和输出神经元数量。

## 核心原理：方差保持

好的初始化使**每层输出的方差保持稳定**，避免逐层放大或衰减：

$$
Y = WX + b
$$

$$
\text{Var}(Y) = n_{in} \cdot \text{Var}(W) \cdot \text{Var}(X)
$$

其中 $b$ 为偏置项。

**Xavier 初始化**：令 $\text{Var}(W) = \frac{1}{n_{in}}$ ，使 $\text{Var}(Y) \approx \text{Var}(X)$

**Kaiming 初始化**：考虑 ReLU 将一半神经元置零，方差加倍 $\text{Var}(W) = \frac{2}{n_{in}}$

```python
# 不同激活函数的初始化选择
nn.init.xavier_uniform_(w)                                  # Xavier均匀初始化，适用于Tanh/Sigmoid，保持前向和反向方差一致

nn.init.kaiming_uniform_(w, mode='fan_in', nonlinearity='relu')  # Kaiming均匀初始化，适配ReLU激活函数，使用fan_in模式保持方差
nn.init.orthogonal_(w)                                      # 正交初始化，生成正交权重矩阵，保持RNN/LSTM长期依赖中的梯度流
```

## ML 中的初始化策略

| 应用场景 | 推荐初始化 | 原因 |
|----------|-----------|------|
| **MLP / CNN（ReLU）** | Kaiming He | 适配 ReLU 的非线性 |
| **MLP（Tanh）** | Xavier Glorot | 信号在 Tanh 饱和区前保持稳定 |
| **RNN / LSTM** | 正交初始化 | 保持长期依赖的梯度流 |
| **ResNet** | Kaiming + BN | BN 在前，初始化影响减弱 |
| **Transformer** | $\mathcal{N}(0, \sqrt{d_{model}})$ | $d_{model}$ 为模型维度，$\sqrt{d_{model}}$ 用于特定缩放（Attention is All You Need） |

## 面试追问

**Q1（基础）**：为什么神经网络权重不能全部初始化为 0？
**回答要点**：

1. 所有参数为 0 时每个神经元输出相同，反向传播梯度也相同
2. 导致对称性破坏失败，所有神经元学习完全一样的特征
3. 随机初始化打破对称性，使不同神经元学到不同特征

**Q2（深挖）**：Kaiming 初始化为什么方差设为 2/n_in 而不是 Xavier 的 1/n_in？
**回答要点**：

1. Kaiming 适配 ReLU 激活函数，ReLU 将一半的神经元输出置 0，信号方差减半
2. 为补偿此衰减，需将权重方差放大一倍，即 2/n_in
3. Xavier 假设激活函数在 0 附近接近线性（适合 Tanh/Sigmoid 的线性区），而 Kaiming 显式建模了 ReLU 的舍入效应

**Q3（实战）**：训练深层网络发现 loss 完全不下降，除了初始化还应排查哪些方面？
**回答要点**：

1. 先用小网络跑通确认数据/代码无误
2. 检查初始化方法和激活函数是否匹配（如用 Xavier + ReLU 会导致方差衰减）
3. 观察前几层激活值的均值和方差是否逐层发散或收缩
4. 尝试用预训练权重或更大的初始化尺度

**Q4（边界）**：Batch Normalization 被广泛使用后，权重初始化的重要性有什么变化？
**回答要点**：

1. BN 将每层激活拉回标准分布，大幅降低了对初始化的敏感性
2. 但初始化仍然重要——极端差的初始化会导致 BN 内部统计量不稳定，训练早期收敛慢
3. Transformer 模型中 LayerNorm 替代 BN，权重初始化（×√d_model）仍是训练稳定的关键因素
