# 反向传播算法

## 定义

反向传播（Backpropagation）是训练神经网络的核心算法。它利用**链式法则**，从输出层到输入层**逐层计算损失函数对每个参数的梯度**，为梯度下降提供更新方向。

$$
\frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial \mathbf{y}} \cdot \frac{\partial \mathbf{y}}{\partial \mathbf{a}^{(L)}} \cdot \prod_{k=l+1}^{L} \frac{\partial \mathbf{a}^{(k)}}{\partial \mathbf{a}^{(k-1)}} \cdot \frac{\partial \mathbf{a}^{(l)}}{\partial W^{(l)}}
$$

其中：
- $W^{(l)}$：第 $l$ 层的权重矩阵
- $\mathbf{y}$：网络的输出向量（预测值）
- $\mathbf{a}^{(l)}$：第 $l$ 层的激活向量（经过激活函数的输出）

## 计算图与自动微分

```python
import torch

# PyTorch 自动记录计算图并执行反向传播
x = torch.tensor([1.0, 2.0], requires_grad=True)  # 创建需要计算梯度的张量，PyTorch将自动追踪其所有运算

y = x[0]**2 + x[1]**3        # 前向传播：构建计算图
y.backward()                  # 反向传播：计算梯度
print(x.grad)                 # tensor([2., 12.])
```

## 四步训练循环

```python
for epoch in range(epochs):                   # 对整个数据集进行多轮迭代训练
    # 1. 前向传播：计算预测值和损失
    y_pred = model(X)                         # 将输入数据传入网络，逐层计算得到预测结果

    loss = criterion(y_pred, y)               # 使用损失函数衡量预测值与真实标签之间的差距

    # 2. 反向传播：计算梯度
    optimizer.zero_grad()     # 清空梯度
    loss.backward()           # 计算梯度

    # 3. 梯度下降：更新参数
    optimizer.step()          # θ = θ - lr * ∇L
```

| 步骤 | 数学操作 | 代码对应 |
|:----:|----------|----------|
| **前向** | $\hat{y} = f_\theta(x)$ | `y_pred = model(X)` |
| **损失** | $L = \ell(\hat{y}, y)$ | `loss = criterion(y_pred, y)` |
| **反向** | $\nabla_\theta L = \frac{\partial L}{\partial \theta}$ | `loss.backward()` |
| **更新** | $\theta_{t+1} = \theta_t - \eta \nabla_\theta L$ | `optimizer.step()` |

## 链式法则的逐层传播

```python
# 链式法则逐层传播示意图：梯度从输出层向输入层反向流动
# ∂L/∂W 表示损失函数 L 对权重 W 的偏导数（梯度）


层3 (输出层):  ∂L/∂W³ = ∂L/∂ŷ × ∂ŷ/∂z³ × ∂z³/∂W³   # 输出层：损失对输出层权重的梯度
     ↓

层2 (隐藏层):  ∂L/∂W² = ∂L/∂ŷ × ∂ŷ/∂z³ × ∂z³/∂a² × ∂a²/∂z² × ∂z²/∂W²  # 隐藏层2：在输出层梯度基础上继续向后传播
     ↓

层1 (隐藏层):  ∂L/∂W¹ = ...  ← 每一层复用了上一层的梯度  # 隐藏层1：进一步复用前层计算的梯度，逐层递推
```

**关键洞察**：反向传播的核心效率在于**梯度复用**——每一层的梯度由上一层的梯度乘以局部 Jacobian 得到，避免了重复计算。

## ML 中的反向传播

| 应用场景 | 体现 |
|----------|------|
| **全连接网络训练** | 标准 BP 算法 |
| **CNN 训练** | BP + 卷积转置（Deconvolution） |
| **RNN / LSTM 训练** | BPTT（沿时间轴反向传播） |
| **Transformer 训练** | BP 通过自注意力和 FFN 层 |
| **GAN 训练** | 生成器和判别器交替 BP |
| **迁移学习 / 微调** | 冻结部分层，BP 只更新后几层 |

## 面试追问

**Q1（基础）**：反向传播算法的核心思想是什么？请用链式法则简要说明。
**回答要点**：

1. 反向传播利用链式法则从输出层向输入层逐层计算损失函数对每个参数的偏导数
2. 前向传播计算损失，反向传播复用上游梯度乘以局部 Jacobian 得到当前层梯度
3. 核心效率在于梯度复用，避免了各层独立求导的重复计算

**Q2（深挖）**：反向传播中的"梯度复用"具体指什么？为什么重要？
**回答要点**：

1. 后一层算出的 ∂L/∂a^(l) 可直接用于前一层 ∂L/∂a^(l-1) 的计算，无需重复求导
2. 若不复用，每层独立计算梯度的时间复杂度为 O(L²)
3. 复用后降低为 O(L)，使深层网络训练成为可能

**Q3（实战）**：loss.backward() 后发现某层梯度为 0，你会如何排查？
**回答要点**：

1. 检查该层激活函数是否处于饱和区或 Dead ReLU，以及权重初始化是否导致输出方差异常
2. 打印梯度范数分布和各层梯度统计，定位梯度消失的起始层
3. 确认损失函数与激活函数组合是否合适，必要时尝试残差连接或 Batch Normalization

**Q4（边界）**：反向传播在网络极深（100+ 层）或存在循环依赖时会遇到什么问题？
**回答要点**：

1. 极深网络中即使使用 ReLU 仍可能出现梯度不稳定，残差连接（Residual Connection）是标准解法
2. 计算图存在循环依赖时无法直接 BP，需按时间展开进行 BPTT（Backpropagation Through Time）
3. BPTT 的内存占用随序列长度线性增长，长序列训练需用 checkpointing 或 truncated BPTT 来缓解
