# 多模态基础

## 定义

多模态学习（Multimodal Learning）是让模型同时理解和关联**多种数据类型**（文本、图像、语音、视频等）的 AI 技术。核心目标是学习不同模态之间的**共享语义空间**，使模型能跨模态理解、检索和生成。

数学形式：学习一个联合嵌入函数 $f: \mathcal{X} \times \mathcal{Y} \rightarrow \mathbb{R}^d$，将不同模态映射到同一语义空间：

$$
\text{sim}(x, y) = \cos(f_\theta(x), g_\phi(y))
$$

其中 $x \in \mathcal{X}$ 为一种模态的输入（如图像），$y \in \mathcal{Y}$ 为另一种模态的输入（如文本），$f_\theta$ 和 $g_\phi$ 为各自的编码器，$\text{sim}$ 为语义相似度。

## 核心范式：对比学习

对比学习是多模态模型的核心训练范式——**拉近匹配的图文对，推远不匹配的图文对**：

$$
\mathcal{L} = -\frac{1}{N} \sum_{i=1}^{N} \log \frac{\exp(\text{sim}(I_i, T_i) / \tau)}{\sum_{j=1}^{N} \exp(\text{sim}(I_i, T_j) / \tau)}
$$

- $I_i$ 为图像编码器输出，$T_i$ 为文本编码器输出
- $\tau$ 为温度参数，控制 softmax 分布的锐度
- 分母为所有 $N$ 个文本中的相似度之和（InfoNCE 损失）

## 代表模型

### CLIP（OpenAI, 2021）

CLIP 是图文多模态的奠基性工作，用 4 亿图文对训练两个编码器：

```
图像 → 图像编码器(ViT) → I_i ──┐
                                 ├── 对比学习 → 对齐的图文嵌入空间
文本 → 文本编码器(Transformer) → T_i ─┘
```

- **零样本迁移**：训练后可直接用于未见过的分类任务（用"猫"、"狗"等文本描述替代分类头）
- **ImageNet 零样本准确率**：76.2%（CLIP ViT-L/14）
- **编码器**：图像用 ViT（Vision Transformer），文本用 GPT/CBERT

### BLIP / BLIP-2

BLIP 在 CLIP 基础上增加了**生成能力**，引入图像 caption 和图文理解的双向训练：

- BLIP-2 引入 Q-Former（Query Transformer）作为视觉和语言模型的桥梁
- 冻结图像编码器和 LLM，仅训练 Q-Former，训练成本低
- 支持图像 caption、VQA、图文推理

### 多模态大语言模型（VLM）

| 模型 | 视觉编码器 | 语言模型 | 连接方式 | 特点 |
|:-----|:----------|:---------|:---------|:------|
| **LLaVA** | CLIP ViT | LLaMA/Vicuna | 线性投影层 | 简单高效的端到端微调 |
| **Qwen-VL** | ViT + 位置编码 | Qwen-7B | 交叉注意力 | 支持多图输入 |
| **CogVLM** | ViT | 自研 | 深层交叉注意力 | 视觉信息深度融合 |
| **GPT-4V** | 未公开 | GPT-4 | 未公开 | 闭源最强 |

## 关键技术

| 技术 | 作用 | 说明 |
|:-----|:------|:------|
| **图文对比学习** | 学习对齐的图文嵌入空间 | CLIP 的 InfoNCE 损失 + 大批量训练 |
| **Q-Former** | 连接视觉编码器和 LLM | BLIP-2 的可学习 Query 桥接两种模态 |
| **视觉编码器** | 将图像转为特征向量 | ViT 成为主流，取代 CNN backbone |
| **位置编码对齐** | 处理图像的分辨率变化 | 2D-RoPE、动态分辨率位置编码 |
| **多模态指令微调** | 让模型理解多模态指令 | LLaVA 的 visual instruction tuning 数据集 |

```python
# CLIP 推理示例（需安装 openai-clip 或 transformers）
from PIL import Image
import torch
from transformers import CLIPProcessor, CLIPModel

# 加载预训练模型
model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")   # ViT-B/32 版本
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")  # 预处理

# 准备图像和候选文本描述
image = Image.open("cat.jpg")                                        # 输入图像
texts = ["a photo of a cat", "a photo of a dog", "a photo of a bird"]  # 候选类别

# 预处理 + 推理
inputs = processor(text=texts, images=image, return_tensors="pt", padding=True)
outputs = model(**inputs)

# 计算相似度：图像与每个文本描述的匹配得分
logits_per_image = outputs.logits_per_image                          # (1, 3) 图像-文本相似度
probs = logits_per_image.softmax(dim=1)                              # 归一化为概率
predicted_class = texts[probs.argmax().item()]                       # 相似度最高的文本描述
```

## 面试追问

**Q1（基础）**：CLIP 的核心训练目标和推理方式是什么？为什么 CLIP 能做零样本分类？
**回答要点**：

1. 训练目标：对比学习 —— 对 4 亿个图文对，拉近匹配的图文对（对角线），推远不匹配的图文对（非对角线）。
2. 零样本分类：将候选类别名称包装为"a photo of a {class}"，计算图像与该文本的相似度，选相似度最高的类别。无需任何下游任务的标注数据。
3. 关键成功因素：海量数据（4 亿） + 大模型（ViT-L/14） + 对比学习范式。

**Q2（深挖）**：CLIP 的零样本分类精度在某些任务上不如有监督模型，原因是什么？如何改进？
**回答要点**：

1. 原因：CLIP 的训练数据是互联网图文对，图像和文本的相关性可能较弱（噪声大）；CLIP 在细粒度分类（区分不同型号的飞机）和抽象概念任务上表现差。
2. 改进方案：Few-shot 适配（用少量标注数据做 linear probe 或 LoRA 微调）；提示词工程（用多个 prompt 模板并投票）；集成多个 CLIP 模型。
3. 在分布偏移（Distribution Shift）场景下，CLIP 的鲁棒性显著优于 ImageNet 训练的有监督模型。

**Q3（实战）**：如何用 CLIP 构建一个商品图文检索系统？你会怎么设计索引和检索流程？
**回答要点**：

1. 离线索引：将所有商品图像用 CLIP 图像编码器转换为嵌入向量，存入向量数据库（Milvus/FAISS）。
2. 在线检索：用户输入文本查询 → CLIP 文本编码器 → 向量检索（余弦相似度）→ Top-K 商品。
3. 优化：对文本嵌入做归一化，余弦相似度退化为内积，可用 MIPS（最大内积搜索）加速；结合商品元数据（价格、类别）做过滤和重排序。

**Q4（边界）**：多模态大模型的幻觉问题比纯文本 LLM 更严重还是更轻？为什么？
**回答要点**：

1. 更严重：多模态模型需要同时对齐视觉和语言空间，两个空间的对齐不完全会导致"看到不存在的东西"——如一只猫的图片，模型说"这是一只戴着帽子的猫"。
2. 原因：视觉编码器的分辨率有限（CLIP 224×224），丢失了细节信息；视觉和语言训练数据的质量差异大；在 VQA 任务中模型可能过度依赖语言先验而忽略图像内容。
3. 缓解：提高视觉编码器的输入分辨率（如 336×336 或动态分辨率）；使用 grounding 技术（将输出与图像中的具体区域关联）；对视觉信息使用更细粒度的注意力机制。
