# Dropout（随机失活）

## 定义

Dropout 是一种神经网络正则化技术：**训练时以概率 $p$ 随机丢弃（置零）神经元的输出，测试时使用所有神经元但将权重乘以 $1-p$**。核心思想是防止神经元之间产生复杂的共适应关系，迫使每个神经元学习更鲁棒的特征。

训练时的数学形式：

$$
\tilde{\mathbf{h}} = \mathbf{m} \odot \mathbf{h}, \quad m_i \sim \text{Bernoulli}(1-p)
$$

其中：
- $\mathbf{h} \in \mathbb{R}^d$ 为某隐藏层的输出向量，$d$ 为神经元数量
- $\mathbf{m} \in \{0, 1\}^d$ 为掩码向量，每个元素独立服从伯努利分布
- $p$ 为丢弃概率（通常 0.2~0.5），$1-p$ 为保留概率
- $\odot$ 表示逐元素乘法（Hadamard 积）
- $\tilde{\mathbf{h}}$ 为 Dropout 后的输出，部分神经元被置零

测试时（Inverted Dropout 实现）：

$$
\mathbf{h}_{\text{test}} = (1-p) \cdot \mathbf{h}
$$

测试时所有神经元都参与计算，但输出乘以 $(1-p)$ 以保持训练和测试的期望输出一致。

## 直观理解

### 为什么 Dropout 能防止过拟合

| 角度 | 解释 |
|:-----|:------|
| **集成学习视角** | 每次丢弃不同神经元等价于训练了一个不同的子网络，测试时相当于所有子网络的集成平均 |
| **特征解耦视角** | 神经元不能依赖其他特定神经元"弥补"自己的错误，必须独立学习有用特征 |
| **正则化视角** | 在权重上引入了乘性噪声，等效于一种自适应 L2 正则化 |

### 丢弃概率的选择

| 层位置 | 推荐丢弃概率 | 说明 |
|:-------|:----------:|:------|
| 输入层 | 0.2 | 丢弃过多会丢失输入信息 |
| 隐藏层 | 0.3 ~ 0.5 | 较大的隐藏层可用更高丢弃率 |
| 输出层 | 0 | 不丢弃，保持完整输出 |

```python
import torch
import torch.nn as nn

# Dropout 在 PyTorch 中的使用
model = nn.Sequential(
    nn.Linear(784, 256),          # 输入层 784 → 隐藏层 256
    nn.ReLU(),                     # 激活函数：引入非线性
    nn.Dropout(p=0.5),             # 训练时随机丢弃 50% 的神经元，防止过拟合
    nn.Linear(256, 128),           # 隐藏层 256 → 隐藏层 128
    nn.ReLU(),
    nn.Dropout(p=0.3),             # 较小丢弃率，因为这一层更接近输出
    nn.Linear(128, 10)             # 输出层 128 → 10 类
)

# Dropout 默认在训练时生效，测试时自动关闭
model.train()   # 训练模式：Dropout 生效
model.eval()    # 评估模式：Dropout 关闭（自动应用 Inverted Dropout 缩放）
```

## Dropout 变体

| 变体 | 核心思想 | 适用场景 |
|:-----|:---------|:---------|
| **标准 Dropout** | 随机丢弃神经元输出 | 全连接层 |
| **Spatial Dropout** | 按通道丢弃整个特征图 | CNN 卷积层（通道级） |
| **DropBlock** | 丢弃特征图中连续区域块 | CNN 卷积层（区域级） |
| **Variational Dropout** | 在 RNN 中重复使用相同的掩码 | RNN 序列模型 |
| **Monte Carlo Dropout** | 测试时也开启 Dropout，多次采样取平均 | 不确定性估计 |

## ML/DL 应用场景

| 应用场景 | 数学形式 | 说明 |
|:---------|:---------|:------|
| 全连接网络防过拟合 | $\tilde{\mathbf{h}} = \mathbf{m} \odot \mathbf{h}$ | 标准 Dropout 在 MLP 中防止神经元共适应 |
| CNN 通道级正则化 | 整个特征图随机丢弃 | Spatial Dropout：按通道丢弃，保留空间结构 |
| 不确定性估计 | $p(y \mid x) \approx \frac{1}{T} \sum_{t=1}^{T} p(y \mid x, \mathbf{M}_t)$ | MC Dropout：T 次前向传播的预测分布量化模型不确定性 |
| RNN 序列模型 | 同一掩码应用于所有时间步 | Variational Dropout：防止 RNN 过拟合同时保持序列依赖 |

## 面试追问

**Q1（基础）**：Dropout 是什么？训练和测试时的行为有何不同？
**回答要点**：

1. 训练时以概率 $p$ 随机丢弃神经元的输出，即将其置零，每次前向传播的掩码都不同。
2. 测试时所有神经元都参与计算，但输出乘以 $(1-p)$（Inverted Dropout），使得训练和测试时每个神经元的期望输出一致。
3. PyTorch 中 `model.train()` 开启 Dropout，`model.eval()` 自动关闭 Dropout 并进行输出缩放。

**Q2（深挖）**：Dropout 为什么能起到正则化作用？从集成学习和特征解耦两个角度解释。
**回答要点**：

1. 集成学习视角：每次 Dropout 相当于采样一个不同的子网络架构，训练过程相当于训练了 $2^n$ 个子网络的集成，测试时所有子网络一起投票。
2. 特征解耦视角：神经元不能依赖其他特定的神经元帮忙补救，必须独立学习有区分力的特征。这迫使网络学习更鲁棒、更通用的特征表示。
3. 数学视角：在损失函数中，Dropout 等效于一种自适应 L2 正则化，其正则化强度与权重大小成正比。

**Q3（实战）**：在 CNN 中应该用标准 Dropout 还是其他变体？Dropout 在 ResNet 这类模型中还常用吗？
**回答要点**：

1. CNN 中全连接层后标准 Dropout 有效，但卷积层后推荐 Spatial Dropout 或 DropBlock——因为卷积层相邻像素共享语义，丢弃单个像素无效。
2. ResNet 等现代架构本身有 BatchNorm 层的正则化效果，通常只在最后的全连接层用 Dropout（p=0.2~0.3）或不使用。
3. Transformer 架构中更常用 Dropout 在注意力权重和 FFN 上（p=0.1~0.2），而不是标准的神经元级 Dropout。

**Q4（边界）**：Dropout 在什么情况下效果不好？有什么替代方案？
**回答要点**：

1. 数据量极少时 Dropout 可能伤害性能——模型本身容量已经不足，再丢弃神经元雪上加霜。
2. 训练数据不足时，优先使用数据增强 + 早停 + L2 正则化，Dropout 作为补充。
3. 替代方案包括：Label Smoothing（标签平滑）、Stochastic Depth（随机深度——对 ResNet 层做 Dropout）、Cutout/CutMix（图像区域丢弃）。
4. 对于大模型（如 LLM），Dropout 通常只在前缀训练阶段使用极小的 p，微调阶段常关闭。
