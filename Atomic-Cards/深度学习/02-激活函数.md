# 激活函数

## 定义

激活函数（Activation Function）是神经网络中引入**非线性**的关键组件。没有激活函数，多层网络退化为单层线性变换。激活函数将神经元的加权和 $z = W^T\mathbf{x} + b$ 映射为输出 $a = \sigma(z)$ 。

## 常用激活函数

| 函数 | 公式 | 值域 | 导数 | 特点 |
|------|------|:----:|:----:|------|
| **Sigmoid** | $\sigma(x) = \frac{1}{1+e^{-x}}$ | $(0,1)$ | $\sigma(x)(1-\sigma(x))$ | 平滑概率输出，但两端饱和 |
| **Tanh** | $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ | $(-1,1)$ | $1 - \tanh^2(x)$ | 零中心，比 Sigmoid 好 |
| **ReLU** | $\text{ReLU}(x) = \max(0, x)$ | $[0,\infty)$ | $x>0:1; x\leq0:0$ | **默认首选**，缓解梯度消失 |
| **Leaky ReLU** | $\text{LReLU}(x) = \max(0.01x, x)$ | $(-\infty,\infty)$ | $x>0:1; x<0:0.01$ | 解决 ReLU 死亡问题 |
| **ELU** | $\text{ELU}(x) = \begin{cases}x & x>0 \\ \alpha(e^x-1) & x\leq0\end{cases}$ | $(-\alpha,\infty)$ | 见公式 | 平滑的负值部分 |

```python
import torch.nn.functional as F

# PyTorch 中的激活函数
z = torch.randn(10)                          # 生成随机输入张量，模拟一个批次中10个样本的加权和


sigmoid = torch.sigmoid(z)      # 或 F.sigmoid(z) (已弃用)

tanh = torch.tanh(z)                         # Tanh：将输出压缩到(-1,1)，零中心化，缓解Sigmoid的偏移问题

relu = F.relu(z)                 # nn.ReLU()

leaky_relu = F.leaky_relu(z)                 # Leaky ReLU：负区间保留微小梯度(0.01x)，防止神经元死亡

elu = F.elu(z)                               # ELU：负区间指数饱和而非截断，输出更平滑，训练更稳定
```

## 选择指南

| 场景 | 推荐激活函数 | 原因 |
|------|-------------|------|
| **隐藏层默认** | ReLU | 简单高效，缓解梯度消失 |
| **二分类输出** | Sigmoid | 输出可解释为概率 |
| **多分类输出** | Softmax | 输出概率和为 1 |
| **回归输出** | 无（恒等） | 不限制输出范围 |
| **RNN 默认** | Tanh | 控制梯度流（配合门控） |
| **神经网络最后层** | 视任务而定 | 见上表 |

## 梯度饱和问题

# 深层网络连乘后，梯度指数级衰减 → 梯度消失

# ReLU 在 x > 0 时导数为 1 → 梯度不衰减

## 面试追问

**Q1（基础）**：ReLU 为什么能缓解梯度消失问题？它本身有什么缺点？

**回答要点**：ReLU 在 x>0 时导数为 1，不压缩梯度，连乘时不会指数衰减；缺点是 x≤0 时导数为 0 导致"神经元死亡"，且输出非零中心可能影响优化。

**Q2（深挖）**：Sigmoid 和 Tanh 的梯度饱和问题具体如何影响深层网络训练？

**回答要点**：Sigmoid 导数最大 0.25，Tanh 导数最大 1，输入进入饱和区后导数趋近 0；链式法则连乘后浅层梯度指数级衰减；导致深层网络浅层参数几乎不更新，网络无法训练。

**Q3（实战）**：项目中遇到大量 Dead ReLU，你会如何排查和解决？

**回答要点**：监控激活值的统计分布，若大部分为 0 则确认 Dead ReLU；调小学习率避免初始化后大量神经元落入负区间；换用 Leaky ReLU / PReLU / ELU 等变体；配合 Batch Normalization 稳定输入分布。

**Q4（边界）**：Transformer 和 CNN 对激活函数的选择偏好有何不同？为什么？

**回答要点**：Transformer 标配 ReLU（或 GELU/SwiGLU），CNN 也以 ReLU 为主；但 Transformer 中 GELU 更常见，因其在 BERT/GPT 中表现更优；不同架构差异在于：CNN 有局部归纳偏置，Transformer 全靠注意力，GELU 的平滑非线性更适合注意力机制的训练动力学。
