# 迁移学习与微调（Transfer Learning & Fine-tuning）

## 定义

**迁移学习**是将一个任务（源任务）上学习到的知识迁移到另一个相关任务（目标任务）上的机器学习方法。其核心思想是：不从头训练模型，而是利用已有模型的知识加速目标任务的学习。

**微调**是迁移学习中最常用的实现方式：在预训练模型的基础上，用目标任务的少量标注数据继续训练，调整模型参数以适应新任务。

数学形式：设源任务 $T_s$ 上训练得到的模型参数为 $\theta_s$，目标任务 $T_t$ 的损失函数为 $\mathcal{L}_t$，目标任务数据集为 $D_t$，微调过程为：

$$
\theta_{\text{final}} = \arg\min_{\theta} \mathcal{L}_t(\theta; D_t) \quad \text{，初始值 } \theta = \theta_s
$$

### 直观理解

> "站在巨人的肩膀上"——让模型先在大规模通用数据上学到基础能力（如语言理解、图像边缘检测），再在小规模特定数据上"略作调整"即可适配新任务，省时省力。

## 核心分类表

| 迁移类型 | 定义 | 典型场景 | 示例 |
|:---------|:-----|:---------|:-----|
| **归纳迁移** | 源任务和目标任务不同，但领域相同 | 图像分类 → 图像分割 | ImageNet 预训练 → 医学影像分割 |
| **转导迁移** | 源任务和目标任务相同，但领域不同 | 领域自适应 | 新闻文本情感分类 → 社交媒体文本情感分类 |
| **无监督迁移** | 目标任务无标注，利用源任务知识 | 少样本/零样本学习 | GPT 的 In-Context Learning |
| **微调（Fine-tuning）** | 全量参数或部分参数继续训练 | 预训练模型适配下游任务 | BERT → 文本分类 |

### 微调策略对比

| 策略 | 参数更新范围 | 适用场景 | 计算成本 | 过拟合风险 |
|:-----|:-------------|:---------|:---------|:-----------|
| 全量微调 | 全部参数 | 目标任务数据充足 | 高 | 中 |
| 最后一层微调 | 仅分类头/输出层 | 数据极少 | 低 | 低 |
| 部分层微调 | 最后 N 层 | 数据中等 | 中 | 中 |
| LoRA/Adapter | 插入少量可训练参数 | 大模型微调（显存受限） | 低 | 低 |

## ML/DL 应用场景

| 应用场景 | 数学形式 | 说明 |
|:---------|:---------|:-----|
| BERT 下游任务微调 | $\mathcal{L}_{\text{task}}(\theta_{\text{BERT}}; D_{\text{task}})$ | 在预训练 BERT 基础上用任务数据微调 |
| 图像分类迁移 | CNN 预训练权重 + 新分类头 | ResNet 在 ImageNet 预训练后用于医学图像 |
| 大模型指令微调 | $\mathcal{L}_{\text{SFT}}(\theta; D_{\text{instruction}})$ | 在基座模型上做监督微调（SFT） |
| LoRA 低秩适配 | $\theta = \theta_0 + \Delta\theta = \theta_0 + BA$ | 冻结原模型，只训练低秩矩阵 $B, A$ |

## 代码示例

```python
import torch
import torch.nn as nn
from transformers import BertForSequenceClassification, AdamW

# 加载预训练 BERT 模型（源任务知识）
model = BertForSequenceClassification.from_pretrained(
    'bert-base-uncased',  # 预训练权重
    num_labels=2          # 目标任务类别数
)

# 冻结除分类头外的所有层（部分微调策略）
for name, param in model.named_parameters():
    if 'classifier' not in name:  # 仅解冻分类头
        param.requires_grad = False

# 定义优化器，仅更新可训练参数
optimizer = AdamW(
    filter(lambda p: p.requires_grad, model.parameters()),  # 只优化可训练参数
    lr=2e-5
)

# 微调训练循环（简化）
model.train()
for epoch in range(3):  # 通常小学习率 + 少轮次
    for batch in dataloader:
        outputs = model(**batch)
        loss = outputs.loss
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
```

### 微调关键技巧

- **学习率策略**：微调使用比从头训练低 1-2 个数量级的学习率（如 BERT 用 2e-5 ~ 5e-5）
- **预热（Warmup）**：前几个 step 线性增加学习率，稳定训练
- **早停（Early Stopping）**：验证集性能不再提升时停止，防止过拟合

## 面试追问

**Q1（基础）**：迁移学习和微调的核心区别是什么？
**回答要点**：

1. 迁移学习是**广义概念**，包含所有利用源任务知识的方法（特征提取、微调、蒸馏等）
2. 微调是迁移学习中最常用的一种**具体实现方式**
3. 迁移学习范围更广，还包含领域自适应、多任务学习、知识蒸馏等方法，微调仅是其中一种实现路径

**Q2（深挖）**：全量微调和 LoRA 微调各自的优缺点？
**回答要点**：

1. 全量微调：效果好但显存大、需存储完整模型副本，适合小规模模型
2. LoRA：显存占用小、可插拔、适合大模型，但效果略低于全量微调
3. LoRA 微调后的参数可合并回原权重，不引入额外推理延迟；全量微调需单独保存完整模型副本

**Q3（实战）**：如果目标任务只有 100 条标注数据，你会怎么微调？
**回答要点**：

1. 采用**冻结大部分层**的策略，只训练分类头或最后 1-2 层
2. 使用**数据增强**（回译、同义词替换）扩充数据集
3. 使用**较小的学习率**和**早停**防止过拟合

**Q4（边界）**：迁移学习在什么情况下会失效（负迁移）？
**回答要点**：

1. 源任务和目标任务**相关性过低**（如从图像分类迁移到语音识别）
2. 目标任务数据**分布与源任务差异极大**且数据量极少
3. 解决：使用领域自适应（Domain Adaptation）或距离度量评估任务相似度
