# LSTM 与门控机制

## 定义

长短期记忆网络（LSTM, Long Short-Term Memory）通过**门控机制**和**细胞状态**解决 RNN 的梯度消失问题，使其能够学习 **100+ 时间步**的长期依赖关系。

$$
f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) \quad \text{遗忘门}
$$

$$
i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i) \quad \text{输入门}
$$

$$
\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C) \quad \text{候选状态}
$$

$$
o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o) \quad \text{输出门}
$$

```python
import torch.nn as nn


lstm = nn.LSTM(input_size=100, hidden_size=256, num_layers=2, batch_first=True)  # 创建LSTM层，通过门控机制和细胞状态捕捉长距离依赖

output, (h_n, c_n) = lstm(x)     # output: (N, L, 256), c_n: 细胞状态
```

## 三种门控

| 门 | 公式 | 作用 | 类比 |
|:--:|:----:|:----:|------|
| **遗忘门 $f_t$ ** | $\sigma(W_f[h_{t-1}, x_t] + b_f)$ | 决定丢弃哪些旧信息 | 选择性忘记过去 |
| **输入门 $i_t$ ** | $\sigma(W_i[h_{t-1}, x_t] + b_i)$ | 决定存储哪些新信息 | 选择性记住现在 |
| **输出门 $o_t$ ** | $\sigma(W_o[h_{t-1}, x_t] + b_o)$ | 决定输出哪些信息 | 选择性输出 |

## 细胞状态更新

```python
遗忘 → C_{t-1} × f_t         丢弃不重要的旧记忆

输入 → C_t = C_{t-1} + i_t × C̃_t  添加重要的新信息

输出 → h_t = o_t × tanh(C_t)   从细胞状态中筛选输出
```

**关键创新**：细胞状态 $C_t$ 上的梯度更新是**加法**而非乘法—— $C_t = C_{t-1} \times f_t + i_t \times \tilde{C}_t$ 。加法操作使梯度可以无损地反向传播，这是 LSTM 解决梯度消失的核心原因。

## LSTM vs 原始 RNN

| 对比 | RNN | LSTM |
|:----:|:----:|:----:|
| 隐藏状态 | 单一 $h_t$ | $h_t$ + 细胞状态 $C_t$ |
| 梯度流 | 连乘（易消失） | 加法（梯度直通） |
| 长期依赖 | ❌ 10 步以上失效 | ✅ 100 步以上 |
| 参数量 | 少 | 多（约 4 倍） |
| 计算速度 | 快 | 慢 |
| 过拟合风险 | 低 | 高（需 Dropout） |

```python
# 对比参数数量
rnn = nn.RNN(100, 256)          # params: 100*256 + 256*256 + 256 ≈ 91K

lstm = nn.LSTM(100, 256)        # params: 4 * (100*256 + 256*256 + 256) ≈ 365K
```

## ML 中的 LSTM

| 应用场景 | 使用方式 | 说明 |
|----------|----------|------|
| **语言模型** | 多层 LSTM 预测下一词 | 2013-2017 年 SOTA |
| **机器翻译** | Encoder LSTM → Decoder LSTM | Seq2Seq 框架 |
| **情感分析** | BiLSTM 编码 + 全连接分类 | 双向上下文 |
| **股票预测** | 多变量 LSTM 多步预测 | 时序预测 |
| **异常检测** | LSTM 预测误差作为异常分 | 时序异常 |

## 面试追问

**Q1（基础）**：LSTM 通过什么机制解决了 RNN 的梯度消失问题？

**回答要点**：引入细胞状态 C_t，其更新是加法操作 C_t = C_{t-1}×f_t + i_t×C̃_t，而不是乘法；加法使梯度可以沿细胞状态无损地反向传播，不经历非线性压缩；遗忘门可学习决定丢弃多少信息，保证了梯度流的稳定性。

**Q2（深挖）**：LSTM 的四个门/状态各自的作用是什么？为什么是"三个门"？

**回答要点**：遗忘门控制丢弃多少旧记忆，输入门控制加入多少新信息，候选状态提供新的候选值，输出门控制输出多少；总共有三组 sigmoid 门（遗忘/输入/输出）+ 一组 tanh 候选，共四组权重，所以参数量是 RNN 的约 4 倍。

**Q3（实战）**：训练 LSTM 时容易过拟合，你会使用哪些正则化手段？

**回答要点**：Dropout——注意 LSTM 需用变分 Dropout（同 mask 作用于所有时间步）；减少 hidden_size 或层数作为模型正则；权重衰减（L2）和学习率调度；early stopping 配合验证集监控。

**Q4（边界）**：LSTM 的串行计算特性限制了其在哪些场景上的应用？业界如何解决？

**回答要点**：长序列训练极慢，无法利用 GPU 并行加速，尤其在 NLP 超大语料上无法扩展；业界解决方案：用 Transformer 替代（完全并行），或在 LSTM 中使用 truncated BPTT 限制展开长度；推理时 LSTM 的串行特性对低延迟场景（如语音实时识别）反而是优势。
