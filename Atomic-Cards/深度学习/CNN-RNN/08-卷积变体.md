# 卷积变体

## 定义

卷积变体是在标准卷积操作基础上，通过修改卷积核的大小、步长、填充方式或计算模式，实现不同功能的一系列卷积操作。每种变体针对特定问题设计，扩展了 CNN 的应用能力。

## 1×1 卷积

### 定义

卷积核大小为 $1 \times 1$，不捕捉空间信息，仅在**通道维度**上进行线性组合：

$$
y_{i,j} = \sum_{c=1}^{C_{\text{in}}} w_c \cdot x_{i,j,c} + b
$$

### 三大作用

| 作用 | 说明 | 图示 |
|:-----|:------|:------|
| **降维/升维** | 改变通道数，减少参数量 | $256 \to 64$（4 倍减少） |
| **跨通道交互** | 在不同通道间引入非线性组合 | 每个输出通道是所有输入通道的加权和 |
| **增加非线性** | 1×1 卷积后接 ReLU，增加网络深度 | 在保持空间尺寸的同时增加非线性层 |

```python
import torch.nn as nn

# 1×1 卷积：降维 → 3×3 卷积 → 1×1 卷积升维（Bottleneck 结构）
bottleneck = nn.Sequential(
    nn.Conv2d(256, 64, kernel_size=1),      # 降维：256→64，减少后续 3×3 卷积的计算量
    nn.ReLU(),
    nn.Conv2d(64, 64, kernel_size=3, padding=1),  # 3×3 空间卷积，输入通道已大幅减少
    nn.ReLU(),
    nn.Conv2d(64, 256, kernel_size=1),      # 升维：64→256，恢复通道数以便残差连接
    nn.ReLU()
)

# Inception 模块中的 1×1 卷积（降维后接不同尺度卷积）
# 输入 192 通道 → 1×1 降至 96 → 3×3 卷积 → 输出
inception_3x3 = nn.Sequential(
    nn.Conv2d(192, 96, kernel_size=1),       # 1×1 降维：计算量降低 2 倍
    nn.ReLU(),
    nn.Conv2d(96, 128, kernel_size=3, padding=1),  # 3×3 卷积，在降维后的空间上计算
    nn.ReLU()
)
```

## 转置卷积（Transposed Convolution）

### 定义

转置卷积（也称反卷积 Deconvolution）执行与标准卷积**相反**的空间变换——将低分辨率特征图上采样到高分辨率：

$$
\text{Output size} = (\text{Input size} - 1) \times \text{stride} - 2 \times \text{padding} + \text{kernel size}
$$

| 参数 | 标准卷积 | 转置卷积 |
|:-----|:---------|:----------|
| 输入 → 输出尺寸 | 大 → 小（下采样） | 小 → 大（上采样） |
| stride 效果 | 步长 > 1 时输出缩小 | 步长 > 1 时输出放大 |
| 矩阵视角 | 乘以 $W$（稀疏矩阵） | 乘以 $W^T$（前向的转置，非逆运算） |

```python
# 转置卷积：将 2×2 上采样到 4×4
transpose_conv = nn.ConvTranspose2d(
    in_channels=128,
    out_channels=64,
    kernel_size=4,        # 卷积核大小
    stride=2,             # 步长 2：输入每个像素在输出上对应 2×2 区域
    padding=1              # 输出尺寸 = (2-1)*2 - 2*1 + 4 = 4
)

# 输入: (batch, 128, 2, 2) → 输出: (batch, 64, 4, 4)
```

**应用**：GAN 生成器（从噪声生成图像）、语义分割（U-Net 的上采样路径）、图像超分辨率。

## 空洞卷积（Dilated Convolution）

### 定义

在卷积核的相邻元素间插入空洞（0），扩大感受野而不增加参数：

$$
\text{Effective kernel size} = \text{kernel size} + (\text{kernel size} - 1) \times (\text{dilation} - 1)
$$

| dilation | 3×3 卷积的有效感受野 | 输出尺寸（pad=1） |
|:--------:|:--------------------:|:----------------:|
| 1（普通） | 3×3 | 同输入 |
| 2 | 5×5 | 同输入 |
| 4 | 9×9 | 同输入 |

```python
# 空洞卷积：扩大感受野而不增加参数
dilated_conv = nn.Conv2d(
    in_channels=64,
    out_channels=128,
    kernel_size=3,
    padding=2,            # padding = dilation（保持输出尺寸不变）
    dilation=2             # dilation=2：3×3 核的有效感受野为 5×5
)
```

**应用**：语义分割（DeepLab 系列，用空洞卷积保持高分辨率特征图的同时扩大感受野）、时序卷积（TCN）。

## 深度可分离卷积

### 定义

将标准卷积分解为两步：**深度卷积**（Depthwise，逐通道空间卷积）+ **逐点卷积**（Pointwise，1×1 卷积）。

计算量对比：

$$
\text{标准卷积} = K_h \times K_w \times C_{\text{in}} \times C_{\text{out}} \times H \times W
$$

$$
\text{深度可分离} = K_h \times K_w \times C_{\text{in}} \times H \times W + C_{\text{in}} \times C_{\text{out}} \times H \times W
$$

节省比例 $\approx \frac{1}{C_{\text{out}}} + \frac{1}{K_h \times K_w}$，当 $C_{\text{out}}=256$、$K_h=K_w=3$ 时计算量约减少 8~9 倍。

## 变体对比

| 变体 | 核心功能 | 参数增加 | 计算量 | 典型应用 |
|:-----|:---------|:-------:|:------:|:---------|
| **1×1 卷积** | 通道变换，降维/升维 | 无 | 低 | Inception, MobileNet |
| **转置卷积** | 上采样，小图变大图 | 同标准 | 中 | GAN, U-Net |
| **空洞卷积** | 扩大感受野，不改变分辨率 | 无 | 同标准 | DeepLab, TCN |
| **深度可分离** | 减少计算量，轻量化 | 无 | **极低** | MobileNet, EfficientNet |
| **可变形卷积** | 自适应感受野形状 | 少量 | 中 | 目标检测（Deformable DETR） |

## ML/DL 应用场景

| 应用场景 | 使用的卷积变体 | 说明 |
|:---------|:---------------|:------|
| 轻量级网络（MobileNet） | 深度可分离卷积 | 计算量减少 8~9 倍，适合移动端 |
| 语义分割（DeepLab） | 空洞卷积 | 保持高分辨率特征图，扩大感受野 |
| GAN 生成器 | 转置卷积 | 从随机噪声逐步上采样到高分辨率图像 |
| ResNet / Inception | 1×1 卷积 | Bottleneck 降维，减少计算量 |
| 目标检测（可变形 DCN） | 可变形卷积 | 自适应感受野形状，匹配物体形态 |

## 面试追问

**Q1（基础）**：1×1 卷积的作用是什么？为什么它能在不损失信息的情况下降维？
**回答要点**：

1. 1×1 卷积在不改变空间尺寸的情况下改变通道数，实现跨通道的信息整合和线性组合。
2. 降维不会损失"信息"的前提是通道间存在冗余——256 个通道中很多通道高度相关，1×1 卷积通过学习加权组合将冗余信息压缩到更少的通道中。
3. 在 ResNet 的 Bottleneck 中：256→64（1×1 降维）→ 3×3 → 256（1×1 升维），中间 3×3 的计算量降低为原来的 1/4。

**Q2（深挖）**：转置卷积和标准卷积在数学上是什么关系？为什么说"反卷积"这个名称不准确？
**回答要点**：

1. 从矩阵乘法视角：标准卷积等价于乘以稀疏矩阵 $W$，转置卷积等价于乘以 $W^T$。$W^T$ 是 $W$ 的转置矩阵，而非逆矩阵 $W^{-1}$。
2. 转置卷积不是卷积的"逆运算"（逆运算是从输出恢复输入，数学上难以实现），它只是执行了与标准卷积相反的空间变换方向（上采样而非下采样）。
3. 转置卷积可能产生棋盘格伪影（checkerboard artifacts），可通过 kernel_size 能被 stride 整除来缓解。

**Q3（实战）**：在语义分割任务中，为什么用空洞卷积替代下采样+上采样？空洞卷积有什么缺点吗？
**回答要点**：

1. 标准分割网络先用下采样缩小特征图（扩大感受野），再用上采样恢复分辨率，这个过程丢失了细节信息。
2. 空洞卷积在不做下采样的情况下扩大感受野，保持特征图的高分辨率，保留空间细节——DeepLabv3+ 用空洞卷积在 stride=16 的特征图上提取多尺度上下文。
3. 空洞卷积的缺点：网格效应（gridding artifact）——连续使用相同 dilation 的空洞卷积会导致部分像素从未被覆盖，信息不连续；可通过混合不同 dilation 率（HDC 策略）缓解。

**Q4（边界）**：深度可分离卷积在什么场景下精度损失明显？MobileNet 是如何弥补的？
**回答要点**：

1. 信息混合不充分：深度卷积逐通道独立运算，通道间的信息交互仅在 1×1 逐点卷积中完成。在通道数较少的浅层网络中，通道间交互不足导致精度下降。
2. 低维空间中的 ReLU 会破坏信息：深度卷积在低维空间中操作，ReLU 会将负值置零，丢失信息。MobileNetV2 引入 Inverted Residual：先用 1×1 升维→深度卷积→1×1 降维，并在低维输出后不使用 ReLU（线性瓶颈）。
3. 在端侧设备和低延迟场景下，少量精度损失（~1%~3%）换来的 8~9 倍计算量减少是值得的。
