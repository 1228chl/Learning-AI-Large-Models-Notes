# 卷积运算

## 定义

卷积（Convolution）是一种**滑动窗口**运算。一个卷积核（Filter / Kernel）在输入上滑动，在每个位置计算核与覆盖区域的**逐元素乘积之和**，生成**特征图（Feature Map）**。

$$
(I * K)_{ij} = \sum_{m} \sum_{n} I_{i+m, j+n} \cdot K_{m, n}
$$

- $I$：输入张量（图像或特征图）
- $K$：卷积核（滤波器）
- $i, j$：输出特征图的空间位置索引
- $m, n$：卷积核内部的空间偏移索引

## 直观理解

### 卷积的滑动窗口机制

卷积核的几何含义：每个卷积核是一个**可学习的局部模式检测器**。当卷积核滑动到图像上某个位置时，它计算该位置的像素模式与自身权重的匹配程度——匹配度越高，输出值越大。

- 第一层卷积核学习检测**低级特征**：边缘、角点、颜色块
- 中间层卷积核组合低级特征形成**中级特征**：纹理、图案、局部形状
- 深层卷积核检测**高级语义特征**：眼睛、轮子、窗户等完整物体部件

### 卷积的局部连接与参数共享

卷积的两个核心设计原则：
- **局部连接**：每个神经元只连接输入的一个局部区域（感受野），而非全连接的所有像素。这利用了图像的局部相关性——相邻像素比远距离像素更相关。
- **参数共享**：同一卷积核在所有空间位置上复用相同的权重。这意味着无论一只猫出现在图像的左上角还是右下角，同一个卷积核都能检测到它——这就是**平移等变性**（translation equivariance），CNN 最关键的归纳偏置。

### 堆叠小卷积核优于单个大卷积核

两个 $3 \times 3$ 卷积堆叠的感受野等于一个 $5 \times 5$ 卷积，但参数量更少（$2 \times 9 = 18$ vs $25$），且中间多了一层非线性变换（ReLU），表达能力更强。这是 VGG 网络的设计原则，也是现代 CNN 的通用做法。

```python
import torch.nn as nn

# 2D 卷积层
conv = nn.Conv2d(  # 实例化2D卷积层，对输入图像进行卷积运算提取局部特征

    in_channels=3,           # 输入通道数（RGB = 3）
    out_channels=64,         # 输出通道数（卷积核数量）
    kernel_size=3,           # 卷积核大小 3×3
    stride=1,                # 步长
    padding=1,               # 填充（保持尺寸）
    dilation=1               # 空洞率
)
```

## 核心参数

```python
# 输出尺寸公式
output_size = (input_size - kernel_size + 2 * padding) // stride + 1  # 计算卷积后特征图的空间尺寸
```

| 参数 | 作用 | 常用值 | 说明 |
|------|------|:------:|------|
| `kernel_size` | 感受野大小 | 3, 5, 7 | 越小参数越少，越大感受野越广 |
| `stride` | 滑动步长 | 1, 2 | > 1 时可下采样 |
| `padding` | 边缘填充 | `same` (保持尺寸), 0 | 保持边界信息不被丢失 |
| `dilation` | 空洞间隔 | 1, 2, 4 | 扩大感受野不增加参数 |

| 填充模式 | 输入→输出 | 说明 |
|----------|:---------:|------|
| **Valid**（无填充） | $n \to n - k + 1$ | 尺寸缩小 |
| **Same**（保持尺寸） | $n \to n$ | $p = (k-1)/2$ |
| **Full**（最大填充） | $n \to n + k - 1$ | 极少使用 |

## ML 中的卷积

| 应用场景 | 典型结构 | 说明 |
|----------|----------|------|
| **图像分类** | Conv + ReLU + Pool → 全连接 | 逐层提取特征 |
| **目标检测** | CNN 主干 + 检测头 | YOLO、Faster R-CNN |
| **语义分割** | 编码器-解码器（转置卷积） | U-Net、DeepLab |
| **图像生成** | 转置卷积（反卷积）上采样 | GAN 生成器 |
| **1D 卷积** | 文本 / 时序 Conv1d | NLP 特征提取 |

## 面试追问

**Q1（基础）**：卷积的局部连接和参数共享分别带来了什么好处？
**回答要点**：

1. 局部连接捕捉空间局部特征（边缘、纹理），符合图像的空间相关性
2. 参数共享使同一卷积核在所有位置复用，大幅减少参数量并引入平移等变性
3. 两者共同使 CNN 比全连接网络在图像任务上参数效率高几个数量级

**Q2（深挖）**：空洞卷积（Dilated Convolution）如何在扩大感受野的同时不增加参数量？
**回答要点**：

1. 标准 3×3 卷积感受野是 3×3；空洞率为 d 的 3×3 卷积感受野为 (2d+1)×(2d+1)
2. 参数量仍为 9（3×3），与普通卷积相同，通过 skip 采样点实现稀疏计算
3. d 越大感受野越大，在不增加参数的前提下有效扩大了感受范围

**Q3（实战）**：设计 CNN 网络时，如何选择 kernel size、stride 和 padding 的组合？
**回答要点**：

1. 常用 3×3 kernel + padding=1 + stride=1 保持尺寸不变；下采样用 stride=2 的卷积或池化
2. 堆叠多个小 kernel（如 3×3）比单个大 kernel（7×7）参数更少、非线性更强
3. 根据输入尺寸和期望输出尺寸反推各层参数

**Q4（边界）**：在 Transformer/ViT 时代，CNN 还有哪些不可替代的优势？
**回答要点**：

1. CNN 内置平移等变性/局部性归纳偏置，小数据量下比 ViT 泛化更好
2. 计算效率高，推理速度快，适合边缘部署
3. 在底层视觉任务（超分、去噪、光流）中仍占主导；ViT 需要大量数据和计算才能超越 CNN
