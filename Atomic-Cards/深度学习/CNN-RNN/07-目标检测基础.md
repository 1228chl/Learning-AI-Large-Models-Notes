# 目标检测基础

## 定义

目标检测（Object Detection）是计算机视觉的核心任务之一：在图像中**定位**和**分类**多个目标物体。输出为每个检测到的物体提供一个边界框（Bounding Box）和类别标签。

数学形式：对于输入图像 $I \in \mathbb{R}^{H \times W \times 3}$，输出检测结果集合：

$$
\mathcal{D} = \{(b_j, c_j, s_j) \mid j = 1, \dots, N\}
$$

其中：
- $b_j = (x, y, w, h)$ 为边界框的中心坐标和宽高
- $c_j \in \{1, \dots, C\}$ 为物体类别
- $s_j \in [0, 1]$ 为置信度得分
- $N$ 为检测到的物体数量

## 核心概念

### 边界框表示

| 表示方式 | 格式 | 说明 |
|:---------|:-----|:------|
| **xyxy** | $(x_1, y_1, x_2, y_2)$ | 左上角和右下角坐标 |
| **xywh** | $(x, y, w, h)$ | 中心坐标 + 宽高 |
| **cxywh** | $(c_x, c_y, w, h)$ | 相对于网格的归一化坐标（YOLO 风格） |

### IoU（交并比）

衡量预测框与真实框的重叠程度，是目标检测的核心评估指标：

$$
\text{IoU} = \frac{\text{Area of Overlap}}{\text{Area of Union}} = \frac{B_{\text{pred}} \cap B_{\text{gt}}}{B_{\text{pred}} \cup B_{\text{gt}}}
$$

- IoU > 0.5 通常认为检测成功
- 作为损失函数时使用 GIoU / DIoU / CIoU 改进

### NMS（非极大值抑制）

去除重复检测框：对同一物体的多个候选框，保留得分最高的，删除与其 IoU 超过阈值的其他框。

```python
import numpy as np

def nms(boxes, scores, iou_threshold=0.5):
    """非极大值抑制：去除重叠度过高的冗余检测框"""
    indices = np.argsort(scores)[::-1]           # 按置信度降序排列
    keep = []                                     # 保留的框索引列表

    while len(indices) > 0:
        i = indices[0]                            # 当前最高置信度的框
        keep.append(i)
        # 计算其余框与当前框的 IoU
        ious = compute_iou(boxes[i], boxes[indices[1:]])
        # 保留 IoU 小于阈值的框（与当前框不高度重叠的框）
        indices = indices[1:][ious < iou_threshold]

    return keep

def compute_iou(box, boxes):
    """计算一个框与多个框的 IoU"""
    x1 = np.maximum(box[0], boxes[:, 0])
    y1 = np.maximum(box[1], boxes[:, 1])
    x2 = np.minimum(box[2], boxes[:, 2])
    y2 = np.minimum(box[3], boxes[:, 3])
    inter = np.maximum(0, x2 - x1) * np.maximum(0, y2 - y1)
    area_box = (box[2] - box[0]) * (box[3] - box[1])
    area_boxes = (boxes[:, 2] - boxes[:, 0]) * (boxes[:, 3] - boxes[:, 1])
    union = area_box + area_boxes - inter
    return inter / union
```

## 两大范式

### 两阶段检测器（R-CNN 系列）

先生成候选区域（Region Proposals），再对每个区域分类和回归：

| 模型 | 特点 | 速度 | 精度 |
|:-----|:-----|:----:|:----:|
| **R-CNN** | 用 Selective Search 生成 2000 个候选框，逐框 CNN | 极慢 | 中 |
| **Fast R-CNN** | 整图一次 CNN + RoI Pooling 提取候选框特征 | 较快 | 较高 |
| **Faster R-CNN** | **RPN（Region Proposal Network）替代 Selective Search** | 快 | **高** |
| **Mask R-CNN** | Faster R-CNN + 分割分支 | 较慢 | 高 |

```
Faster R-CNN 流程：
输入图像 → CNN backbone → 特征图 → RPN(生成候选框) → RoI Pooling → 分类+回归
```

### 单阶段检测器（YOLO / SSD）

直接回归边界框和类别，无需候选区域步骤：

| 模型 | 特点 | 速度 | 精度 |
|:-----|:-----|:----:|:----:|
| **YOLO** | 将图像划分为 $S \times S$ 网格，每个网格预测 $B$ 个框 | **最快** | 较低 |
| **YOLOv3** | 多尺度预测 + Darknet-53 backbone | 快 | 较高 |
| **YOLOv5/v8** | Anchor Free + Mosaic 增强 + 工程优化 | 快 | 高 |
| **SSD** | 多尺度特征图预测 | 快 | 中高 |

```
YOLO 核心思路：
将图像分成 S×S 网格 → 每个网格预测 B 个边界框 + C 个类别概率
输出张量形状: (S, S, B * 5 + C)    # 5 = x, y, w, h, confidence
```

## 评估指标

| 指标 | 公式 | 说明 |
|:-----|:-----|:------|
| **mAP** | $\frac{1}{C} \sum_{c=1}^C \text{AP}_c$ | 所有类别的平均 AP |
| **AP@0.5** | IoU 阈值 0.5 时的 AP | 宽松评估 |
| **AP@0.5:0.95** | 多个 IoU 阈值下的平均 AP | 严格评估（COCO 标准） |
| **FPS** | Frames Per Second | 推理速度，工业级需 >30 FPS |

## ML/DL 应用场景

| 应用场景 | 常用模型 | 说明 |
|:---------|:---------|:------|
| 自动驾驶 | YOLOv8 / 实时检测 | 检测车辆、行人、交通标志，要求高 FPS |
| 安防监控 | YOLO + 跟踪算法 | 实时行人/车辆检测和追踪 |
| 工业质检 | Faster R-CNN | 检测产品表面缺陷，精度优先 |
| 医学影像 | Mask R-CNN | 检测和分割病灶区域 |
| 无人机视觉 | YOLO-NAS | 轻量级模型在边缘设备上运行 |

## 面试追问

**Q1（基础）**：目标检测和图像分类有什么区别？为什么目标检测比分类更复杂？
**回答要点**：

1. 图像分类输出单一类别标签，目标检测输出不定数量的边界框 + 类别 + 置信度。
2. 目标检测需要解决：物体在图像中的位置（定位）、物体的大小和宽高比变化（尺度）、同一类别的多个实例（重复检测）、背景与物体的区分。
3. NMS 是目标检测特有的后处理步骤，用于解决重复检测问题——分类任务不需要。

**Q2（深挖）**：两阶段检测器（Faster R-CNN）和单阶段检测器（YOLO）的核心区别是什么？各自优缺点？
**回答要点**：

1. 两阶段先 RPN 生成候选区域再分类回归，精度更高但速度慢；单阶段直接回归位置和类别，速度快但正负样本极端不平衡。
2. Faster R-CNN 的 RPN 利用 anchor boxes 解决多尺度问题，但计算量大；YOLO 将检测视为回归问题一步到位。
3. Focal Loss 的提出专门解决单阶段检测器的类别不平衡问题，使 RetinaNet 达到两阶段的精度同时保持单阶段的速度。

**Q3（实战）**：小目标检测（如远距离行人）性能差，你会如何改进？
**回答要点**：

1. 利用多尺度特征图：FPN（特征金字塔网络）将高层语义与低层细节融合，让小目标在分辨率高的低层特征图上检测。
2. 增大输入图像分辨率或使用更大尺度的特征图（YOLOv4 的 52×52 特征图适合小目标）。
3. 数据增强：Mosaic 增强将多张图拼接，增加小目标的样本量；Copy-Paste 将小目标复制到不同背景中。
4. 改进 anchor 设计：对小目标聚类更密集更小的 anchor 尺寸。

**Q4（边界）**：YOLO 将图像划分为网格的假设有什么局限性？Anchor-Free 方法如何解决？
**回答要点**：

1. 网格划分假设每个网格最多包含一个目标中心，密集小目标场景下多个目标可能落在同一网格导致漏检。
2. Anchor-Free 方法（如 FCOS、CenterNet）直接预测每个像素到目标边界的距离，消除了对 anchor 尺寸和大小的依赖。
3. Anchor-Free 简化了检测流程（无需 anchor 聚类和匹配），在处理非常规宽高比的目标时更灵活，但在极端多尺度和密集场景下仍面临挑战。
