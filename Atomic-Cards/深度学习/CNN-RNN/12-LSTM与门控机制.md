# LSTM 与门控机制

## 定义

长短期记忆网络（LSTM, Long Short-Term Memory）通过**门控机制**和**细胞状态**解决 RNN 的梯度消失问题，使其能够学习 **100+ 时间步**的长期依赖关系。

设 $W_f, W_i, W_C, W_o$ 为各门的权重矩阵，$b_f, b_i, b_C, b_o$ 为对应的偏置项，$h_{t-1}$ 为上一时刻的隐藏状态，$x_t$ 为当前输入向量：

$$
f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) \quad \text{遗忘门}
$$

$$
i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i) \quad \text{输入门}
$$

$$
\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C) \quad \text{候选状态}
$$

$$
o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o) \quad \text{输出门}
$$

## 直观理解

### LSTM 的核心创新：加法梯度流

原始 RNN 的梯度消失根源于 $\partial h_t / \partial h_{t-1}$ 的连乘——每个时间步的梯度都要乘以 $\tanh$ 的导数（小于 1），经过 $n$ 步后指数衰减到零。LSTM 的解决方案是在隐藏状态之外引入**细胞状态 $C_t$**，其更新公式为：

$$
C_t = C_{t-1} \times f_t + i_t \times \tilde{C}_t
$$

这里的关键是**加法操作**：$\partial C_t / \partial C_{t-1} = f_t$（遗忘门的输出，范围 0~1）。梯度通过细胞状态回传时，只乘以一个标量 $f_t$ 而非整个雅可比矩阵，而且 $f_t$ 由网络学习决定——当需要记住长期信息时，网络可以学习让 $f_t \approx 1$，使梯度几乎无损通过。

### 三条传送带

LSTM 的信息流可以理解为三条平行的"传送带"：

1. **细胞状态 $C_t$**（主传送带）：信息直通，梯度无损，只在三扇门处被修改
2. **隐藏状态 $h_t$**（输出传送带）：从细胞状态中筛选出需要输出的内容
3. **门控信号**（控制开关）：遗忘门、输入门、输出门各自决定信息的"开"与"关"

这种设计使得 LSTM 可以"记住"100 步前的信息——只要遗忘门保持开启，细胞状态中的信息就不会衰减。

```python
import torch.nn as nn


lstm = nn.LSTM(input_size=100, hidden_size=256, num_layers=2, batch_first=True)  # 创建LSTM层，通过门控机制和细胞状态捕捉长距离依赖

output, (h_n, c_n) = lstm(x)     # output: (N, L, 256), c_n: 细胞状态
```

## 三种门控

| 门 | 公式 | 作用 | 类比 |
|:--:|:----:|:----:|------|
| **遗忘门 $f_t$ ** | $\sigma(W_f[h_{t-1}, x_t] + b_f)$ | 决定丢弃哪些旧信息 | 选择性忘记过去 |
| **输入门 $i_t$ ** | $\sigma(W_i[h_{t-1}, x_t] + b_i)$ | 决定存储哪些新信息 | 选择性记住现在 |
| **输出门 $o_t$ ** | $\sigma(W_o[h_{t-1}, x_t] + b_o)$ | 决定输出哪些信息 | 选择性输出 |

## 细胞状态更新

```python
遗忘 → C_{t-1} × f_t         丢弃不重要的旧记忆

输入 → C_t = C_{t-1} + i_t × C̃_t  添加重要的新信息

输出 → h_t = o_t × tanh(C_t)   从细胞状态中筛选输出
```

**关键创新**：细胞状态 $C_t$ 上的梯度更新是**加法**而非乘法—— $C_t = C_{t-1} \times f_t + i_t \times \tilde{C}_t$ 。加法操作使梯度可以无损地反向传播，这是 LSTM 解决梯度消失的核心原因。

## LSTM vs 原始 RNN

| 对比 | RNN | LSTM |
|:----:|:----:|:----:|
| 隐藏状态 | 单一 $h_t$ | $h_t$ + 细胞状态 $C_t$ |
| 梯度流 | 连乘（易消失） | 加法（梯度直通） |
| 长期依赖 | ❌ 10 步以上失效 | ✅ 100 步以上 |
| 参数量 | 少 | 多（约 4 倍） |
| 计算速度 | 快 | 慢 |
| 过拟合风险 | 低 | 高（需 Dropout） |

```python
# 对比参数数量
rnn = nn.RNN(100, 256)          # params: 100*256 + 256*256 + 256 ≈ 91K

lstm = nn.LSTM(100, 256)        # params: 4 * (100*256 + 256*256 + 256) ≈ 365K
```

## ML 中的 LSTM

| 应用场景 | 使用方式 | 说明 |
|----------|----------|------|
| **语言模型** | 多层 LSTM 预测下一词 | 2013-2017 年 SOTA |
| **机器翻译** | Encoder LSTM → Decoder LSTM | Seq2Seq 框架 |
| **情感分析** | BiLSTM 编码 + 全连接分类 | 双向上下文 |
| **股票预测** | 多变量 LSTM 多步预测 | 时序预测 |
| **异常检测** | LSTM 预测误差作为异常分 | 时序异常 |

## 面试追问

**Q1（基础）**：LSTM 通过什么机制解决了 RNN 的梯度消失问题？
**回答要点**：

1. 引入细胞状态 C_t，其更新是加法操作 C_t = C_{t-1}×f_t + i_t×C̃_t，而不是乘法
2. 加法使梯度可以沿细胞状态无损地反向传播，不经历非线性压缩
3. 遗忘门可学习决定丢弃多少信息，保证了梯度流的稳定性

**Q2（深挖）**：LSTM 的四个门/状态各自的作用是什么？为什么是"三个门"？
**回答要点**：

1. 遗忘门控制丢弃多少旧记忆，输入门控制加入多少新信息
2. 候选状态提供新的候选值，输出门控制从细胞状态输出多少信息
3. 总共有三组 sigmoid 门（遗忘/输入/输出）+ 一组 tanh 候选，共四组权重，所以参数量是 RNN 的约 4 倍

**Q3（实战）**：训练 LSTM 时容易过拟合，你会使用哪些正则化手段？
**回答要点**：

1. Dropout——注意 LSTM 需用变分 Dropout（同 mask 作用于所有时间步）
2. 减少 hidden_size 或层数作为模型正则
3. 权重衰减（L2）和学习率调度；early stopping 配合验证集监控

**Q4（边界）**：LSTM 的串行计算特性限制了其在哪些场景上的应用？业界如何解决？
**回答要点**：

1. 长序列训练极慢，无法利用 GPU 并行加速，尤其在 NLP 超大语料上无法扩展
2. 业界解决方案：用 Transformer 替代（完全并行），或在 LSTM 中使用 truncated BPTT 限制展开长度
3. 推理时 LSTM 的串行特性对低延迟场景（如语音实时识别）反而是优势
