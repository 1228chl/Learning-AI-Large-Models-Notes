# 池化层

## 定义

池化（Pooling）是一种**下采样**操作，在滑动窗口内取**最大值**或**平均值**，降低特征图的空间尺寸，保留最显著的特征，同时增强**平移不变性**。

```python
import torch.nn as nn


max_pool = nn.MaxPool2d(kernel_size=2, stride=2)     # 尺寸减半

avg_pool = nn.AvgPool2d(kernel_size=2, stride=2)  # 创建平均池化层，对特征图进行下采样平滑

# 全局平均池化（代替全连接层，如 ResNet）
global_avg_pool = nn.AdaptiveAvgPool2d((1, 1))       # 输出 1×1
```

## 池化类型

| 类型 | 操作 | 公式 | 特点 |
|------|------|------|------|
| **最大池化（MaxPool）** | 取窗口内最大值 | $\text{output} = \max_{(i,j) \in \Omega} x_{ij}$ | 保留最强特征，默认首选 |
| **平均池化（AvgPool）** | 取窗口内平均值 | $\text{output} = \frac{1}{\vert\Omega\vert} \sum_{(i,j) \in \Omega} x_{ij}$ | 保留整体信息 |
| **全局平均池化（GAP）** | 整个特征图取平均 | $\frac{1}{H \times W} \sum_i \sum_j x_{ij}$ | 替代 Flatten + 全连接 |

## 池化 vs 卷积步长

```python
# 池化：无参数，固定操作
pool = nn.MaxPool2d(2)    # 参数数量 = 0

# 步长卷积：有参数，可学习
stride_conv = nn.Conv2d(64, 128, 3, stride=2, padding=1)  # 参数 = 64*128*3*3
```

| 对比 | 池化 | 步长卷积 |
|:----:|:----:|:--------:|
| 参数 | 0（无参数） | 有可学习参数 |
| 计算量 | 极小 | 较大 |
| 保留信息 | 位置信息丢失 | 保留位置信息 |
| 用途 | 下采样 | 下采样 + 特征提取 |

## ML 中的池化

```python
# 经典 CNN 结构模式
# Conv → ReLU → Pool → Conv → ReLU → Pool → Flatten → FC
```

| 应用场景 | 池化方式 | 说明 |
|----------|----------|------|
| **LeNet / AlexNet / VGG** | MaxPool2d(2) | 经典 CNN 标配 |
| **ResNet** | Conv(stride=2) 替代 Pool | 用步长卷积下采样 |
| **ResNet 最后** | Global AvgPool | 代替全连接层，减少参数 |
| **Transformer 编码器** | 无池化 | 自注意力中不使用 |
| **NLP 中的池化** | Max / Avg over sequence | 序列分类时聚合 token 特征 |

## 面试追问

**Q1（基础）**：池化层的主要作用是什么？为什么能增强平移不变性？

**回答要点**：下采样降低特征图空间尺寸，减少参数量和计算量；在窗口内取最大值或平均值，图像轻微平移后池化结果变化不大；这种粗粒度聚合使后续层对输入的微小位置偏移更鲁棒。

**Q2（深挖）**：为什么 ResNet 用步长卷积替代池化进行下采样？两者的本质区别是什么？

**回答要点**：步长卷积可学习，能保留位置信息并提取特征，池化是无参数固定操作；步长卷积用 stride=2 的 Conv 替代 MaxPool，减少信息丢失；ResNet 设计哲学是让所有下采样层都参与特征学习，避免信息瓶颈。

**Q3（实战）**：全局平均池化（GAP）相比 Flatten + 全连接的优势和适用场景？

**回答要点**：GAP 将特征图压缩为每个通道一个值，参数量为 0，天然防止过拟合；Flatten + FC 参数量极大（H×W×C×num_classes），易过拟合；GAP 适合分类任务最后层，FC 更灵活适合需要空间信息的检测/分割。

**Q4（边界）**：池化丢失位置信息对哪些视觉任务有显著负面影响？如何弥补？

**回答要点**：目标检测（需精确定位）、语义分割（逐像素分类）、姿态估计等空间敏感任务受影响大；弥补方法包括用步长卷积替代池化、在解码器中恢复空间信息（U-Net 跳跃连接）、保留池化索引（SegNet）。
