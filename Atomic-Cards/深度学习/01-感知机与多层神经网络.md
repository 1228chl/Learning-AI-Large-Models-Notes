# 感知机与多层神经网络

## 定义

**感知机**（Perceptron）是最早的人工神经网络，由 Rosenblatt 于 1958 年提出。它对输入做加权和，通过阶跃函数输出二分类结果：

$$
y = \begin{cases} 1, & \sum w_i x_i + b > 0 \\ 0, & \text{otherwise} \end{cases}
$$

**多层感知机（MLP）** 由输入层、若干隐藏层和输出层组成，每层神经元与下一层全连接，通过非线性激活函数使网络具备表达复杂函数的能力：

$$
\mathbf{h}_1 = \sigma(W_1 \mathbf{x} + \mathbf{b}_1), \quad \mathbf{h}_2 = \sigma(W_2 \mathbf{h}_1 + \mathbf{b}_2), \quad \hat{\mathbf{y}} = W_3 \mathbf{h}_2 + \mathbf{b}_3
$$

```python
import torch.nn as nn

# 两层的 MLP
model = nn.Sequential(  # 按顺序堆叠网络层：前一层输出自动成为后一层输入
    nn.Linear(784, 256),      # 输入层 → 隐藏层
    nn.ReLU(),                 # 激活函数（非线性）
    nn.Linear(256, 10)        # 隐藏层 → 输出层
)
```

## 感知机的局限

| 局限 | 说明 | 解决方案 |
|------|------|----------|
| **线性可分限制** | 单层感知机只能解决线性可分问题 | 增加隐藏层（MLP） |
| **无法处理 XOR** | XOR 是线性不可分的经典例子 | 至少一层隐藏层 + 非线性激活 |
| **阶跃函数不可导** | 无法使用梯度下降训练 | 改用连续可导的激活函数（Sigmoid/ReLU） |

## 神经网络的结构

```python
# 网络架构示意图：展示数据从输入到分类输出的完整流动路径
# 括号内数字表示每层的神经元数量，箭头代表数据流向
输入层(784) → 隐藏层(256) → 隐藏层(128) → 输出层(10)
  [数据]      [特征提取]     [特征组合]     [分类结果]
```

| 组件 | 作用 | 说明 |
|------|------|------|
| **输入层** | 接收原始数据 | 神经元数 = 特征维度 |
| **隐藏层** | 逐层提取和组合特征 | "深度" 即隐藏层数量 |
| **输出层** | 输出预测结果 | 分类 = Softmax，回归 = 线性 |
| **权重 $W$ ** | 线性变换的参数 | 可学习 |
| **偏置 $b$ ** | 平移 | 可学习 |
| **激活函数 $\sigma$ ** | 引入非线性 | 见 [02-激活函数](./02-激活函数.md) |

## 为什么需要深度？

| 深度 | 表达能力 | 参数效率 |
|:----:|:---------:|:---------:|
| 浅层（1 层） | 只能表示线性函数 | — |
| 2 层 | 可逼近任意连续函数（万能近似定理） | 需大量神经元 |
| **深层** | 同样函数用更少参数、更好泛化 | 分层特征抽象更高效 |

> 万能近似定理：一个足够宽的单隐藏层网络可以逼近任意连续函数。但深度网络在实践中更高效——**深而窄** 优于 **浅而宽**。

## 面试追问

**Q1（基础）**：感知机为什么无法解决 XOR 问题？如何解决？

**回答要点**：XOR 是线性不可分问题，单层感知机只能做线性划分；解决方法是增加隐藏层并使用非线性激活函数，构成 MLP；至少一个隐藏层+非线性激活即可拟合 XOR。

**Q2（深挖）**：万能近似定理说单隐藏层网络可以逼近任意连续函数，那为什么还需要深度网络？

**回答要点**：浅而宽的网络理论上可逼近任意函数但参数效率极低；深度网络通过分层特征抽象，用更少参数达到相同表达能力；深层结构提供更好的泛化能力和特征层级化表示。

**Q3（实战）**：在项目中设计 MLP 时，如何选择隐藏层数量和神经元大小？

**回答要点**：从简开始（1-2 个隐藏层），根据数据复杂度逐步增加；神经元数量通常在输入/输出维度之间，先按 2^n 设定（128/256/512）；用验证集监控过拟合，配合 Dropout/BatchNorm 正则化。

**Q4（边界）**：MLP 在处理图像、文本等非结构化数据时有什么根本局限？

**回答要点**：全连接结构不利用空间/序列局部性，参数量随输入维度平方增长；图像需要平移不变性，MLP 每个像素位置单独学习权重；实践中 CNN/Transformer 通过归纳偏置（局部连接/自注意力）大幅优于 MLP。
