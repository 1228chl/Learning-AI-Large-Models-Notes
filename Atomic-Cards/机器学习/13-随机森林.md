# 随机森林

## 定义

随机森林（Random Forest）是 Bagging 集成 + **决策树** + **额外随机性**的组合。它在 Bagging 的基础上引入了**特征随机采样**——每棵树分裂时只考虑随机子集的特征，使得树之间更加多样化。

$$
 \text{Random Forest} = \text{Bagging} + \text{Decision Trees} + \text{Random Subspace} 
$$

```python
from sklearn.ensemble import RandomForestClassifier, RandomForestRegressor

rf = RandomForestClassifier(
    n_estimators=100,           # 树的数量
    max_depth=10,               # 每棵树的最大深度
    min_samples_split=5,
    max_features='sqrt',        # 每棵树随机选取 sqrt(n) 个特征
    oob_score=True,             # 袋外得分
    n_jobs=-1,                  # 使用所有 CPU 并行
    random_state=42
)
rf.fit(X_train, y_train)

print(f"OOB Score: {rf.oob_score_:.4f}")
print(f"Test Acc: {rf.score(X_test, y_test):.4f}")
```

## 双重随机性

| 随机性来源 | 方式 | 作用 |
|-----------|------|------|
| **样本随机（Bagging）** | 有放回采样，每棵树用 63.2% 数据 | 减少树之间的相关性 |
| **特征随机** | 每棵树每次分裂随机选 $\sqrt{n}$ 个特征 | 进一步去相关，防止过拟合 |

## 特征重要性

随机森林可以天然输出特征重要性：

```python
importances = rf.feature_importances_

# 可视化
for name, imp in sorted(zip(feature_names, importances), key=lambda x: x[1], reverse=True)[:10]:
    print(f"{name}: {imp:.4f}")
```

| 重要性类型 | 原理 | 说明 |
|-----------|------|------|
| **基尼重要性** | 节点分裂时基尼系数的总下降量 | 默认，偏向高基数特征 |
| **排列重要性** | 打乱特征值后预测精度下降程度 | 更准确，计算量大 |

## 超参数调优

```python
from sklearn.model_selection import GridSearchCV

param_grid = {
    'n_estimators': [100, 200, 500],
    'max_depth': [5, 10, 20, None],

grid = GridSearchCV(RandomForestClassifier(), param_grid, cv=5, n_jobs=-1)

```

## 随机森林 vs 单棵决策树

| 对比 | 单棵决策树 | 随机森林 |
|------|:---------:|:--------:|
| 方差 | 高 | 低（平均后降低） |
| 过拟合 | 严重 | 大大缓解 |
| 稳定性 | 差（数据微变→树结构大变） | 好 |
| 可解释性 | ⭐⭐⭐ 树可画图 | ⭐ 集成不可视 |
| 预测速度 | 快 | 慢（需遍历所有树） |
| 训练速度 | 快 | 可并行，尚可 |

## 优缺点总结

```python
# 随机森林是 "开箱即用"（out-of-the-box）最好的算法之一
# 无需太多调参就表现良好，适合结构化数据
```

| 优点 | 缺点 |
|------|------|
| 无需太多调参，默认就很好 | 不如 Boosting 精度高 |
| 可并行训练，扩展性好 | 模型体积大（数百棵树） |
| 天然输出特征重要性 | 预测速度较慢 |
| 不易过拟合 | 回归时不能外推（超出范围） |
| 处理高维数据好 | 对极稀疏数据不如 SVM |

## 面试追问

**Q1（基础）**：随机森林在 Bagging 的基础上增加了什么额外随机性？为什么需要它？

**回答要点**：随机森林在 Bagging（样本随机采样）基础上增加了特征随机采样——每棵树分裂时只考虑随机子集的特征（默认 sqrt(n)）；目的是使树之间更加多样化，进一步降低树间的相关性；树越不相关，平均后方差降低越明显。

**Q2（深挖）**：随机森林如何计算特征重要性？基尼重要性和排列重要性有什么区别？

**回答要点**：基尼重要性基于节点分裂时基尼系数的总下降量，计算快但偏向高基数特征；排列重要性通过打乱某特征值后观察预测精度下降程度，更准确但计算量大；实践中先用基尼重要性做快速初筛，再用排列重要性确认关键特征。

**Q3（实战）**：项目中选择随机森林还是 XGBoost/LightGBM？依据是什么？

**回答要点**：随机森林开箱即用、不易过拟合、可并行训练，适合快速基线和对预测延迟有要求且不追求极致精度的场景；XGBoost/LightGBM 精度通常更高但超参数更多、容易过拟合；结构化数据比赛首选 XGBoost/LightGBM；特征数很多时随机森林更稳健。

**Q4（边界）**：随机森林在回归任务中有什么固有缺陷？原因是什么？

**回答要点**：随机森林回归时不能外推（extrapolate）——训练数据范围外的样本预测值会被限制在训练集目标值的范围内；因为每棵树只做叶子节点平均，组合后仍然是训练集目标值的加权平均；需要外推预测时应改用线性回归或 XGBoost/神经网络。
