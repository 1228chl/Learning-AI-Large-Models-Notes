# 层次聚类（Hierarchical Clustering）

## 定义

层次聚类构建一个聚类的**树状图**（Dendrogram），可展示不同粒度下的聚类结果，无需预先指定簇数量。主要分为**自底向上**（聚合聚类，Agglomerative）和**自顶向下**（分裂聚类）两种方式。

## 聚合聚类（Agglomerative，自底向上）

以每个样本为初始簇，逐步合并最近的两个簇，直到达到目标簇数：

1. 每个样本作为一个独立簇
2. 计算所有簇对之间的距离
3. 合并距离最近的簇对
4. 重复 2-3 直到达到预设簇数

```python
from sklearn.cluster import AgglomerativeClustering
from scipy.cluster.hierarchy import dendrogram, linkage
import matplotlib.pyplot as plt

# 聚合聚类（自底向上）：每个样本作为独立簇，逐步合并最近的两个簇
hc = AgglomerativeClustering(n_clusters=5, linkage='ward')  # ward最小化簇内方差

labels = hc.fit_predict(X)  # 训练并获取最终聚类标签

# 画树状图（Dendrogram）：展示不同粒度下的聚类合并过程
Z = linkage(X, method='ward')  # 计算聚类合并的层次结构

plt.figure(figsize=(10, 5))
dendrogram(Z)  # 画出树状图，Y轴为合并距离
plt.show()
```

## 连接方式（Linkage Criteria）

连接方式决定如何度量两个簇之间的距离：

| 方式 | 原理 | 特点 | 常用度 |
|:----:|:-----|:-----|:------:|
| **ward** | 最小化簇内方差（合并后 SSE 增量最小） | 默认，生成近似球状簇 | ⭐ 最常用 |
| **complete** | 最长距离（两簇最远点距离） | 生成紧凑簇 | ⭐ |
| **average** | 平均距离（所有点对距离的平均） | 折中，对噪声较鲁棒 | ⭐ |
| **single** | 最短距离（两簇最近点距离） | 易形成链状簇（Chaining Effect） | ⚠️ 谨慎使用 |

聚类距离度量公式对比：

- **ward**： $\Delta(A,B) = \frac{\|c_A - c_B\|^2}{1/n_A + 1/n_B}$ ，其中 $c$ 为簇中心， $n$ 为簇大小
- **complete**： $\Delta(A,B) = \max_{x\in A, y\in B} \|x - y\|$
- **average**： $\Delta(A,B) = \frac{1}{n_A n_B} \sum_{x\in A} \sum_{y\in B} \|x - y\|$
- **single**： $\Delta(A,B) = \min_{x\in A, y\in B} \|x - y\|$

## 树状图解读

Dendrogram 的 Y 轴表示**合并距离**（距离越大，合并的簇差异越大）：

- 在某一高度横切 → 得到对应数量的簇
- 长垂直线 → 自然的簇划分
- 通过观察树状图可以直观决定合适的簇数

```python
# 树状图切割示例：在某一高度横切可得到对应数量的簇
    ──┬──     ← 在此高度切割得到 2 个簇（长垂直线表示自然的簇划分）
      │
    ──┼──┬──
      │  │
      │  ├──
      ├──┤
      │  ├──
      ├──┤  │
      │  │  ├──
```

## ML/DL 应用场景

| 应用场景 | 说明 |
|----------|------|
| 基因表达聚类 | 基因表达数据层次化分组，展示不同表达模式的关系树 |
| 文档主题层次 | 新闻文档按主题逐级聚合，从粗粒度到细粒度主题层次 |
| 客户细分 | 从大群体逐步细分到小群体，支持不同粒度的营销策略 |
| 异常检测 | 树状图中孤立的长分支可作为异常候选 |

## 面试追问

**Q1（基础）**：层次聚类的自底向上（聚合）和自顶向下（分裂）有什么区别？哪种更常用？

**回答要点**：聚合（Agglomerative）从每个样本为独立簇开始逐步合并，复杂度 O(n³) 但可用优化降到 O(n² log n)；分裂（Divisive）从所有样本为一个簇开始逐步分割，需在每个簇上运行 K-means 类算法找到最佳分割方向，计算更复杂；实践中聚合聚类远更常用（scikit-learn 的 AgglomerativeClustering）。

**Q2（深挖）**：层次聚类中四种连接方式（ward/complete/average/single）有什么区别？如何选择？

**回答要点**：ward 最小化簇内方差，默认首选生成近似球状簇；complete 以最远两点距离为准，生成紧凑簇；average 取平均距离，折中方案；single 以最近两点为准，易形成链状簇（将不相干点拉成一条链）；实践中 ward 最常用，数据有噪声时 complete 或 average 更鲁棒。

**Q3（实战）**：如何通过树状图（Dendrogram）直观确定最佳聚类数？和其他方法比有什么优势？

**回答要点**：观察树状图中的**最长垂直线**（在合并前能保持最长的垂直距离），在此位置横切得到合理簇数；优势是能直观看到不同划分粒度下的层次关系，而非像肘部法只能看单一 K 值的指标变化；可配合轮廓系数（Silhouette Score）交叉验证。

**Q4（边界）**：层次聚类在数据量大的时候为什么性能不佳？有没有改进方案？

**回答要点**：经典聚合聚类需要维护 O(n²) 的距离矩阵，时间和空间复杂度都是 O(n²)，n>1 万时不可行；改进方案：先对数据采样做层次聚类再分配其余点、用 BIRCH（增量式层次聚类，sklearn 的 Birch）处理大规模数据、或用 Mini-Batch K-means 先粗聚类再对簇中心做层次聚类。
