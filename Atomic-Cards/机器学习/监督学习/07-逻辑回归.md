# 逻辑回归

## 定义

逻辑回归（Logistic Regression）虽然名称中有"回归"，但实际是**分类算法**。设 $\mathbf{w}$ 为权重向量，$\mathbf{x}$ 为输入特征向量，$b$ 为偏置项，线性回归的输出为 $z$，将其通过 **Sigmoid 函数**映射到 $[0,1]$ 区间，表示属于正类的概率：

$$
z = \mathbf{w}^T \mathbf{x} + b
$$

$$
\hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}} \in (0, 1)
$$

## 决策边界

$$
\hat{y} = 
\begin{cases}
1 & \sigma(z) \geq 0.5 \quad (\text{即 } z \geq 0) \\
0 & \sigma(z) < 0.5 \quad (\text{即 } z < 0)
\end{cases}
$$

逻辑回归的决策边界是**线性的**——这是它的主要局限，也是它的主要优势（可解释性强）。

```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# C是正则化强度的倒数，C越小正则化越强（模型越简单），C越大正则化越弱
clf = LogisticRegression(C=1.0)       # C = 1/λ，越小正则化越强
clf.fit(X_train, y_train)             # 用训练数据学习决策边界（通过最大化对数似然）


y_pred = clf.predict(X_test)         # 输出硬分类结果（0或1）

y_prob = clf.predict_proba(X_test)[:, 1]   # 输出属于正类的概率值（0到1之间），用于AUC等指标
```

## 损失函数

使用**交叉熵损失（Binary Cross-Entropy）**，也称为对数损失：

$$L(w) = -\frac{1}{n} \sum_{i=1}^n \big[y_i \log(\hat{y}_i) + (1-y_i) \log(1-\hat{y}_i)\big]
$$

其中：
- $n$：样本数量
- $y_i$：第 $i$ 个样本的真实标签（0 或 1）
- $\hat{y}_i$：第 $i$ 个样本的预测概率

**为什么不用 MSE？** 因为 MSE + Sigmoid 导致损失函数非凸，梯度下降难收敛。

## 多分类：Softmax 回归

```python
from sklearn.linear_model import LogisticRegression

# multi_class='multinomial' 使用 Softmax 进行多分类，solver需选择支持多分类的优化器
clf = LogisticRegression(multi_class='multinomial', solver='lbfgs')
clf.fit(X_train, y_train)                    # y 是 0, 1, 2 等多类别标签
```

Softmax 函数将 $K$ 个类别的得分 $z_k$ 转换为概率分布：

$$
P(y = k \mid \mathbf{x}) = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}
$$

## 逻辑回归 vs 线性回归

| 对比 | 线性回归 | 逻辑回归 |
|------|----------|----------|
| **输出** | 连续值 $(-\infty, \infty)$ | 概率 $(0, 1)$ |
| **激活函数** | 无（恒等） | Sigmoid / Softmax |
| **损失函数** | MSE | 交叉熵 |
| **任务** | 回归 | 分类 |
| **决策边界** | 超平面 | 线性超平面 |

## 优点与局限

| 优点 | 局限 |
|------|------|
| 可解释性强（系数即特征权重） | 决策边界线性，无法处理非线性 |
| 输出概率，可做置信度校准 | 需要手动特征工程（交互项、多项式） |
| 训练快速，适合大规模数据 | 对异常值敏感 |
| 正则化易用（L1/L2/ElasticNet） | 特征间相关性高时系数不稳定 |

## 面试追问

**Q1（基础）**：为什么逻辑回归名字里有"回归"却是分类算法？Sigmoid 函数在这里起什么作用？
**回答要点**：

1. 逻辑回归先用线性回归计算 $z = \mathbf{w}^T \mathbf{x} + b$，再通过 Sigmoid 函数 $\sigma(z) = 1/(1+e^{-z})$ 将连续值映射到 $(0,1)$ 概率区间
2. 模型实际输出为概率值，再通过阈值（如 0.5）做分类决策
3. 因此逻辑回归本质是分类算法，而非回归算法

**Q2（深挖）**：为什么逻辑回归用交叉熵损失而不是均方误差（MSE）？
**回答要点**：

1. MSE + Sigmoid 组合导致损失函数非凸，存在多个局部极小值，梯度下降难以收敛到全局最优
2. 交叉熵损失是凸函数，梯度下降可以保证收敛到全局最优
3. 从概率视角看，交叉熵对应极大似然估计（MLE），具有更好的统计性质

**Q3（实战）**：逻辑回归的决策边界是线性的——这个局限在实际项目中怎么克服？
**回答要点**：

1. 通过特征工程引入非线性：多项式特征（特征交叉 $x_1 \cdot x_2$）、分箱处理（将连续值分段）、核方法
2. 使用正则化控制特征工程带来的过拟合风险
3. 实践中若特征工程成本过高，可直接换用非线性模型如随机森林、XGBoost、神经网络

**Q4（边界）**：逻辑回归进行多分类时（Softmax 回归）有什么潜在问题？有什么替代方案？
**回答要点**：

1. Softmax 回归假设类别互斥，不适用于多标签分类任务（一个样本可属多个类别）
2. 类别数很多时，Softmax 计算归一化分母需要遍历所有类别，计算量大
3. 替代方案包括一对一（OvO）和一对其余（OvR）策略，或改用其他多分类模型
