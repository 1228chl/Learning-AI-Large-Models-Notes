# 正则化

## 定义

正则化（Regularization）是在损失函数中添加**惩罚项**来限制模型复杂度，是防止过拟合最有效的手段之一。

$$
\text{Total Loss} = \text{Data Loss} + \lambda \cdot \text{Penalty}
$$

- $\lambda$：正则化强度，$\lambda$ 越大 → 模型越简单（欠拟合倾向），$\lambda$ 越小 → 模型越复杂（过拟合倾向）

## 直观理解

### 正则化的约束区域几何

从几何角度看，正则化等价于在参数空间中给权重 $\mathbf{w}$ 添加一个约束区域：

- **L2（Ridge）**：$\|\mathbf{w}\|_2^2 \leq t$，约束区域是**球体/圆形**。损失函数的等高线与球体相切时，切点通常在坐标轴之外（所有权重非零，但都缩小了）。
- **L1（Lasso）**：$\|\mathbf{w}\|_1 \leq t$，约束区域是**菱形**。菱形的尖角位于坐标轴上，等高线与尖角相切时，对应特征的权重被压为零。
- **ElasticNet**：约束区域是 L1 菱形和 L2 圆形的混合体——既有圆角（保留群组效应）又有尖角（产生稀疏性）。

这就是 L1 产生稀疏解而 L2 不产生的几何原因：菱形有尖角而圆形没有。

### 为什么 $\lambda$ 越大模型越简单？

$\lambda$ 控制惩罚项在总损失中的权重。$\lambda$ 越大，优化器越倾向于将权重 $\mathbf{w}$ 保持在零附近——因为离开零会导致巨大的惩罚。这等价于缩小了约束区域的半径 $t$（$t$ 与 $1/\lambda$ 正相关），使参数只能在更小的范围内取值，降低了模型的自由度。

正则化主要包括三种形式，各有不同特性（详细解析见独立卡片）：

| 类型 | 核心效果 | 适用场景 | 详细卡片 |
|:----:|:---------|:---------|:--------:|
| **L2 (Ridge / 权重衰减)** | 权重均匀缩小但不为零 | 特征数少、所有特征都有用 | [L2正则化(Ridge)](./21-L2正则化%28Ridge%29.md) |
| **L1 (Lasso)** | 产生稀疏解，天然特征选择 | 高维稀疏、需要特征选择 | [L1正则化(Lasso)](./22-L1正则化%28Lasso%29.md) |
| **ElasticNet** | L1 + L2 混合，有群组效应 | 高维 + 特征高度相关 | [ElasticNet正则化](04-ElasticNet正则化.md) |

## 三种正则化对比

| 特性 | L2（Ridge） | L1（Lasso） | ElasticNet |
|:----:|:-----------:|:-----------:|:----------:|
| 惩罚形式 | $\sum w_j^2$ | $\sum \vert w_j\vert$ | 两者混合 |
| 权重效果 | 缩小（但不为零） | **压为零**（稀疏） | 折中 |
| 特征选择 | ❌ | ✅ | ✅（群组效应） |
| 解的唯一性 | ✅ 唯一 | ⚠️ 可能不唯一 | ✅ |
| 相关特征处理 | 一起保留 | 随机选一个 | 群组保留 |
| 适用特征数 | 少特征 | **高维稀疏** | 高维 + 相关特征 |

## 正则化的几何解释

```python
# 正则化的几何解释：约束区域的形状决定了权重的行为
L2(Ridge): 约束区域为圆形 → 权重均匀缩小但都不为零（等高线切于圆上非轴点）
L1(Lasso): 约束区域为菱形 → 角点处更易产生稀疏解（等高线切于坐标轴）

对比：Lasso 更可能让权重在坐标轴上被截断为0，实现特征选择
```

## 其他正则化技术

| 技术 | 原理 | 使用方式 |
|------|------|----------|
| **早停（Early Stopping）** | 验证集损失不再下降时停止训练 | 所有模型 |
| **Dropout** | 训练时随机丢弃一部分神经元 | 神经网络 |
| **数据增强（Data Augmentation）** | 通过变换生成更多训练样本 | 图像/文本 |
| **Batch Normalization** | 每层归一化，引入轻微噪声 | 深度学习 |
| **随机深度（Stochastic Depth）** | 训练时随机跳过某些层 | 残差网络 |

## ML 中的交叉验证调 λ

```python
# 逻辑回归的正则化路径：自动交叉验证选择最优正则化强度
from sklearn.linear_model import LogisticRegressionCV


clf = LogisticRegressionCV(

    Cs=10,                        # 自动在C值网格（对数尺度10个候选值）上搜索

    penalty='l2',                 # 使用L2正则化

    cv=5,                         # 5折交叉验证

    solver='lbfgs',               # 优化求解器

    max_iter=1000                  # 最大迭代次数，确保收敛
)
clf.fit(X_train, y_train)

print(f"最佳 C（=1/λ）: {clf.C_[0]}")  # C越大正则化越弱，C越小正则化越强
```

## 面试追问

**Q1（基础）**：L1 正则化（Lasso）和 L2 正则化（Ridge）对权重的影响有什么本质区别？
**回答要点**：

1. L2 惩罚权重的平方和，使权重均匀缩小但不为零，所有权重都保留但变小
2. L1 惩罚权重绝对值，产生稀疏解，不重要特征的权重被压为 0，天然实现特征选择
3. 几何上 L2 约束区域是圆形，L1 是菱形，菱形角点处更容易在坐标轴上截断为零

**Q2（深挖）**：为什么 L1 正则化能产生稀疏解而 L2 不能？从几何或优化角度解释。
**回答要点**：

1. 几何解释：L1 约束区域是菱形（有尖角），等高线更容易碰在坐标轴尖角上使某维度为 0
2. L2 约束区域是圆形（平滑），等高线碰在圆上各维都非零
3. 优化角度：L1 在零点不可导，其 proximal operator 有软阈值效果，将小系数直接置零

**Q3（实战）**：正则化强度 λ（或 C=1/λ）如何选择？实际项目中用什么方法？
**回答要点**：

1. λ 过大导致模型过于简单（欠拟合），λ 过小导致正则化不足（过拟合）
2. 使用交叉验证选择最优 λ：sklearn 的 RidgeCV/LassoCV/ElasticNetCV 自动在候选值上搜索
3. 对于大范围搜索，先用对数尺度粗搜再局部精搜

**Q4（边界）**：除了 L1/L2 正则化，还有哪些常用的正则化技术？各适用于什么模型？
**回答要点**：

1. 早停适用于所有模型，在验证集损失不再下降时停止训练
2. Dropout 适用于神经网络，训练时随机丢弃神经元；数据增强适用于图像/文本，通过变换生成更多样本
3. Batch Normalization 适用于深度学习，每层归一化引入轻微噪声；随机深度适用于残差网络，随机跳过某些层
