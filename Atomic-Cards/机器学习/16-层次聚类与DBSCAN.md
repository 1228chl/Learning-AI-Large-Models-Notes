# 层次聚类与 DBSCAN

两种聚类算法的概览，详细内容见独立卡片：

| 算法 | 核心思想 | 适用场景 | 详细卡片 |
|:----:|:---------|:---------|:--------:|
| **DBSCAN** | 基于密度，自动发现任意形状簇和噪声 | 不规则簇、噪声多、不需指定 K | [24-DBSCAN密度聚类](./24-DBSCAN密度聚类.md) |
| **层次聚类** | 构建树状图，展示不同粒度的聚类层次 | 需要层次分析、K 不确定 | [25-层次聚类](./25-层次聚类.md) |

## DBSCAN vs K-means

| 对比 | K-means | DBSCAN |
|------|:-------:|:------:|
| **簇形状** | 仅球状 | **任意形状** |
| **K 值** | 需预设 | 自动发现 |
| **噪声处理** | ❌ 所有点强制入簇 | ✅ 自动识别噪声 |
| **异常值敏感** | 敏感 | 鲁棒 |
| **密度不均** | 好 | 差（不同密度需调参） |
| **高维数据** | 好 | 差（维度灾难） |

## 聚类算法选择指南

```python
# 聚类算法选择策略：根据数据规模、簇形状需求和是否需要层次结构来决定
if data_size > 10000:

    choose = "Mini-Batch K-means"        # 大数据首选Mini-Batch K-means，线性复杂度

elif cluster_shape == "任意形状":

    choose = "DBSCAN"                     # 非球形簇用DBSCAN，自动发现任意形状
elif need_hierarchy or n_clusters不确定:

    choose = "层次聚类"                    # 需要树状图分析时用层次聚类
else:

    choose = "K-means"                    # 默认用K-means，简单快速效果好
```

| 场景 | 推荐算法 | 原因 |
|------|----------|------|
| 大量样本（>10 万） | Mini-Batch K-means | 线性复杂度 |
| 任意形状簇 + 噪声 | DBSCAN | 密度聚类 |
| 需要树状图分析 | 层次聚类 | 可视化不同粒度 |
| 高维数据 | K-means | 距离在高维仍有效 |
| 默认首选 | K-means++ | 简单快速效果好 |

## 面试追问

**Q1（基础）**：什么场景下应该选择 DBSCAN 而不是 K-means？

**回答要点**：数据簇形状为任意形状（非球形）时选 DBSCAN；数据中含有明显噪声且不希望噪声被强行分配到最近簇时选 DBSCAN；完全不知道簇数 K 时选 DBSCAN（自动发现簇数）；如果数据量大且簇形状接近球形，K-means 更高效。

**Q2（深挖）**：DBSCAN 的 eps 和 min_samples 两个参数如何调优？

**回答要点**：eps（邻域半径）决定一个点的"邻近范围"，过小导致大量点被识别为噪声（欠聚类），过大会合并不同簇（过聚类）；常用 k-distance 图选择 eps——找到距离每个点第 k 近的邻居距离，排序后寻找"拐点"位置；min_samples 通常设为特征维度的 2 倍（min_samples >= 2D），数据量大时可适当增大。

**Q3（深挖）**：DBSCAN 在高维数据上表现如何？维度灾难如何影响密度聚类？

**回答要点**：高维空间中"近邻"和"远邻"的区别极为模糊（维度灾难），所有点之间的距离趋向均匀，DBSCAN 的密度概念在高维中失去意义；实践中当维度 D > 20 时 DBSCAN 效果显著下降；高维聚类建议先降维（PCA、t-SNE）再做 DBSCAN，或改用 K-means、谱聚类等方法。

**Q4（实战）**：层次聚类的树状图如何帮助确定最优簇数？

**回答要点**：树状图的纵轴表示合并距离（或相似度），横轴越长的分支表示越不同的簇；在树状图中寻找"最长竖直距离"的位置画水平切割线，切割线穿过的分支数即为推荐的簇数；这种方法比肘部法则更直观，并且能看出不同粒度下的聚类结构。
