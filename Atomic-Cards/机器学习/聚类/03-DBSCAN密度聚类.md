# DBSCAN 密度聚类

## 定义

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) 基于样本的**密度**进行聚类，能发现任意形状的簇，并自动识别**噪声点**（标签为 -1）。不需要预先指定簇数量 K。

## 核心概念

**两个参数**：

- `eps`：邻域半径，决定一个点的"邻域"范围
- `min_samples`：核心点的最小邻居数（含自身）

**三种点类型**：

| 类型 | 条件 | 说明 |
|:----:|:-----|:-----|
| **核心点** | 邻域内 ≥ min_samples 个点 | 密度高的区域中心 |
| **边界点** | 邻域内 < min_samples 个点，但属于某个核心点的邻域 | 簇的边缘 |
| **噪声点** | 既不是核心点也不是边界点 | 孤立异常点 |

## 算法流程

1. 对每个点，计算其 eps 邻域内的点数
2. 标记核心点（邻域内点数 ≥ min_samples）
3. 连接核心点的邻域——密度直达的点属于同一簇
4. 将边界点分配到关联核心点的簇
5. 剩余点为噪声点（标签 -1）

```python
from sklearn.cluster import DBSCAN

# DBSCAN基于密度聚类：eps控制邻域半径，min_samples决定核心点的密度阈值
dbscan = DBSCAN(eps=0.5, min_samples=5)

labels = dbscan.fit_predict(X)  # 训练并返回聚类标签，标签为-1表示噪声点

# -1 表示噪声点（不属于任何簇的孤立点）
n_clusters = len(set(labels)) - (1 if -1 in labels else 0)  # 排除噪声标签后计算簇数

n_noise = list(labels).count(-1)  # 统计被标记为噪声（-1）的样本数
print(f"簇数量: {n_clusters}, 噪声点: {n_noise}")
```

## DBSCAN vs K-means

| 对比 | K-means | DBSCAN |
|:----:|:-------:|:------:|
| **簇形状** | 仅球状 | **任意形状** |
| **K 值** | 需预设 | 自动发现 |
| **噪声处理** | ❌ 所有点强制入簇 | ✅ 自动识别噪声 |
| **异常值敏感** | 敏感 | 鲁棒 |
| **密度不均** | 好 | 差（不同密度需调参） |
| **高维数据** | 好 | 差（维度灾难） |

## ML/DL 应用场景

| 应用场景 | 说明 |
|----------|------|
| 异常检测（反欺诈） | 噪声点标记为异常交易，无需预设异常类别 |
| 地理空间聚类 | 基于经纬度密度发现高密度活动区域（如商圈识别） |
| 用户行为分群 | 发现不规则形状的用户群体，自动排除沉默用户 |
| 图像分割 | 基于像素颜色密度分割图像，不要求规则形状 |

## 面试追问

**Q1（基础）**：DBSCAN 的两个核心参数是什么？它们各自控制什么？
**回答要点**：

1. eps（邻域半径）：决定一个点邻域范围的大小——eps 太小大部分点成为噪声，eps 太大不同簇可能合并。
2. min_samples（核心点的最小邻居数）：决定密度阈值——min_samples 越大核心点要求越严格，更多边界点可能沦为噪声。
3. 两个参数需联合调参，eps 对聚类结果更敏感。

**Q2（深挖）**：DBSCAN 相比 K-means 最大的优势是什么？什么时候你选 DBSCAN 而不选 K-means？
**回答要点**：

1. DBSCAN 最大的优势是无需预设簇数 K、能发现任意形状的簇（月牙形、螺旋形等），且自动识别噪声点（标签为 -1）。
2. 选择 DBSCAN 的场景：不知道 K 值、数据簇形状不规则、数据含大量噪声点、需要异常检测。
3. 但 DBSCAN 在密度差异大和高维数据下效果较差，此时 K-means 结合 PCA 可能更合适。

**Q3（实战）**：实际数据中 DBSCAN 的 eps 参数如何选择？有没有启发式方法？
**回答要点**：

1. 使用 **k 距离图**（k-distance graph）：计算每个样本到其 k 个最近邻的距离，排序后绘制距离曲线，选择"拐点"（elbow）处的距离作为 eps 值。
2. min_samples 一般取数据维度 d 的 2 倍（即 min_samples = 2d），数据量大时适当增大。
3. eps 对结果比 min_samples 更敏感，建议先用 k 距离图粗选 eps，再结合领域知识微调。

**Q4（边界）**：DBSCAN 在密度不均匀的数据和高维数据下有什么问题？怎么解决？
**回答要点**：

1. 密度不均匀时，单一 (eps, min_samples) 无法适应全局分布——稀疏区域簇被当作噪声，密集区域多个簇可能合并。
2. 高维数据中距离度量失效（维度灾难），且密度定义困难，聚类效果大幅下降。
3. 解决方案：使用 OPTICS 算法（对 eps 不敏感）、先降维（PCA 等）再用 DBSCAN、或根据不同密度区域分别调参。
