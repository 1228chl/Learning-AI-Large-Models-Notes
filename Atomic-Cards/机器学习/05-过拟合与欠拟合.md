# 过拟合与欠拟合

## 定义

| 问题 | 表现 | 训练误差 | 测试误差 | 原因 |
|------|------|:--------:|:--------:|------|
| **欠拟合（Underfitting）** | 模型太简单，学不到规律 | 高 | 高 | 模型容量不足 |
| **过拟合（Overfitting）** | 模型太复杂，记忆了噪声 | 低 | 高 | 模型容量过大 |

## 诊断：学习曲线

```python
from sklearn.model_selection import learning_curve
import matplotlib.pyplot as plt

# 生成学习曲线：横轴为训练样本量（从10%到100%等分10个点），纵轴为得分
# 通过观察训练得分和验证得分随样本量变化的趋势来诊断模型状态
train_sizes, train_scores, val_scores = learning_curve(
    model, X, y, cv=5, train_sizes=np.linspace(0.1, 1.0, 10)
)

# 过拟合：训练得分高（>0.95），验证得分低（<0.8），且两者差距大
# 欠拟合：两者都低（<0.7），且趋近于平行（说明模型容量不足）
# 拟合良好：两者都高且接近（说明模型有好的泛化能力）
```

## 偏差-方差权衡（Bias-Variance Tradeoff）

$$
\text{泛化误差} = \text{偏差}^2 + \text{方差} + \text{噪声}
$$

| 分量 | 含义 | 欠拟合 | 过拟合 |
|------|------|:------:|:------:|
| **偏差（Bias）** | 模型预测的期望与真实值的差距 | 高 | 低 |
| **方差（Variance）** | 不同训练集上预测的波动程度 | 低 | 高 |
| **噪声（Noise）** | 数据本身的不可约误差（下限） | 不变 | 不变 |

## 应对策略

```python
# 模型复杂度控制示例：多项式回归的 degree 选择，展示过拟合和欠拟合的典型表现
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import PolynomialFeatures

for degree in [1, 3, 10]:
    model = Pipeline([
        ('poly', PolynomialFeatures(degree=degree)),  # 生成多项式特征（如 x², x³）
        ('linear', LinearRegression())                # 对扩展后的特征进行线性回归拟合
    ])
    model.fit(X_train, y_train)
    train_score = model.score(X_train, y_train)       # 计算训练集上的R²得分
    test_score = model.score(X_test, y_test)           # 计算测试集上的R²得分
    # degree=1: 欠拟合（训练得分和测试得分都低）
    # degree=10: 过拟合（训练得分高但测试得分低，差距大）
    # degree=3: 最佳折中（两者都较高且接近）
```

| 策略 | 解决过拟合 | 解决欠拟合 |
|------|:---------:|:---------:|
| **增加训练数据** | ✅ 最强 | ❌ |
| **降低模型复杂度**（减少层/树深） | ✅ | ❌ |
| **正则化（L1/L2）** | ✅ | ❌ |
| **早停（Early Stopping）** | ✅ | ❌ |
| **Dropout** | ✅ | ❌ |
| **数据增强** | ✅ | ❌ |
| **增加模型复杂度** | ❌ | ✅ |
| **增加特征** | ❌ | ✅ |
| **减少正则化** | ❌ | ✅ |
| **训练更长时间** | ❌ | ✅ |

## 面试追问

**Q1（基础）**：如何通过训练误差和测试误差判断模型是过拟合还是欠拟合？

**回答要点**：过拟合表现为训练误差低但测试误差高（差距大），模型记住了噪声；欠拟合表现为训练误差和测试误差都高（差距小），模型太简单学不到规律；拟合良好则是两者都低且接近。

**Q2（深挖）**：请解释偏差-方差权衡（Bias-Variance Tradeoff），过拟合和欠拟合分别对应什么？

**回答要点**：泛化误差=偏差²+方差+噪声；欠拟合偏差高方差低（模型过于简单，预测偏离真实值）；过拟合偏差低方差高（模型过于复杂，在不同训练集上波动大）；目标是找到偏差和方差的最佳折中。

**Q3（实战）**：在实际项目中，你如何诊断过拟合并选择应对策略？列举至少三个有效方法。

**回答要点**：通过学习曲线（训练分高验证分低且差距大）诊断；应对策略包括：增加训练数据（最有效）、降低模型复杂度、添加正则化(L1/L2)、早停、Dropout（神经网络）；应对欠拟合则相反：增加模型复杂度或特征。

**Q4（边界）**：深度学习模型参数量远超样本数时，为何有时不会严重过拟合？这对传统认知有何挑战？

**回答要点**：深度学习的"过参数化"现象与传统 ML 理论矛盾；现代观点认为 SGD 隐式正则化、数据的内在低维流形结构、以及大模型在"插值"时仍能泛化；但实践中仍需通过数据增强、Dropout、正则化等手段控制过拟合。
