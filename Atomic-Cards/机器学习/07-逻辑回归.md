# 逻辑回归

## 定义

逻辑回归（Logistic Regression）虽然名称中有"回归"，但实际是**分类算法**。它将线性回归的输出通过 **Sigmoid 函数**映射到 $[0,1]$ 区间，表示属于正类的概率：

$$z = \mathbf{w}^T \mathbf{x} + b$$

$$\hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}} \in (0, 1)$$

## 决策边界

$$\hat{y} = 
\begin{cases}
1 & \sigma(z) \geq 0.5 \quad (\text{即 } z \geq 0) \\
0 & \sigma(z) < 0.5 \quad (\text{即 } z < 0)
\end{cases}$$

逻辑回归的决策边界是**线性的**——这是它的主要局限，也是它的主要优势（可解释性强）。

```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

clf = LogisticRegression(C=1.0)       # C = 1/λ，越小正则化越强
clf.fit(X_train, y_train)

y_pred = clf.predict(X_test)
y_prob = clf.predict_proba(X_test)[:, 1]   # 正类概率
```

## 损失函数

使用**交叉熵损失（Binary Cross-Entropy）**，也称为对数损失：

$$L(w) = -\frac{1}{n} \sum_{i=1}^n \big[y_i \log(\hat{y}_i) + (1-y_i) \log(1-\hat{y}_i)\big]$$

**为什么不用 MSE？** 因为 MSE + Sigmoid 导致损失函数非凸，梯度下降难收敛。

## 多分类：Softmax 回归

```python
from sklearn.linear_model import LogisticRegression

# multi_class='multinomial' 使用 Softmax
clf = LogisticRegression(multi_class='multinomial', solver='lbfgs')
clf.fit(X_train, y_train)                    # y 是 0, 1, 2 等多类别
```

Softmax 函数将 $K$ 个类别的得分转换为概率分布：

$$P(y = k \mid \mathbf{x}) = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}$$

## 逻辑回归 vs 线性回归

| 对比 | 线性回归 | 逻辑回归 |
|------|----------|----------|
| **输出** | 连续值 $(-\infty, \infty)$ | 概率 $(0, 1)$ |
| **激活函数** | 无（恒等） | Sigmoid / Softmax |
| **损失函数** | MSE | 交叉熵 |
| **任务** | 回归 | 分类 |
| **决策边界** | 超平面 | 线性超平面 |

## 优点与局限

| 优点 | 局限 |
|------|------|
| 可解释性强（系数即特征权重） | 决策边界线性，无法处理非线性 |
| 输出概率，可做置信度校准 | 需要手动特征工程（交互项、多项式） |
| 训练快速，适合大规模数据 | 对异常值敏感 |
| 正则化易用（L1/L2/ElasticNet） | 特征间相关性高时系数不稳定 |
