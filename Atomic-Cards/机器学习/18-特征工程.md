# 特征工程

## 定义

特征工程（Feature Engineering）是将原始数据转化为最能代表问题特征的过程。**数据和特征决定了机器学习的上限，而模型只是逼近这个上限。**

## 特征缩放

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler

# 标准化（Z-score）：将数据转为均值为0、方差为1的分布，适合正态分布或默认首选
scaler = StandardScaler()
X_std = scaler.fit_transform(X)

# 归一化（Min-Max）：将数据缩放到 [0, 1] 区间，适合有界的特征（如图像像素）
mm = MinMaxScaler()
X_mm = mm.fit_transform(X)

# 鲁棒缩放：用中位数和四分位距（IQR）缩放，对异常值不敏感
rs = RobustScaler()
X_rs = rs.fit_transform(X)
```

| 方法 | 公式 | 适用场景 |
|------|------|----------|
| **StandardScaler** | $z = \frac{x - \mu}{\sigma}$ | 默认首选，适合正态分布 |
| **MinMaxScaler** | $x' = \frac{x - min}{max - min}$ | 需要固定范围 [0,1] 时 |
| **RobustScaler** | $x' = \frac{x - median}{IQR}$ | 数据含较多异常值时 |

## 特征编码

```python
from sklearn.preprocessing import OneHotEncoder, LabelEncoder, OrdinalEncoder

# 有序类别编码（Ordinal）：将有序类别映射为整数，保留顺序关系（如低<中<高）
oe = OrdinalEncoder()
X_ord = oe.fit_transform([['low'], ['medium'], ['high']])  # 输出 [[0], [1], [2]]

# 无序类别独热编码（One-Hot）：将每个类别变为独立的二进制列，不引入顺序偏差
ohe = OneHotEncoder(sparse_output=False)
X_ohe = ohe.fit_transform([['red'], ['blue'], ['green']])
# → [[1,0,0], [0,1,0], [0,0,1]]  每行只有一个1，表示所属类别

# 目标编码（Target Encoding）：用目标变量的均值替换类别值，适合高基数的类别特征
# 注意：需要交叉验证生成以防过拟合
```

## 特征构造

```python
import numpy as np
import pandas as pd

# 多项式特征（交互项 + 幂次）：将原始特征扩展到组合特征，捕捉非线性关系
from sklearn.preprocessing import PolynomialFeatures
poly = PolynomialFeatures(degree=2, include_bias=False)
X_poly = poly.fit_transform(X)      # 从[x1, x2]扩展为[x1, x2, x1², x2², x1·x2]

# 分箱（Binning）：将连续值分段为离散区间，减少噪声影响
ages = pd.cut(df['age'], bins=[0, 18, 30, 50, 100], labels=['child', 'young', 'mid', 'old'])

# 对数变换（处理长尾分布）：对偏态分布取对数，使其更接近正态分布
df['price_log'] = np.log1p(df['price'])  # log1p = log(1+x)，避免x=0时无定义

# 时间特征：从时间戳中提取周期性特征
df['hour'] = pd.to_datetime(df['time']).dt.hour  # 提取小时
df['is_weekend'] = df['dayofweek'].isin([5, 6]).astype(int)  # 判断是否为周末
```

## 特征选择

```python
# 过滤法（Filter）：基于统计检验快速筛选特征，与下游模型无关
from sklearn.feature_selection import SelectKBest, f_classif
selector = SelectKBest(f_classif, k=20)  # 用方差分析F检验选择与目标最相关的20个特征
X_selected = selector.fit_transform(X, y)

# 包裹法（Wrapper）：RFE 递归特征消除，反复训练模型逐步剔除不重要特征，精度高但计算贵
from sklearn.feature_selection import RFE
selector = RFE(RandomForestClassifier(), n_features_to_select=20)
selector.fit(X, y)

# 嵌入法（Embedded）：L1 正则化 + 树模型重要性，特征选择内置在模型训练过程中
from sklearn.linear_model import LogisticRegression
model = LogisticRegression(penalty='l1', solver='liblinear')  # L1正则化自动产生稀疏解
model.fit(X, y)
selected = model.coef_[0] != 0        # 系数非零的特征即为被选中的特征
```

| 特征选择方法 | 复杂度 | 与模型的关系 | 适用场景 |
|-------------|:-----:|:----------:|----------|
| **过滤法**（Filter） | 低 | 无关 | 快速初筛 |
| **包裹法**（Wrapper） | 高 | 依赖 | 最终精选 |
| **嵌入法**（Embedded） | 中 | 内置 | 默认首选 |

## 面试追问

**Q1（基础）**：StandardScaler、MinMaxScaler、RobustScaler 三种特征缩放方法各适用于什么场景？

**回答要点**：StandardScaler（Z-score）将数据转为均值为 0 方差为 1，默认首选适合服从正态分布的数据；MinMaxScaler 缩放到 [0,1]，适合有界范围的特征（如图像像素）；RobustScaler 用中位数和 IQR，对异常值不敏感，适合数据含较多异常值的场景。

**Q2（深挖）**：为什么无序类别特征应该用 One-Hot 编码而不是直接用整数编码（Label Encoding）？

**回答要点**：Label Encoding 给无序类别赋予整数（如红=1,蓝=2,绿=3），模型会错误认为类别间有大小关系（蓝>红/绿>蓝），引入虚假的序数关系；One-Hot 编码每个类别是独立维度，不引入顺序偏见；但 One-Hot 在类别数多时导致维度爆炸，此时可用目标编码或嵌入。

**Q3（实战）**：过滤法、包裹法、嵌入法三种特征选择方法的优缺点是什么？实际项目中怎么配合？

**回答要点**：过滤法（如卡方检验）计算快但与模型无关，适合快速初筛去噪；包裹法（RFE）反复训练模型精度高但计算昂贵，适合最终精选少量特征；嵌入法（L1 正则化、树模型重要性）内置在模型中，计算适中，是默认首选；实践中先用过滤法粗筛再交给模型自身的嵌入法。

**Q4（边界）**：过度特征工程可能带来什么问题？如何避免"特征工程过拟合"？

**回答要点**：过度创造特征（如极高次多项式、大量交互项）会导致维度灾难和过拟合——模型记住了噪声特征而非真实规律；大量特征需要更多数据防止过拟合，也增加计算和存储成本；避免策略：使用交叉验证评估特征影响、用正则化(L1)自动选择特征、坚持"少而精"优于"多而杂"。
