# t-SNE 与 UMAP 非线性降维

## 定义

t-SNE（t-Distributed Stochastic Neighbor Embedding）和 UMAP（Uniform Manifold Approximation and Projection）是**非线性降维**方法，专门用于高维数据的可视化。它们能保留数据的局部邻域结构，在 2D/3D 空间中展现高维数据的流形结构。

> PCA 保留全局线性结构（方差最大化），t-SNE/UMAP 保留局部邻域结构（概率分布匹配）。

## t-SNE

```python
from sklearn.manifold import TSNE

tsne = TSNE(n_components=2, perplexity=30, random_state=42)
X_tsne = tsne.fit_transform(X)

# 可视化
plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y, cmap='viridis')
```

**核心参数**：

- `perplexity`（困惑度，5~50，默认 30）：平衡局部与全局结构的关注度
- `n_components`：目标维度（通常 2 或 3）
- `learning_rate`：学习率，通常 [10, 1000]

## UMAP

```python
import umap

reducer = umap.UMAP(n_neighbors=15, min_dist=0.1, random_state=42)
X_umap = reducer.fit_transform(X)
```

**核心参数**：

- `n_neighbors`（邻居数，2~200，默认 15）：控制局部 vs 全局的权衡
- `min_dist`（最小距离，0~1，默认 0.1）：控制点的聚集程度

## 对比

| 维度 | PCA | t-SNE | UMAP |
|:----:|:---:|:-----:|:----:|
| **线性？** | ✅ 线性 | ❌ 非线性 | ❌ 非线性 |
| **速度** | 快 | 慢 | **快** |
| **可视化效果** | 一般 | **极好** | 极好 |
| **保留全局结构** | ✅ 好 | ❌ 差 | ✅ **较好** |
| **保留局部结构** | 差 | ✅ **极好** | ✅ 极好 |
| **可逆（inverse_transform）** | ✅ | ❌ | ❌ |
| **随机性** | 确定 | 每次运行结果不同 | 每次运行结果不同 |
| **适合作为特征用于建模** | ✅ | ❌ | ⚠️ 谨慎 |

## 工作原理（直觉）

- **t-SNE**：在高维空间用高斯分布度量点对相似度，在低维空间用 t 分布度量点对相似度，然后最小化两个分布间的 **KL 散度**。t 分布比高斯分布有更重的尾部，使低维空间中相距较远的点保持较远，缓解"拥挤问题"。
- **UMAP**：基于**流形理论**和**拓扑数据分析**，先在高维空间构建模糊拓扑表示，再在低维空间寻找最相似的拓扑表示。数学基础比 t-SNE 更扎实，速度快且保留更多全局结构。

## ML/DL 应用场景

| 应用场景 | 说明 |
|----------|------|
| 高维数据探索可视化 | 基因表达、词嵌入、图像特征降维到 2D 观察聚类结构 |
| 模型中间层特征分析 | 可视化神经网络隐藏层表示，检查类别是否可分 |
| 聚类效果验证 | 降维后用散点图直观检查聚类分配是否合理 |
| 异常检测辅助 | 正常点和异常点在降维空间中分离 |

## 面试追问

**Q1（基础）**：t-SNE 和 PCA 的核心区别是什么？为什么 t-SNE 可视化的效果通常比 PCA 好？

**回答要点**：PCA 是线性方法，保留全局方差最大的方向，对复杂流形结构的展示有限；t-SNE 是非线性方法，保留局部邻域结构，能将高维空间的同类簇在低维空间中紧密聚在一起，视觉效果更好。但 t-SNE 更适合可视化而非特征提取。

**Q2（深挖）**：t-SNE 的 perplexity 参数如何影响可视化结果？不同 perplexity 值会看到什么？

**回答要点**：perplexity 可以理解为"每个点考虑多少个邻居"。perplexity 太小（<5）→ 关注极局部结构，形成许多小碎片；perplexity 太大（>50）→ 更关注全局结构，可能丢失精细的局部模式；通常 5~50 之间调参，默认 30；小数据集用较小的 perplexity。

**Q3（实战）**：UMAP 相比 t-SNE 有哪些优势？什么场景下应该用 UMAP 替代 t-SNE？

**回答要点**：UMAP 速度明显更快（尤其是大数据集）；保留更多全局结构（t-SNE 容易丢失全局信息）；UMAP 的结果更可重复；除了可视化外，UMAP 的嵌入还可作为特征用于下游建模（t-SNE 的嵌入则不可靠）；大数据集首选 UMAP。

**Q4（边界）**：为什么说 t-SNE 和 UMAP 不适合作为特征提取用于建模？什么情况下可以谨慎使用？

**回答要点**：t-SNE/UMAP 降维不可逆，无法对新的测试点做变换（需重新拟合）；结果有随机性，每次运行可能不同；降维过程仅依赖相似度而非目标任务（无监督），可能丢失任务相关的重要信息；但在自编码器的瓶颈特征上再用 UMAP 进一步降维做可视化，或作为非任务特征的探索性分析时，可以谨慎使用。
