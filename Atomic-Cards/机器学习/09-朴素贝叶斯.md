# 朴素贝叶斯

## 定义

朴素贝叶斯（Naive Bayes）是基于**贝叶斯定理** + **条件独立假设**的生成式分类器。它假设每个特征在给定类别下**相互独立**——"朴素"指的就是这个简化的强假设。

$$P(y \mid \mathbf{x}) = \frac{P(y) \prod_{i=1}^n P(x_i \mid y)}{P(\mathbf{x})}$$

预测时选择后验概率最大的类别：$\hat{y} = \arg\max\limits_y P(y) \prod_{i} P(x_i \mid y)$

```python
from sklearn.naive_bayes import GaussianNB, MultinomialNB, BernoulliNB

# 高斯朴素贝叶斯（数值特征，假设服从正态分布）
gnb = GaussianNB()
gnb.fit(X_train, y_train)
y_pred = gnb.predict(X_test)

# 多项式朴素贝叶斯（计数特征，如词频）
mnb = MultinomialNB(alpha=1.0)          # alpha: 拉普拉斯平滑
mnb.fit(X_train_counts, y_train)

# 伯努利朴素贝叶斯（二值特征，如词是否出现）
bnb = BernoulliNB()
bnb.fit(X_train_binary, y_train)
```

## 三种变体

| 变体 | 假设 | 特征类型 | 适用场景 |
|------|------|----------|----------|
| **GaussianNB** | $P(x_i \mid y) \sim \mathcal{N}(\mu_{iy}, \sigma_{iy}^2)$ | 连续数值 | 任何数值特征 |
| **MultinomialNB** | $P(x_i \mid y) = \frac{N_{iy} + \alpha}{N_y + n\alpha}$ | 计数（词频） | 文本分类、文档分类 |
| **BernoulliNB** | $x_i \in \{0,1\}$ | 二进制（词是否出现） | 短文本分类、情感分析 |

## 优点与局限

| 优点 | 局限 |
|------|------|
| 训练极快（仅计算先验和条件概率） | 条件独立假设通常不真实 |
| 小样本下表现良好 | 无法学习特征间的关系（如词组） |
| 可解释性强 | 数值特征如不满足分布假设性能下降 |
| 天然支持增量学习（partial_fit） | 零概率问题需平滑处理 |

## 文本分类示例

```python
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline

# 文本分类流水线
pipe = Pipeline([
    ('vect', CountVectorizer(max_features=5000)),
    ('clf', MultinomialNB(alpha=1.0))
])
pipe.fit(X_text_train, y_train)
y_pred = pipe.predict(["This movie is great!"])

# 查看每个类别的对数概率
log_probs = pipe.predict_log_proba(["New text"])
```

## ML 中的贝叶斯

| 应用 | 形式 |
|------|------|
| **垃圾邮件过滤** | 最经典的 Naive Bayes 应用 |
| **文档分类** | 新闻分类、情感分析 |
| **贝叶斯推断** | $P(\theta \vert \mathcal{D}) \propto P(\mathcal{D} \vert \theta) P(\theta)$ |
| **贝叶斯超参优化** | 用高斯过程代理模型搜索最佳超参数 |
| **贝叶斯神经网络** | 权重为概率分布，输出有不确定性估计 |
