# 朴素贝叶斯

## 定义

朴素贝叶斯（Naive Bayes）是基于**贝叶斯定理** + **条件独立假设**的生成式分类器。它假设每个特征在给定类别下**相互独立**——"朴素"指的就是这个简化的强假设。

设 $y$ 为类别标签，$\mathbf{x}$ 为特征向量，$x_i$ 为第 $i$ 个特征，$P(y)$ 为先验概率，$P(x_i \mid y)$ 为似然概率，$P(\mathbf{x})$ 为证据因子：

$$
P(y \mid \mathbf{x}) = \frac{P(y) \prod_{i=1}^n P(x_i \mid y)}{P(\mathbf{x})}
$$

预测时选择后验概率最大的类别： $\hat{y} = \arg\max\limits_y P(y) \prod_{i} P(x_i \mid y)$

```python
from sklearn.naive_bayes import GaussianNB, MultinomialNB, BernoulliNB

# 高斯朴素贝叶斯（数值特征，假设每个类别下的特征服从正态分布）
gnb = GaussianNB()
gnb.fit(X_train, y_train)  # 学习每个类别下各特征的均值和方差

y_pred = gnb.predict(X_test)  # 根据后验概率最大的原则预测类别

# 多项式朴素贝叶斯（计数特征，如词频），适合文本分类中的词频统计
mnb = MultinomialNB(alpha=1.0)          # alpha: 拉普拉斯平滑，防止零概率问题
mnb.fit(X_train_counts, y_train)

# 伯努利朴素贝叶斯（二值特征，如词是否出现），适合短文本分类和情感分析
bnb = BernoulliNB()
bnb.fit(X_train_binary, y_train)
```

## 三种变体

| 变体 | 假设 | 特征类型 | 适用场景 | 说明 |
|------|------|----------|----------|------|
| **GaussianNB** | $P(x_i \mid y) \sim \mathcal{N}(\mu_{iy}, \sigma_{iy}^2)$ | 连续数值 | 任何数值特征 | $\mu_{iy}$：类别 $y$ 下特征 $i$ 的均值；$\sigma_{iy}^2$：类别 $y$ 下特征 $i$ 的方差 |
| **MultinomialNB** | $P(x_i \mid y) = \frac{N_{iy} + \alpha}{N_y + n\alpha}$ | 计数（词频） | 文本分类、文档分类 | $N_{iy}$：类别 $y$ 下特征 $i$ 的计数；$N_y$：类别 $y$ 的总计数；$n$：特征总数 |
| **BernoulliNB** | $x_i \in \{0,1\}$ | 二进制（词是否出现） | 短文本分类、情感分析 | |

## 优点与局限

| 优点 | 局限 |
|------|------|
| 训练极快（仅计算先验和条件概率） | 条件独立假设通常不真实 |
| 小样本下表现良好 | 无法学习特征间的关系（如词组） |
| 可解释性强 | 数值特征如不满足分布假设性能下降 |
| 天然支持增量学习（partial_fit） | 零概率问题需平滑处理 |

## 文本分类示例

```python
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline

# 文本分类流水线：将文本向量化和朴素贝叶斯分类串联成一个步骤
pipe = Pipeline([

    ('vect', CountVectorizer(max_features=5000)),  # 将文本转为词频向量，最多保留5000个最频繁的词

    ('clf', MultinomialNB(alpha=1.0))              # 用多项式朴素贝叶斯进行分类
])
pipe.fit(X_text_train, y_train)  # 训练流水线：先向量化文本再训练分类器

y_pred = pipe.predict(["This movie is great!"])  # 对新的文本进行预测

# 查看每个类别的对数概率（取对数后避免数值下溢，且便于对比）
log_probs = pipe.predict_log_proba(["New text"])
```

## ML 中的贝叶斯

| 应用 | 形式 |
|------|------|
| **垃圾邮件过滤** | 最经典的 Naive Bayes 应用 |
| **文档分类** | 新闻分类、情感分析 |
| **贝叶斯推断** | $P(\theta \vert \mathcal{D}) \propto P(\mathcal{D} \vert \theta) P(\theta)$ |
| **贝叶斯超参优化** | 用高斯过程代理模型搜索最佳超参数 |
| **贝叶斯神经网络** | 权重为概率分布，输出有不确定性估计 |

## 面试追问

**Q1（基础）**：朴素贝叶斯中的"朴素"指的是什么假设？这个假设为什么能简化计算？
**回答要点**：

1. "朴素"指条件独立假设——每个特征在给定类别下相互独立
2. 联合概率 $P(x \mid y)$ 可分解为各特征概率的乘积 $\prod P(x_i \mid y)$，避免了高维联合分布的计算
3. 虽然假设通常不真实，但使得模型训练极快，小样本下仍表现良好

**Q2（深挖）**：GaussianNB、MultinomialNB、BernoulliNB 三种变体各适用于什么场景？如何选择？
**回答要点**：

1. GaussianNB 假设特征服从正态分布，适合连续数值特征
2. MultinomialNB 适合计数特征（如词频），是文本分类的经典选择
3. BernoulliNB 适合二值特征（如词是否出现），适合短文本和情感分析

**Q3（实战）**：朴素贝叶斯在文本分类中如何解决"零概率"问题？拉普拉斯平滑的原理是什么？
**回答要点**：

1. 当某个词在训练集中未出现时，概率估算为 0 会导致整个乘积为零
2. 拉普拉斯平滑（alpha 参数）在每个类别的计数上加 $\alpha$，避免零概率
3. MultinomialNB(alpha=1.0) 是默认设置，alpha 越大正则化越强、平滑程度越高

**Q4（边界）**：当条件独立假设严重不成立时，朴素贝叶斯会出什么问题？什么时候它依然有效？
**回答要点**：

1. 当特征间高度相关时，概率估计会偏差（低估或高估）
2. 但分类决策只关心相对大小——即使概率不准，排名可能仍正确，因此在特征相关性不破坏决策边界的场景下仍有效
3. 严重时需改用能建模特征关系的模型（逻辑回归、树模型等）
