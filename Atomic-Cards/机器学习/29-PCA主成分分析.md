# PCA 主成分分析

## 定义

主成分分析（Principal Component Analysis, PCA）是最常用的**无监督线性降维**方法。它找到数据中**方差最大的方向**（主成分），将数据投影到低维子空间，同时尽可能保留原始数据的方差信息。

## 数学本质

PCA 对**协方差矩阵** $\Sigma = \frac{1}{n} X^T X$ 做**特征值分解**：

$$
\Sigma \mathbf{v}_i = \lambda_i \mathbf{v}_i
$$

- 特征向量 $\mathbf{v}_i$ → 主成分方向
- 特征值 $\lambda_i$ → 该方向上的方差大小

```python
from sklearn.decomposition import PCA

# 降维到 2 维：找到方差最大的2个方向，将高维数据投影到2维空间
pca = PCA(n_components=2)

X_2d = pca.fit_transform(X)
print(f"解释方差比: {pca.explained_variance_ratio_}")  # 每个主成分单独解释的方差比例
print(f"累积方差: {pca.explained_variance_ratio_.cumsum()}")  # 前k个主成分累积解释的方差

# 保留指定方差比例：自动选择能解释95%方差的最少主成分数
pca = PCA(n_components=0.95)

X_reduced = pca.fit_transform(X)
print(f"保留 {pca.n_components_} 个主成分")

# 查看各特征在主成分上的贡献权重（载荷矩阵）
loadings = pca.components_  # 每行是一个主成分，每列是原始特征的权重
```

## 算法步骤

1. 数据中心化（减去均值）
2. 计算协方差矩阵 $\Sigma = \frac{1}{n} X^T X$
3. 对 $\Sigma$ 做特征值分解
4. 按特征值大小排序，取前 k 个特征向量
5. 将数据投影到 k 个主成分方向： $X_{\text{new}} = X W_k$

## 主成分数量选择

| 方法 | 策略 | 说明 |
|:----:|:-----|:-----|
| **累积方差比** | 保留 90%~99% 方差 | 最常用，`PCA(n_components=0.95)` |
| **Kaiser 准则** | 保留特征值 > 1 的主成分 | 适用于标准化数据 |
| **肘部法** | 特征值下降变缓的点 | 观察 Scree Plot |

## ML/DL 应用场景

| 应用场景 | 说明 |
|----------|------|
| 数据可视化 | 降到 2D/3D 后用散点图观察数据分布 |
| 去噪 | 丢弃方差小（即噪声）的维度，提升信噪比 |
| 加速训练 | 减少特征数，降低模型复杂度 |
| 缓解维度灾难 | 高维→低维，距离计算更稳定 |
| 多重共线性处理 | PCA 去相关后再建模，消除特征间线性依赖 |

## 面试追问

**Q1（基础）**：PCA 的核心思想是什么？它找到的"主成分"数学上是什么？

**回答要点**：PCA 找到数据中方差最大的方向（第一主成分），然后找与第一主成分正交的次大方差方向（第二主成分）；数学上是对协方差矩阵做特征值分解，特征向量=主成分方向，特征值=该方向的方差大小。

**Q2（深挖）**：如何选择 PCA 保留的主成分数量？为什么通常保留 95% 的方差？

**回答要点**：通过累积解释方差比曲线选择，保留 95% 方差表示保留原始数据 95% 的信息量而丢弃 5% 的噪声/冗余；可以用 `PCA(n_components=0.95)` 自动选择；保留太多失去降维意义，保留太少丢失关键信息。

**Q3（实战）**：PCA 在 ML 项目中有哪些典型应用？说至少三个使用场景。

**回答要点**：数据可视化（降到 2D/3D）；去噪（丢弃小方差维度）；加速训练（减少特征数降低模型复杂度）；处理多重共线性（PCA 去相关后再建模）；缓解维度灾难（使距离计算更稳定）。

**Q4（边界）**：PCA 是一个线性降维方法，对于非线性流形数据有什么局限？什么情况下不应该用 PCA？

**回答要点**：PCA 只能捕捉全局线性结构，对非线性流形（如瑞士卷三维数据）无法有效展开；当数据分布高度非线性时，PCA 降维后距离关系失真——相近的点在低维可能变得很远；此时应使用 t-SNE 或 UMAP 等非线性降维方法进行可视化，或使用自编码器进行非线性特征提取。
