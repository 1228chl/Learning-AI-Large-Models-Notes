# 模型选择与超参数调优

## 定义

超参数（Hyperparameter）是**训练前**设置的参数（如树的深度、学习率），不同于模型参数（如权重 $w$）——模型参数由训练学习，超参数由人工设定。

## 三种调优方法

### 网格搜索（Grid Search）

```python
from sklearn.model_selection import GridSearchCV
from sklearn.ensemble import RandomForestClassifier

param_grid = {
    'n_estimators': [100, 200],
    'max_depth': [5, 10, None],
    'min_samples_split': [2, 5]
}   # 共 2 × 3 × 2 = 12 种组合

grid = GridSearchCV(
    RandomForestClassifier(),
    param_grid,
    cv=5,                       # 5 折交叉验证
    scoring='accuracy',         # 评分指标
    n_jobs=-1,                  # 并行
    verbose=1
)
grid.fit(X_train, y_train)

print(f"最佳参数: {grid.best_params_}")
print(f"最佳得分: {grid.best_score_:.4f}")
```

### 随机搜索（Random Search）

```python
from sklearn.model_selection import RandomizedSearchCV
from scipy.stats import randint, uniform

param_dist = {
    'n_estimators': randint(50, 500),
    'max_depth': randint(3, 30),
    'min_samples_split': randint(2, 20),
    'max_features': uniform(0.5, 0.5)         # 0.5~1.0 均匀分布
}

random = RandomizedSearchCV(
    RandomForestClassifier(),
    param_dist,
    n_iter=50,                   # 只尝试 50 次（网格可能需要几百次）
    cv=5,
    scoring='accuracy',
    n_jobs=-1,
    random_state=42
)
random.fit(X_train, y_train)
```

### 贝叶斯优化（Bayesian Optimization）

```python
# pip install scikit-optimize
from skopt import BayesSearchCV

opt = BayesSearchCV(
    RandomForestClassifier(),
    {
        'n_estimators': (50, 500),
        'max_depth': (3, 30),
        'min_samples_split': (2, 20)
    },
    n_iter=30,
    cv=5
)
opt.fit(X_train, y_train)
```

## 三种方法对比

| 方法 | 策略 | 尝试次数 | 适用场景 | 超参数多时 |
|:----:|:----:|:--------:|----------|:---------:|
| **Grid Search** | 笛卡尔积 | $O(K^d)$ | 少参数（< 4） | ❌ 指数爆炸 |
| **Random Search** | 随机采样 | 固定 $N$ 次 | 中等参数 | ✅ 效果好 |
| **Bayesian Search** | 高斯过程代理 | 固定 $N$ 次 | 参数多 + 评估慢 | ✅ 最优 |

**关键发现**（Bergstra & Bengio, 2012）：随机搜索在多数情况下比网格搜索**更高效**，因为它不会浪费资源在"不重要"的参数组合上。

## 学习曲线与验证曲线

```python
from sklearn.model_selection import validation_curve

param_range = [1, 3, 5, 10, 20]
train_scores, val_scores = validation_curve(
    DecisionTreeClassifier(), X, y,
    param_name='max_depth',
    param_range=param_range,
    cv=5, scoring='accuracy'
)

# 验证曲线解读：
# 训练分 ↑、验证分 ↑ → 尚可增加复杂度
# 训练分 ↑、验证分 ↓ → 过拟合，应降低复杂度
# 两者都低 → 欠拟合，应增加复杂度或换模型
```

## 模型选择策略

```python
# 系统化的模型选择流程
models = {
    'Logistic Regression': LogisticRegression(max_iter=1000),
    'KNN': KNeighborsClassifier(),
    'Decision Tree': DecisionTreeClassifier(),
    'Random Forest': RandomForestClassifier(),
    'SVM': SVC(probability=True),
    'XGBoost': XGBClassifier(use_label_encoder=False)
}

for name, model in models.items():
    scores = cross_val_score(model, X_train, y_train, cv=5)
    print(f"{name:20s}: {scores.mean():.4f} ± {scores.std():.4f}")
```

| 场景 | 推荐模型 | 原因 |
|------|----------|------|
| 小样本 + 高维 | SVM (线性核) / 逻辑回归 | 不易过拟合 |
| 结构化数据 | XGBoost / LightGBM / 随机森林 | 精度最高 |
| 文本分类 | 朴素贝叶斯 / SVM | 稀疏数据表现好 |
| 可解释性优先 | 逻辑回归 / 决策树 | 系数/树结构可直接解释 |
| 图像 / 序列 | 深度学习 | 端到端自动特征学习 |
| 快速基线 | 逻辑回归 / 随机森林默认参数 | 开箱即用 |
