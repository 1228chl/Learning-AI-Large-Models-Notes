# 决策树

## 定义

决策树（Decision Tree）是一种树形结构的监督学习模型，通过一系列**特征判断**逐步将数据划分到不同的区域（叶子节点）。可以同时用于分类和回归。

```python
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor, plot_tree
import matplotlib.pyplot as plt

# 分类
clf = DecisionTreeClassifier(max_depth=3, min_samples_split=10)
clf.fit(X_train, y_train)

# 可视化
plt.figure(figsize=(12, 8))
plot_tree(clf, filled=True, feature_names=feature_names)
plt.show()

# 回归
reg = DecisionTreeRegressor(max_depth=5)
reg.fit(X_train, y_train)
```

## 树结构

| 组件 | 含义 | 类比 |
|------|------|------|
| **根节点** | 第一个分裂特征 | 第一个问题 |
| **内部节点** | 特征上的判断条件 | 是/否问题 |
| **分支** | 判断结果 | 答案路径 |
| **叶子节点** | 最终预测结果 | 结论 |

## 分裂准则

| 准则 | 公式 | 任务 | 特点 |
|------|------|:----:|------|
| **基尼系数（Gini）** | $G = 1 - \sum_{k} p_k^2$ | 分类 | 默认，计算快 |
| **信息增益（Entropy）** | $H = -\sum_{k} p_k \log p_k$ | 分类 | 对分布更敏感 |
| **均方误差（MSE）** | $MSE = \frac{1}{n} \sum (y_i - \bar{y})^2$ | 回归 | 最小化方差 |

```python
# 分裂准则的选择
clf_gini = DecisionTreeClassifier(criterion='gini')       # 默认
clf_entropy = DecisionTreeClassifier(criterion='entropy') # 信息增益
reg_mse = DecisionTreeRegressor(criterion='squared_error')
```

## 剪枝（Pruning）

决策树容易**过拟合**——树越深，对训练数据记忆越精确。剪枝是防止过拟合的关键：

```python
# 预剪枝（Pre-pruning）：在树生长过程中提前停止
clf = DecisionTreeClassifier(
    max_depth=5,                    # 限制最大深度
    min_samples_split=10,           # 内部节点最少样本数
    min_samples_leaf=5,             # 叶子节点最少样本数
    max_leaf_nodes=50,              # 最大叶子数
    min_impurity_decrease=0.01      # 分裂至少降低的不纯度
)
```

## 决策树的重大局限

| 问题 | 后果 | 解决 |
|------|------|------|
| **过拟合** | 深度大时泛化差 | 剪枝、集成学习 |
| **不稳定** | 数据微小变化导致树结构大变 | 随机森林（多棵树平均） |
| **贪心分裂** | 当前最优分裂未必全局最优 | 不能回退，无法纠正 |
| **轴对齐分裂** | 对角线决策边界需很多深度 | 需旋转特征或改用其他模型 |

> **决策树的真正价值不在于单棵树，而在于作为集成学习的基础组件。**

> **面试追问**
> 
> Q1（基础）：决策树的树结构由哪些组件组成？决策过程是怎样的？
> 回答要点：根节点（第一个分裂特征）、内部节点（特征判断条件）、分支（判断结果路径）、叶子节点（最终预测结果）；决策过程从根节点开始，逐层根据特征值走分支，直到到达叶子节点得到预测结果。
> 
> Q2（深挖）：基尼系数和信息增益两种分裂准则有什么区别？什么情况下应该用哪一个？
> 回答要点：基尼系数 G=1-Σpk² 计算快是默认选择；信息增益 H=-Σpk·log pk 对分布更敏感，但计算稍慢（有对数运算）；两者在大多数场景下结果相近；信息增益偏向多取值特征（需信息增益比修正）；sklearn 默认用基尼系数。
> 
> Q3（实战）：决策树非常容易过拟合，实际项目中如何通过剪枝来控制？列举至少三个参数。
> 回答要点：预剪枝在树生长过程中提前停止：max_depth（限制最大深度）、min_samples_split（内部节点最少样本数）、min_samples_leaf（叶子节点最少样本数）、max_leaf_nodes（最大叶子数）、min_impurity_decrease（最小不纯度下降量）；实际中先限制 max_depth 和 min_samples_leaf 最有效。
> 
> Q4（边界）：决策树采用贪心分裂策略，这个策略有什么局限性？
> 回答要点：贪心分裂只考虑当前节点的最优分裂，不保证全局最优——当前的最佳分裂可能导致后续分裂困难；决策边界轴对齐（每次只在一个特征上分裂），对角线决策需要很多深度；因此单棵决策树性能有限，真正的价值在于作为集成学习（随机森林、GBDT）的基础组件。
