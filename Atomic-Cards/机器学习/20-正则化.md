# 正则化

## 定义

正则化（Regularization）是在损失函数中添加**惩罚项**来限制模型复杂度，是防止过拟合最有效的手段之一。

$$\text{Total Loss} = \text{Data Loss} + \lambda \cdot \text{Penalty}$$

其中 $\lambda$ 控制正则化强度：$\lambda$ 越大 → 模型越简单（欠拟合倾向），$\lambda$ 越小 → 模型越复杂（过拟合倾向）。

## L2 正则化（Ridge / 权重衰减）

$$L_{\text{ridge}} = L_{\text{data}} + \lambda \sum_{j=1}^p w_j^2 = L_{\text{data}} + \lambda \|\mathbf{w}\|_2^2$$

```python
from sklearn.linear_model import Ridge, RidgeCV

# 自动用交叉验证选最优 alpha（= λ）
ridge = RidgeCV(alphas=[0.01, 0.1, 1.0, 10.0], cv=5)
ridge.fit(X_train, y_train)
print(f"最佳 alpha: {ridge.alpha_}")

# 手动指定
ridge = Ridge(alpha=1.0)
ridge.fit(X_train, y_train)
```

**效果**：权重趋向于较小的值（但不为0），所有特征都保留但贡献减弱。

## L1 正则化（Lasso）

$$L_{\text{lasso}} = L_{\text{data}} + \lambda \sum_{j=1}^p |w_j| = L_{\text{data}} + \lambda \|\mathbf{w}\|_1$$

```python
from sklearn.linear_model import Lasso, LassoCV

lasso = LassoCV(alphas=[0.001, 0.01, 0.1, 1.0], cv=5)
lasso.fit(X_train, y_train)
print(f"非零系数数量: {np.sum(lasso.coef_ != 0)}")
```

**效果**：产生**稀疏解**——不重要特征的权重被压为0，天然实现**特征选择**。

## ElasticNet（L1 + L2 混合）

$$L_{\text{enet}} = L_{\text{data}} + \lambda_1 \|\mathbf{w}\|_1 + \lambda_2 \|\mathbf{w}\|_2^2$$

```python
from sklearn.linear_model import ElasticNet, ElasticNetCV

enet = ElasticNetCV(
    l1_ratio=[0.1, 0.3, 0.5, 0.7, 0.9],  # L1 占比，0=纯Ridge，1=纯Lasso
    alphas=[0.001, 0.01, 0.1, 1.0],
    cv=5
)
enet.fit(X_train, y_train)
```

## 三种正则化对比

| 特性 | L2（Ridge） | L1（Lasso） | ElasticNet |
|:----:|:-----------:|:-----------:|:----------:|
| 惩罚形式 | $\sum w_j^2$ | $\sum \vert w_j\vert$ | 两者混合 |
| 权重效果 | 缩小（但不为零） | **压为零**（稀疏） | 折中 |
| 特征选择 | ❌ | ✅ | ✅（群组效应） |
| 解的唯一性 | ✅ 唯一 | ⚠️ 可能不唯一 | ✅ |
| 相关特征处理 | 一起保留 | 随机选一个 | 群组保留 |
| 适用特征数 | 少特征 | **高维稀疏** | 高维 + 相关特征 |

## 正则化的几何解释

```
L2(Ridge): 约束区域为圆形 → 权重均匀缩小
L1(Lasso): 约束区域为菱形 → 角点产生稀疏

对比 Lasso 更可能让权重在坐标轴截断（=0）
```

## 其他正则化技术

| 技术 | 原理 | 使用方式 |
|------|------|----------|
| **早停（Early Stopping）** | 验证集损失不再下降时停止训练 | 所有模型 |
| **Dropout** | 训练时随机丢弃一部分神经元 | 神经网络 |
| **数据增强（Data Augmentation）** | 通过变换生成更多训练样本 | 图像/文本 |
| **Batch Normalization** | 每层归一化，引入轻微噪声 | 深度学习 |
| **随机深度（Stochastic Depth）** | 训练时随机跳过某些层 | 残差网络 |

## ML 中的交叉验证调 λ

```python
# 逻辑回归的正则化路径
from sklearn.linear_model import LogisticRegressionCV

clf = LogisticRegressionCV(
    Cs=10,                        # 自动在 C 值网格上搜索
    penalty='l2',
    cv=5,
    solver='lbfgs',
    max_iter=1000
)
clf.fit(X_train, y_train)
print(f"最佳 C（=1/λ）: {clf.C_[0]}")
```
