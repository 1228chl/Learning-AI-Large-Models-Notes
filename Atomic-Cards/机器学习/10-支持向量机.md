# 支持向量机（SVM）

## 定义

支持向量机（Support Vector Machine, SVM）是一种**二分类**模型，核心思想是找到一个**间隔最大**的决策超平面将两类样本分开。"支持向量"就是那些距离超平面最近的样本点。

**核心公式**：

$$
\max_{\mathbf{w}, b} \frac{2}{\|\mathbf{w}\|} \quad \text{s.t.} \quad y_i(\mathbf{w}^T \mathbf{x}_i + b) \geq 1, \forall i
$$

等价于最小化 $\frac{1}{2}\|\mathbf{w}\|^2$ ，即在约束条件下最大化间隔。

```python
from sklearn.svm import SVC

# 线性 SVM：用线性核找最大间隔超平面，适合线性可分数据
svm = SVC(kernel='linear', C=1.0)  # C是误分类惩罚系数，越大容错越小
svm.fit(X_train, y_train)

# 核 SVM（处理非线性）：用RBF核将数据映射到高维空间，使线性不可分变为线性可分
svm_rbf = SVC(kernel='rbf', gamma='scale', C=1.0)  # gamma控制RBF核的影响范围
svm_rbf.fit(X_train, y_train)

# 输出支持向量：即距离决策超平面最近的样本点，它们唯一决定超平面位置
print(f"支持向量数量: {len(svm.support_)}")
```

## 核技巧（Kernel Trick）

通过核函数将数据映射到高维空间，使原本线性不可分的数据在高维线性可分，而**无需显式计算高维映射**：

$$
K(\mathbf{x}_i, \mathbf{x}_j) = \langle \phi(\mathbf{x}_i), \phi(\mathbf{x}_j) \rangle
$$

| 核函数 | 公式 | 适用场景 | 关键参数 |
|--------|------|----------|----------|
| **线性核** | $K(\mathbf{x}_i, \mathbf{x}_j) = \mathbf{x}_i^T \mathbf{x}_j$ | 线性可分、高维稀疏文本 | 无 |
| **多项式核** | $K(\mathbf{x}_i, \mathbf{x}_j) = (\gamma \mathbf{x}_i^T \mathbf{x}_j + r)^d$ | 图像 | $d$ （度数） |
| **RBF 核**（高斯核） | $K(\mathbf{x}_i, \mathbf{x}_j) = \exp(-\gamma \ |\mathbf{x}_i - \mathbf{x}_j\|^2)$ | **默认首选**、非线性 | $\gamma$ |
| **Sigmoid 核** | $K(\mathbf{x}_i, \mathbf{x}_j) = \tanh(\gamma \mathbf{x}_i^T \mathbf{x}_j + r)$ | 神经网络类比 | $\gamma, r$ |

## 软间隔与参数 C

现实数据通常不是完全线性可分的。**软间隔（Soft Margin）** 引入松弛变量 $\xi_i$ ，允许部分样本被错误分类：

$$
\min_{\mathbf{w}, b, \xi} \frac{1}{2}\|\mathbf{w}\|^2 + C \sum_{i=1}^n \xi_i
$$

| C 值 | 间隔 | 允许的误分类 | 模型 |
|:----:|:----:|:------------:|:----:|
| **大 C** | 窄 | 少 | 过拟合（严格分类） |
| **小 C** | 宽 | 多 | 欠拟合（容忍错误） |

```python
# C 的调参：通过网格搜索在对数尺度上寻找最优C和gamma组合
from sklearn.model_selection import GridSearchCV


params = {'C': [0.01, 0.1, 1, 10, 100], 'gamma': ['scale', 'auto']}

grid = GridSearchCV(SVC(kernel='rbf'), params, cv=5)  # 5折交叉验证评估每种参数组合
grid.fit(X_train, y_train)
print(f"最佳参数: {grid.best_params_}")  # 输出交叉验证得分最高的参数组合
```

## SVM vs 逻辑回归

| 对比维度 | SVM | 逻辑回归 |
|----------|:---:|:--------:|
| **目标** | 最大化间隔 | 最大化似然 |
| **输出** | 硬分类（可输出距离） | 概率输出 |
| **核技巧** | ✅ 天然支持 | ❌ 需手动特征工程 |
| **小样本** | ✅ 好 | ⚠️ 一般 |
| **大样本** | ⚠️ 慢（ $O(n^2 \sim n^3)$ ） | ✅ 快 |
| **可解释性** | ⭐（核 SVM 黑箱） | ⭐⭐⭐（系数权重） |

> SVM + RBF 核是深度学习流行前最强大的"万能"分类器，适合**中小规模数据**。对于大规模数据（>10 万样本），逻辑回归或随机森林更实用。

## 面试追问

**Q1（基础）**：支持向量机的核心思想是什么？什么是"支持向量"？

**回答要点**：SVM 的核心是找到一个间隔最大的决策超平面将两类分开；支持向量就是距离超平面最近的样本点，它们唯一决定了超平面的位置——其他样本点移动不影响超平面，体现了 SVM 的稀疏性。

**Q2（深挖）**：核技巧（Kernel Trick）的原理是什么？为什么说它"巧妙"？

**回答要点**：核技巧通过核函数 K(xi,xj)=⟨φ(xi),φ(xj)⟩ 在低维空间计算高维空间的内积，无需显式计算高维映射 φ(x)；这使得原本线性不可分的数据在高维线性可分，而计算复杂度保持不变；RBF 核是默认首选。

**Q3（实战）**：SVM 中的参数 C 起什么作用？C 值大小如何影响模型？

**回答要点**：C 控制软间隔的惩罚力度，大 C 对误分类惩罚大 → 间隔窄，严格分类 → 容易过拟合；小 C 容忍更多误分类 → 间隔宽 → 容易欠拟合；C 通常通过 GridSearchCV 在对数尺度上搜索（0.01~100），配合交叉验证选择最优值。

**Q4（边界）**：SVM 在大规模数据场景下有什么局限性？现在哪些场景它仍然不可替代？

**回答要点**：SVM 训练复杂度 O(n²~n³)，样本超过 10 万时训练极慢；核 SVM 是黑箱模型，可解释性差；但在小样本高维场景（如基因数据、文本分类）仍有优势；深度学习流行前 SVM+RBF 是最强"万能"分类器，当前在中小规模数据和特定领域仍被广泛使用。
