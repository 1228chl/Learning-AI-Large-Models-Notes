# 评估指标

## 分类指标

## 直观理解

### 混淆矩阵的分类结果分析

混淆矩阵将预测结果与实际结果交叉对比，形成四个象限。从这四象限可以推导出几乎所有分类指标：

- **准确率（Accuracy）** = (TP+TN) / (TP+TN+FP+FN)：所有预测中正确的比例。在类别平衡时好用，但类别极度不平衡时（如 99% 负类），准确率 99% 可能毫无意义（模型全预测为负类）。
- **精确率（Precision）** = TP/(TP+FP)：预测为正类的样本中，有多少是真正的正类。"我不希望误报"时关注此项（如垃圾邮件过滤——误判正常邮件为垃圾邮件的代价很高）。
- **召回率（Recall）** = TP/(TP+FN)：实际为正类的样本中，模型找出了多少。"我不希望遗漏"时关注此项（如癌症筛查——漏诊的代价远高于误诊）。
- **F1 分数** = 2×P×R/(P+R)：精确率和召回率的调和平均，两者都高时 F1 才高。

### 如何选择指标？

任务类型决定指标选择：癌症筛查看召回率（不能漏掉病人），垃圾邮件过滤看精确率（不能误删正常邮件），推荐系统看 AUC（排序质量）。

### 混淆矩阵（Confusion Matrix）

```python
from sklearn.metrics import confusion_matrix, classification_report

# 真实标签和模型预测结果，用于计算混淆矩阵
y_true = [0, 1, 0, 1, 1, 0]

y_pred = [0, 1, 0, 0, 1, 0]


print(confusion_matrix(y_true, y_pred))   # 输出混淆矩阵：[[TP FN] [FP TN]] = [[3 0] [1 2]]
print(classification_report(y_true, y_pred))  # 输出精确率、召回率、F1分数等详细分类指标报告
```

| 指标 | 公式 | 关注点 | 适用场景 |
|------|------|--------|----------|
| **准确率（Accuracy）** | $\frac{TP+TN}{TP+TN+FP+FN}$ | 整体正确率 | 类别平衡时 |
| **精确率（Precision）** | $\frac{TP}{TP+FP}$ | 查准率（预测为正的对了多少） | 垃圾邮件（误判代价高） |
| **召回率（Recall）** | $\frac{TP}{TP+FN}$ | 查全率（找出了多少正例） | 癌症筛查（漏诊代价高） |
| **F1 分数** | $2 \cdot \frac{P \cdot R}{P + R}$ | 精确率与召回率的调和平均 | 类别不平衡时首选 |
| **特异性（Specificity）** | $\frac{TN}{TN+FP}$ | 负类的识别率 | 医学诊断 |

### AUC-ROC

AUC（Area Under ROC Curve）衡量模型对正负类的区分能力：

- **AUC = 1.0**：完美分类器
- **AUC = 0.5**：随机猜测
- **AUC < 0.5**：还不如随机

```python
from sklearn.metrics import roc_auc_score, roc_curve


y_prob = model.predict_proba(X_test)[:, 1]  # 获取模型预测的正类概率（第1列），而非硬分类结果

auc = roc_auc_score(y_test, y_prob)          # 计算AUC值，衡量模型对正负类的区分能力
print(f"AUC: {auc:.4f}")
```

## 回归指标

| 指标 | 公式 | 说明 | 取值范围 |
|------|------|------|:--------:|
| **MSE**（均方误差） | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | 大误差被放大（平方）；$y_i$ 为真实值，$\hat{y}_i$ 为预测值，$n$ 为样本数 | $[0, \infty)$ |
| **RMSE**（均方根误差） | $\sqrt{MSE}$ | 与 y 同量纲 | $[0, \infty)$ |
| **MAE**（平均绝对误差） | $\frac{1}{n}\sum\vert y_i - \hat{y}_i\vert$ | 直观易解释；$y_i$ 为真实值，$\hat{y}_i$ 为预测值，$n$ 为样本数 | $[0, \infty)$ |
| **R²**（决定系数） | $1 - \frac{SS_{res}}{SS_{tot}}$ | 模型解释了多大比例的方差；$SS_{res}$ 为残差平方和，$SS_{tot}$ 为总平方和 | $(-\infty, 1]$ |

```python
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

# 真实值和预测值样例，用于演示回归评估指标的计算
y_true = [3.0, 2.5, 4.0, 3.5]

y_pred = [2.8, 2.7, 3.9, 3.6]


mse = mean_squared_error(y_true, y_pred)       # 均方误差，对大误差惩罚更大，结果为0.0175

rmse = mse ** 0.5                               # 均方根误差，与y同量纲更直观，结果为0.132

mae = mean_absolute_error(y_true, y_pred)       # 平均绝对误差，所有误差的均值，结果为0.125

r2 = r2_score(y_true, y_pred)                   # R²决定系数，衡量模型解释了多大比例的方差，0.965接近1说明拟合良好
```

## 聚类指标

| 指标 | 需要真实标签 | 说明 |
|------|:-----------:|------|
| **轮廓系数（Silhouette Score）** | ❌ | 衡量簇内紧密度 + 簇间分离度， $[-1,1]$ |
| **Calinski-Harabasz 指数** | ❌ | 簇间方差 / 簇内方差，越大越好 |
| **Davies-Bouldin 指数** | ❌ | 簇间相似度的均值，越小越好 |
| **调整兰德指数（ARI）** | ✅ | 与真实标签的聚类一致性 |
| **标准化互信息（NMI）** | ✅ | 聚类结果与真实标签的互信息 |

## 指标选择指南

| 场景 | 首选指标 | 原因 |
|------|----------|------|
| 类别平衡的分类 | Accuracy | 直观 |
| 类别不平衡（如 99:1） | F1、AUC、Precision-Recall | Accuracy 会虚高 |
| 癌症筛查 | Recall（召回率） | 漏诊不可接受 |
| 回归预测 | R² + RMSE | 组合评估 |
| 聚类无标签 | 轮廓系数 | 无需先验知识 |

## 面试追问

**Q1（基础）**：混淆矩阵的四个值（TP、FP、FN、TN）分别代表什么？根据它们可以计算出哪些关键指标？
**回答要点**：

1. TP（真正例）= 实际为正，预测为正；FN（假负例）= 实际为正，预测为负；FP（假正例）= 实际为负，预测为正；TN（真负例）= 实际为负，预测为负
2. 基于混淆矩阵可推导出 Accuracy、Precision、Recall、F1、Specificity 等核心分类指标
3. 混淆矩阵是分类模型评估的基础，能直观反映模型在各类别上的表现差异

**Q2（深挖）**：为什么在类别不平衡时准确率（Accuracy）不可靠？应该用什么指标替代？
**回答要点**：

1. 以 95:5 的不平衡数据为例，全部预测为负类即可获得 95% 的准确率，但模型完全丧失对正类的识别能力
2. 应优先使用 F1 分数（精确率与召回率的调和平均）、AUC-ROC（排序能力）和 Precision-Recall 曲线
3. F1 分数对少数类的表现更敏感，能更真实地反映模型在不平衡数据上的实际价值

**Q3（实战）**：在一个癌症筛查项目中，应该优先优化哪个指标？为什么？
**回答要点**：

1. 应优先优化召回率（Recall），因为漏诊（FN）的代价远高于误诊（FP）——漏诊可能导致患者错过最佳治疗时机
2. 同时需考虑误诊带来的心理负担和额外检查成本，实际中常在 Recall 和 Precision 之间寻求平衡
3. 可根据业务需求设定最低 Precision 阈值，在此约束下最大化 Recall

**Q4（边界）**：AUC 作为评估指标有什么潜在缺陷？什么情况下会误导？
**回答要点**：

1. AUC 仅衡量模型对正负类的整体排序质量，不关心概率输出的校准度，高 AUC 的模型概率值可能严重偏移
2. 在极端不平衡场景下 AUC 可能过于乐观，因为大量负类被正确排序可能掩盖正类表现不佳的问题
3. 实际业务中需结合具体阈值下的 Precision/Recall 曲线来综合评估，不能仅凭 AUC 判断模型优劣
