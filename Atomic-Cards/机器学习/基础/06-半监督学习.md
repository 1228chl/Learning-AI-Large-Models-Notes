# 半监督学习

## 定义

半监督学习（Semi-Supervised Learning, SSL）是介于监督学习和无监督学习之间的一种学习范式：**少量标注数据 + 大量未标注数据** 一起参与模型训练，利用未标注数据蕴含的分布信息来提升模型性能。

$$
\hat{\theta} = \arg\max_{\theta} \left[ \sum_{i=1}^{L} \log P(y_i \mid x_i; \theta) + \lambda \sum_{j=1}^{U} \log P(x_j; \theta) \right]
$$

其中：
- $L$ 为标注样本数，$U$ 为未标注样本数，通常 $U \gg L$
- $P(y_i \mid x_i; \theta)$ 为标注数据的条件概率（监督损失）
- $P(x_j; \theta)$ 为未标注数据的边缘概率（无监督损失）
- $\lambda$ 为平衡系数，控制无监督项对总损失的贡献大小

## 为什么需要半监督学习

现实场景中标注数据获取成本极高（需要专家标注、时间长、费用高），而未标注数据大量存在（网络爬取、传感器采集等）。SSL 试图用少量标注 + 大量未标注达到接近全监督的效果：

| 场景 | 标注成本 | 未标注数据 | SSL 的价值 |
|:-----|:--------:|:----------:|:-----------|
| 医疗影像 | 高（需专业医生） | 大量历史影像 | 显著降低标注需求 |
| 文本分类 | 中（人工标注） | 海量网络文本 | 利用数据分布提升泛化 |
| 语音识别 | 高（需转写） | 大量录音 | 半监督训练大幅降本 |
| 遥感图像 | 高（需专家解译） | 大量卫星图 | 少量标注即可覆盖 |

## 核心方法

### 自训练（Self-Training）

最直观的 SSL 方法，核心是"用模型自己的高置信度预测作为伪标签"：

1. 用少量标注数据训练一个初始模型
2. 用该模型预测未标注数据，选取置信度最高的样本
3. 将高置信度的预测结果作为伪标签加入训练集
4. 重新训练模型，重复 2-3 步

```python
# 伪代码：自训练流程
from sklearn.semi_supervised import SelfTrainingClassifier
from sklearn.ensemble import RandomForestClassifier

# 标注数据：X_labeled, y_labeled
# 未标注数据：X_unlabeled（标签设为 -1）
import numpy as np
X_combined = np.vstack([X_labeled, X_unlabeled])         # 拼接标注和未标注数据
y_combined = np.hstack([y_labeled, [-1] * len(X_unlabeled)])  # 未标注标签设为 -1 表示缺失

# SelfTrainingClassifier 内部自动执行伪标签迭代
model = SelfTrainingClassifier(RandomForestClassifier(), threshold=0.8)
model.fit(X_combined, y_combined)
```

- $X_{\text{labeled}}$ 为标注特征矩阵，形状为 $[L, d]$
- $X_{\text{unlabeled}}$ 为未标注特征矩阵，形状为 $[U, d]$
- `threshold=0.8` 表示仅当预测概率超过 80% 才当作伪标签加入

**直觉**：自训练就像考试时做完有答案的题后，用掌握的规律去猜测没答案的题，挑最确定的答案补进知识库，再继续学。

### 协同训练（Co-Training）

将特征分成两个独立的视图（view），在两个视图上分别训练分类器，互相为对方的未标注数据打伪标签。要求两个视图条件独立 —— 即给定类别标签时，两个视图的特征分布独立。

### 生成式方法（Generative SSL）

假设数据由某个混合分布生成（如高斯混合模型 GMM），用 EM 算法同时估计分布参数和未标注数据的隐标签：

- E 步：根据当前参数估计未标注数据的后验标签分布
- M 步：用标注数据的真实标签和未标注数据的估计标签更新参数

### 基于图的方法（Graph-based SSL）

将数据点视为图中的节点，边权重表示相似度。标签通过图上的边从标注节点传播到未标注节点 —— 标签传播算法（Label Propagation）。

## 假设前提

SSL 有效依赖以下假设之一（否则可能伤害性能）：

| 假设 | 含义 | 直观理解 |
|:-----|:-----|:---------|
| **平滑假设** | 临近的样本具有相同标签 | 距离近的点大概率是一类 |
| **聚类假设** | 数据存在天然聚类结构，同一簇内标签相同 | 物以类聚，人以群分 |
| **流形假设** | 高维数据嵌入在低维流形上，流形上临近的点标签相似 | 数据虽在高维空间，但实际分布在更低维的结构上 |

## ML/DL 应用场景

| 应用场景 | 数学形式 | 说明 |
|:---------|:---------|:------|
| 文本分类少量标注 | $\min_{\theta} \sum_{i=1}^{L} \text{CE}(y_i, f(x_i)) + \lambda \sum_{j=1}^{U} \text{CE}(\hat{y}_j, f(x_j))$ | 少量标注 + 大量未标注文本，伪标签迭代训练分类器 |
| 半监督图像分类 | MixMatch / FixMatch 算法 | 对未标注图像做弱增强预测→伪标签→强增强一致性训练 |
| 医疗影像辅助诊断 | 自训练 + 置信度阈值 | 少量放射科医生标注 + 大量历史 CT 影像 |
| 异常检测 | SSL 二阶段训练 | 正常样本大量存在（未标注），异常样本极少（标注） |

## 面试追问

**Q1（基础）**：半监督学习与监督学习和无监督学习的核心区别是什么？
**回答要点**：

1. 监督学习使用全部标注数据 $(x, y)$，无监督学习使用全部未标注数据 $x$，半监督学习使用少量标注 + 大量未标注。
2. 半监督学习的目标函数由两部分组成：标注数据的监督损失 + 未标注数据的无监督损失（或正则化项），通过共享模型参数联合优化。
3. 半监督学习的前提假设（平滑/聚类/流形）决定了未标注数据是否真的能帮助提升性能 —— 如果假设不成立，未标注数据反而可能降低模型效果。

**Q2（深挖）**：自训练中的"伪标签"方法有什么风险？如何避免？
**回答要点**：

1. 错误累积风险：早期模型预测错误的伪标签会污染训练集，导致后续模型越来越差（自我强化偏差）。
2. 置信度校准风险：模型可能对错误预测给出高置信度（如 Softmax 输出 0.9 但分类错误），特别是在分布外样本上。
3. 缓解策略：设置高置信度阈值（如 0.95），使用多个模型投票（协同训练），加入噪声增强（只有增强后预测一致性高才接受伪标签），定期用标注数据验证集评估伪标签质量。

**Q3（实战）**：你在实际项目中如果标注数据只有 500 条，而未标注数据有 10 万条，你会怎样设计半监督方案？
**回答要点**：

1. 先用 500 条标注数据训练一个强基线模型（如预训练模型微调），评估其在验证集上的性能作为基准。
2. 使用自训练 + 高置信度阈值（如 0.95）为未标注数据生成伪标签，每轮只加入最确定的样本，迭代 3-5 轮。
3. 同时采用数据增强一致性约束（如 FixMatch 中的弱增强→预测→强增强→一致性损失），利用未标注数据训练模型对扰动的鲁棒性。
4. 关注"确认偏差"：定期回退检查伪标签质量，如果伪标签准确率低于 90% 则降低阈值或重新评估。

**Q4（边界）**：半监督学习在什么情况下不仅不能提升性能，反而会降低？如何诊断？
**回答要点**：

1. 当未标注数据与标注数据来自不同分布时（分布偏移），未标注数据包含的"结构信息"会误导模型。
2. 当数据不满足平滑/聚类/流形假设时——例如标签在特征空间中呈交错分布，临近区域有不同类别的样本。
3. 诊断方法：在只使用标注数据的基线上，逐步加入未标注数据并监控验证集性能变化；如果加入后性能下降，说明未标注数据与标注数据不一致或假设不成立。
4. 实践中常用"分阶段验证"：先用标注数据训练一个初始模型，用它对未标注数据做预测，然后人工抽查一批预测结果来评估伪标签质量。
