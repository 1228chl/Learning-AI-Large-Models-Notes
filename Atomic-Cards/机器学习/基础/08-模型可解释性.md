# 模型可解释性

## 定义

模型可解释性（Explainable AI, XAI）是理解机器学习模型**为何做出特定预测**的技术集合。分为全局可解释性（整个模型的行为逻辑）和局部可解释性（单个预测的原因）。

数学形式：对于模型 $f: \mathbb{R}^d \rightarrow \mathcal{Y}$，可解释性方法输出每个特征对预测 $f(x)$ 的贡献 $\phi_i$：

$$
f(x) = \phi_0 + \sum_{i=1}^{d} \phi_i
$$

其中 $\phi_0$ 为基准预测（所有特征的平均预测），$\phi_i$ 为第 $i$ 个特征的贡献值。

## 为什么需要可解释性

| 需求 | 原因 | 示例 |
|:-----|:-----|:------|
| **调试模型** | 发现模型学到了错误的特征 | 分类器用"水印"而非"猫"识别猫 |
| **建立信任** | 用户/客户需要理解决策依据 | 贷款被拒绝时解释原因 |
| **合规要求** | 法规要求解释自动决策 | GDPR 的"解释权" |
| **发现偏差** | 检测模型是否依赖敏感属性 | 性别/种族歧视 |
| **知识发现** | 从模型中提取领域洞察 | 医疗模型发现新标记物 |

## 主要方法

### 特征重要性（全局）

树模型的默认可解释性方法，衡量每个特征在减少不纯度上的贡献：

$$
\text{Importance}_i = \sum_{\text{node}} \frac{N_{\text{node}}}{N} \cdot \Delta \text{Impurity}_{\text{node}} \cdot \mathbb{I}(\text{node uses feature } i)
$$

### SHAP

基于博弈论 Shapley 值的特征归因方法，计算每个特征对预测的边际贡献：

$$
\phi_i = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|!(|F| - |S| - 1)!}{|F|!} \left[ f(x_{S \cup \{i\}}) - f(x_S) \right]
$$

其中 $F$ 为所有特征的集合，$S$ 为特征子集，$f(x_S)$ 为仅使用 $S$ 中特征时的预测值。

SHAP 满足三个公理：
- **局部准确性**：特征贡献之和等于预测值与基准值的差
- **缺失性**：不影响预测的特征贡献为 0
- **一致性**：模型改变使某个特征依赖增大，其 SHAP 值不会减小

```python
import shap
import xgboost as xgb
from sklearn.datasets import load_boston

# 训练模型
X, y = load_boston(return_X_y=True)            # 加载波士顿房价数据集
model = xgb.XGBRegressor().fit(X, y)            # 训练 XGBoost 模型

# SHAP 全局解释：计算所有特征的 Shapley 值
explainer = shap.Explainer(model)               # 创建解释器（基于树模型的高效算法 TreeSHAP）
shap_values = explainer(X)                      # 计算整个数据集的 SHAP 值

# SHAP 总结图：展示每个特征的影响方向和大小
shap.summary_plot(shap_values, X)
```

### LIME

在预测点附近拟合一个可解释的局部代理模型（如线性回归）：

$$
\xi(x) = \arg\min_{g \in \mathcal{G}} \mathcal{L}(f, g, \pi_x) + \Omega(g)
$$

- $f$ 为原始黑盒模型
- $g$ 为可解释的代理模型（线性模型）
- $\pi_x$ 为预测点 $x$ 附近的样本权重
- $\Omega(g)$ 为代理模型的复杂度惩罚

```python
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_iris

# 训练黑盒模型
X, y = load_iris(return_X_y=True)
blackbox = LogisticRegression(max_iter=200).fit(X, y)
```

## 方法对比

| 维度 | SHAP | LIME | 特征重要性（树） | PDP |
|:-----|:----:|:----:|:--------------:|:---:|
| 类型 | 局部+全局 | 局部 | 全局 | 全局 |
| 适用范围 | 任何模型 | 任何模型 | 树模型 | 任何模型 |
| 理论基础 | Shapley 值（博弈论） | 局部代理 | 不纯度减少 | 边际效应 |
| 计算速度 | 慢（精确计算指数级） | 快 | 极快 | 快 |
| 一致性 | ✅ 满足 | ❌ 局部不可靠 | ❌ 可能不一致 | — |
| 特征交互 | ✅ 可捕捉 | ❌ 忽略 | ❌ 忽略 | ❌ 忽略 |

| 应用场景 | 使用方法 | 说明 |
|:---------|:---------|:------|
| 信用评分模型 | SHAP 解释拒绝原因 | 满足合规要求，告诉用户哪些特征导致被拒 |
| 医疗诊断模型 | SHAP 展示病灶区域 | 在医学图像上叠加热力图，标出模型关注的区域 |

| 风险控制 | 特征重要性监控 | 监控模型依赖的特征是否随时间偏移 |

## 面试追问

**Q1（基础）**：全局可解释性和局部可解释性有什么区别？分别有什么典型方法？
**回答要点**：

1. 全局可解释性回答"模型整体是如何工作的"——特征重要性、PDP（部分依赖图）展示特征的平均影响。
2. 局部可解释性回答"为什么这个样本被预测为这个类"——SHAP、LIME 计算每个特征对单个预测的贡献。
3. 两者互补：全局解释告诉你"房价预测中地理位置最重要"，局部解释告诉你"这栋房子的预测价格高是因为面积大 + 位置好"。

**Q2（深挖）**：SHAP 和 LIME 的核心数学原理是什么？为什么 SHAP 理论上优于 LIME？
**回答要点**：

1. SHAP 基于 Shapley 值，考虑所有可能的特征子集组合，计算每个特征的平均边际贡献，满足局部准确性、缺失性、一致性三个公理。
2. LIME 在预测点附近生成扰动样本，用这些样本训练一个可解释的局部代理模型（线性回归/决策树），用代理模型的系数作为特征重要性。
3. SHAP 理论上优于 LIME：LIME 的扰动采样和邻域定义可能不稳定（不同种子给出不同解释），SHAP 的 Shapley 值是唯一满足三个公理的解。

**Q3（实战）**：在实际项目中，你发现模型在测试集上精度很高但上线后效果很差，如何用可解释性方法排查？
**回答要点**：

1. 用 SHAP 比较训练集和线上数据的特征分布和 SHAP 贡献分布——找"特征偏移"（某个重要特征的分布变了）或"概念偏移"（同一个特征值对预测的影响变了）。
2. 检查 SHAP 依赖图：某个特征在训练集和线上数据中的贡献模式是否一致。
3. 典型发现：模型依赖了训练集存在但线上不存在的特征（如时间戳、用户 ID）、或特征含义在线上环境中发生了变化。

**Q4（边界）**：SHAP 的计算复杂度很高，在大模型或高维特征场景下有什么优化方案？
**回答要点**：

1. TreeSHAP：针对树模型的优化算法，时间复杂度从指数级降到 $O(TLD^2)$（T 为树的数量，L 为叶子数，D 为最大深度）。
2. KernelSHAP 近似：用核函数近似采样特征子集，而非枚举所有 $2^d$ 种组合。
3. 深度学习场景：Grad-CAM（基于梯度热力图）、Integrated Gradients（积分梯度，用路径积分替代 Shapley 值计算）。
4. 工程实践：先用特征重要性筛选 Top-20 特征，再用 SHAP 做局部解释，避免高维灾难。
