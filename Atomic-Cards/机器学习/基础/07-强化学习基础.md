# 强化学习基础

## 定义

强化学习（Reinforcement Learning, RL）是机器学习的三大范式之一：**智能体（Agent）在环境（Environment）中通过试错学习，根据状态（State）采取行动（Action），获得奖励（Reward），目标是最大化累积奖励**。

形式化定义为马尔可夫决策过程（MDP）：

$$
\pi^* = \arg\max_{\pi} \mathbb{E}\left[ \sum_{t=0}^{\infty} \gamma^t R_t \;\middle|\; \pi \right]
$$

其中：
- $\pi$ 为策略函数 $\pi(a \mid s)$，表示在状态 $s$ 下选择行动 $a$ 的概率分布
- $\pi^*$ 为最优策略，使累积奖励期望最大
- $\gamma \in [0, 1)$ 为折扣因子，控制未来奖励的权重（越接近 0 越短视，越接近 1 越远视）
- $R_t$ 为第 $t$ 步的即时奖励
- $\mathbb{E}[\cdot]$ 表示在策略 $\pi$ 下的期望累积奖励

## 四要素

强化学习的四个核心要素，构成学习循环：

| 要素 | 符号 | 含义 | 类比 |
|:-----|:----|:-----|:-----|
| **智能体（Agent）** | — | 做出决策的学习者 | 玩家 |
| **环境（Environment）** | — | Agent 交互的外部世界 | 游戏规则 |
| **状态（State）** | $s \in \mathcal{S}$ | 环境的当前观测 | 棋盘局面 |
| **行动（Action）** | $a \in \mathcal{A}$ | Agent 可执行的操作 | 落子的位置 |
| **奖励（Reward）** | $r \in \mathcal{R}$ | 环境对行动的即时反馈 | 得分或扣分 |

```
Agent ──→ action a ──→ Environment
       ←── reward r, next state s' ←──
```

## 监督学习 vs 强化学习

| 维度 | 监督学习 | 强化学习 |
|:-----|:---------|:---------|
| 数据来源 | 给定的标注数据集 $(x, y)$ | 与环境的交互产生的经验 $(s, a, r, s')$ |
| 反馈形式 | 即时正确的标签 $y$ | 延迟且稀疏的奖励信号 |
| 目标 | 最小化预测误差 | 最大化累积奖励 |
| 探索 | 不需要（数据已固定） | 需要探索未知行动（exploration vs exploitation 权衡） |
| 时间依赖性 | 样本独立同分布 | 当前行动影响未来状态 |

**直觉**：监督学习像有标准答案的考试，强化学习像学会骑自行车——你摔倒（负奖励）才知道姿势不对，但没人告诉你具体哪块肌肉该发力。

## 关键概念

### 探索 vs 利用（Exploration vs Exploitation）

强化学习的核心矛盾：

- **探索**：尝试从未选过的行动，可能发现更好的策略，但有短期风险
- **利用**：选择当前已知的最佳行动，确保当前利益，但可能错过更好的选择

常用策略：$\epsilon$-greedy —— 以 $\epsilon$ 概率随机探索，以 $1-\epsilon$ 概率选择当前最优行动。

### 值函数与策略

| 概念 | 定义 | 符号 |
|:-----|:-----|:------|
| **状态值函数** | 从状态 $s$ 出发，按策略 $\pi$ 行动的期望累积奖励 | $V^{\pi}(s) = \mathbb{E}_{\pi}[\sum \gamma^t R_t \mid s_0 = s]$ |
| **行动值函数** | 在状态 $s$ 采取行动 $a$，之后按策略 $\pi$ 行动的期望累积奖励 | $Q^{\pi}(s, a) = \mathbb{E}_{\pi}[\sum \gamma^t R_t \mid s_0 = s, a_0 = a]$ |
| **策略** | 从状态到行动的映射，决定 Agent 的行为方式 | $\pi(a \mid s)$ |

### 贝尔曼方程

值函数的核心递推关系，是几乎所有 RL 算法的数学基础：

$$
V^{\pi}(s) = \sum_{a} \pi(a \mid s) \left[ R(s, a) + \gamma \sum_{s'} P(s' \mid s, a) V^{\pi}(s') \right]
$$

其中 $R(s, a)$ 为在状态 $s$ 采取行动 $a$ 的即时奖励，$P(s' \mid s, a)$ 为转移到状态 $s'$ 的状态转移概率。

## 主要方法分类

| 类别 | 代表算法 | 特点 |
|:-----|:---------|:-----|
| **基于值函数** | Q-Learning, DQN | 学习 $Q(s, a)$，策略从值函数隐式导出（选最大 Q 值行动） |
| **基于策略** | Policy Gradient, REINFORCE | 直接学习策略 $\pi(a \mid s)$，适合连续动作空间 |
| **Actor-Critic** | A2C, A3C, PPO | 同时学习策略（Actor）和值函数（Critic），结合两者优势 |
| **基于模型** | Dyna, MCTS | 显式建模环境转移概率 $P(s' \mid s, a)$，用模型规划 |

## ML/DL 应用场景

| 应用场景 | 数学形式 | 说明 |
|:---------|:---------|:------|
| 游戏 AI | DQN 在 Atari 上的端到端学习 | 从屏幕像素直接学习游戏策略，DeepMind 的里程碑工作 |
| 机器人控制 | PPO / SAC 做连续动作控制 | 根据传感器输入直接输出电机扭矩，用真实物理世界的奖励训练 |
| 自动驾驶 | 模拟器中训练 + 真实环境微调 | 在模拟器中用 RL 训练基本驾驶策略，再迁移到真实车辆 |
| 推荐系统 | 将用户交互建模为 MDP | 每次推荐为动作，用户点击/购买为奖励，长期优化用户留存 |
| 大模型 RLHF | PPO 算法优化语言模型 | 用人类偏好作为奖励信号，微调 LLM 使其输出更符合人类期望 |

## 面试追问

**Q1（基础）**：强化学习四要素是什么？Agent 通过什么方式与环境交互？
**回答要点**：

1. 四要素是 Agent、Environment、State、Action，加上 Reward 构成五要素的常用描述。Agent 根据当前状态选择行动，环境根据行动返回新状态和即时奖励。
2. 交互方式是循环：观测状态 → 选择行动 → 执行行动 → 接收奖励和新状态 → 重复。
3. 与监督学习的本质区别：RL 没有"正确答案"，只有延迟的奖励信号；当前行动会影响后续状态和奖励分布。

**Q2（深挖）**：Exploration 和 Exploitation 的权衡在强化学习中为什么重要？$\epsilon$-greedy 策略如何工作？
**回答要点**：

1. 如果不探索，Agent 可能永远找不到最优策略（被困在局部最优）；如果只探索不利用，Agent 无法积累足够奖励来确认策略好坏。
2. $\epsilon$-greedy 以概率 $\epsilon$ 随机选择行动（探索），以 $1-\epsilon$ 选择当前 Q 值最高的行动（利用）。通常在训练初期设较大 $\epsilon$（0.5~1.0），后期逐渐衰减到 0.01~0.1。
3. 更高级的探索策略包括：UCB（不确定度优先）、Thompson Sampling（按后验概率采样）、Noisy Net（在参数空间加噪声）。

**Q3（实战）**：如何用强化学习解决一个实际的推荐系统问题？你会怎么设计状态、动作和奖励？
**回答要点**：

1. 状态（State）：用户历史行为序列、当前上下文（时间/设备/位置）、用户画像特征。
2. 动作（Action）：推荐候选物品列表（离散）或推荐策略参数（连续）。
3. 奖励（Reward）：即时奖励（点击/购买+1，不加−0.1） + 延迟奖励（次日回访+5），需要平衡短期和长期回报。
4. 训练：离线用历史日志做 Off-Policy 训练（解决"推荐什么数据就有什么"的偏差问题），在线做 A/B 测试验证。

**Q4（边界）**：强化学习在大模型 RLHF 中扮演什么角色？和传统 RL（如游戏 AI）有什么不同？
**回答要点**：

1. RLHF 用 PPO 算法微调大模型：先训练一个奖励模型（Reward Model）拟合人类偏好，再用 PPO 优化语言模型使奖励最大化。
2. 与传统 RL 的不同：动作空间是词表（离散超大）、状态是对话历史（变长文本）、奖励来自奖励模型而非真实环境、需要 KL 正则化防止模型偏离原始分布太远。
3. RLHF 的核心挑战：奖励模型本身的偏差会放大到策略中（reward hacking），实际常用 KL 惩罚项和人类回标来缓解。
