# 机器学习概述

## 定义

机器学习（Machine Learning）是一种让计算机**从数据中自动学习规律**，而不需要为每个步骤显式编程的方法。

| 范式 | 输入 | 输出 |
|------|------|------|
| **传统编程** | 规则 + 数据 | 答案 |
| **机器学习** | 答案 + 数据 | 规则 |

## 三要素

| 要素 | 说明 | 类比 |
|------|------|------|
| **数据（Data）** | 模型学习的材料，包含特征 $X$ 和标签 $y$ | 教材 |
| **模型（Model）** | 用于学习规律的数学结构 | 大脑 |
| **学习算法（Algorithm）** | 调整模型参数的方法（如梯度下降） | 学习方法 |

## 基本工作流程

```python
# 1. 收集数据 → 2. 预处理 → 3. 选择模型 → 4. 训练 → 5. 评估 → 6. 调优 → 7. 部署

from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 数据
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 预处理
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

# 训练
model = RandomForestClassifier()
model.fit(X_train, y_train)

# 评估
y_pred = model.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, y_pred):.4f}")
```

## 学习类型

| 类型 | 数据要求 | 目标 | 典型算法 |
|------|----------|------|----------|
| **监督学习** | $X + y$ （特征+标签） | 学习 $X \to y$ 的映射 | 线性回归、随机森林、SVM |
| **无监督学习** | $X$ （仅有特征） | 发现数据内在结构 | K-means、PCA、DBSCAN |
| **强化学习** | 状态+动作+奖励 | 学习最优决策策略 | Q-Learning、PPO、DQN |
| **半监督学习** | 少量 $y$ + 大量 $X$ | 利用未标注数据提升性能 | 自训练、伪标签 |
| **自监督学习** | $X$ （自动构造标签） | 学习通用表示 | BERT、MAE、SimCLR |

## 面试追问

**Q1（基础）**：机器学习的三要素是什么？各自的作用是什么？

**回答要点**：数据（学习的材料，含特征 X 和标签 y）、模型（学习规律的数学结构）、学习算法（如梯度下降用于调整模型参数）；三者缺一不可，数据是基础，模型是载体，算法是引擎。

**Q2（深挖）**：传统编程与机器学习的核心区别是什么？为什么这种转变很重要？

**回答要点**：传统编程=规则+数据→答案，机器学习=答案+数据→规则；ML 让计算机自动从数据中学习规律，无需显式编程；这种转变使机器能处理传统编程难以编写规则的任务（如图像识别、自然语言理解）。

**Q3（实战）**：在实际项目中，机器学习工作流的哪个环节最容易被忽视？后果是什么？

**回答要点**：数据预处理和特征工程最常被忽视，但"垃圾进垃圾出"；跳过预处理直接建模会导致模型性能差、泛化能力弱；实际项目 80% 时间花在数据准备上，模型选择只占小部分。

**Q4（边界）**：机器学习在什么场景下不适用或效果很差？

**回答要点**：数据量极少时（小样本学习仍是开放问题）；需要完全可解释的领域（如金融风控的法律合规要求）；因果推断任务（ML 学的是相关性不是因果性）；动态变化环境（数据分布漂移导致模型失效）。
