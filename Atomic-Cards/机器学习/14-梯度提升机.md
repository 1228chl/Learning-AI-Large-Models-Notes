# 梯度提升机（GBDT / XGBoost / LightGBM）

## 定义

梯度提升（Gradient Boosting）是 Boosting 流派中最成功的方法。它**串行**训练决策树，每棵新树学习**前一棵树的残差**（实际值 - 预测值），逐步降低整体偏差。

```python
# GBDT（sklearn 原生）
from sklearn.ensemble import GradientBoostingClassifier

gbdt = GradientBoostingClassifier(
    n_estimators=100,
    max_depth=3,
    learning_rate=0.1               # 每棵树的贡献幅度
)
gbdt.fit(X_train, y_train)
```

## 核心思想

$$\text{第 t 步:} \quad F_t(x) = F_{t-1}(x) + \eta \cdot h_t(x)$$

其中 $h_t(x)$ 是拟合**负梯度**（残差方向）的新树，$\eta$ 是学习率。

```python
# 手动理解 GBDT 的串行逻辑
from sklearn.tree import DecisionTreeRegressor

# 第一棵树：直接拟合原始目标
tree1 = DecisionTreeRegressor(max_depth=3)
tree1.fit(X, y)
residual1 = y - tree1.predict(X)    # 残差

# 第二棵树：拟合残差
tree2 = DecisionTreeRegressor(max_depth=3)
tree2.fit(X, residual1)
residual2 = residual1 - tree2.predict(X)  # 更新残差

# 集成预测 = tree1 + lr * tree2 + lr * tree3 + ...
```

## XGBoost — 工业级实现

XGBoost 在原始 GBDT 基础上做了大量优化：

```python
import xgboost as xgb

model = xgb.XGBClassifier(
    n_estimators=200,
    max_depth=6,
    learning_rate=0.1,
    subsample=0.8,                  # 行采样（防止过拟合）
    colsample_bytree=0.8,           # 列采样（类似随机森林）
    reg_alpha=0.1,                  # L1 正则化
    reg_lambda=1.0,                 # L2 正则化
    eval_metric='logloss',
    early_stopping_rounds=20,        # 早停
    use_label_encoder=False
)

model.fit(
    X_train, y_train,
    eval_set=[(X_val, y_val)],
    verbose=False
)
```

## LightGBM — 更快更强

```python
import lightgbm as lgb

lgb_model = lgb.LGBMClassifier(
    n_estimators=200,
    num_leaves=31,                  # 叶子数（控制复杂度）
    max_depth=-1,                   # 不限深度
    learning_rate=0.1,
    subsample=0.8,
    colsample_bytree=0.8,
    reg_alpha=0.1,
    reg_lambda=1.0
)

lgb_model.fit(
    X_train, y_train,
    eval_set=[(X_val, y_val)],
    callbacks=[lgb.early_stopping(20)]
)
```

## 三种主流实现对比

| 特性 | GBDT（sklearn） | XGBoost | LightGBM |
|------|:--------------:|:-------:|:--------:|
| **分裂策略** | 逐层分裂（Level-wise） | 逐层分裂 | 逐叶分裂（Leaf-wise） |
| **训练速度** | 慢 | 中 | **最快** |
| **内存占用** | 高 | 中 | **最低** |
| **分类特征** | ❌ 需编码 | ❌ 需编码 | ✅ **原生支持** |
| **缺失值处理** | ❌ 需填充 | ✅ 自动学习分裂方向 | ✅ 自动处理 |
| **GPU 加速** | ❌ | ✅ | ✅ |
| **分布式** | ❌ | ✅ | ✅ |
| **精度** | 基准 | 略高 | 与 XGBoost 相当 |

## 超参数速查

| 参数 | 控制 | 调高 | 调低 |
|------|------|:----:|:----:|
| `n_estimators` | 树的数量 | 过拟合 | 欠拟合 |
| `learning_rate` | 每棵树贡献 | 过拟合 | 欠拟合 |
| `max_depth` / `num_leaves` | 树的复杂度 | 过拟合 | 欠拟合 |
| `subsample` | 行采样比例 | 过拟合 | 欠拟合 |
| `reg_alpha` / `reg_lambda` | 正则化强度 | 欠拟合 | 过拟合 |
