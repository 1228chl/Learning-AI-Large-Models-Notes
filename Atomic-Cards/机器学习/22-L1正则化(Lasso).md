# L1 正则化（Lasso）

## 定义

L1 正则化（Lasso）在损失函数中添加权重的**绝对值之和**作为惩罚项，产生**稀疏解**——不重要特征的权重被压为 0，天然实现**特征选择**。

$$
L_{\text{lasso}} = L_{\text{data}} + \lambda \sum_{j=1}^p |w_j| = L_{\text{data}} + \lambda \|\mathbf{w}\|_1
$$

其中 $\lambda$ 控制正则化强度：$\lambda$ 越大 → 权重越稀疏（更多特征被置零），$\lambda$ 越小 → 保留更多特征。

## 核心公式

L1 在零点不可导，使用**软阈值**（Soft Thresholding）求解：

$$
\text{prox}_{\lambda}(w) = \text{sign}(w) \cdot \max(|w| - \lambda, 0)
$$

```python
from sklearn.linear_model import Lasso, LassoCV

lasso = LassoCV(alphas=[0.001, 0.01, 0.1, 1.0], cv=5)
lasso.fit(X_train, y_train)
print(f"非零系数数量: {np.sum(lasso.coef_ != 0)}")
```

## 几何解释

L1 的约束区域是**菱形**：
- 菱形有**尖角**落在坐标轴上
- 等高线更容易碰在尖角处 → 某维度权重 = 0
- 维度越高，尖角越多，稀疏性越强

```
L1 约束：|w₁| + |w₂| ≤ t
菱形角点落在 (t,0) 和 (0,t)
角点上 w₁=0 或 w₂=0
```

## 特性总结

| 特性 | 说明 |
|------|------|
| 权重效果 | 压为 0（稀疏解） |
| 特征选择 | ✅ 天然特征选择 |
| 解的唯一性 | ⚠️ 高维时可能不唯一（非严格凸） |
| 相关特征处理 | 随机选一个保留 |
| 适用场景 | 高维稀疏数据、需要特征选择 |

## ML/DL 应用场景

| 应用场景 | 数学形式 | 说明 |
|----------|----------|------|
| 高维特征选择 | $\min \|Xw-y\|^2 + \lambda\|w\|_1$ | 基因组学、文本分类中从百万特征中选关键特征 |
| 稀疏编码 | $\min \|x-D\alpha\|_2^2 + \lambda\|\alpha\|_1$ | 字典学习中用 L1 约束编码系数稀疏性 |
| 图像去噪（TV 正则化） | $\min \|x-y\|_2^2 + \lambda\|\nabla x\|_1$ | 在相邻像素差上施加 L1，保留边缘 |
| Lasso 回归 | sklearn `Lasso` / `LassoCV` | 线性模型特征选择 + 回归 |

## 面试追问

**Q1（基础）**：L1 正则化为什么能产生稀疏解？与 L2 有什么区别？
**回答要点**：L1 约束区域是菱形（有尖角），等高线更容易碰在坐标轴尖角上导致某维为 0；L2 约束区域是圆形（光滑），切点各维都非零；优化角度上 L1 的 proximal operator 有软阈值效果，直接将小系数置零。

**Q2（深挖）**：Lasso 在高维数据（p >> n，特征数远多于样本数）中最多能选出多少个特征？
**回答要点**：经典 Lasso 最多能选出 n 个非零特征（样本数）；当 p >> n 时，Lasso 会饱和——后续增加 $\lambda$ 不再减少特征数；弹性网（ElasticNet）通过 L2 项突破此限制，可在 p >> n 时选出超过 n 个特征。

**Q3（实战）**：实际项目中如何用 Lasso 做特征选择？选出的特征如何用于下游模型？
**回答要点**：用 LassoCV 交叉验证确定最优 $\lambda$，提取非零系数对应的特征列；Lasso 选出的特征可直接用于线性模型，或作为特征子集输入非线性模型（树模型/神经网络）；注意：Lasso 在相关特征组中会随机选一个，若需要稳定选择可用 ElasticNet 或 Stability Selection。

**Q4（边界）**：L1 正则化的解在什么情况下不唯一？这在实际应用中有什么影响？
**回答要点**：当特征数 p 大于样本数 n，且存在特征高度相关时，L1 的惩罚项不是严格凸函数（在零点不可导），可能有多组同等最优的稀疏解；Lasso 随机选择一组，导致特征选择结果不稳定——重复运行可能选出不同特征集；解决方案：用 ElasticNet（加 L2 使问题严格凸）或 Bootstrap Lasso 取交集。
