# L1 正则化（Lasso）

## 定义

L1 正则化（Lasso）在损失函数中添加权重的绝对值之和作为惩罚项，产生稀疏解——不重要特征的权重被压为 0，天然实现**特征选择**。

设 $L_{\text{data}}$ 为原始数据损失项，$p$ 为特征数量，$w_j$ 为第 $j$ 个特征的权重：

$$
L_{\text{lasso}} = L_{\text{data}} + \lambda \sum_{j=1}^p |w_j| = L_{\text{data}} + \lambda \|\mathbf{w}\|_1
$$

其中 $\lambda$ 控制正则化强度： $\lambda$ 越大 → 权重越稀疏（更多特征被置零）， $\lambda$ 越小 → 保留更多特征。

## 核心公式

L1 在零点不可导，使用**软阈值**（Soft Thresholding）求解：

$$
\text{prox}_{\lambda}(w) = \text{sign}(w) \cdot \max(|w| - \lambda, 0)
$$

```python
from sklearn.linear_model import Lasso, LassoCV

# LassoCV自动用交叉验证选择最优alpha，同时产生稀疏解实现特征选择
lasso = LassoCV(alphas=[0.001, 0.01, 0.1, 1.0], cv=5)  # 在候选alpha上做5折交叉验证
lasso.fit(X_train, y_train)

print(f"非零系数数量: {np.sum(lasso.coef_ != 0)}")  # 统计系数中非零的个数，即被保留的特征数
```

## 几何解释

L1 的约束区域是**菱形**：

- 菱形有**尖角**落在坐标轴上
- 等高线更容易碰在尖角处 → 某维度权重 = 0
- 维度越高，尖角越多，稀疏性越强

```python
# L1约束的几何解释：权重向量必须落在菱形约束区域内
L1 约束：|w₁| + |w₂| ≤ t
菱形角点落在 (t,0) 和 (0,t)

角点上 w₁=0 或 w₂=0（等高线更容易碰在坐标轴尖角上，产生稀疏解）
```

## 特性总结

| 特性 | 说明 |
|------|------|
| 权重效果 | 压为 0（稀疏解） |
| 特征选择 | ✅ 天然特征选择 |
| 解的唯一性 | ⚠️ 高维时可能不唯一（非严格凸） |
| 相关特征处理 | 随机选一个保留 |
| 适用场景 | 高维稀疏数据、需要特征选择 |

## ML/DL 应用场景

| 应用场景 | 数学形式 | 说明 |
|----------|----------|------|
| 高维特征选择 | $\min \ |Xw-y\|^2 + \lambda\|w\|_1$ | $X$ 为特征矩阵，$y$ 为标签向量；基因组学、文本分类中从百万特征中选关键特征 |
| 稀疏编码 | $\min \ |x-D\alpha\|_2^2 + \lambda\|\alpha\|_1$ | $x$ 为输入信号，$D$ 为字典矩阵，$\alpha$ 为编码系数；字典学习中用 L1 约束编码系数稀疏性 |
| 图像去噪（TV 正则化） | $\min \ |x-y\|_2^2 + \lambda\|\nabla x\|_1$ | $x$ 为去噪后图像，$y$ 为含噪图像，$\nabla x$ 为图像梯度；在相邻像素差上施加 L1，保留边缘 |
| Lasso 回归 | sklearn `Lasso` / `LassoCV` | 线性模型特征选择 + 回归 |

## 面试追问

**Q1（基础）**：L1 正则化为什么能产生稀疏解？与 L2 有什么区别？
**回答要点**：

1. 几何角度：L1约束区域是菱形（有尖角），等高线更容易碰在坐标轴尖角上导致某维权重为0；L2约束区域是圆形（光滑），切点各维都非零。
2. 优化角度：L1的proximal operator具有软阈值（Soft Thresholding）效果，直接将小系数置零。
3. 贝叶斯角度：L1等价于给权重引入拉普拉斯先验（Laplace Prior），拉普拉斯分布在0处概率密度最大，促使权重趋向0。

**Q2（深挖）**：Lasso 在高维数据（p >> n，特征数远多于样本数）中最多能选出多少个特征？
**回答要点**：

1. 经典Lasso最多能选出n个非零特征（n为样本数），当p >> n时Lasso会饱和。
2. 饱和后继续增加λ不会进一步减少特征数，特征选择能力受限。
3. 弹性网（ElasticNet）通过加入L2正则化项突破此限制，可在p >> n时选出超过n个特征。

**Q3（实战）**：实际项目中如何用 Lasso 做特征选择？选出的特征如何用于下游模型？
**回答要点**：

1. 使用LassoCV交叉验证确定最优λ，提取非零系数对应的特征列作为选出的特征子集。
2. Lasso选出的特征可直接用于线性模型，或作为特征子集输入非线性模型（树模型/神经网络）。
3. Lasso在相关特征组中会随机选一个，若需要稳定特征选择可用ElasticNet或Stability Selection。

**Q4（边界）**：L1 正则化的解在什么情况下不唯一？这在实际应用中有什么影响？
**回答要点**：

1. L1惩罚项不是严格凸函数（在零点不可导），当p > n且特征高度相关时，可能存在多组同等最优的稀疏解。
2. Lasso随机选择一组解，导致特征选择结果不稳定——重复运行可能选出不同的特征集。
3. 解决方案：使用ElasticNet（加入L2正则化使目标函数严格凸）或Bootstrap Lasso取交集提高稳定性。
