# 线性回归

## 定义

线性回归（Linear Regression）假设目标值 $y$ 是特征 $X$ 的**线性组合**加上噪声，目标是找到最优的权重 $w$ 和偏置 $b$，得到预测值 $\hat{y}$：

$$
\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b = \mathbf{w}^T \mathbf{x} + b
$$

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 创建线性回归模型，假设目标值与特征之间存在线性关系
model = LinearRegression()
model.fit(X_train, y_train)  # 用训练数据学习最优权重 w 和偏置 b（最小二乘法）

y_pred = model.predict(X_test)  # 对测试集进行预测

print(f"系数: {model.coef_}")      # 每个特征的权重 w，表示该特征对预测值的影响大小
print(f"截距: {model.intercept_:.4f}")  # 偏置 b，即所有特征为0时的基准预测值
print(f"R²: {r2_score(y_test, y_pred):.4f}")  # 决定系数，衡量模型拟合优度，越接近1越好
```

## 损失函数

**MSE（均方误差）** 是最常用的损失函数：

$$
L(w) = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2 = \frac{1}{n} \| \mathbf{y} - X\mathbf{w} \|_2^2
$$

- $n$：样本数量
- $y_i$：第 $i$ 个样本的真实值
- $\hat{y}_i$：第 $i$ 个样本的预测值
- $\mathbf{y}$：所有样本真实值组成的向量

## 求解方法

| 方法 | 公式 | 复杂度 | 适用场景 | 说明 |
|------|------|:------:|----------|------|
| **正规方程** | $\mathbf{w} = (X^TX)^{-1}X^T\mathbf{y}$ | $O(n^3)$ | 小数据（ $n < 10^4$ ） | |
| **梯度下降** | $\mathbf{w} := \mathbf{w} - \eta \cdot \frac{1}{n} X^T(X\mathbf{w} - \mathbf{y})$ | $O(n)$ 每轮 | 大数据 | $\eta$：学习率 |

```python
# 梯度下降手动实现：通过迭代更新权重来最小化MSE损失
import numpy as np


def linear_regression_gd(X, y, lr=0.01, epochs=1000):
    """批量梯度下降求解线性回归，lr为学习率，epochs为迭代轮数"""

    m, n = X.shape

    w = np.zeros(n)  # 初始化权重为零向量

    b = 0            # 初始化偏置为零
    for _ in range(epochs):

        y_pred = X @ w + b          # 前向传播：计算当前预测值

        dw = (1/m) * X.T @ (y_pred - y)  # 权重梯度：损失对w的偏导

        db = (1/m) * np.sum(y_pred - y)  # 偏置梯度：损失对b的偏导

        w -= lr * dw                # 沿梯度负方向更新权重，减小损失

        b -= lr * db                # 沿梯度负方向更新偏置
    return w, b
```

## 多项式回归

将线性回归扩展到非线性关系：添加特征的幂次作为新特征。

```python
from sklearn.preprocessing import PolynomialFeatures

# 将原始特征扩展到指定次数的多项式特征（如 x → x, x², x³），捕捉非线性关系
poly = PolynomialFeatures(degree=3, include_bias=False)

X_poly = poly.fit_transform(X)         # 添加 x², x³ 等多项式特征


model = LinearRegression()
model.fit(X_poly, y)  # 在多项式特征上拟合线性回归，实现非线性拟合能力
```

## 假设与诊断

| 假设 | 违反时的影响 | 诊断方法 |
|------|-------------|----------|
| **线性关系** | 模型偏差大 | 残差 vs 预测值图（应随机分布） |
| **误差独立** | 系数估计不准 | Durbin-Watson 检验 |
| **同方差性** | 置信区间不准 | 残差图呈喇叭形 → 异方差 |
| **误差正态** | 小样本下推断不可靠 | Q-Q 图、Shapiro-Wilk 检验 |
| **无多重共线性** | 系数不稳定 | VIF（方差膨胀因子）> 10 需处理 |

## 面试追问

**Q1（基础）**：线性回归的基本原理是什么？它的数学表达式和损失函数分别是什么？
**回答要点**：

1. 线性回归假设目标值 y 是特征 X 的线性组合加上噪声，数学表达式为 ŷ = wᵀx + b
2. 使用 MSE（均方误差）作为损失函数：L(w) = 1/n Σ(yi - ŷi)²
3. 目标是找到最优权重 w 和偏置 b，使得预测值与真实值的平方误差最小化

**Q2（深挖）**：正规方程和梯度下降两种求解方式的区别是什么？各自适合什么场景？
**回答要点**：

1. 正规方程通过 w = (XᵀX)⁻¹Xᵀy 一步求解，复杂度 O(n³)，适合小数据（n < 10⁴）
2. 梯度下降迭代求解，每轮 O(n)，适合大数据场景
3. 正规方程在特征数大于样本数时 XᵀX 不可逆，需改用梯度下降或正则化

**Q3（实战）**：线性回归有哪些关键假设？如果违反会有什么后果？如何诊断？
**回答要点**：

1. 关键假设包括：线性关系、误差独立、同方差性、误差正态、无多重共线性
2. 线性关系被违反导致模型偏差大，多重共线性导致系数不稳定
3. 诊断方法包括残差 vs 预测值图（线性关系）、VIF > 10（多重共线性）、Q-Q 图（正态性）

**Q4（边界）**：多项式回归扩展了线性回归的非线性能力，但有什么风险？怎么处理？
**回答要点**：

1. 多项式回归本质仍是线性模型，只是添加了幂次特征
2. 风险在于高次多项式易在边界处剧烈震荡（Runge 现象），且容易严重过拟合
3. 缓解方法包括限制 degree、加正则化（Ridge/Lasso）、或换用非线性模型（树模型、SVM 等）
