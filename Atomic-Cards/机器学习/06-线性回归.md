# 线性回归

## 定义

线性回归（Linear Regression）假设目标值 $y$ 是特征 $X$ 的**线性组合**加上噪声，目标是找到最优的权重 $w$ 和偏置 $b$：

$$\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b = \mathbf{w}^T \mathbf{x} + b$$

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(f"系数: {model.coef_}")      # 每个特征的权重 w
print(f"截距: {model.intercept_:.4f}")  # 偏置 b
print(f"R²: {r2_score(y_test, y_pred):.4f}")
```

## 损失函数


**MSE（均方误差）** 是最常用的损失函数：

$$L(w) = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2 = \frac{1}{n} \| \mathbf{y} - X\mathbf{w} \|_2^2$$

## 求解方法

| 方法 | 公式 | 复杂度 | 适用场景 |
|------|------|:------:|----------|
| **正规方程** | $\mathbf{w} = (X^TX)^{-1}X^T\mathbf{y}$ | $O(n^3)$ | 小数据（$n < 10^4$） |
| **梯度下降** | $\mathbf{w} := \mathbf{w} - \eta \cdot \frac{1}{n} X^T(X\mathbf{w} - \mathbf{y})$ | $O(n)$ 每轮 | 大数据 |

```python
# 梯度下降手动实现
import numpy as np

def linear_regression_gd(X, y, lr=0.01, epochs=1000):
    m, n = X.shape
    w = np.zeros(n)
    b = 0
    for _ in range(epochs):
        y_pred = X @ w + b
        dw = (1/m) * X.T @ (y_pred - y)
        db = (1/m) * np.sum(y_pred - y)
        w -= lr * dw
        b -= lr * db
    return w, b
```

## 多项式回归

将线性回归扩展到非线性关系：添加特征的幂次作为新特征。

```python
from sklearn.preprocessing import PolynomialFeatures

poly = PolynomialFeatures(degree=3, include_bias=False)
X_poly = poly.fit_transform(X)        # 添加 x², x³ 等

model = LinearRegression()
model.fit(X_poly, y)
```

## 假设与诊断

| 假设 | 违反时的影响 | 诊断方法 |
|------|-------------|----------|
| **线性关系** | 模型偏差大 | 残差 vs 预测值图（应随机分布） |
| **误差独立** | 系数估计不准 | Durbin-Watson 检验 |
| **同方差性** | 置信区间不准 | 残差图呈喇叭形 → 异方差 |
| **误差正态** | 小样本下推断不可靠 | Q-Q 图、Shapiro-Wilk 检验 |
| **无多重共线性** | 系数不稳定 | VIF（方差膨胀因子）> 10 需处理 |
