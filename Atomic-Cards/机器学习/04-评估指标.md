# 评估指标

## 分类指标

### 混淆矩阵（Confusion Matrix）

| | 预测为正 | 预测为负 |
|--|:--------:|:--------:|
| **实际为正** | TP（真正例） | FN（假负例） |
| **实际为负** | FP（假正例） | TN（真负例） |

```python
from sklearn.metrics import confusion_matrix, classification_report

y_true = [0, 1, 0, 1, 1, 0]
y_pred = [0, 1, 0, 0, 1, 0]

print(confusion_matrix(y_true, y_pred))   # [[3 0]
                                            #  [1 2]]
print(classification_report(y_true, y_pred))
```

| 指标 | 公式 | 关注点 | 适用场景 |
|------|------|--------|----------|
| **准确率（Accuracy）** | $\frac{TP+TN}{TP+TN+FP+FN}$ | 整体正确率 | 类别平衡时 |
| **精确率（Precision）** | $\frac{TP}{TP+FP}$ | 查准率（预测为正的对了多少） | 垃圾邮件（误判代价高） |
| **召回率（Recall）** | $\frac{TP}{TP+FN}$ | 查全率（找出了多少正例） | 癌症筛查（漏诊代价高） |
| **F1 分数** | $2 \cdot \frac{P \cdot R}{P + R}$ | 精确率与召回率的调和平均 | 类别不平衡时首选 |
| **特异性（Specificity）** | $\frac{TN}{TN+FP}$ | 负类的识别率 | 医学诊断 |

### AUC-ROC

AUC（Area Under ROC Curve）衡量模型对正负类的区分能力：

- **AUC = 1.0**：完美分类器
- **AUC = 0.5**：随机猜测
- **AUC < 0.5**：还不如随机

```python
from sklearn.metrics import roc_auc_score, roc_curve

y_prob = model.predict_proba(X_test)[:, 1]
auc = roc_auc_score(y_test, y_prob)
print(f"AUC: {auc:.4f}")
```


## 回归指标

| 指标 | 公式 | 说明 | 取值范围 |
|------|------|------|:--------:|
| **MSE**（均方误差） | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | 大误差被放大（平方） | $[0, \infty)$ |
| **RMSE**（均方根误差） | $\sqrt{MSE}$ | 与 y 同量纲 | $[0, \infty)$ |
| **MAE**（平均绝对误差） | $\frac{1}{n}\sum\vert y_i - \hat{y}_i\vert$ | 直观易解释 | $[0, \infty)$ |
| **R²**（决定系数） | $1 - \frac{SS_{res}}{SS_{tot}}$ | 模型解释了多大比例的方差 | $(-\infty, 1]$ |

```python
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

y_true = [3.0, 2.5, 4.0, 3.5]
y_pred = [2.8, 2.7, 3.9, 3.6]

mse = mean_squared_error(y_true, y_pred)      # 0.0175
rmse = mse ** 0.5                              # 0.132
mae = mean_absolute_error(y_true, y_pred)      # 0.125
r2 = r2_score(y_true, y_pred)                  # 0.965（接近1，拟合良好）
```

## 聚类指标

| 指标 | 需要真实标签 | 说明 |
|------|:-----------:|------|
| **轮廓系数（Silhouette Score）** | ❌ | 衡量簇内紧密度 + 簇间分离度，$[-1,1]$ |
| **Calinski-Harabasz 指数** | ❌ | 簇间方差 / 簇内方差，越大越好 |
| **Davies-Bouldin 指数** | ❌ | 簇间相似度的均值，越小越好 |
| **调整兰德指数（ARI）** | ✅ | 与真实标签的聚类一致性 |
| **标准化互信息（NMI）** | ✅ | 聚类结果与真实标签的互信息 |

## 指标选择指南

| 场景 | 首选指标 | 原因 |
|------|----------|------|
| 类别平衡的分类 | Accuracy | 直观 |
| 类别不平衡（如 99:1） | F1、AUC、Precision-Recall | Accuracy 会虚高 |
| 癌症筛查 | Recall（召回率） | 漏诊不可接受 |
| 回归预测 | R² + RMSE | 组合评估 |
| 聚类无标签 | 轮廓系数 | 无需先验知识 |
