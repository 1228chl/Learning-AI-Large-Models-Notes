# 集成学习

## 定义

集成学习（Ensemble Learning）通过**组合多个弱学习器**（Weak Learners）来构建一个强学习器。核心逻辑：**三个臭皮匠，顶个诸葛亮**。

## 三大流派

| 流派 | 训练方式 | 目标 | 代表算法 | 示意图 |
|------|----------|------|----------|--------|
| **Bagging** | 并行训练，独立构建 | **降低方差** | 随机森林 | 各模型独立训练 → 平均/投票 |
| **Boosting** | 串行训练，逐步纠错 | **降低偏差** | AdaBoost、GBDT、XGBoost | 前一个的错误被下一个修正 |
| **Stacking** | 层级训练，元学习 | **结合不同模型优势** | 多层融合 | 基模型 → 元模型 |

## Bagging（Bootstrap Aggregating）

对训练数据进行**有放回采样**（Bootstrap）产生多个子集，每个子集训练一个模型：

```python
from sklearn.ensemble import BaggingClassifier
from sklearn.tree import DecisionTreeClassifier

bagging = BaggingClassifier(
    estimator=DecisionTreeClassifier(),
    n_estimators=100,               # 100 棵树
    max_samples=0.8,                # 每棵树用 80% 数据
    bootstrap=True,                 # 有放回采样
    oob_score=True                  # 袋外得分（等价于交叉验证）
)
bagging.fit(X_train, y_train)
print(f"OOB Score: {bagging.oob_score_:.4f}")
```

## Boosting

串行地训练多个弱学习器，每个新模型重点学习前一个模型的**错误样本**：

```python
from sklearn.ensemble import AdaBoostClassifier

ada = AdaBoostClassifier(
    estimator=DecisionTreeClassifier(max_depth=1),  # 弱学习器（树桩）
    n_estimators=100,
    learning_rate=1.0
)
ada.fit(X_train, y_train)
```

| 特点 | Bagging | Boosting |
|------|:-------:|:--------:|
| 训练方式 | 并行独立 | 串行依赖 |
| 主要降低 | 方差 | 偏差 |
| 过拟合风险 | 低 | 高（需早停/正则化） |
| 训练时间 | 可并行 | 无法并行 |
| 典型代表 | 随机森林 | XGBoost、LightGBM |

## Stacking（堆叠）

用多个不同基模型的输出作为新特征，训练一个**元模型**（Meta Model）：

```python
from sklearn.ensemble import StackingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC
from sklearn.ensemble import RandomForestClassifier

stacking = StackingClassifier(
    estimators=[
        ('lr', LogisticRegression()),
        ('rf', RandomForestClassifier()),
        ('svm', SVC(probability=True))
    ],
    final_estimator=LogisticRegression(),  # 元模型
    cv=5
)
stacking.fit(X_train, y_train)
```

## 集成为什么有效

| 条件 | 说明 |
|------|------|
| **准确性** | 每个基模型至少比随机好 |
| **多样性** | 基模型犯错方式不同 |
| 满足上述条件时，投票/平均的集成几乎**保证**优于单个模型 |

> **面试追问**
> 
> Q1（基础）：集成学习的三大流派（Bagging、Boosting、Stacking）在训练方式上有什么区别？
> 回答要点：Bagging 并行训练独立模型，通过平均/投票降低方差；Boosting 串行训练逐步纠错，新模型重点学习前一个模型的错误，主要降低偏差；Stacking 层级训练，用不同基模型的输出作为元模型的输入特征，结合不同模型优势。
> 
> Q2（深挖）：为什么 Bagging 能降低方差而 Boosting 能降低偏差？从偏差-方差角度解释。
> 回答要点：Bagging 对有放回采样多个子集训练模型后平均，各模型方差部分相互抵消，显著降低方差但偏差不变；Boosting 串行拟合残差，每次迭代都在减少偏差，但可能增加方差（容易过拟合）；所以随机森林不易过拟合，GBDT 需要更多正则化。
> 
> Q3（实战）：Stacking 相比 Bagging 和 Boosting 有什么额外风险？如何降低这些风险？
> 回答要点：Stacking 最大的风险是过拟合——如果用训练集预测结果训练元模型，会严重过拟合；解决方案：用 K 折交叉验证生成基模型的 out-of-fold 预测作为元模型输入特征（防止信息泄露），基模型要足够多样性（不同算法、不同超参数）。
> 
> Q4（边界）：集成学习生效需要满足什么条件？在什么情况下集成反而比单个模型差？
> 回答要点：两个必要条件：基模型至少比随机好（准确性）、基模型错误方式不同（多样性）；如果基模型高度相关（如同参数同数据的多棵树），集成效果几乎无提升；若某个基模型表现极差（不如随机），集成反而会被拖累。
