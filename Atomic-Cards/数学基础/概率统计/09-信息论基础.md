# 信息论基础

## 定义

信息论是研究信息量化、存储和通信的数学理论。在机器学习中，信息论为损失函数设计、模型评估和特征选择提供了核心理论工具。

**信息量**：事件 $x$ 发生的不确定性度量，概率越小信息量越大：

$$
I(x) = -\log_2 P(x)
$$

其中 $P(x)$ 为事件 $x$ 发生的概率，$\log_2$ 表示以 2 为底（单位为比特 bit），也可用自然对数 $\ln$（单位为纳特 nat）。

## 核心概念

### 信息熵

熵是信息量的期望，衡量一个概率分布的**不确定性**或**混乱程度**：

$$
H(X) = -\sum_{i=1}^{n} P(x_i) \log P(x_i)
$$

- 熵越大，不确定性越大（如均匀分布熵最大）
- 熵越小，确定性越大（如确定事件熵为 0）
- 分类任务中常用交叉熵作为损失函数，本质是衡量预测分布与真实分布的差异

### 交叉熵

用模型分布 $Q$ 编码真实分布 $P$ 所需的平均比特数：

$$
H(P, Q) = -\sum_{i} P(x_i) \log Q(x_i) = H(P) + D_{\text{KL}}(P \parallel Q)
$$

**这是分类任务中最常用的损失函数**。最小化交叉熵等价于最小化 KL 散度（因为 $H(P)$ 是常数）。

### KL 散度（相对熵）

衡量两个概率分布 $P$ 和 $Q$ 之间的差异：

$$
D_{\text{KL}}(P \parallel Q) = \sum_{i} P(x_i) \log \frac{P(x_i)}{Q(x_i)}
$$

性质：
- $D_{\text{KL}}(P \parallel Q) \geq 0$，当且仅当 $P=Q$ 时取等
- **非对称**：$D_{\text{KL}}(P \parallel Q) \neq D_{\text{KL}}(Q \parallel P)$
- 不是真正的距离度量（不满足对称性和三角不等式）

### 互信息

两个随机变量 $X$ 和 $Y$ 之间共享的信息量：

$$
I(X; Y) = \sum_{x,y} P(x,y) \log \frac{P(x,y)}{P(x)P(y)} = H(X) - H(X \mid Y)
$$

- 互信息为 0 表示 $X$ 和 $Y$ 独立
- 用于特征选择（选择与标签互信息最大的特征）
- 信息增益 = 互信息，是决策树分裂的依据

```python
import numpy as np
from scipy.special import kl_div, entr  # entr 计算 -p*log(p)，kl_div 计算 p*log(p/q)

# 两个概率分布
p = np.array([0.5, 0.3, 0.2])            # 真实分布 P
q = np.array([0.4, 0.4, 0.2])            # 模型预测分布 Q

# 信息熵 H(P)
entropy = -np.sum(p * np.log2(p))         # 熵：衡量 P 的不确定性程度
print(f"H(P) = {entropy:.4f} bits")       # H(P) = 1.4855 bits

# 交叉熵 H(P, Q)
cross_entropy = -np.sum(p * np.log2(q))  # 交叉熵：用 Q 编码 P 所需的比特数
print(f"H(P, Q) = {cross_entropy:.4f} bits")  # H(P, Q) = 1.5219 bits

# KL 散度 D_KL(P || Q)
kl = np.sum(p * np.log2(p / q))           # KL 散度 = 交叉熵 - 熵
print(f"D_KL(P||Q) = {kl:.4f} bits")      # D_KL(P||Q) = 0.0364 bits
# 验证：H(P,Q) = H(P) + D_KL(P||Q) = 1.4855 + 0.0364 = 1.5219 ✅
```

## 概念对比

| 概念 | 公式 | 范围 | 对称性 | 应用 |
|:-----|:-----|:----:|:------:|:-----|
| **信息熵** | $H(P) = -\sum P \log P$ | $[0, \log n]$ | — | 衡量不确定性 |
| **交叉熵** | $H(P,Q) = -\sum P \log Q$ | $[0, \infty)$ | 否 | 分类损失函数 |
| **KL 散度** | $D_{\text{KL}}(P\|Q) = \sum P \log (P/Q)$ | $[0, \infty)$ | 否 | 分布差异度量 |
| **互信息** | $I(X;Y) = H(X) - H(X\|Y)$ | $[0, \min(H(X),H(Y))]$ | **是** | 特征选择、关联分析 |

## ML/DL 应用场景

| 应用场景 | 数学形式 | 说明 |
|:---------|:---------|:------|
| 分类损失函数 | $\mathcal{L} = -\sum y_i \log \hat{y}_i$ | 交叉熵损失，分类任务的标准损失函数 |
| 决策树分裂 | $\text{Gain}(D, a) = H(D) - H(D \mid a)$ | 信息增益 = 互信息，ID3 算法的分裂依据 |
| KL 散度正则化 | $D_{\text{KL}}(q_\theta(z) \parallel p(z))$ | VAE 中约束隐变量分布接近先验 |
| 策略梯度 | $\nabla J = \mathbb{E}[\nabla \log \pi_\theta(a\|s) R]$ | 策略梯度中的 $\log \pi$ 来自信息论中的 score function |
| 知识蒸馏 | $\mathcal{L} = \alpha \cdot \text{CE}(y, \hat{y}_s) + \beta \cdot D_{\text{KL}}(p_t \parallel p_s)$ | 学生模型拟合教师模型的软标签分布 |

## 面试追问

**Q1（基础）**：熵、交叉熵、KL 散度的关系是什么？为什么分类任务用交叉熵而不用 MSE？
**回答要点**：

1. 交叉熵 = 熵 + KL 散度，即 $H(P, Q) = H(P) + D_{\text{KL}}(P \parallel Q)$。当真实分布 $P$ 固定时，最小化交叉熵等价于最小化 KL 散度。
2. MSE 对概率输出不敏感，梯度在输出接近 0 或 1 时饱和；交叉熵的梯度与预测误差成正比，收敛更快。
3. 从信息论视角：交叉熵衡量用模型分布 $Q$ 编码真实分布 $P$ 所需的额外比特数，最小化交叉熵即使模型分布逼近真实分布。

**Q2（深挖）**：KL 散度为什么不满足对称性？在机器学习中这种不对称性有什么实际意义？
**回答要点**：

1. $D_{\text{KL}}(P \parallel Q) = \sum P \log(P/Q)$ 以 $P$ 为权重求和，因此 $P$ 和 $Q$ 互换后权重不同，结果不同。
2. $D_{\text{KL}}(P \parallel Q)$（前向 KL）迫使 $Q$ 覆盖 $P$ 的所有高概率区域，倾向于产生"发散"的分布；$D_{\text{KL}}(Q \parallel P)$（反向 KL）迫使 $Q$ 集中在 $P$ 的某个高概率模式上，倾向于产生"集中"的分布。
3. 实际意义：VAE 使用反向 KL（$D_{\text{KL}}(q \parallel p)$，让 $q$ 集中在 $p$ 的一个模式上，生成清晰但多样性不足），而某些强化学习算法使用前向 KL 鼓励探索。

**Q3（实战）**：在知识蒸馏中，为什么用 KL 散度而不用交叉熵作为蒸馏损失？温度参数 T 的作用是什么？
**回答要点**：

1. KL 散度直接衡量两个分布之间的差异，且只关心相对差异；交叉熵会受到教师模型自身熵的影响。
2. 温度 T 软化 Softmax 输出：$q_i = \exp(z_i/T) / \sum \exp(z_j/T)$。T 越大，分布越平滑（类间相对关系更清晰），让学生模型学到更多"类别间相似性"信息。
3. T 太小退化为 one-hot（失去暗知识），T 太大分布过于均匀（失去区分度），通常取 T=2~8。

**Q4（边界）**：互信息在特征选择中相比相关系数有什么优势？计算互信息有什么难点？
**回答要点**：

1. 相关系数只能捕捉线性关系，互信息能捕捉**任意非线性关系**（如 $y = x^2$ 的平方关系，相关系数为 0 但互信息很大）。
2. 互信息对特征缩放不敏感（基于概率分布而非数值），适合混合类型特征。
3. 计算难点：连续变量的互信息估计需要密度估计或分箱（离散化），分箱数量影响结果稳定性；高维数据的互信息估计有偏，需要偏差校正。
