# TF-IDF 算法

## 定义

TF-IDF（Term Frequency-Inverse Document Frequency，词频-逆文档频率）是一种用于信息检索和文本挖掘的加权技术，用于评估一个词对一篇文档的重要程度。其核心思想是：**词在文档中频繁出现且在整个文档集合中罕见出现时，该词对文档具有较高的代表性**。

## TF（词频）

$$
TF(w_t, d_i) = \frac{c(w_t)}{c(d_i)}
$$

- $w_t$：第 $t$ 个词项（term），即待计算的词语
- $d_i$：第 $i$ 篇文档
- $c(w_t)$：词 $w_t$ 在文档 $d_i$ 中出现的次数
- $c(d_i)$：文档 $d_i$ 的总词数
- $TF(w_t, d_i)$：词 $w_t$ 在文档 $d_i$ 中的词频，值域为 $[0, 1]$

TF 衡量一个词在单篇文档中的出现频率。TF 越高，说明该词对这篇文档越重要。但仅用 TF 会有问题：常见词（如"的"、"是"）在所有文档中 TF 都很高，但缺乏区分度。

## IDF（逆文档频率）

$$
IDF(w_t) = \log \frac{N}{n_t + 1}
$$

- $N$：文档集合中的文档总数
- $n_t$：包含词 $w_t$ 的文档数量
- $n_t + 1$：加 1 防止分母为 0（当词在文档集合中未出现时）
- $IDF(w_t)$：词 $w_t$ 的逆文档频率，值越大说明该词越稀有、越有区分度

IDF 衡量一个词在整个文档集合中的稀有程度。词出现在越少的文档中，IDF 越高，说明该词具有越强的文档区分能力。

## TF-IDF

$$
TF\text{-}IDF(w_t, d_i) = TF(w_t, d_i) \times IDF(w_t)
$$

TF-IDF 是 TF 和 IDF 的乘积，同时考虑了词在文档内的频繁程度（TF）和词在整个集合中的稀有程度（IDF），两者的平衡使得常见词（高 TF 但低 IDF）被自动降权，而关键词（高 TF 且高 IDF）被突出。

## 核心思想

| 维度 | 描述 | 数学表现 |
|:-----|:-----|:---------|
| **词频高 → 重要** | 词在文档中频繁出现，说明是该文档的核心内容 | TF↑ |
| **文档频次低 → 有区分度** | 词在很少文档中出现，说明能有效区分不同文档 | IDF↑ |
| **两者结合 → 关键词** | 高频出现在本文档 + 低频出现在其他文档 = 真正的关键词 | TF × IDF↑ |
| **自动过滤常见词** | 停用词（"的"、"是"、"在"）虽然 TF 高，但 IDF 接近 0，被降权 | TF-IDF ≈ 0 |

## TF-IDF 计算举例

设有 3 篇文档（已分词）：

- D1 = ["我", "喜欢", "看", "篮球", "比赛"]
- D2 = ["我", "喜欢", "看", "足球", "比赛"]
- D3 = ["篮球", "和", "足球", "都", "是", "有趣", "的", "体育", "运动"]

**词汇表**（全部 13 个唯一词）：["我", "喜欢", "看", "篮球", "比赛", "足球", "和", "都", "是", "有趣", "的", "体育", "运动"]

**IDF 计算**（N = 3）：

| 词 | $n_t$（包含文档数） | $IDF = \log(N/(n_t+1))$ |
|:---|:------------------:|:------------------------:|
| "我" | 2 | $\log(3/3) = 0$ |
| "喜欢" | 2 | $\log(3/3) = 0$ |
| "看" | 2 | $\log(3/3) = 0$ |
| "篮球" | 2 | $\log(3/3) = 0$ |
| "比赛" | 2 | $\log(3/3) = 0$ |
| "足球" | 2 | $\log(3/3) = 0$ |
| "和" | 1 | $\log(3/2) \approx 0.405$ |
| "都" | 1 | $\log(3/2) \approx 0.405$ |
| "是" | 1 | $\log(3/2) \approx 0.405$ |
| "有趣" | 1 | $\log(3/2) \approx 0.405$ |
| "的" | 1 | $\log(3/2) \approx 0.405$ |
| "体育" | 1 | $\log(3/2) \approx 0.405$ |
| "运动" | 1 | $\log(3/2) \approx 0.405$ |

> 说明：出现在 2/3 文档中的词（"我"、"篮球"等）IDF = 0，表明这些词是文档之间的共现词，没有区分能力；仅出现在 1 篇文档中的词（"体育"、"运动"等）具有非零 IDF，能够区分不同文档。

**TF-IDF 向量化结果**（每篇文档映射为 13 维向量）：

| 词 | D1 (TF-IDF) | D2 (TF-IDF) | D3 (TF-IDF) |
|:---|:-----------:|:-----------:|:-----------:|
| "我" | $1/5 \times 0 = 0$ | $1/5 \times 0 = 0$ | 0 |
| "喜欢" | $1/5 \times 0 = 0$ | $1/5 \times 0 = 0$ | 0 |
| "看" | $1/5 \times 0 = 0$ | $1/5 \times 0 = 0$ | 0 |
| "篮球" | $1/5 \times 0 = 0$ | 0 | $1/9 \times 0 = 0$ |
| "比赛" | $1/5 \times 0 = 0$ | $1/5 \times 0 = 0$ | 0 |
| "足球" | 0 | $1/5 \times 0 = 0$ | $1/9 \times 0 = 0$ |
| "和" | 0 | 0 | $1/9 \times 0.405 \approx 0.045$ |
| "都" | 0 | 0 | $1/9 \times 0.405 \approx 0.045$ |
| "是" | 0 | 0 | $1/9 \times 0.405 \approx 0.045$ |
| "有趣" | 0 | 0 | $1/9 \times 0.405 \approx 0.045$ |
| "的" | 0 | 0 | $1/9 \times 0.405 \approx 0.045$ |
| "体育" | 0 | 0 | $1/9 \times 0.405 \approx 0.045$ |
| "运动" | 0 | 0 | $1/9 \times 0.405 \approx 0.045$ |

> **结果分析**：D1 与 D2 的 TF-IDF 向量完全相同（都是零向量），因为它们包含的词汇完全重合；D3 因包含大量独特词（体育、运动等），其向量在对应维度上有非零值。通过 TF-IDF 向量化，文档被表示为固定长度的数值向量，可直接用于计算文档间的余弦相似度。

## TF-IDF 与 BM25 的关系

TF-IDF 是 BM25 的基础。BM25 在 TF-IDF 的基础上引入了两项关键改进：

| 对比维度 | TF-IDF | BM25 |
|:---------|:-------|:-----|
| **TF 项** | 线性增长（TF↑则 TF-IDF↑） | 词频饱和（TF 达到阈值后不再增加） |
| **长度归一化** | 无 | 引入文档长度归一化因子 |
| **可调参数** | 无 | $k_1$（词频饱和参数）、$b$（长度归一化参数） |
| **效果** | 基础加权方案 | 工业级检索标准算法 |

## ML/DL 应用场景

| 应用场景 | 数学形式 | 说明 |
|:---------|:---------|:-----|
| **RAG 稀疏检索** | $\text{score}(q, d) = \sum_{w \in q} TF\text{-}IDF(w, d)$ | 将查询词的 TF-IDF 求和作为文档相关性得分，是混合检索中稀疏向量的基础 |
| **关键词提取** | $\text{keyword}(d) = \arg\max_{w \in d} TF\text{-}IDF(w, d)$ | 选取文档中 TF-IDF 最高的 Top-K 词作为关键词 |
| **文本相似度** | $\text{sim}(d_i, d_j) = \cos(v_i, v_j)$ | 将文档映射为 TF-IDF 向量后计算余弦相似度，衡量文档间的相似程度 |
| **文本分类特征** | $x_d = [TF\text{-}IDF(w_1,d), \dots, TF\text{-}IDF(w_m,d)]$ | 将 TF-IDF 向量作为传统机器学习分类器（SVM、朴素贝叶斯）的输入特征 |

## 面试追问

**Q1（基础）**：TF-IDF 中的 TF 和 IDF 各自衡量什么？为什么需要两者相乘而不是只用其中一个？
**回答要点**：

1. TF（词频）衡量一个词在单篇文档中的出现频率，词出现越多越能代表该文档内容。
2. IDF（逆文档频率）衡量一个词在整个文档集合中的稀有程度，词出现在越少文档中越有区分度。
3. 只用 TF 的问题：常见词（"的"、"是"）在所有文档中 TF 都很高，无法区分文档；只用 IDF 的问题：稀有词可能只在文档中出现一次，无法代表文档内容。两者相乘取长补短，高 TF + 高 IDF 才被标记为关键词。

**Q2（深挖）**：TF-IDF 计算公式中 IDF 的分母为什么要加 1（$n_t + 1$）？如果不加 1 会有什么问题？
**回答要点**：

1. 加 1 是为了防止除零错误。当一个词在文档集合中从未出现时（$n_t = 0$），$N/0$ 无定义。
2. 在检索场景中，用户查询词可能包含知识库中没有的词（如拼写错误、全新术语），加 1 确保这种情况下 IDF 仍然有定义且为最大值。
3. 平滑处理使 IDF 值不会趋于无穷大，保持了数值稳定性，确保与其他词的 IDF 在可比范围内。

**Q3（实战）**：在 RAG 系统中，如何使用 TF-IDF 实现文档检索？它与稠密向量检索相比有什么优劣势？
**回答要点**：

1. 实现：将知识库每篇文档计算 TF-IDF 向量并建立倒排索引，用户查询时计算查询词的 TF-IDF 向量，通过余弦相似度找到最相似的文档。
2. 优势：精确匹配关键词（专业术语、缩写），可解释性强（能明确知道是哪个词匹配上了），计算资源需求低。
3. 劣势：无法处理同义词和近义表达（"汽车"和"车"被视为不同词），忽略语义上下文，无法理解深层语义关系。
4. 在 RAG 混合检索中，TF-IDF 通常作为稀疏检索分支与稠密语义检索分支互补使用。

**Q4（边界）**：TF-IDF 有哪些已知的局限性？在实际应用中有哪些改进方案？
**回答要点**：

1. TF 线性增长问题：一个词在文档中出现 10 次的重要性并非出现 1 次的 10 倍——出现几次后就达到饱和。改进方案：BM25 引入词频饱和参数 $k_1$ 限制 TF 的无限增长。
2. 忽略文档长度：长文档天然有更高的 TF，短文档的关键词被低估。改进方案：BM25 引入长度归一化参数 $b$。
3. 词汇表外词问题：新词、拼写错误无法匹配。改进方案：结合子词嵌入或稠密向量做语义回退。
4. 无法捕捉语义相似性："电脑"和"计算机"虽然同义但 TF-IDF 视作不同词。改进方案：混合检索中同时使用 TF-IDF 稀疏向量和稠密语义向量。
