# 深度卡片：线性回归（机器学习的起点）

## L1：是什么（定义/公式/结构）

### 严谨定义
线性回归是一种参数化监督学习算法，假设目标变量 $y$ 与特征向量 $\mathbf{x}$ 之间存在线性关系 $y = \mathbf{w}^T\mathbf{x} + b + \epsilon$（$\epsilon \sim N(0, \sigma^2)$ 是高斯噪声），通过最小化经验均方误差 $\hat{R}(\mathbf{w}) = \frac{1}{n}\sum_{i=1}^n (y_i - \mathbf{w}^T\mathbf{x}_i - b)^2$ 估计参数 $\mathbf{w}^*$ 和 $b^*$。

### 核心公式

| 公式 | 名称 | 用途 |
|------|------|------|
| $\hat{y} = \mathbf{w}^T\mathbf{x} + b$ | 假设函数 | 预测 |
| $J(\mathbf{w}) = \frac{1}{2n}\|\mathbf{y} - X\mathbf{w}\|^2$ | 损失函数（MSE） | 衡量误差 |
| $\mathbf{w}^* = (X^TX)^{-1}X^T\mathbf{y}$ | 正规方程 | 闭式解 |
| $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla J$ | 梯度下降 | 迭代优化 |

### 三种视角

| 视角 | 核心思想 | 数学基础 |
|------|----------|----------|
| **概率视角** | 最大似然估计（高斯噪声假设） | 对数似然 |
| **优化视角** | 最小化凸二次函数 | 正规方程/梯度下降 |
| **几何视角** | 正交投影到列空间 | 投影矩阵 |

## L2：为什么（设计意图/解决什么问题）

### 为什么需要线性回归？

**问题1：如何预测连续值？**

房价预测、温度预测、销售额预测等任务需要输出连续数值。线性回归是最简单的回归模型，提供了：
- 清晰的数学公式
- 系数的可解释性（每增加一个单位，目标变化多少）
- 快速的训练和推理

**问题2：作为复杂模型的基线**

线性回归是所有回归模型的基线：
- 如果线性回归效果好，说明数据本身是线性的
- 如果线性回归效果差，说明需要非线性模型
- 复杂模型应该显著优于线性回归才有价值

**问题3：可解释性需求**

在金融、医疗等领域，模型决策需要可解释。线性回归的系数 $w_j$ 直接解释为：
- $w_j > 0$：特征 $x_j$ 增加时，目标 $y$ 增加
- $w_j < 0$：特征 $x_j$ 增加时，目标 $y$ 减少
- $|w_j|$ 越大，影响越强

### 最小二乘法的概率论基础

假设噪声 $\epsilon \sim N(0, \sigma^2)$，则：
$$P(y|\mathbf{x}, \mathbf{w}) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(y - \mathbf{w}^T\mathbf{x})^2}{2\sigma^2}\right)$$

最大似然估计：
$$\mathbf{w}_{MLE} = \arg\max_{\mathbf{w}} \prod_{i=1}^n P(y_i|\mathbf{x}_i, \mathbf{w})$$

取对数后等价于最小化MSE：
$$\mathbf{w}_{MLE} = \arg\min_{\mathbf{w}} \sum_{i=1}^n (y_i - \mathbf{w}^T\mathbf{x}_i)^2$$

## L3：怎么用（代码实现/调参/场景）

### sklearn实现

```python
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score

# 准备数据
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 训练模型
model = LinearRegression()
model.fit(X_train, y_train)

# 查看参数
print(f"系数: {model.coef_}")
print(f"截距: {model.intercept_}")

# 预测
y_pred = model.predict(X_test)

# 评估
mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)
print(f"MSE: {mse:.4f}, R²: {r2:.4f}")
```

### 正则化版本

```python
from sklearn.linear_model import Ridge, Lasso

# Ridge回归（L2正则化）
ridge = Ridge(alpha=1.0)
ridge.fit(X_train, y_train)

# Lasso回归（L1正则化）
lasso = Lasso(alpha=0.1)
lasso.fit(X_train, y_train)
```

## L4：坑在哪（边界条件/失效场景/常见误解）

### 常见误解

| 误解 | 正确理解 | 后果 |
|------|----------|------|
| "线性回归只能处理线性关系" | 可以通过特征工程引入非线性 | 错误放弃线性模型 |
| "系数越大越重要" | 系数大小受特征尺度影响 | 需要标准化后比较 |
| "R²高就是好模型" | 可能过拟合 | 需要交叉验证 |

### 边界条件

**1. 多重共线性**

当特征之间高度相关时（如面积和房间数），$X^TX$ 接近奇异，系数估计不稳定。

**诊断**：方差膨胀因子（VIF）> 10
**解决**：删除冗余特征、使用Ridge回归、PCA降维

**2. 异常值敏感**

MSE对异常值敏感（平方放大误差）。一个极端异常值可能严重扭曲拟合结果。

**解决**：使用Huber回归（对异常值鲁棒）、数据清洗

**3. 非线性关系**

如果真实关系是非线性的，线性回归会系统性偏差。

**诊断**：残差图呈现明显模式（如U型、周期性）
**解决**：添加多项式特征、使用非线性模型

### 面试常见陷阱

**Q：线性回归的正规方程有什么缺点？**

**正确回答**：
1. 需要计算 $(X^TX)^{-1}$，复杂度 $O(n^3)$，当特征数 $n$ 很大时不可行
2. 如果 $X^TX$ 不可逆（奇异矩阵），无法求解
3. 只适用于离线训练，无法增量学习
4. 对多重共线性敏感

**替代方案**：梯度下降（$O(n)$ 每步）、SGD（在线学习）、正则化（处理共线性）

**Q：如何判断线性回归是否适用？**

**正确回答**：
1. **残差分析**：残差应随机分布（无模式），否则说明模型miss了非线性关系
2. **线性假设检验**：添加多项式特征后看是否显著提升
3. **特征与目标的散点图**：直观判断线性关系
4. **基线比较**：线性回归应该是最简单的基线，复杂模型应显著优于它

## 💼 面试追问树

### Q1（基础）：解释线性回归的假设和损失函数

**回答要点**：
1. 假设：$y = \mathbf{w}^T\mathbf{x} + b + \epsilon$，$\epsilon \sim N(0, \sigma^2)$
2. 损失函数：MSE = $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$
3. 等价于高斯噪声下的最大似然估计
4. 最小化MSE等价于最大似然

### Q2（深挖）：线性回归的正规方程和梯度下降有什么区别？

**回答要点**：
1. **正规方程**：闭式解，一次性求解，$O(n^3)$，需要矩阵可逆
2. **梯度下降**：迭代优化，$O(n)$ 每步，适合大规模数据
3. **选择依据**：特征少（<10000）用正规方程，特征多用梯度下降
4. **实际中**：sklearn用正规方程，深度学习用梯度下降

### Q3（更深）：如何处理线性回归的多重共线性？

**回答要点**：
1. **诊断**：计算VIF，VIF>10表示严重共线性
2. **删除冗余特征**：相关系数>0.9的特征删除一个
3. **Ridge回归**：L2正则化稳定系数估计
4. **PCA降维**：将相关特征转换为不相关的主成分
5. **业务理解**：有时共线性是业务固有的（如面积和房间数），保留一个即可

### Q4（边界）：线性回归什么时候会失效？

**回答要点**：
1. **非线性关系**：残差呈现明显模式 → 添加多项式特征或使用非线性模型
2. **异常值**：MSE对异常值敏感 → 使用Huber回归
3. **多重共线性**：系数估计不稳定 → 使用Ridge回归
4. **异方差**：残差方差不恒定 → 使用加权最小二乘
5. **小样本**：过拟合风险 → 使用正则化
