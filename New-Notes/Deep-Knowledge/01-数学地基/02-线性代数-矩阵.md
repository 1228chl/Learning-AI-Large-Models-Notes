# 深度卡片：矩阵（线性代数核心）

## L1：是什么（定义/公式/结构）

### 严谨定义

矩阵是按照矩形阵列排列的 $m \times n$ 个标量组成的数学对象 $A \in \mathbb{R}^{m \times n}$，其中 $m$ 是行数，$n$ 是列数。矩阵是线性变换的数值表示，在机器学习中用于存储模型参数、表示数据特征、执行线性变换。

### 核心运算

| 运算 | 公式 | 复杂度 | ML应用 |
|------|------|--------|--------|
| 矩阵乘法 | $C_{ij} = \sum_k A_{ik}B_{kj}$ | $O(mnk)$ | 神经网络前向传播 |
| 转置 | $(A^T)_{ij} = A_{ji}$ | $O(mn)$ | 注意力计算 |
| 逆矩阵 | $AA^{-1} = I$ | $O(n^3)$ | 正规方程求解 |
| 行列式 | $\det(A) = \sum_{\sigma} \text{sgn}(\sigma)\prod_i A_{i,\sigma(i)}$ | $O(n!)$ | 可逆性判断 |
| 特征值分解 | $A = Q\Lambda Q^{-1}$ | $O(n^3)$ | PCA、谱聚类 |

### 特殊矩阵类型

| 类型 | 定义 | 性质 | ML应用 |
|------|------|------|--------|
| 对称矩阵 | $A = A^T$ | 特征值为实数 | 协方差矩阵、Hessian |
| 正交矩阵 | $A^TA = I$ | $A^{-1} = A^T$ | 旋转、PCA |
| 对角矩阵 | $a_{ij} = 0, i \neq j$ | 特征值在对角线 | 缩放、BatchNorm |
| 稀疏矩阵 | 大部分元素为0 | 存储高效 | NLP的one-hot |
| 半正定矩阵 | $\mathbf{x}^TA\mathbf{x} \geq 0$ | 特征值≥0 | 协方差矩阵、核矩阵 |

## L2：为什么（设计意图/解决什么问题）

### 为什么需要矩阵？

**问题1：如何批量处理数据？**

假设有1000个样本，每个样本有100个特征。如果用向量逐个处理，需要1000次循环。将数据组织成矩阵 $X \in \mathbb{R}^{1000 \times 100}$，可以通过一次矩阵乘法 $Y = XW + \mathbf{b}$ 批量处理所有样本。

**问题2：如何表示线性变换？**

神经网络的每一层是线性变换 $\mathbf{y} = W\mathbf{x} + \mathbf{b}$，其中 $W$ 是权重矩阵。矩阵乘法实现了从输入空间到输出空间的映射：

- 输入：$\mathbf{x} \in \mathbb{R}^{d_{in}}$
- 权重：$W \in \mathbb{R}^{d_{out} \times d_{in}}$
- 输出：$\mathbf{y} = W\mathbf{x} \in \mathbb{R}^{d_{out}}$

**问题3：如何同时存储多个向量？**

词嵌入矩阵 $E \in \mathbb{R}^{|V| \times d}$ 将整个词汇表的词向量存储在一个矩阵中，通过索引 $E[i]$ 快速获取第 $i$ 个词的向量。

### 矩阵乘法的深层含义

**几何意义**：矩阵乘法是线性变换的组合。两个矩阵相乘 $C = AB$ 表示先做变换 $B$ 再做变换 $A$。

**计算意义**：矩阵乘法将多层线性变换串联起来：

$$
\mathbf{y} = W_L(W_{L-1}(...(W_1\mathbf{x} + \mathbf{b}_1)...) + \mathbf{b}_{L-1}) + \mathbf{b}_L
$$

**优化意义**：GPU的SIMD（单指令多数据）架构天然适合矩阵乘法，可以并行计算所有元素。

## L3：怎么用（代码实现/调参/场景）

### NumPy实现

```python
import numpy as np

# 创建矩阵
A = np.array([[1, 2], [3, 4]])  # 2x2矩阵
B = np.array([[5, 6], [7, 8]])

# 矩阵乘法
C = np.dot(A, B)  # 或 A @ B
# C = [[19, 22], [43, 50]]

# 转置
A_T = A.T  # [[1, 3], [2, 4]]

# 逆矩阵（如果存在）
A_inv = np.linalg.inv(A)

# 特征值分解
eigenvalues, eigenvectors = np.linalg.eig(A)

# SVD分解
U, S, VT = np.linalg.svd(A)
```

### PyTorch实现

```python
import torch

# 创建矩阵
A = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
B = torch.tensor([[5.0, 6.0], [7.0, 8.0]])

# 矩阵乘法
C = torch.mm(A, B)  # 或 torch.matmul(A, B) 或 A @ B

# 批量矩阵乘法（Batch Matrix Multiply）
batch_A = torch.randn(32, 128, 64)  # batch_size=32
batch_B = torch.randn(32, 64, 256)
batch_C = torch.bmm(batch_A, batch_B)  # (32, 128, 256)
```

### 实际应用场景

| 场景 | 矩阵表示 | 运算 |
|------|----------|------|
| 神经网络层 | 权重矩阵 $W$ | $Y = XW + \mathbf{b}$ |

## L4：坑在哪（边界条件/失效场景/常见误解）

### 常见误解

| 误解 | 正确理解 | 后果 |
|------|----------|------|
| "矩阵乘法满足交换律" | $AB \neq BA$（一般情况） | 注意力计算顺序不能随意交换 |
| "所有矩阵都可逆" | 只有方阵且行列式≠0才可逆 | 奇异矩阵会导致求解失败 |
| "矩阵乘法可以并行" | 行和列的计算可以并行，但依赖链存在 | GPU加速有上限 |

### 边界条件

**1. 矩阵乘法的计算复杂度**

朴素矩阵乘法复杂度为 $O(mnk)$，对于大矩阵（如 $n > 10000$）计算成本很高：

- Transformer的注意力矩阵：$O(n^2d)$，n是序列长度
- 全连接层：$O(d_{in} \cdot d_{out})$

**优化方法**：

- 分块矩阵乘法（提高缓存命中率）
- Strassen算法（$O(n^{2.807})$）
- 混合精度训练（FP16加速）

**2. 数值稳定性问题**

- **病态矩阵**：条件数 $\kappa(A) = \frac{\sigma_{max}}{\sigma_{min}}$ 很大时，求逆会放大数值误差
- **奇异矩阵**：行列式为0，不可逆
- **浮点精度**：大数+小数可能丢失精度

**处理方法**：

- 使用伪逆（Moore-Penrose伪逆）
- 添加正则化项（岭回归）
- 使用SVD分解而非直接求逆

**3. 内存限制**

大矩阵可能超出GPU内存：

- 注意力矩阵：序列长度1024，头数8，维度64 → $1024 \times 1024 \times 8 \times 64$ 浮点数
- 全连接层：输入4096，输出4096 → $4096 \times 4096$ 浮点数

**处理方法**：

- 梯度检查点（用计算换内存）
- 模型并行（矩阵分片到多个GPU）
- 混合精度（FP16减少内存）

### 面试常见陷阱

**Q：为什么Transformer的注意力计算复杂度是O(n²)？**

**正确回答**：

1. Q, K, V矩阵的维度是 $n \times d$（n是序列长度，d是维度）
2. 注意力分数计算：$QK^T$ 是 $n \times n$ 矩阵
3. softmax对每个查询独立计算，复杂度 $O(n^2)$
4. 加权求和：$n \times n$ 矩阵乘以 $n \times d$ 矩阵，复杂度 $O(n^2d)$
5. 因此总复杂度是 $O(n^2d)$，当 $n > d$ 时主要瓶颈是 $O(n^2)$

**Q：如何加速大矩阵乘法？**

**正确回答**：

1. **硬件层面**：使用GPU的Tensor Core（专门的矩阵乘法加速单元）
2. **算法层面**：分块矩阵乘法（提高缓存命中率）、Strassen算法
3. **精度层面**：混合精度训练（FP16），计算量减半
4. **架构层面**：稀疏矩阵（只计算非零元素）、低秩近似（SVD分解）

## 💼 面试追问树

### Q1（基础）：矩阵乘法的时间复杂度是多少？为什么？

**回答要点**：

1. 朴素算法：$O(mnk)$，m是A的行数，k是公共维度，n是B的列数
2. 原因：每个元素 $C_{ij}$ 需要k次乘法和k-1次加法
3. 总共有 $m \times n$ 个元素
4. 优化算法：Strassen $O(n^{2.807})$，但常数大，实际不常用

### Q2（深挖）：为什么Transformer中要用矩阵乘法计算注意力？

**回答要点**：

1. 并行计算：矩阵乘法可以一次性计算所有查询-键对的相似度
2. GPU加速：矩阵乘法是GPU最擅长的操作
3. 数学等价：$\text{Attention}(Q,K,V) = \text{softmax}(QK^T/\sqrt{d})V$ 可以分解为三次矩阵乘法
4. 如果用循环实现，复杂度相同但无法利用GPU并行

### Q3（更深）：如何处理大矩阵的内存问题？

**回答要点**：

1. 梯度检查点：前向传播时只保存部分中间结果，反向传播时重新计算
2. 模型并行：将矩阵分片到多个GPU
3. 混合精度：使用FP16而非FP32，内存减半
4. 稀疏矩阵：只存储非零元素
5. 低秩近似：通过SVD将大矩阵分解为小矩阵

### Q4（边界）：什么情况下矩阵乘法会出问题？

**回答要点**：

1. 病态矩阵：条件数很大，求逆会放大误差 → 使用正则化
2. 奇异矩阵：行列式为0，不可逆 → 使用伪逆或SVD
3. 数值溢出：大数相乘超出浮点范围 → 使用对数空间或归一化
4. 内存溢出：矩阵太大超出GPU内存 → 使用分块或并行
