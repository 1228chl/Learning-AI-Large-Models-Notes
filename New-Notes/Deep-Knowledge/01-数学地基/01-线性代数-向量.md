# 深度卡片：向量（线性代数基础）

## L1：是什么（定义/公式/结构）

### 严谨定义
向量是线性空间中的基本元素，定义为一组有序的标量集合 $\mathbf{v} = [v_1, v_2, ..., v_n]^T \in \mathbb{R}^n$，可以表示空间中的一个点、一个方向或一个位移，是机器学习中特征表示、参数存储和梯度计算的数学基础。

### 核心公式

| 运算 | 公式 | 几何意义 |
|------|------|----------|
| 加法 | $\mathbf{u} + \mathbf{v} = [u_1+v_1, ..., u_n+v_n]^T$ | 平行四边形法则 |
| 标量乘法 | $\alpha\mathbf{v} = [\alpha v_1, ..., \alpha v_n]^T$ | 缩放方向 |
| 点积 | $\mathbf{u} \cdot \mathbf{v} = \sum_{i=1}^n u_i v_i = \|\mathbf{u}\|\|\mathbf{v}\|\cos\theta$ | 投影长度 |
| 范数 | $\|\mathbf{v}\|_p = (\sum_{i=1}^n |v_i|^p)^{1/p}$ | 向量长度/大小 |

### 向量空间的关键概念

| 概念 | 定义 | 重要性 |
|------|------|--------|
| 线性无关 | 任意向量不能被其他向量线性表示 | 基底选择 |
| 基底 | 线性无关且张成整个空间的向量组 | 坐标系 |
| 维度 | 基底中向量的个数 | 空间大小 |
| 子空间 | 对加法和标量乘法封闭的子集 | 降维基础 |

## L2：为什么（设计意图/解决什么问题）

### 为什么需要向量？

**问题1：如何表示高维数据？**

一张 $28 \times 28$ 的灰度图像有784个像素，每个像素是一个数值。如果用784个独立变量表示，无法进行统一的数学运算。向量将这784个数值组织成一个整体 $\mathbf{x} \in \mathbb{R}^{784}$，使得：
- 可以进行批量计算（矩阵乘法）
- 可以定义距离（范数）
- 可以进行线性变换（矩阵乘法）

**问题2：如何衡量相似性？**

"猫"和"狗"的图像在像素空间中哪个更相似？通过将图像表示为向量，可以计算余弦相似度：
$$\text{sim}(\mathbf{x}_{\text{猫}}, \mathbf{x}_{\text{狗}}) = \frac{\mathbf{x}_{\text{猫}} \cdot \mathbf{x}_{\text{狗}}}{\|\mathbf{x}_{\text{猫}}\| \|\mathbf{x}_{\text{狗}}\|}$$

**问题3：如何进行线性变换？**

神经网络的每一层本质上是一个线性变换 $\mathbf{y} = W\mathbf{x} + \mathbf{b}$，其中 $W$ 是权重矩阵，$\mathbf{x}$ 是输入向量。向量是理解这一变换的基础。

### 向量在ML中的核心作用

| 作用 | 具体应用 | 示例 |
|------|----------|------|
| **特征表示** | 将原始数据编码为数值向量 | 词向量、图像特征 |
| **参数存储** | 将模型参数组织为向量/矩阵 | 权重向量、偏置向量 |
| **梯度表示** | 将参数更新方向表示为向量 | 梯度向量 |
| **相似度计算** | 衡量两个样本的相似程度 | 余弦相似度、欧氏距离 |

## L3：怎么用（代码实现/调参/场景）

### NumPy实现

```python
import numpy as np

# 创建向量
v1 = np.array([1, 2, 3])  # 一维数组
v2 = np.array([4, 5, 6])

# 向量运算
addition = v1 + v2           # [5, 7, 9]
scalar_mult = 2 * v1         # [2, 4, 6]
dot_product = np.dot(v1, v2) # 32 = 1*4 + 2*5 + 3*6
norm = np.linalg.norm(v1)    # 3.74 = sqrt(1+4+9)

# 余弦相似度
cosine_sim = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
```

### PyTorch实现

```python
import torch

# 创建向量（1D张量）
v1 = torch.tensor([1.0, 2.0, 3.0])
v2 = torch.tensor([4.0, 5.0, 6.0])

# 向量运算
dot_product = torch.dot(v1, v2)  # tensor(32.)
norm = torch.norm(v1)            # tensor(3.7417)
cosine_sim = torch.nn.functional.cosine_similarity(v1.unsqueeze(0), v2.unsqueeze(0))
```

### 实际应用场景

| 场景 | 向量表示 | 相似度度量 |
|------|----------|------------|
| 文本分类 | TF-IDF向量、词向量 | 余弦相似度 |
| 图像检索 | CNN特征向量 | 欧氏距离 |
| 推荐系统 | 用户/物品嵌入向量 | 内积 |
| 语音识别 | MFCC特征向量 | 动态时间规整 |

## L4：坑在哪（边界条件/失效场景/常见误解）

### 常见误解

| 误解 | 正确理解 | 为什么重要 |
|------|----------|------------|
| "向量就是一维数组" | 向量是线性空间的元素，有特定的运算规则 | 理解向量空间的结构 |
| "点积就是向量乘法" | 点积是内积的一种，结果是标量；向量乘法还有外积等 | 避免混淆不同运算 |
| "范数越大向量越重要" | 范数只表示大小，不表示重要性；归一化后范数为1 | 避免特征尺度问题 |

### 边界条件

**1. 高维向量的维度灾难**

当向量维度 $d$ 很大时（如 $d > 1000$）：
- 计算成本：点积从 $O(n)$ 变为 $O(d)$，高维时显著
- 存储成本：每个样本需要 $d$ 个浮点数
- 距离失效：在高维空间中，所有点之间的距离趋于相等（维度灾难）

**解决方案**：降维（PCA、t-SNE）、稀疏表示、特征选择

**2. 零向量的特殊性**

零向量 $\mathbf{0}$ 是加法单位元，但：
- 范数为0，无法归一化
- 方向未定义，余弦相似度计算会除以0
- 在词向量中，零向量没有语义意义

**处理方法**：检测零向量并特殊处理，或添加小的扰动

**3. 数值稳定性问题**

- 大数相加可能溢出（使用 log-sum-exp 技巧）
- 小数相乘可能下溢（使用对数空间计算）
- 点积计算时如果向量范数差异大，可能导致数值不精确

**处理方法**：使用 float64、归一化、数值稳定算法

### 面试常见陷阱

**Q：余弦相似度和欧氏距离有什么区别？**

**错误回答**：它们都是衡量相似度的方法。

**正确回答**：
- **余弦相似度**衡量的是方向相似性，忽略大小。适合文本分类（词频差异大但方向重要）
- **欧氏距离**衡量的是绝对距离，同时考虑方向和大小。适合图像检索（像素值的绝对差异重要）
- 关键区别：归一化后的向量，余弦相似度与欧氏距离有单调关系；未归一化时，两者可能给出相反的结果

**Q：为什么神经网络的权重初始化很重要？**

**正确回答**：
- 如果权重全初始化为0，所有神经元输出相同，梯度也相同，网络无法学习（对称性问题）
- 如果权重太大，激活值饱和（如sigmoid输出接近0或1），梯度消失
- 如果权重太小，激活值接近0，梯度也接近0，学习缓慢
- 解决方案：Xavier/Glorot初始化（考虑输入输出维度）、He初始化（考虑ReLU）

## 💼 面试追问树

### Q1（基础）：什么是向量？它在机器学习中有什么用？

**回答要点**：
1. 定义：一组有序数值，表示空间中的点或方向
2. 作用：特征表示、参数存储、梯度计算、相似度计算
3. 示例：词向量将单词编码为[1, 128]的向量

### Q2（深挖）：向量的点积和余弦相似度有什么区别？

**回答要点**：
1. 点积：$\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\|\|\mathbf{v}\|\cos\theta$，受向量大小影响
2. 余弦相似度：$\cos\theta = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$，只关注方向
3. 选择依据：需要考虑大小时用点积（如推荐系统打分），只需要方向时用余弦相似度（如文本分类）

### Q3（更深）：高维向量会有什么问题？如何解决？

**回答要点**：
1. 维度灾难：高维空间中距离失效，所有点趋于等距
2. 计算成本：点积复杂度O(d)，d很大时慢
3. 解决方案：降维（PCA、t-SNE）、稀疏表示、特征选择
4. 实际案例：Word2Vec将百万维one-hot压缩为300维稠密向量

### Q4（边界）：为什么神经网络不能直接处理类别特征（如"红/蓝/绿"）？

**回答要点**：
1. 类别特征没有数值意义，不能进行加法/点积运算
2. One-hot编码：[红,蓝,绿]→[[1,0,0],[0,1,0],[0,0,1]]，但高维稀疏
3. 嵌入层：将one-hot映射为稠密向量，可学习语义关系
4. 示例：颜色嵌入后，"红"和"橙"的向量距离比"红"和"蓝"更近
