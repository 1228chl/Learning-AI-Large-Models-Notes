## 🎯 使用指南

### 第一步：建立依赖关系（1-2小时）

阅读 `核心依赖链.md`，理解知识点之间的层级关系：
- 层级0：数学地基（必须最先掌握）
- 层级1：编程实现（数学到代码的桥梁）
- 层级2：模型基础（机器学习核心）
- 层级3：深度模型（深度学习架构）
- 层级4：NLP应用（自然语言处理）
- 层级5：工程应用（实际落地）

### 第二步：逐层深度梳理（3-5天）

按层级顺序，逐个阅读深度卡片，重点关注：
- **L2（为什么）**：设计意图、解决什么问题
- **L4（坑在哪）**：边界条件、失效场景、常见误解

### 第三步：建立逻辑连接（穿插进行）

阅读 `连接词索引.md`，理解知识点之间的演进关系：
- 数学→ML的转化
- ML内部的演进
- DL内部的演进
- NLP→LLM应用的转化

### 第四步：准备面试追问（面试前2周）

阅读 `面试追问树.md`，练习回答多层追问：
- Q1（基础）：是什么
- Q2（深挖）：为什么
- Q3（更深）：怎么用、如何选择
- Q4（边界）：什么时候失效
