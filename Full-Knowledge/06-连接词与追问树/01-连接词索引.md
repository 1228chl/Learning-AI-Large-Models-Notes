# 连接词索引：知识点之间的逻辑转换

## 📌 一句话概述

连接词是解释"如何从知识点A走到知识点B"的逻辑桥梁，揭示了知识之间的因果关系、演进动机和设计意图，是打通知识脉络、建立深层理解的核心工具。

---

## 一、数学→机器学习的转化

| 从 | 到 | 连接词（逻辑转换） |
|----|----|------------------|
| 线性代数-向量 | 特征表示 | 机器学习需要将原始数据编码为数值向量才能进行数学运算，向量是特征的数学表示形式 |
| 矩阵乘法 | 神经网络层 | 神经网络的每一层本质是矩阵乘法 $\mathbf{y} = W\mathbf{x} + \mathbf{b}$，将输入向量通过权重矩阵映射到输出空间 |
| 概率-条件概率 | 贝叶斯分类器 | 基于贝叶斯公式 $P(y\vert\mathbf{x}) \propto P(\mathbf{x}\vert y)P(y)$，通过条件概率实现分类 |
| 微积分-导数 | 梯度下降 | 导数告诉我们函数值变化的方向，梯度是多变量版本，沿着负梯度方向移动可以最小化函数 |
| 链式法则 | 反向传播 | 反向传播是链式法则在神经网络中的应用，将输出误差逐层分配到每个参数 |
| 概率-最大似然 | 损失函数 | MSE是高斯噪声假设下的负对数似然，交叉熵是Categorical分布假设下的负对数似然 |

## 二、机器学习内部的演进

| 从 | 到 | 连接词（逻辑转换） |
|----|----|------------------|
| 线性回归 | 逻辑回归 | 线性回归输出范围是(-∞,+∞)，无法直接做概率预测。将输出通过sigmoid函数压缩到(0,1)并配合交叉熵损失，就变成了逻辑回归——解决二分类问题 |
| 线性回归 | 神经网络 | 单层线性回归只能拟合线性关系。堆叠多层线性变换+非线性激活，就变成了神经网络——可以拟合任意非线性函数 |
| 决策树 | 随机森林 | 单棵决策树容易过拟合。通过bootstrap采样构建多棵树并投票/平均，就变成了随机森林——降低方差，提高泛化能力 |
| KNN | 核密度估计 | KNN是基于距离的非参数方法。用核函数平滑距离权重，就变成了核密度估计——更连续的概率估计 |

## 三、深度学习内部的演进

| 从 | 到 | 连接词（逻辑转换） |
|----|----|------------------|
| 全连接网络 | CNN | 全连接网络对图像处理参数量太大且忽略空间结构。引入局部连接和权重共享，就变成了CNN——大幅减少参数并捕捉空间模式 |
| CNN | ResNet | 深层CNN训练困难（梯度消失）。引入跳跃连接让梯度直接跨层传播，就变成了ResNet——可以训练上百层的网络 |
| RNN | LSTM | RNN在长序列上梯度消失/爆炸。引入门控机制（遗忘门、输入门、输出门）和细胞状态，就变成了LSTM——选择性保留或丢弃信息 |
| LSTM | GRU | LSTM参数多、训练慢。将遗忘门和输入门合并为更新门，就变成了GRU——参数更少，性能相当 |
| 注意力机制 | Transformer | 注意力机制最初是RNN的增强。完全抛弃RNN，只用自注意力+位置编码，就变成了Transformer——可以并行计算，训练更快 |
| Transformer编码器 | BERT | Transformer是Seq2Seq架构。只用编码器+掩码语言模型预训练，就变成了BERT——擅长文本理解任务 |
| Transformer解码器 | GPT | 只用解码器+自回归语言模型预训练，就变成了GPT——擅长文本生成任务 |

## 四、NLP→LLM应用的转化

| 从 | 到 | 连接词（逻辑转换） |
|----|----|------------------|
| Word2Vec | BERT嵌入 | Word2Vec是静态词向量（一词一向量）。BERT通过上下文动态生成词向量（一词多向量），解决了多义词问题 |
| BERT | 微调 | BERT在大规模语料上预训练通用语言表示。在下游任务数据上微调，就变成了任务特定的模型——迁移学习的核心 |
| GPT-2 | GPT-3 | GPT-2参数15亿。将参数扩展到1750亿并使用更多数据训练，就变成了GPT-3——涌现出少样本学习能力 |
| GPT-3 | ChatGPT | GPT-3可以生成文本但不遵循指令。通过RLHF（人类反馈强化学习）对齐人类偏好，就变成了ChatGPT——安全、有用、诚实 |
| LLM | RAG | LLM的知识截止于训练数据且可能产生幻觉。在生成前检索外部知识库，就变成了RAG——解决知识更新和幻觉问题 |
| LLM | Agent | LLM只能生成文本。赋予LLM调用工具、规划步骤、与环境交互的能力，就变成了Agent——从"内容生成器"升级为"动作执行者" |

## 五、工程实践的逻辑链

| 从 | 到 | 连接词（逻辑转换） |
|----|----|------------------|
| 训练好的模型 | 模型导出 | 训练好的模型只存在于内存中。序列化为ONNX/TorchScript格式，就可以持久化存储和跨平台部署 |
| 模型导出 | 模型优化 | 原始模型可能过大或过慢。通过量化（FP32→INT8）、剪枝（移除冗余参数）、蒸馏（大模型教小模型），就变成了轻量级模型——适合边缘部署 |
| 模型优化 | API服务 | 轻量级模型需要对外提供服务。用Flask/FastAPI封装成REST API，就变成了在线推理服务——支持高并发请求 |
| 监控数据 | 持续优化 | 生产环境的数据分布可能变化。监控数据漂移和性能指标，触发模型重训练，就变成了MLOps闭环——保持模型持续有效 |
