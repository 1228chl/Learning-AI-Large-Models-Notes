# 完整知识体系：从476个知识点到深层理解

## 📌 一句话概述

本文件夹按照"六步梳理法"将476个知识点重新组织，从表层的"是什么"深入到"为什么"、"怎么用"、"坑在哪"，建立知识点之间的逻辑连接，构建完整的面试追问树，是系统梳理AI大模型知识体系的核心资源。

## 🎯 每张深度卡片包含的内容

| 层级 | 内容 | 字数 |
|------|------|------|
| **L1：是什么** | 定义、公式、结构 | 200-300字 |
| **L2：为什么** | 设计意图、解决什么问题 | 300-500字 |
| **L3：怎么用** | 代码实现、调参、场景 | 200-300字 |
| **L4：坑在哪** | 边界条件、失效场景、面试陷阱 | 300-500字 |
