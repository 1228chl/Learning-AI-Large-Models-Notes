# 深度卡片：向量与线性代数

## L1：是什么（定义/公式/结构）

### 严谨定义
向量是线性空间中的基本元素，定义为一组有序的标量集合 $\mathbf{v} = [v_1, v_2, ..., v_n]^T \in \mathbb{R}^n$，可以表示空间中的一个点、一个方向或一个位移，是机器学习中特征表示、参数存储和梯度计算的数学基础。

### 核心公式

| 运算    | 公式                                                                                            | 几何意义    |
| ----- | --------------------------------------------------------------------------------------------- | ------- |
| 加法    | $\mathbf{u} + \mathbf{v} = [u_1+v_1, ..., u_n+v_n]^T$                                         | 平行四边形法则 |
| 标量乘法  | $\alpha\mathbf{v} = [\alpha v_1, ..., \alpha v_n]^T$                                          | 缩放方向    |
| 点积    | $\mathbf{u} \cdot \mathbf{v} = \sum_{i=1}^n u_i v_i = \|\mathbf{u}\|\|\mathbf{v}\|\cos\theta$ | 投影长度    |
| 范数    | $\|\mathbf{v}\|_p = (\sum_{i=1}^n \vert v_i\vert^p)^{1/p}$                                    | 向量长度/大小 |
| 余弦相似度 | $\cos\theta = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$               | 方向相似性   |

### 向量空间的关键概念

| 概念 | 定义 | 重要性 |
|------|------|--------|
| 线性无关 | 任意向量不能被其他向量线性表示 | 基底选择 |
| 基底 | 线性无关且张成整个空间的向量组 | 坐标系 |
| 维度 | 基底中向量的个数 | 空间大小 |
| 子空间 | 对加法和标量乘法封闭的子集 | 降维基础 |

## L2：为什么（设计意图/解决什么问题）

### 为什么需要向量？

**问题1：如何表示高维数据？**

一张 $28 \times 28$ 的灰度图像有784个像素，每个像素是一个数值。如果用784个独立变量表示，无法进行统一的数学运算。向量将这784个数值组织成一个整体 $\mathbf{x} \in \mathbb{R}^{784}$，使得：
- 可以进行批量计算（矩阵乘法）
- 可以定义距离（范数）
- 可以进行线性变换（矩阵乘法）

**问题2：如何衡量相似性？**

"猫"和"狗"的图像在像素空间中哪个更相似？通过将图像表示为向量，可以计算余弦相似度：
$$\text{sim}(\mathbf{x}_{\text{猫}}, \mathbf{x}_{\text{狗}}) = \frac{\mathbf{x}_{\text{猫}} \cdot \mathbf{x}_{\text{狗}}}{\|\mathbf{x}_{\text{猫}}\| \|\mathbf{x}_{\text{狗}}\|}$$

**问题3：如何进行线性变换？**

神经网络的每一层本质上是一个线性变换 $\mathbf{y} = W\mathbf{x} + \mathbf{b}$，其中 $W$ 是权重矩阵，$\mathbf{x}$ 是输入向量。向量是理解这一变换的基础。

### 向量在ML中的核心作用

| 作用 | 具体应用 | 示例 |
|------|----------|------|
| **特征表示** | 将原始数据编码为数值向量 | 词向量、图像特征 |
| **参数存储** | 将模型参数组织为向量/矩阵 | 权重向量、偏置向量 |
| **梯度表示** | 将参数更新方向表示为向量 | 梯度向量 |
| **相似度计算** | 衡量两个样本的相似程度 | 余弦相似度、欧氏距离 |

## L3：怎么用（代码实现/调参/场景）

### NumPy实现

```python
import numpy as np

# 创建向量
v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])

# 向量运算
addition = v1 + v2           # [5, 7, 9]
dot_product = np.dot(v1, v2) # 32
norm = np.linalg.norm(v1)    # 3.74

# 余弦相似度
cosine_sim = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
```

### 实际应用场景

| 场景 | 向量表示 | 相似度度量 |
|------|----------|------------|
| 文本分类 | TF-IDF向量、词向量 | 余弦相似度 |
| 图像检索 | CNN特征向量 | 欧氏距离 |
| 推荐系统 | 用户/物品嵌入向量 | 内积 |

## L4：坑在哪（边界条件/失效场景/常见误解）

### 常见误解

| 误解 | 正确理解 | 后果 |
|------|----------|------|
| "向量就是一维数组" | 向量是线性空间的元素，有特定的运算规则 | 理解向量空间的结构 |
| "点积就是向量乘法" | 点积是内积的一种，结果是标量 | 避免混淆不同运算 |

### 边界条件

**1. 高维向量的维度灾难**

当向量维度 $d$ 很大时（如 $d > 1000$）：
- 计算成本：点积从 $O(n)$ 变为 $O(d)$
- 距离失效：在高维空间中，所有点之间的距离趋于相等

**解决方案**：降维（PCA、t-SNE）、稀疏表示、特征选择

**2. 零向量的特殊性**

零向量 $\mathbf{0}$ 是加法单位元，但：
- 范数为0，无法归一化
- 方向未定义，余弦相似度计算会除以0

**处理方法**：检测零向量并特殊处理

## 💼 面试追问树

### Q1（基础）：什么是向量？它在机器学习中有什么用？

**回答要点**：
1. 定义：一组有序数值，表示空间中的点或方向
2. 作用：特征表示、参数存储、梯度计算、相似度计算
3. 示例：词向量将单词编码为[1, 128]的向量

### Q2（深挖）：向量的点积和余弦相似度有什么区别？

**回答要点**：
1. 点积：$\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\|\|\mathbf{v}\|\cos\theta$，受向量大小影响
2. 余弦相似度：$\cos\theta = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$，只关注方向
3. 选择依据：需要考虑大小时用点积，只需要方向时用余弦相似度

### Q3（更深）：高维向量会有什么问题？如何解决？

**回答要点**：
1. 维度灾难：高维空间中距离失效
2. 计算成本：点积复杂度O(d)
3. 解决方案：降维（PCA、t-SNE）、稀疏表示
