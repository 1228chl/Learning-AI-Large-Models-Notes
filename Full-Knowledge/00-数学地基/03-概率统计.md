# 深度卡片：概率统计

## L1：是什么（定义/公式/结构）

### 严谨定义
概率论是研究随机现象数量规律的数学分支，通过概率空间 $(\Omega, \mathcal{F}, P)$ 描述随机事件的可能性；数理统计是通过样本数据推断总体特征的方法论。在机器学习中，概率统计是理解数据分布、设计损失函数、进行模型推断的理论基础。

### 核心概念

| 概念 | 定义 | 公式 | ML应用 |
|------|------|------|--------|
| 条件概率 | 在事件B发生条件下事件A发生的概率 | $P(A\vert B) = \frac{P(A \cap B)}{P(B)}$ | 贝叶斯推断 |
| 贝叶斯公式 | 后验概率的计算 | $P(A\vert B) = \frac{P(B\vert A)P(A)}{P(B)}$ | 分类、RAG |
| 期望 | 随机变量的平均值 | $E[X] = \sum_x xP(x)$ | 损失函数设计 |
| 方差 | 随机变量的离散程度 | $\text{Var}(X) = E[(X-E[X])^2]$ | 正则化、归一化 |
| 协方差 | 两个变量的线性关系 | $\text{Cov}(X,Y) = E[(X-\mu_X)(Y-\mu_Y)]$ | PCA、特征选择 |

### 常见概率分布

| 分布 | 概率函数 | 参数 | ML应用 |
|------|----------|------|--------|
| 伯努利分布 | $P(X=k) = p^k(1-p)^{1-k}$ | $p \in [0,1]$ | 二分类 |
| 二项分布 | $P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$ | $n, p$ | 多次试验 |
| 正态分布 | $f(x) = \frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu, \sigma^2$ | 权重初始化、噪声 |
| 均匀分布 | $f(x) = \frac{1}{b-a}$ | $a, b$ | 随机采样 |
| Categorical分布 | $P(X=x_k) = p_k$ | $[p_1,...,p_K]$ | 多分类 |

## L2：为什么（设计意图/解决什么问题）

### 为什么需要概率统计？

**问题1：如何量化不确定性？**

机器学习模型的预测本质是对不确定性的建模。例如：
- 医疗诊断：模型预测"90%概率是良性"比"是良性"更有价值
- 自动驾驶：需要估计检测结果的置信度以决定是否刹车

**问题2：如何从数据中学习规律？**

给定一组数据 $\{x_1, ..., x_n\}$，如何推断其背后的分布？这是**统计推断**的核心问题：
- **参数估计**：假设数据来自正态分布，估计参数
- **假设检验**：判断两组数据是否来自同一分布

**问题3：如何设计损失函数？**

损失函数的选择有概率论依据：
- **MSE损失**：等价于高斯噪声假设下的最大似然估计
- **交叉熵损失**：等价于Categorical分布假设下的最大似然估计

### 最大似然估计的深层含义

给定数据 $D = \{x_1, ..., x_n\}$，似然函数为：
$$L(\theta) = P(D\vert\theta) = \prod_{i=1}^n P(x_i\vert\theta)$$

取对数后：
$$\log L(\theta) = \sum_{i=1}^n \log P(x_i\vert\theta)$$

最大化对数似然等价于最小化负对数似然，这就是**损失函数的概率论基础**。

## L3：怎么用（代码实现/调参/场景）

### NumPy实现

```python
import numpy as np
from scipy import stats

# 生成正态分布数据
data = np.random.normal(loc=0, scale=1, size=1000)

# 参数估计
mean_est = np.mean(data)
var_est = np.var(data)

# 假设检验（t检验）
group1 = np.random.normal(0, 1, 100)
group2 = np.random.normal(0.5, 1, 100)
t_stat, p_value = stats.ttest_ind(group1, group2)
```

### PyTorch实现

```python
import torch
import torch.nn.functional as F

# 交叉熵损失
logits = torch.randn(32, 10)
labels = torch.randint(0, 10, (32,))
loss = F.cross_entropy(logits, labels)
```

## L4：坑在哪（边界条件/失效场景/常见误解）

### 常见误解

| 误解 | 正确理解 | 后果 |
|------|----------|------|
| "概率为0就是不可能" | 连续分布中单点概率为0，但事件可能发生 | 混淆离散/连续分布 |
| "相关等于因果" | 相关是统计关系，因果需要干预实验 | 误导结论 |

### 边界条件

**1. 独立同分布（i.i.d.）假设失效**

大多数ML算法假设训练数据i.i.d.，但实际数据往往：
- **时序依赖**：股票价格、语音信号
- **分布漂移**：训练数据和测试数据分布不同

**2. 小样本问题**

当样本量 $n$ 很小时：
- 参数估计不准确（方差大）
- 无法可靠估计高维分布

**3. 维度灾难**

当数据维度 $d$ 很高时：
- 指数级增长的可能取值
- 距离度量失效

## 💼 面试追问树

### Q1（基础）：解释贝叶斯公式及其在机器学习中的应用

**回答要点**：
1. 公式：$P(A\vert B) = \frac{P(B\vert A)P(A)}{P(B)}$
2. 后验 = 似然 × 先验 / 证据
3. 应用：朴素贝叶斯分类器、垃圾邮件过滤

### Q2（深挖）：最大似然估计和最大后验估计有什么区别？

**回答要点**：
1. MLE：$\hat{\theta}_{MLE} = \arg\max_\theta P(D\vert\theta)$，只考虑数据
2. MAP：$\hat{\theta}_{MAP} = \arg\max_\theta P(\theta\vert D) = \arg\max_\theta P(D\vert\theta)P(\theta)$，加入先验
3. 当先验是均匀分布时，MLE = MAP

### Q3（边界）：什么情况下概率模型会失效？

**回答要点**：
1. i.i.d.假设失效：时序数据、分布漂移
2. 小样本：无法可靠估计分布
3. 高维数据：维度灾难
