# 深度卡片：CNN卷积神经网络

## L1：是什么（定义/公式/结构）

### 严谨定义
CNN是专门设计用于处理具有网格状拓扑结构数据的深度学习架构，通过局部连接、权重共享和空间下采样三种机制，实现对平移不变特征的层次化自动提取。

### 核心组件

| 组件 | 公式 | 作用 |
|------|------|------|
| 卷积层 | $Y_{j,p,q} = \sum_{i,u,v} K_{j,i,u,v} \cdot X_{i, p+u, q+v} + b_j$ | 局部特征提取 |
| 池化层 | $Y_{j,p,q} = \max_{(u,v) \in \mathcal{N}} X_{j,u,v}$ | 下采样 |
| 批归一化 | $\hat{x} = \frac{x - \mu}{\sigma}$ | 稳定训练 |
| 全连接层 | $\mathbf{y} = W\mathbf{x} + \mathbf{b}$ | 分类输出 |

### 特征图尺寸计算

$$H_{out} = \lfloor \frac{H_{in} - k + 2p}{s} \rfloor + 1$$

其中：$H_{in}$是输入高度，$k$是卷积核大小，$p$是填充，$s$是步长

### 经典架构

| 网络 | 年份 | 核心创新 | 参数量 |
|------|------|----------|--------|
| LeNet-5 | 1998 | 首个CNN | 60K |
| AlexNet | 2012 | ReLU、Dropout、GPU | 60M |
| VGGNet | 2014 | 小卷积核堆叠 | 138M |
| GoogLeNet | 2014 | Inception模块 | 6.8M |
| ResNet | 2015 | 残差连接 | 25M |

## L2：为什么（设计意图/解决什么问题）

### 为什么需要CNN？

**问题1：全连接网络处理图像参数量太大**

一张 $224 \times 224 \times 3$ 的图像有150528个像素。如果用全连接层（假设1000个神经元），需要 $150528 \times 1000 = 1.5$ 亿参数，容易过拟合且计算量大。

CNN通过**局部连接**和**权重共享**大幅减少参数：
- 局部连接：每个神经元只连接 $k \times k$ 的局部区域
- 权重共享：同一个卷积核在整个图像上使用相同参数

**问题2：图像具有空间结构**

全连接网络将图像展平为一维向量，丢失了空间信息。CNN保持图像的空间结构，通过卷积核捕捉局部模式。

**问题3：平移不变性**

同一个物体在图像中任意位置出现，CNN应该都能检测到。权重共享实现了平移不变性。

### 卷积的数学本质

卷积是互相关运算，具有：
1. **局部性**：输出只依赖输入的局部区域
2. **平移等变性**：输入平移后输出也相应平移
3. **参数效率**：参数量与输入大小无关

## L3：怎么用（代码实现/调参/场景）

### PyTorch实现

```python
import torch.nn as nn

# 定义CNN模型
class CNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=3, padding=1),
            nn.BatchNorm2d(64),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(2, 2),
            nn.Conv2d(64, 128, kernel_size=3, padding=1),
            nn.BatchNorm2d(128),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(2, 2),
        )
        self.classifier = nn.Sequential(
            nn.AdaptiveAvgPool2d((1, 1)),
            nn.Flatten(),
            nn.Dropout(0.5),
            nn.Linear(128, num_classes)
        )
    
    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x
```

## L4：坑在哪（边界条件/失效场景/常见误解）

### 常见误解

| 误解 | 正确理解 | 后果 |
|------|----------|------|
| "CNN只能处理图像" | CNN可以处理任何网格状数据 | 限制应用范围 |
| "层数越多越好" | 可能过拟合、训练困难 | 需要残差连接 |

### 边界条件

**1. 感受野有限**

标准CNN的感受野增长缓慢，需要堆叠很多层才能覆盖大区域。

**解决方案**：空洞卷积、全局平均池化、ViT

**2. 对几何变换敏感**

CNN对旋转、缩放等变换不鲁棒。

**解决方案**：数据增强、空间变换网络（STN）

**3. 计算成本高**

大图像需要大量计算。

**解决方案**：轻量化网络（MobileNet）、模型剪枝

## 💼 面试追问树

### Q1（基础）：CNN的核心思想是什么？

**回答要点**：
1. 局部连接：每个神经元只与输入的局部区域相连
2. 权重共享：同一个卷积核在整个图像上使用相同参数
3. 池化：下采样降低特征图分辨率

### Q2（深挖）：感受野如何计算？为什么重要？

**回答要点**：
1. 递推公式：$RF_l = RF_{l-1} + (k_l - 1) \cdot \prod_{i=1}^{l-1} s_i$
2. 重要性：决定网络能看到多大的区域
3. 应用：目标检测需要大感受野检测大物体

### Q3（边界）：CNN有什么局限性？

**回答要点**：
1. 感受野增长慢
2. 缺乏全局注意力
3. 对几何变换敏感
4. 计算成本高
