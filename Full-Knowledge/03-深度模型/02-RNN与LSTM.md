# 深度卡片：RNN与LSTM

## L1：是什么（定义/公式/结构）

### RNN核心概念

| 组件 | 公式 | 说明 |
|------|------|------|
| 隐藏状态 | $h_t = \tanh(W_{ih}x_t + W_{hh}h_{t-1} + b)$ | 记忆历史信息 |
| 输出 | $y_t = W_{hy}h_t + b_y$ | 当前时间步输出 |

### LSTM核心概念

| 门 | 公式 | 作用 |
|----|------|------|
| 遗忘门 | $f_t = \sigma(W_f[h_{t-1}, x_t] + b_f)$ | 决定保留多少旧信息 |
| 输入门 | $i_t = \sigma(W_i[h_{t-1}, x_t] + b_i)$ | 决定写入多少新信息 |
| 输出门 | $o_t = \sigma(W_o[h_{t-1}, x_t] + b_o)$ | 决定输出多少信息 |
| 细胞状态 | $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$ | 信息传送带 |

### GRU核心概念

| 门 | 公式 | 作用 |
|----|------|------|
| 更新门 | $z_t = \sigma(W_z[h_{t-1}, x_t])$ | 合并遗忘门和输入门 |
| 重置门 | $r_t = \sigma(W_r[h_{t-1}, x_t])$ | 决定如何组合新旧信息 |

## L2：为什么（设计意图/解决什么问题）

### 为什么需要RNN？

**问题：如何处理序列数据？**

全连接网络和CNN假设输入是固定长度的，但序列数据（文本、语音、时间序列）长度可变。RNN通过：
1. **循环连接**：隐藏状态在时间步之间传递
2. **参数共享**：所有时间步使用相同参数
3. **变长输入**：可以处理任意长度的序列

### 为什么需要LSTM？

**问题：RNN的长期依赖问题**

RNN在处理长序列时，梯度通过时间步连乘，导致：
- **梯度消失**：早期信息无法传递到后期
- **梯度爆炸**：梯度数值不稳定

LSTM通过门控机制解决：
1. **细胞状态**：像传送带，信息可以无损传递
2. **遗忘门**：选择性丢弃不重要的信息
3. **输入门**：选择性添加新信息

### GRU vs LSTM

| 特性 | LSTM | GRU |
|------|------|-----|
| 参数量 | 较多（4个门） | 较少（2个门） |
| 训练速度 | 较慢 | 较快 |
| 性能 | 相当 | 相当 |
| 适用场景 | 复杂序列 | 简单序列 |

## L3：怎么用（代码实现/调参/场景）

### PyTorch实现

```python
import torch.nn as nn

# LSTM层
lstm = nn.LSTM(
    input_size=128,    # 输入维度
    hidden_size=256,   # 隐藏层维度
    num_layers=2,      # 层数
    batch_first=True,  # 输入形状为(batch, seq, feature)
    dropout=0.3,       # dropout
    bidirectional=True # 双向
)

# 输入: (batch_size, seq_len, input_size)
# 输出: (batch_size, seq_len, hidden_size * num_directions)
```

## L4：坑在哪（边界条件/失效场景/常见误解）

### 常见误解

| 误解 | 正确理解 | 后果 |
|------|----------|------|
| "LSTM能记住所有历史" | 门控机制只能选择性保留 | 长序列仍会丢失信息 |
| "双向RNN可以在线使用" | 双向需要完整序列 | 无法实时预测 |

### 边界条件

**1. 序列长度限制**

RNN在超长序列（>1000步）上性能下降。

**解决方案**：Transformer、分段处理

**2. 并行化困难**

RNN必须串行计算（$h_t$依赖$h_{t-1}$）。

**解决方案**：Transformer（完全并行）

**3. 长距离依赖**

即使LSTM，超长距离依赖仍难以捕捉。

**解决方案**：注意力机制、Transformer

## 💼 面试追问树

### Q1（基础）：RNN为什么能处理序列数据？

**回答要点**：
1. 循环连接：隐藏状态在时间步之间传递
2. 参数共享：所有时间步使用相同参数
3. 变长输入：可以处理任意长度的序列

### Q2（深挖）：LSTM的门控机制是如何工作的？

**回答要点**：
1. 遗忘门：决定保留多少旧信息
2. 输入门：决定写入多少新信息
3. 输出门：决定输出多少信息
4. 细胞状态：信息传送带，梯度可以直接流动

### Q3（边界）：RNN/LSTM什么时候还有用？

**回答要点**：
1. 在线学习：数据流式到达
2. 实时推理：需要逐token生成
3. 资源受限：RNN参数量比Transformer小
4. 简单时序任务：不需要Transformer的复杂性
