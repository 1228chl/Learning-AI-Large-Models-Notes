# 深度卡片：神经网络与反向传播

## L1：是什么（定义/公式/结构）

### 严谨定义
神经网络是由多层相互连接的计算单元（神经元）组成的参数化函数逼近器，每个神经元对输入进行加权求和并通过非线性激活函数变换。反向传播是训练神经网络的核心算法，利用链式法则从输出层到输入层逐层计算损失函数关于每个参数的梯度。

### 核心公式

| 组件 | 公式 | 说明 |
|------|------|------|
| 线性变换 | $\mathbf{z}^{(l)} = W^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}$ | 加权求和+偏置 |
| 激活函数 | $\mathbf{a}^{(l)} = \sigma(\mathbf{z}^{(l)})$ | 引入非线性 |
| 输出层 | $\hat{y} = f(\mathbf{a}^{(L)})$ | 最终预测 |
| 损失函数 | $L(\hat{y}, y)$ | 衡量误差 |

### 反向传播公式

| 步骤 | 公式 | 说明 |
|------|------|------|
| 输出层误差 | $\delta^{(L)} = \nabla_{\mathbf{a}^{(L)}} L \odot \sigma'(\mathbf{z}^{(L)})$ | 损失对输出的梯度 |
| 隐藏层误差 | $\delta^{(l)} = (W^{(l+1)})^T \delta^{(l+1)} \odot \sigma'(\mathbf{z}^{(l)})$ | 误差反向传播 |
| 参数梯度 | $\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (\mathbf{a}^{(l-1)})^T$ | 权重梯度 |

### 激活函数对比

| 激活函数 | 公式 | 优点 | 缺点 | 适用场景 |
|----------|------|------|------|----------|
| ReLU | $\max(0, x)$ | 计算简单、缓解梯度消失 | Dead ReLU | 隐藏层（默认） |
| Sigmoid | $\frac{1}{1+e^{-x}}$ | 输出(0,1)，可解释 | 梯度消失 | 二分类输出层 |
| Tanh | $\frac{e^x - e^{-x}}{e^x + e^{-x}}$ | 零中心化 | 梯度消失 | RNN |
| GELU | $x \cdot \Phi(x)$ | 平滑、Transformer常用 | 计算复杂 | Transformer |

## L2：为什么（设计意图/解决什么问题）

### 为什么需要神经网络？

**问题1：如何拟合非线性关系？**

线性回归只能拟合线性关系。现实世界中，大多数关系是非线性的。神经网络通过：
1. 多层结构：逐层抽象特征
2. 非线性激活：打破线性叠加
3. 通用近似定理：理论上可以拟合任意连续函数

**问题2：如何自动学习特征？**

传统机器学习需要人工设计特征。神经网络通过端到端学习：
1. 浅层：学习低级特征（边缘、纹理）
2. 中层：学习中级特征（部件、形状）
3. 深层：学习高级特征（物体、场景）

### 为什么需要反向传播？

**问题：如何更新数百万个参数？**

神经网络可能有数百万个参数，手动计算每个参数的梯度不可行。反向传播利用链式法则，高效计算所有参数的梯度：
- 时间复杂度：与前向传播相同
- 空间复杂度：需要保存中间激活值

**反向传播 vs 数值梯度**

| 方法 | 复杂度 | 精度 | 实际应用 |
|------|--------|------|----------|
| 数值梯度 | $O(P)$ 次前向传播 | 近似 | 调试、验证 |
| 反向传播 | $O(1)$ 次前向+反向传播 | 精确 | 实际训练 |

## L3：怎么用（代码实现/调参/场景）

### PyTorch实现

```python
import torch
import torch.nn as nn
import torch.optim as optim

# 定义模型
class NeuralNet(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(hidden_dim, output_dim)
    
    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x

# 创建模型
model = NeuralNet(input_dim=784, hidden_dim=256, output_dim=10)

# 损失函数和优化器
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 训练循环
for epoch in range(100):
    for inputs, labels in train_loader:
        outputs = model(inputs)
        loss = criterion(outputs, labels)
        
        optimizer.zero_grad()
        loss.backward()  # 反向传播
        optimizer.step()
```

## L4：坑在哪（边界条件/失效场景/常见误解）

### 常见误解

| 误解 | 正确理解 | 后果 |
|------|----------|------|
| "层数越多越好" | 可能梯度消失/爆炸、过拟合 | 训练困难 |
| "隐藏层越宽越好" | 计算成本高、容易过拟合 | 资源浪费 |

### 边界条件

**1. 梯度消失与爆炸**

**梯度消失**：sigmoid/tanh导数<1，深层网络梯度指数级减小
**梯度爆炸**：权重初始化不当，梯度指数级增大

**解决方案**：
- 激活函数：ReLU
- 归一化：BatchNorm
- 残差连接：ResNet
- 权重初始化：Xavier/He

**2. 过拟合**

神经网络参数量大，容易记住训练数据的噪声。

**解决方案**：
- 正则化：L2、Dropout
- 早停：监控验证集性能
- 数据增强

**3. 训练不稳定**

学习率太大→震荡/发散；太小→收敛慢。

**解决方案**：
- 学习率调度：warmup + 余弦衰减
- 梯度裁剪
- BatchNorm

## 💼 面试追问树

### Q1（基础）：解释神经网络的前向传播和反向传播

**回答要点**：
1. **前向传播**：输入逐层经过线性变换+激活函数，得到输出
2. **反向传播**：从输出层开始，利用链式法则逐层计算梯度
3. **参数更新**：$\theta_{t+1} = \theta_t - \eta \nabla L$

### Q2（深挖）：为什么需要非线性激活函数？

**回答要点**：
1. 如果没有激活函数，多层网络等价于单层线性变换
2. 数学证明：$W_2 W_1 \mathbf{x} = W' \mathbf{x}$，仍然是线性
3. 非线性激活打破了线性叠加，使网络可以拟合任意函数

### Q3（更深）：如何选择网络结构？

**回答要点**：
1. **从简单开始**：先用1-2层
2. **逐步增加**：如果欠拟合，增加层数/神经元数
3. **监控过拟合**：训练/验证曲线差距大时停止增加
4. **经验法则**：隐藏层神经元数在输入和输出维度之间

### Q4（边界）：神经网络什么时候不如传统方法？

**回答要点**：
1. **小样本**：数据少时传统方法可能更好
2. **结构化数据**：表格数据用XGBoost通常优于神经网络
3. **可解释性需求**：金融、医疗等领域需要可解释模型
4. **计算资源受限**：嵌入式设备可能无法运行大模型
