# 深度卡片：线性回归与逻辑回归

## L1：是什么（定义/公式/结构）

### 线性回归

**定义**：假设目标变量 $y$ 与特征向量 $\mathbf{x}$ 之间存在线性关系 $y = \mathbf{w}^T\mathbf{x} + b + \epsilon$，通过最小化MSE估计参数。

| 公式 | 名称 | 用途 |
|------|------|------|
| $\hat{y} = \mathbf{w}^T\mathbf{x} + b$ | 假设函数 | 预测 |
| $J(\mathbf{w}) = \frac{1}{2n}\|\mathbf{y} - X\mathbf{w}\|^2$ | 损失函数（MSE） | 衡量误差 |
| $\mathbf{w}^* = (X^TX)^{-1}X^T\mathbf{y}$ | 正规方程 | 闭式解 |
| $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla J$ | 梯度下降 | 迭代优化 |

### 逻辑回归

**定义**：将线性回归的输出通过sigmoid函数压缩到(0,1)区间，配合交叉熵损失，用于二分类。

| 公式 | 名称 | 用途 |
|------|------|------|
| $\sigma(z) = \frac{1}{1+e^{-z}}$ | sigmoid函数 | 输出概率 |
| $h_\theta(\mathbf{x}) = \sigma(\theta^T\mathbf{x})$ | 假设函数 | 预测概率 |
| $J(\theta) = -\frac{1}{m}\sum[y\log(h) + (1-y)\log(1-h)]$ | 交叉熵损失 | 衡量误差 |

### 三种视角对比

| 视角 | 线性回归 | 逻辑回归 |
|------|----------|----------|
| 概率视角 | 高斯噪声下的MLE | Categorical分布下的MLE |
| 优化视角 | 最小化凸二次函数 | 最小化凸函数 |
| 几何视角 | 正交投影到列空间 | 分类边界 |

## L2：为什么（设计意图/解决什么问题）

### 为什么需要线性回归？

**问题1：如何预测连续值？**

房价预测、温度预测、销售额预测等任务需要输出连续数值。线性回归是最简单的回归模型，提供了：
- 清晰的数学公式
- 系数的可解释性
- 快速的训练和推理

**问题2：作为复杂模型的基线**

线性回归是所有回归模型的基线：
- 如果线性回归效果好，说明数据本身是线性的
- 如果效果差，说明需要非线性模型
- 复杂模型应该显著优于线性回归才有价值

### 为什么需要逻辑回归？

**问题1：如何输出概率？**

线性回归输出范围是(-∞,+∞)，无法直接做概率预测。通过sigmoid函数压缩到(0,1)区间，输出可以解释为概率。

**问题2：分类问题需要决策边界**

逻辑回归学习一个线性分类边界 $\theta^T\mathbf{x} = 0$，将特征空间分为两部分。

**问题3：概率输出的价值**

- 可以设置不同阈值调整精确率/召回率
- 可以输出置信度，用于风险评估

### 最小二乘法的概率论基础

假设噪声 $\epsilon \sim N(0, \sigma^2)$，则：
$$P(y\vert\mathbf{x}, \mathbf{w}) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(y - \mathbf{w}^T\mathbf{x})^2}{2\sigma^2}\right)$$

最大似然估计等价于最小化MSE。

## L3：怎么用（代码实现/调参/场景）

### sklearn实现

```python
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.model_selection import train_test_split

# 线性回归
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
lr = LinearRegression()
lr.fit(X_train, y_train)
print(f"系数: {lr.coef_}, 截距: {lr.intercept_}")

# 逻辑回归
clf = LogisticRegression()
clf.fit(X_train, y_train)
print(f"准确率: {clf.score(X_test, y_test)}")
```

### 正则化版本

```python
from sklearn.linear_model import Ridge, Lasso

# Ridge回归（L2正则化）
ridge = Ridge(alpha=1.0)

# Lasso回归（L1正则化）
lasso = Lasso(alpha=0.1)
```

## L4：坑在哪（边界条件/失效场景/常见误解）

### 常见误解

| 误解 | 正确理解 | 后果 |
|------|----------|------|
| "线性回归只能处理线性关系" | 可以通过特征工程引入非线性 | 错误放弃线性模型 |
| "系数越大越重要" | 系数大小受特征尺度影响 | 需要标准化后比较 |
| "逻辑回归是回归算法" | 逻辑回归是分类算法 | 名称误导 |

### 边界条件

**1. 多重共线性（线性回归）**

当特征之间高度相关时，$X^TX$ 接近奇异，系数估计不稳定。

**诊断**：方差膨胀因子（VIF）> 10
**解决**：删除冗余特征、使用Ridge回归、PCA降维

**2. 异常值敏感（线性回归）**

MSE对异常值敏感（平方放大误差）。

**解决**：使用Huber回归、数据清洗

**3. 线性不可分（逻辑回归）**

如果数据线性不可分，逻辑回归无法找到好的分类边界。

**解决**：添加多项式特征、使用非线性模型

### 面试常见陷阱

**Q：线性回归的正规方程有什么缺点？**

**正确回答**：
1. 需要计算 $(X^TX)^{-1}$，复杂度 $O(n^3)$
2. 如果 $X^TX$ 不可逆，无法求解
3. 只适用于离线训练，无法增量学习

**替代方案**：梯度下降、SGD、正则化
