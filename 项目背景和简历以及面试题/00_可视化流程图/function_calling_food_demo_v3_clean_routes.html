责任边界LLM 不直接访问数据库，也不亲自执行函数。应用程序接收结构化调用后，才会连接这些真实业务系统。

      


      

        
同一句话，两种能力边界

        

          
💬 仅聊天模式
LLM 可以理解“你想点外卖”，也可以给出建议，但它没有真实系统的数据与操作权限。
只能生成文字 ↓
我无法访问真实外卖系统，也不能替你下单。

          
ƒ Function Calling
应用把函数定义提供给 LLM。LLM 生成结构化调用，应用完成校验并执行真实 API。
结构化调用 ↓
{"name":"search_dishes", ...}

        

        
Function Calling 不是给模型“魔法权限”，而是建立一条可校验、可授权、可追踪的工具调用通道。
