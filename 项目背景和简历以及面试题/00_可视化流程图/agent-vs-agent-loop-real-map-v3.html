Agent 与 Agent Loop：给出一次方案，还是持续把任务做成？

同一路网 · 多条候选路线先存在 · 封路后从备选中切换，而不是凭空长出一条路
先记住：它们不是两种互斥技术

Agent 是“谁在做事”；Agent Loop 是 Agent 持续感知、决策、行动、观察的运行机制。导航里：路网先有候选，再选中执行。
