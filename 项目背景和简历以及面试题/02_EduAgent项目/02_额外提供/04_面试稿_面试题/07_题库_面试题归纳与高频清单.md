## 1. 分类规划（给同学的备考地图）

按可训练技能分 12 区，而不是按公司罗列：

1. **RAG 检索增强** — 链路、切分、向量、召回、重排、知识库运维
2. **Agent 智能体** — 规划、工具、多代理、工作流框架
3. **MCP / FC / Skill** — 协议、工具调用、技能规范
4. **大模型原理** — Transformer、上下文、采样
5. **微调与训练** — LoRA、数据、RAG对比选型
6. **提示与记忆** — Prompt、多轮、Memory
7. **评测与质量** — 幻觉、指标、安全
8. **部署落地** — Docker、Ollama、vLLM、量化、API
9. **多模态** — 图文音视频与OCR
10. **工程能力** — 前后端、排查、AI编码治理
11. **项目与软素质** — 项目深挖、岗位、规划、对客
12. **业务产品** — 场景、需求、价值

### 建议复习路径

1. RAG 全链路（必考基本盘）
2. Agent + MCP / Function Call / Skill（近两年高频增量）
3. 幻觉定位与评测
4. RAG vs 微调选型 + LoRA
5. 部署（Docker / Ollama / 量化 / API）
6. 项目深挖与软素质（贯穿全程）
