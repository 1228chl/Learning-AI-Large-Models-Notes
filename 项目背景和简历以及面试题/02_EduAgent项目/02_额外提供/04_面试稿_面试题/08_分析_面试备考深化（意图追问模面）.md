## 6. 四条追问链（按链练，不按单题练）

### RAG 主链路追问

为什么重要：企业面最高频：从能讲到能调优

1. RAG 基本链路（入库→检索→生成）
2. 清洗 / 分块策略与块大小
3. Embedding / 向量库选型
4. 召回不准如何优化（混合检索、Rerank）
5. 幻觉：检索问题还是生成问题
6. 效果如何评测（抽检、命中率、人工评审）

### Agent 工具链追问

为什么重要：近两年增量考点，常和项目绑定

1. Agent 是什么 / 常见模式
2. Function Call vs MCP vs Skill
3. LangChain / LangGraph 用在哪一步
4. Multi-Agent 何时必要
5. AI 写代码如何防失控
6. 端到端如何评测与可观测

### 微调选型追问

为什么重要：高频，且容易答成空话

1. 何时 RAG、何时微调
2. LoRA / QLoRA 原理与资源开销
3. 训练数据从哪来、怎么质检
4. 如何评估微调是否有效
5. 上线后知识更新怎么做

### 项目深挖追问

为什么重要：贯穿全程，决定 offer 可信度

1. 业务背景与指标
2. 你负责模块与分工
3. 关键技术选型与取舍
4. 踩坑 / 效果数据
5. 如果重做会怎么改


## 7. 按意图的答题骨架（可直接套）

- **概念解释**：定义 → 关键组件/步骤 → 一个项目落点 → 边界/常见误解
- **方案设计**：目标/约束 → 方案选项 → 为什么选它 → 关键实现点 → 如何验证
- **排查排障**：现象复现 → 分层定位（数据/检索/模型/工程）→ 验证假设 → 修复与回归
- **项目深挖**：背景指标 → 你的职责 → 关键决策 → 结果数据 → 复盘改进
- **动手实操**：场景 → 具体命令/参数/配置 → 注意点 → 排障经验
- **软素质行为**：观点一句 → STAR 事例 → 与岗位连接 → 收尾可衡量
- **取舍权衡**：对比维度表 → 场景落点 → 你项目里怎么选 → 代价与回退

## 9. 90 分钟模拟面试脚本

1. **热身 10′**：自我介绍（90秒）；项目一句话 + 指标；岗位理解
2. **核心 50′**：RAG 全链路讲解（白板/口述）；分块与召回优化追问；幻觉定位演练；Agent + MCP/FC/Skill 辨析；微调 vs RAG 选型案例
3. **项目 20′**：负责模块深挖；线上问题复盘；如果重做怎么改
4. **收尾 10′**：职业规划；反问（团队指标/数据闭环/评测体系）

## 10. 面试前材料包（带这些去准备）

- **一张 RAG 架构图（含切分/向量库/Rerank）** — 面试官最爱让你边画边讲
- **一份评测小表（离线+线上）** — 证明你能闭环，不只是调 prompt
- **MCP/FC/Skill 对比卡** — 新热点，答清边界就能拉开差距
- **显存/成本小抄（7B/14B + LoRA/量化）** — 部署与微调题的“数字感”
- **项目 STAR 三件套** — 覆盖深挖与软素质
- **线上故障复盘一页纸** — 对应排查类 L4 题

## 11. 同学可执行的每周节奏

1. **输入 40%**：按追问链补知识，不撒网背百科
2. **输出 40%**：口述录音 + 白板图，每天至少 2 条 P0
3. **证据 20%**：把项目数字、评测表、故障复盘补齐
4. **周五模面**：严格 90 分钟，只复盘卡壳的 L3/L4
