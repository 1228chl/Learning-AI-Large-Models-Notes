# RAG项目简历构写

### **基于RAG的教育领域智能问答系统（EduRAG）**

**项目时间**：2025.03 – 2025.08
**技术栈**：Python, Milvus, BERT, Qwen2.5-7B, LoRA, RagAS, OCR, FastAPI，BGE-m3

#### **项目背景**

公式【**帮助谁，解决了什么问题？**达到了什么效果?】

针对教培行业高频、重复性咨询问题（如课程安排、退费政策、学习规划等），传统FAQ匹配准确率低、知识更新滞后，难以满足用户实时精准答疑需求。为此设计并实现了一套融合结构化数据检索与RAG技术的智能问答系统——**EduRAG**，显著提升回答准确率与用户体验。

#### 项目流程

- 文档预处理：加载、清洗、分块
- 向量数据库构建：collection设计，field和index设计，数据插入
- 高频问题缓存：MySQL高频问题存储与检索、Redis可靠问题存储与检索、FQA系统构建
- RAG检索系统：意图识别模块、策略选择模块、向量检索模块、答案生成模块、评估模块

#### **主要职责**

**架构设计：**

- 负责EduRAG系统的整体设计，包括流程设计、组件选型、模型设计与优化、项目部署设计等。

    【参与EduRAG系统的整体设计，负责部分组件的调研、试用和评测工作。】

**文档预处理：**

公式：【收集了xxxG的文档，包含xxx的类型，采用父子分块的方式，完成了对xxxx操作，最终得到了xxx(规模)的知识库】

- 自定义pdfloader/docloader/pptloader等文档加载器，实现对PDF、Word、PPT等格式的书籍、课件、练习题、笔记等文件读取；
- 使用Python，完成对数据的清洗、去重、格式化等操作；
- 使用LangChain的字符文本切分器、语义文本切分器、结构文本切分器等完成对文档内容的切分，将其切分成子块和父块，累计构建**50万+条数据**。

**向量数据库构建：**

- 设计多集合（3个collections）存储策略，支持课程、政策、服务等不同类型知识的隔离管理与高效检索，并结合数据特点和业务要求，设计field和index。
- 使用bge-m3模型对文档进行embedding，获取稠密向量和稀疏向量，分别存储到对应字段中，从而支持混合检索，提高有效文档的召回率和精确率。
- 设计并实现知识库的更新模块，实现对增量文档的自动解析和更新插入，满足企业知识库更新的需求。

**高频问题缓存：**

- 负责MySQL高频问题缓存表的设计，并整理历史高频问答对，插入到数据表中。
- 负责每日增量高频问题对的整理，并对数据库内容进行增量更新。
- 使用BM25模型+softmax，完成查询问题与MySQL中高频问题的相似性检索，如果相似度大于0.85即判定为同一问题，直接返回MySQL中的答案，加快查询效率，使平均响应时长降低了0.4秒。
- 负责Redis数据库中可靠问题的存储、查询与更新，基于Redis实现对相同问题的极速检索，使命中的问题的响应时长降低到毫秒级别。

**RAG检索系统：**

- 基于 BERT 训练意图识别模块，支持4种意图分类如：（课程咨询、退费政策、学习规划、通用问题），F1-score达 **92%**。
- 设计多策略query改写机制，对原始问题进行改写，将上下文召回率提升34%。
- 使用加权排名的方式对子块进行稠密向量和稀疏向量的混合检索，并使用bge-reranker-large对去重后的父块内容进行重排序，将上下文召回率提升至81%。
- 设计和调整结构化Prompt模板，控制生成格式，调用大语言模型，完成最终答案的生成。
- 构建1000条人工标注测试集，并使用 RagAS 自动评估框架对RAG全流程进行量化评测。

**项目部署：**

- 使用vllm部署Qwen2.5-14B模型，实现模型的高效推理。



#### **项目优化**

1. **多模态文档处理增强**
   
   - 针对PDF/PPT中图片、表格等内容，引入 OCR工具（PaddleOCR）与多模态大模型提取图文信息，提升知识覆盖完整性。
   
2. **Query理解与重构优化**
   设计多策略query改写机制：
   
   - HyDE策略（伪答案生成）
   - 子查询分解（复杂问题拆解）
   - 回溯问题（简化问题）
   - 历史会话融合（上下文感知重写）
   - 关键词扩展（同义词/领域词增强）
   - 通用去噪（去除口语化表达）
   
   显著提升模糊查询的召回率。
   
   ==【可以使用提示词的方式来实现，也可以使用大模型微调的方式来实现】==
   
3. **文档索引与检索优化**

   - 构建层级化文档存储机制，父块负责全局语义召回，子块用于精细语义匹配，提升检索质量；
   - 实现 **稀疏向量 与 稠密向量 混合检索**，通过加权融合提升召回准确率；
   - 引入 **Rerank模块**，使用bge-reranker-large模型对Top-k结果进行精细化排序，Top-5相关性提升35%。

4. **模型微调与生成优化**
   
   - 对 **Qwen2.5-14B模型进行LoRA微调**，适配教育领域术语与回答风格，显著提升回答专业性与流畅度；
